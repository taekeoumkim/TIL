## 학습 목표

- 정답(Label)이 없는 데이터를 다루는 비지도학습의 개념을 설명할 수 있다.
- 지도학습과 비지도학습의 차이를 구분할 수 있다.
- 군집화(Clustering)의 목적과 활용 사례를 설명할 수 있다.
- K-Means 군집화의 동작 원리를 설명하고 코드로 적용할 수 있다.
- 군집 결과를 데이터의 특성과 비즈니스 목적에 맞게 해석할 수 있다.

---

## 1. 정답이 없는 데이터는 어떻게 분석할까?

지금까지 학습한 분류와 회귀는 정답인 Label이 있는 데이터를 이용한다. 모델은 입력 데이터와 정답의 관계를 학습한 뒤 새로운 데이터의 클래스나 값을 예측한다.

하지만 실제 데이터에는 정답이 없는 경우도 많다. 예를 들어 고객별 방문 횟수와 구매 금액은 기록되어 있지만, 누가 충성 고객이고 누가 이탈 위험 고객인지 미리 정해진 정보는 없을 수 있다.

이때는 정답을 예측하는 대신 데이터 자체를 살펴보며 다음과 같은 질문에 답해야 한다.

- 서로 비슷한 행동을 보이는 고객들이 존재하는가?
- 데이터 안에는 어떤 구조와 패턴이 있는가?
- 다른 데이터와 크게 다른 이상한 관측값이 있는가?
- 많은 Feature를 더 적은 차원으로 표현할 수 있는가?

이처럼 Label 없이 데이터에 존재하는 구조, 패턴, 관계를 발견하는 학습 방법을 **비지도학습(Unsupervised Learning)**이라고 한다.

---

## 2. 비지도학습이란?

비지도학습은 정답을 맞히는 것이 아니라 데이터가 가진 특징을 분석하여 숨겨진 구조를 찾는 방법이다.

대표적인 비지도학습 작업은 다음과 같다.

| 작업 | 목적 | 활용 예시 |
|---|---|---|
| 군집화(Clustering) | 비슷한 데이터를 같은 그룹으로 묶기 | 고객 세분화 |
| 차원 축소(Dimension Reduction) | 많은 Feature를 적은 차원으로 표현하기 | 데이터 시각화 |
| 이상치 탐지(Anomaly Detection) | 일반적인 패턴에서 크게 벗어난 데이터 찾기 | 이상 거래 탐지 |

### 고객 이용 패턴 예시

고객 유형 Label 없이 월 방문 횟수와 월 구매 금액만 있다고 가정한다.

```python
import pandas as pd

customers = pd.DataFrame({
    "visit_count": [2, 3, 4, 12, 14, 15],
    "purchase_amount": [20, 25, 30, 180, 210, 230],
})

print(customers)
```

실행 결과:

```text
   visit_count  purchase_amount
0            2               20
1            3               25
2            4               30
3           12              180
4           14              210
5           15              230
```

고객 유형을 나타내는 정답은 없지만, 값을 살펴보면 방문 횟수와 구매 금액이 모두 낮은 고객들과 두 값이 모두 높은 고객들이 서로 다른 패턴을 보인다. 비지도학습을 사용하면 이러한 데이터의 구조를 발견하고 고객 세분화와 같은 분석으로 연결할 수 있다.

---

## 3. 지도학습과 비지도학습의 차이

두 학습 방식의 가장 큰 차이는 학습에 사용할 정답인 Label의 유무이다.

| 구분 | 지도학습(Supervised Learning) | 비지도학습(Unsupervised Learning) |
|---|---|---|
| Label | 있음 | 없음 |
| 목적 | 입력을 바탕으로 정답 예측 | 데이터의 구조·패턴·관계 탐색 |
| 대표 작업 | 회귀, 분류 | 군집화, 차원 축소, 이상치 탐지 |
| 예시 | 집값 예측, 스팸 분류 | 고객 세분화, 데이터 시각화, 이상 거래 탐지 |

지도학습은 모델의 예측값을 실제 정답과 비교하여 성능을 평가한다. 반면 비지도학습에는 비교할 정답이 없으므로 분석 목적에 맞는 기준으로 결과를 평가해야 한다.

군집화의 경우에는 일반적으로 다음과 같은 상태가 잘 만들어졌는지 확인한다.

- 같은 군집에 속한 데이터는 서로 비슷하다.
- 서로 다른 군집에 속한 데이터는 잘 구분된다.
- 만들어진 군집이 실제 분석 및 비즈니스 목적에 활용할 수 있다.

즉, 비지도학습에서는 정답을 얼마나 많이 맞혔는지가 아니라 **데이터의 구조를 얼마나 잘 발견했는가**가 중요하다.

---

## 4. 군집화(Clustering)

군집화는 비슷한 특성을 가진 데이터를 유사성을 기준으로 하나의 그룹인 군집(Cluster)으로 묶는 작업이다.

정답 정보가 없어도 데이터 사이의 유사성을 이용해 자연스러운 그룹을 찾을 수 있다. 고객 데이터에 군집화를 적용하면 방문 횟수, 구매 빈도, 구매 금액과 같은 행동 특성이 비슷한 고객들을 묶고, 각 그룹에 다른 마케팅 전략을 적용할 수 있다.

예를 들어 온라인 쇼핑몰 고객을 다음과 같이 나눌 수 있다.

| 데이터에서 발견한 특성 | 비즈니스 해석 예시 | 활용 전략 예시 |
|---|---|---|
| 방문과 구매가 모두 활발함 | 우수 고객 | VIP 혜택 및 충성도 강화 |
| 방문과 구매가 보통 수준임 | 일반 고객 | 구매 빈도 증가 프로모션 |
| 활동이 적거나 구매가 오래됨 | 휴면 고객 | 재방문 유도 캠페인 |

이 이름들은 알고리즘이 자동으로 정하는 것이 아니다. 분석가가 각 군집의 실제 특성을 확인하고 비즈니스 맥락에 맞게 해석해야 한다.

---

## 5. K-Means 군집화

K-Means는 데이터를 미리 지정한 **K개의 군집**으로 나누는 대표적인 군집화 알고리즘이다.

- **K**: 만들고자 하는 군집의 개수
- **Centroid**: 각 군집을 대표하는 중심점
- **거리**: 데이터와 중심점이 얼마나 가까운지 나타내는 기준

K-Means는 일반적으로 유클리드 거리(Euclidean Distance)를 사용하여 각 데이터를 가장 가까운 중심점의 군집에 할당한다.

두 데이터 $x=(x_1, x_2)$와 $c=(c_1, c_2)$ 사이의 유클리드 거리는 다음과 같다.

$$
d(x,c)=\sqrt{(x_1-c_1)^2+(x_2-c_2)^2}
$$

거리가 작을수록 두 점은 서로 유사한 위치에 있다고 볼 수 있다.

---

## 6. K-Means의 동작 과정

K-Means는 중심점과 데이터의 군집 할당을 반복해서 갱신한다.

```text
1. 만들 군집의 개수 K를 정한다.
2. 초기 중심점 K개를 정한다.
3. 각 데이터를 가장 가까운 중심점의 군집에 할당한다.
4. 각 군집에 속한 데이터의 평균 위치를 새로운 중심점으로 계산한다.
5. 데이터 할당과 중심점 갱신을 반복한다.
6. 중심점이 거의 움직이지 않으면 반복을 종료한다.
```

이 과정을 통해 같은 군집 안의 데이터는 서로 가까워지고, 서로 다른 군집의 데이터는 구분되는 형태를 만들게 된다.

초기 중심점에 따라 결과가 달라질 수 있으므로 여러 초기값으로 학습을 반복해 더 나은 결과를 선택할 수 있다. scikit-learn의 `n_init`은 서로 다른 초기 중심점으로 알고리즘을 실행하는 횟수를 지정한다.

## 7. 카페 고객을 3개 군집으로 나누기

고객별 월 방문 횟수와 월 결제 금액을 이용하여 고객을 3개 그룹으로 나눈다.

```python
import pandas as pd
from sklearn.cluster import KMeans

customers = pd.DataFrame({
    "visit_count": [1, 2, 3, 7, 8, 9, 15, 16, 18],
    "monthly_spend": [10, 15, 20, 70, 80, 90, 180, 200, 220],
})

model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10,
)

customers["cluster"] = model.fit_predict(
    customers[["visit_count", "monthly_spend"]]
)

print(customers)
```

실행 결과 예시:

```text
   visit_count  monthly_spend  cluster
0            1             10        2
1            2             15        2
2            3             20        2
3            7             70        0
4            8             80        0
5            9             90        0
6           15            180        1
7           16            200        1
8           18            220        1
```

### 주요 코드 해석

| 코드 | 의미 |
|---|---|
| `n_clusters=3` | 데이터를 3개의 군집으로 나눈다. |
| `random_state=42` | 난수 기준을 고정하여 실행 결과를 재현할 수 있게 한다. |
| `n_init=10` | 서로 다른 초기 중심점으로 10번 실행한다. |
| `fit_predict()` | 모델을 학습하고 각 데이터의 군집 번호를 반환한다. |

결과의 `cluster` 값인 0, 1, 2는 단순한 군집 식별 번호이다. 숫자의 크기나 순서에는 의미가 없으며, `cluster=0`이 자동으로 일반 고객이나 VIP 고객을 뜻하지 않는다.

따라서 군집별 방문 횟수와 결제 금액의 평균 등을 확인한 뒤 각 군집의 특성을 해석해야 한다.

```python
cluster_summary = customers.groupby("cluster")[[
    "visit_count",
    "monthly_spend",
]].mean()

print(cluster_summary)
```

이처럼 K-Means의 결과를 실제 비즈니스에 활용하려면 **군집 생성 → 군집별 특성 분석 → 의미 부여 → 전략 수립**의 과정이 필요하다.

## 8. 비즈니스 문제를 군집화 문제로 정의하기

군집화를 적용하기 전에 단순히 고객을 여러 그룹으로 나누겠다고 생각하기보다 분석의 목적과 사용할 Feature를 명확히 정의해야 한다.

| 정의 항목 | 고객 군집화 예시 |
|---|---|
| 비즈니스 목표 | 고객 행동에 맞는 마케팅 전략 수립 |
| 분석 대상 | 카페 이용 고객 |
| 사용할 Feature | 월 방문 횟수, 월 결제 금액 |
| 군집 개수 | 3개 |
| 기대 결과 | 이용 패턴이 비슷한 고객 그룹 발견 |
| 결과 활용 | 군집별 혜택과 마케팅 메시지 차별화 |

군집에는 미리 정해진 정답이 없기 때문에 결과가 나왔다고 분석이 끝나는 것이 아니다. 각 군집이 어떤 고객들로 구성되어 있는지 설명하고, 실제 의사결정에 활용할 수 있는지를 판단하는 과정이 중요하다.

## 9. 핵심 정리

- 비지도학습은 Label 없이 데이터 안의 구조, 패턴, 관계를 찾는다.
- 군집화는 특성이 비슷한 데이터를 같은 그룹으로 묶는 비지도학습 작업이다.
- K-Means는 데이터를 미리 지정한 K개의 군집으로 나눈다.
- 각 데이터는 가장 가까운 중심점이 있는 군집에 할당된다.
- 군집에 속한 데이터의 평균 위치로 중심점을 갱신하고, 중심점이 거의 움직이지 않을 때까지 이 과정을 반복한다.
- K-Means는 거리 기반 알고리즘이며 일반적으로 유클리드 거리를 사용한다.
- 군집 번호는 단순한 식별자이므로 숫자 자체에는 의미가 없다.
- 군집화의 결과는 분석가가 군집별 특성을 확인하고 비즈니스 맥락에 맞게 해석해야 한다.

---

## 오늘의 한 문장

> 비지도학습은 정답을 예측하는 학습이 아니라 데이터 안에 숨어 있는 구조를 발견하는 학습이며, K-Means의 군집 번호를 유용한 고객 유형으로 만드는 것은 분석가의 해석이다.
