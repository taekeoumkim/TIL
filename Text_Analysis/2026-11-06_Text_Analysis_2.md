## 오늘의 학습 주제

단순 단어 빈도 분석의 한계를 이해하고, TF와 IDF를 결합하여 문서별 특징적인 단어를 찾는 방법을 배웠다. TF-IDF 행렬을 만들고 상위 키워드를 추출·시각화한 뒤, 결과를 원문과 도메인 맥락에서 해석하는 과정을 학습했다.

## 1. 단순 빈도만으로 중요한 단어를 찾기 어려운 이유

다음은 형태소 분석 등 전처리가 끝났다고 가정한 학습용 문서다.

| 문서 | 전처리된 텍스트 |
| --- | --- |
| 문서 1 | 배송 빠름 상품 만족 |
| 문서 2 | 배송 지연 상품 불만 |
| 문서 3 | 배송 지연 파손 |

전체 빈도에서는 `배송`이 세 번으로 가장 많지만 모든 문서에 공통으로 등장한다. 반면 `파손`은 문서 3에만 있어 해당 문서의 특징을 구분하는 데 도움이 된다.

단순 빈도는 전반적으로 자주 쓰이는 단어를 확인하는 데 유용하다. 문서별 특징을 찾으려면 **문서 안의 등장 횟수와 다른 문서에서의 등장 정도**를 함께 고려해야 한다.

## 2. TF·DF·IDF의 차이와 계산 원리

| 개념 | 의미 |
| --- | --- |
| TF(Term Frequency) | 특정 문서에서 단어가 등장한 빈도 |
| DF(Document Frequency) | 해당 단어가 한 번 이상 등장한 문서 수 |
| IDF(Inverse Document Frequency) | 문서 집합에서 단어의 희소성을 나타내는 값 |
| TF-IDF | 문서 내 빈도와 문서 간 희소성을 결합한 가중치 |

### TF: 한 문서 안에서의 빈도

이번 학습의 기본 수식은 단순 등장 횟수를 사용한다.

```text
TF(t, d) = 문서 d에서 단어 t가 등장한 횟수
```

`배송 지연 배송 불만`에서 `배송`의 TF는 2, `지연`과 `불만`의 TF는 각각 1이다. TF는 정규화 등 다른 계산 방식도 있지만, 여기서는 원리 이해에 집중한다.

### DF: 횟수가 아니라 문서 수

한 문서에서 `배송`이 열 번 등장해도 그 문서가 DF에 기여하는 값은 1이다. 위 세 문서에서 `배송`의 DF는 3, `지연`은 2, `파손`은 1이다.

### IDF: 적은 문서에 등장할수록 높은 값

기본 수식은 다음과 같다.

```text
IDF(t) = ln(N / DF(t))

N: 전체 문서 수
DF(t): 단어 t를 포함하는 문서 수
ln: 자연로그
```

전체 문서가 세 개일 때 계산 결과는 다음과 같다.

| 단어 | DF | 기본 IDF |
| --- | --- | --- |
| 배송 | 3 | ln(3/3) = 0 |
| 지연 | 2 | ln(3/2) ≈ 0.405 |
| 파손 | 1 | ln(3/1) ≈ 1.099 |

모든 문서에 공통으로 등장하는 단어는 문서를 구분하는 힘이 약하다. 상대적으로 드문 단어에는 더 높은 IDF가 부여된다.

### TF-IDF: 빈도와 희소성의 결합

```text
TF-IDF(t, d) = TF(t, d) × IDF(t)
```

문서 3의 단어는 각각 한 번씩 등장하므로 TF가 모두 1이다.

| 단어 | TF | 기본 IDF | 기본 TF-IDF |
| --- | --- | --- | --- |
| 배송 | 1 | 0 | 0 |
| 지연 | 1 | 0.405 | 0.405 |
| 파손 | 1 | 1.099 | 1.099 |

단순 빈도는 같아도 TF-IDF에서는 `파손`에 더 높은 가중치가 부여된다. 다만 높은 점수가 곧 업무적으로 중요한 단어라는 뜻은 아니다. 오타나 의미 없는 희귀 표현도 높은 점수를 받을 수 있다.

## 3. TF-IDF 행렬과 상위 키워드

단어 집합(Vocabulary)은 분석 문서에서 추출한 고유 단어들의 집합이다. 위 예시에는 `배송`, `빠름`, `상품`, `만족`, `지연`, `불만`, `파손`의 일곱 단어가 있다.

TF-IDF 행렬은 다음 구조를 갖는다.

- 행: 개별 문서
- 열: 단어 집합의 각 단어
- 값: 해당 문서에서 단어의 TF-IDF 가중치

문서 3개와 고유 단어 7개이므로 행렬 크기는 **3행 × 7열**이다. 기본 수식으로 계산한 일부 열은 다음과 같다.

| 문서 | 배송 | 지연 | 만족 | 불만 | 파손 |
| --- | --- | --- | --- | --- | --- |
| 문서 1 | 0 | 0 | 1.099 | 0 | 0 |
| 문서 2 | 0 | 0.405 | 0 | 1.099 | 0 |
| 문서 3 | 0 | 0.405 | 0 | 0 | 1.099 |

행별 가중치를 내림차순으로 정렬하면 문서별 상위 키워드 후보를 찾을 수 있다. 키워드 후보를 얻는 과정과 그 의미를 해석하는 과정은 구분해야 한다.

## 4. Python으로 행렬 생성·키워드 추출·시각화

학습자료에서는 Scikit-learn의 `TfidfVectorizer`를 사용했다. 아래 코드는 전처리된 세 문서로 행렬을 만들고 문서별 상위 단어와 문서 3의 막대그래프를 확인하는 학습 예시다.

```python
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
from sklearn.feature_extraction.text import TfidfVectorizer

# 형태소 분석 등이 이미 끝난 예시 문서
documents = [
    "배송 빠름 상품 만족",
    "배송 지연 상품 불만",
    "배송 지연 파손",
]

vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(documents)
words = vectorizer.get_feature_names_out()

# 소규모 예제의 행렬 확인용
tfidf_df = pd.DataFrame(
    tfidf_matrix.toarray(),
    columns=words,
    index=["문서 1", "문서 2", "문서 3"],
)
print(tfidf_df.round(3))

for name, scores in tfidf_df.iterrows():
    # 등장하지 않은 단어의 0점을 키워드로 선택하지 않도록 제외
    top_keywords = scores[scores > 0].nlargest(2)
    print(name, top_keywords.index.tolist())

available_fonts = {font.name for font in fm.fontManager.ttflist}
for font_name in ["Malgun Gothic", "AppleGothic", "NanumGothic"]:
    if font_name in available_fonts:
        plt.rcParams["font.family"] = font_name
        break
plt.rcParams["axes.unicode_minus"] = False

scores = tfidf_df.loc["문서 3"]
top_keywords = scores[scores > 0].nlargest(3).sort_values()

plt.figure(figsize=(7, 4))
plt.barh(top_keywords.index, top_keywords.values)
plt.xlabel("TF-IDF")
plt.title("문서 3 주요 키워드")
plt.tight_layout()
plt.show()
```

| 기능 | 역할 |
| --- | --- |
| `fit_transform()` | 문서에서 단어 집합과 가중치를 학습하고 행렬로 변환 |
| `get_feature_names_out()` | 행렬 열에 대응하는 단어 목록 확인 |
| `toarray()` | 행렬을 일반 배열로 변환하여 표로 확인 |
| `nlargest(2)` | 값이 큰 두 항목 선택 |
| `sort_values()` | 가로 막대그래프의 표시 순서 정리 |
| `barh()` | 단어별 가중치를 가로 막대로 표현 |

전체 행렬을 배열과 DataFrame으로 바꾸는 방식은 소규모 학습 예제에 적합하다. 실제 문서와 단어가 많으면 메모리 사용량이 커질 수 있으므로 희소 행렬을 유지하는 방향을 고려한다. 한글 글꼴이 없으면 그래프의 한글이 깨질 수 있다.

### 기본 수식과 라이브러리 결과 구분

학습자료의 기본 수식은 `TF × ln(N/DF)`다. 반면 `TfidfVectorizer`의 기본 설정은 IDF 보정과 벡터 정규화를 적용하므로 숫자가 다르다.

특히 모든 문서에 등장하는 `배송`은 기본 수식에서 0이지만, 라이브러리 기본 설정에서는 0이 아닌 값을 가진다. 가중치가 다르다고 바로 계산 오류로 판단하지 않고 사용한 설정과 수식을 확인한다.

학습자료가 제시한 라이브러리 결과 예시는 다음과 같다. 아래 값과 키워드는 자료에 제시된 예시이며, 이 TIL 작성 과정에서 코드를 실행한 결과는 아니다.

| 문서 | 상위 키워드 2개 |
| --- | --- |
| 문서 1 | 만족, 빠름 |
| 문서 2 | 불만, 상품 |
| 문서 3 | 파손, 지연 |

문서 3의 가중치는 `파손 ≈ 0.720`, `지연 ≈ 0.548`, `배송 ≈ 0.425`다. 막대 길이는 등장 횟수가 아닌 TF-IDF 가중치를 나타낸다. 같은 점수의 단어들은 출력 순서만으로 중요도의 차이를 해석하지 않는다.

## 5. 키워드 결과 해석과 한계

### 높은 가중치는 문맥 이해를 의미하지 않는다

다음 문장들은 모두 `파손`이라는 단어를 포함하지만 의미가 다르다.

- 상품이 파손되어 도착했습니다.
- 상품이 파손되지 않고 안전하게 도착했습니다.

TF-IDF 가중치만으로 긍정·부정과 부정 표현을 충분히 해석할 수 없다. `파손`이 상위에 있다면 원문에서 실제 파손 불만인지 확인해야 한다. `만족`도 무엇에 대한 만족인지 원문을 통해 살펴야 한다.

### 의미가 비슷해도 단어가 다르면 한계가 있다

`배송이 빨라서 만족합니다`와 `상품이 금방 도착해서 만족합니다`는 유사한 의미지만 표현이 다르다. TF-IDF는 단어의 빈도와 분포에 기반하므로 의미적 유사성을 충분히 반영하기 어렵다. 문장 전체의 의미를 비교하려면 이후 학습할 텍스트 임베딩 등을 고려할 수 있다.

### 문서 집합이 바뀌면 가중치도 바뀐다

기본 IDF 수식에서 문서가 추가된 상황을 비교하면 다음과 같다.

| 상황 | 전체 문서 수 N | 파손의 DF | 기본 IDF |
| --- | --- | --- | --- |
| 기존 문서 | 3 | 1 | ln(3/1) ≈ 1.099 |
| 파손을 포함한 문서 1개 추가 | 4 | 2 | ln(4/2) ≈ 0.693 |

가중치는 단어 자체의 고정된 중요도가 아니라 **분석한 문서 집합 안에서의 상대적 값**이다. 소규모 문서 집합에서는 문서 몇 개의 변화에도 결과가 크게 달라질 수 있다.

### 해석할 때 확인할 사항

- 상위 단어가 실제 문서의 특징을 설명하는가?
- 오타나 의미 없는 표현이 희귀하다는 이유로 올라오지 않았는가?
- 전처리와 토큰화 기준이 목적에 맞는가?
- 분석 문서의 수와 내용이 충분하며 편중되지 않았는가?
- 기본 수식과 라이브러리 설정을 구분하여 해석했는가?
- 원문과 업무 분야의 맥락을 함께 검토했는가?

## 오늘 배운 점

- TF는 한 문서 안의 등장 빈도이고 DF는 단어를 포함한 문서 수이므로 구분해야 한다.
- TF-IDF는 흔한 단어의 영향과 문서별 희귀 단어의 특징을 함께 고려하는 가중치다.
- TF-IDF 행렬은 문서 × 단어 구조이며, 각 행의 높은 값을 키워드 후보로 활용할 수 있다.
- 전처리 방식, 문서 집합, 라이브러리 설정이 달라지면 단어 목록과 가중치도 달라진다.
- 시각화는 가중치 비교를 돕지만, 키워드의 실제 의미와 긍정·부정은 원문에서 확인해야 한다.
- TF-IDF는 문서별 특징적인 단어를 찾는 데 유용하며, 의미 기반 비교에는 별도 방법이 필요하다.

> 오늘의 핵심: 자주 나온 단어와 문서를 구분하는 단어는 다를 수 있으며, TF-IDF 점수는 원문과 문서 집합의 맥락 속에서 해석해야 한다.
