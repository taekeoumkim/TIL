## 1. 시계열 데이터의 이해

### 1.1 시계열 데이터란?

시계열 데이터(Time Series Data)는 **시간의 흐름에 따라 순서대로 관측된 데이터**다.

대표적인 예시는 다음과 같다.

- 일별 매출과 주가
- 시간별 웹사이트 방문자 수
- 월별 사용자 수
- 시간별 기온과 전력 사용량

일반적인 데이터는 행의 순서가 중요하지 않은 경우가 많지만, 시계열 데이터는 값과 함께 **관측 시점과 순서**도 중요한 정보다. 값의 순서를 섞으면 증가·감소 흐름이나 반복 패턴을 파악하기 어려워진다.

| 일반적인 데이터 | 시계열 데이터 |
|---|---|
| 관측값 자체가 중요 | 관측값과 시간이 함께 중요 |
| 행의 순서가 중요하지 않은 경우가 많음 | 시간 순서를 유지해야 함 |
| 관측값을 독립적으로 다루는 경우가 많음 | 서로 다른 시점의 값이 관련될 수 있음 |

### 1.2 주기(Frequency)

Frequency는 데이터가 관측되는 시간 간격이다.

- 시간별 방문자 수: 1시간 단위
- 일별 매출: 하루 단위
- 월별 사용자 수: 한 달 단위

같은 지표도 Frequency에 따라 확인할 수 있는 변화가 달라진다. 시간별 매출은 하루 안의 변화를, 일별 매출은 날짜별 변화를, 월별 매출은 장기적인 변화를 보여준다.

### 1.3 자기상관(Autocorrelation)

자기상관은 하나의 시계열에서 **현재 값과 과거 값 사이에 나타나는 상관관계**다.

예를 들어 오늘의 기온은 어제의 기온과 관련될 수 있고, 이번 달 사용자 수는 지난달 사용자 수와 관련될 수 있다. 모든 시계열이 강한 자기상관을 갖는 것은 아니며, 관계의 정도는 데이터마다 다르다.

과거 값과 현재 값의 관계는 이후 과거 데이터를 이용해 현재 또는 미래를 예측하는 시계열 모델링의 기반이 된다.

### 1.4 Python으로 시계열 데이터 확인하기

시계열 분석의 출발점은 날짜 자료형을 정리하고 관측 순서를 복원하는 것이다.

```python
import pandas as pd
import matplotlib.pyplot as plt

data = pd.DataFrame({
    "date": [
        "2026-01-03", "2026-01-01", "2026-01-05",
        "2026-01-02", "2026-01-04"
    ],
    "sales": [128, 120, 165, 135, 150]
})

# 문자열을 datetime으로 변환한 뒤 시간순으로 정렬
data["date"] = pd.to_datetime(data["date"])
data = data.sort_values("date")

# 시간에 따른 변화 확인
plt.plot(data["date"], data["sales"])
plt.xlabel("Date")
plt.ylabel("Sales")
plt.title("Daily Sales")
plt.show()
```

기본 확인 순서는 다음과 같다.

1. 날짜·시간 컬럼과 결측 시점을 확인한다.
2. 날짜를 `datetime` 자료형으로 변환한다.
3. 데이터를 시간 순서대로 정렬한다.
4. Frequency가 시간별, 일별, 월별 중 무엇인지 확인한다.
5. 선 그래프로 전체 변화를 확인한다.

## 2. 시계열 데이터의 주요 패턴

하나의 시계열에는 추세, 계절성, 잔차가 함께 나타날 수 있다.

### 2.1 추세(Trend)

Trend는 시간이 지나면서 나타나는 **장기적인 증가 또는 감소 흐름**이다.

개별 시점에서 값이 일시적으로 반대 방향으로 움직이더라도 장기간의 전체적인 수준이 상승하거나 하락한다면 Trend가 있다고 볼 수 있다.

### 2.2 계절성(Seasonality)

Seasonality는 **일정한 시간 간격을 두고 반복되는 패턴**이다. 여기서 계절은 사계절만 의미하지 않는다.

- 시간별 데이터: 하루 중 특정 시간대의 반복
- 일별 데이터: 특정 요일의 반복
- 월별 데이터: 특정 월의 반복

한 번만 발생한 이벤트는 반복성이 없으므로 Seasonality라고 보기 어렵다.

### 2.3 잔차(Residual)

Residual은 Trend와 Seasonality 등 주요 구조로 설명하고 남은 변동이다. 우연한 변동이나 예상하지 못한 사건의 영향이 포함될 수 있다.

특정 이벤트가 발생했다는 이유만으로 관측값 자체를 Residual이라고 부르는 것은 아니다. 실제 시계열에서 Trend와 Seasonality를 분리한 뒤 남은 부분이 Residual이다.

| 패턴 | 의미 | 예시 |
|---|---|---|
| Trend | 장기적인 증가·감소 흐름 | 연도가 지날수록 전반적인 매출 증가 |
| Seasonality | 일정한 주기로 반복되는 패턴 | 매년 11~12월 매출 증가 |
| Residual | 주요 구조로 설명하고 남은 변동 | 일시적인 프로모션 영향 등이 반영된 변동 |

### 2.4 시계열 분해(Time Series Decomposition)

하나의 시계열을 여러 구성 요소로 나누어 살펴보는 것을 시계열 분해라고 한다. 덧셈 모형은 다음 관계를 가정한다.

$$
Observed = Trend + Seasonal + Residual
$$

- **Observed**: 실제 관측된 시계열
- **Trend**: 장기적인 증가 또는 감소 흐름
- **Seasonal**: 일정한 주기로 반복되는 패턴
- **Residual**: Trend와 Seasonal로 설명하고 남은 변동

```python
import pandas as pd
import matplotlib.pyplot as plt
from statsmodels.tsa.seasonal import seasonal_decompose

# data의 index는 DatetimeIndex, sales는 월별 매출이라고 가정
result = seasonal_decompose(
    data["sales"],
    model="additive",
    period=12
)

fig = result.plot()
fig.set_size_inches(14, 9)
plt.show()
```

#### 주요 매개변수

- `model="additive"`: 관측값을 Trend, Seasonal, Residual의 합으로 분해한다.
- `period=12`: 12개 관측값을 한 반복 주기로 사용한다. 월별 데이터라면 1년 주기를 의미한다.

`period`는 항상 12가 아니라 데이터의 Frequency와 찾으려는 반복 주기에 맞춰 설정해야 한다.

#### Trend와 NaN

`seasonal_decompose()`는 이동평균을 기반으로 Trend를 추정한다. 중심 이동평균은 현재 시점의 앞뒤 관측값이 필요하므로 시계열의 처음과 마지막에서는 Trend를 계산하지 못할 수 있다.

이 구간의 Trend는 0이 아니라 `NaN`이며, 아래 계산에 Trend가 필요하므로 Residual도 `NaN`이 될 수 있다.

$$
Residual = Observed - Trend - Seasonal
$$

## 3. 정상성(Stationarity)의 이해

### 3.1 정상성이란?

정상성은 시간이 지나더라도 시계열의 **통계적인 특성이 안정적으로 유지되는 성질**이다.

이번 학습에서 확인하는 핵심 특성은 다음 세 가지다.

| 확인할 특성 | 의미 |
|---|---|
| 평균(Mean) | 데이터가 움직이는 평균적인 수준 |
| 분산(Variance) | 데이터가 평균을 중심으로 변동하는 정도 |
| 시점 사이의 관계 | 일정한 시차를 가진 값 사이의 관계 |

정상적인 시계열은 시간이 지나도 다음 성질이 크게 달라지지 않는다.

- 평균적인 수준
- 변동의 크기
- 동일한 시차에서 나타나는 관계

정상성은 모든 값이 같거나 변하지 않는다는 뜻이 아니다. 각 값은 계속 변할 수 있지만, 일정한 수준을 중심으로 비슷한 크기로 움직이고 시간적 관계가 안정적으로 유지되어야 한다.

### 3.2 시차(Lag)와 관계의 안정성

정상적인 시계열에서 두 시점의 관계는 구체적인 날짜보다 **두 시점이 얼마나 떨어져 있는지**에 따라 결정된다.

예를 들어 1월 1일과 1월 2일, 2월 1일과 2월 2일은 관측 날짜는 다르지만 모두 1일의 Lag를 갖는다. 정상 시계열이라면 같은 Lag에서 나타나는 관계가 시간에 따라 크게 달라지지 않는다.

### 3.3 정상 시계열과 비정상 시계열

| 구분 | 정상성에 가까운 시계열 | 비정상 시계열 |
|---|---|---|
| 평균 수준 | 비교적 일정 | 시간에 따라 증가·감소 |
| 변동 크기 | 비슷한 범위 | 시간에 따라 변화 |
| 동일 Lag의 관계 | 비교적 안정적 | 시간에 따라 달라질 수 있음 |
| 대표적인 구조 | 일정 수준 주변의 변동 | Trend 또는 구조적 변화 |

뚜렷한 Trend는 평균 수준을 변화시키므로 원본 시계열이 정상성을 만족하지 못하게 할 수 있다. Seasonality도 시점에 따라 반복되는 평균 구조를 만들기 때문에 정상성 진단에서 함께 확인해야 한다.

시계열 모델은 과거의 관계와 패턴을 미래에도 적용한다. 따라서 과거와 미래의 통계적 특성이 크게 다르면 과거에서 학습한 패턴의 활용이 어려워질 수 있다.

### 3.4 시각화와 이동평균

정상성을 확인할 때 먼저 원본 시계열을 시각화하고 평균 수준과 변동 크기가 시간에 따라 달라지는지 관찰한다.

이동평균(Rolling Mean)은 일정 구간의 평균을 구한 뒤 그 구간을 이동시키며 평균을 반복 계산하는 방법이다.

```python
# 현재 시점을 포함한 최근 3개 관측값의 평균
data["rolling_mean"] = data["users"].rolling(window=3).mean()

plt.plot(data.index, data["users"], label="Users")
plt.plot(data.index, data["rolling_mean"], label="Rolling Mean")
plt.xlabel("Date")
plt.ylabel("Users")
plt.title("Monthly Users and Rolling Mean")
plt.legend()
plt.show()
```

이동평균이 계속 상승하거나 하락한다면 평균적인 수준이 시간에 따라 변하고 있음을 의심할 수 있다. 다만 그래프와 이동평균은 직관적인 진단 방법이므로 통계 검정과 함께 판단해야 한다.

## 4. 정상성 진단과 변환

### 4.1 단위근(Unit Root)

어떤 시계열은 다음과 같이 이전 값에 현재의 변화가 더해져 만들어질 수 있다.

$$
y_t = y_{t-1} + \epsilon_t
$$

이 구조에서는 과거에 발생한 충격의 영향이 이후 값에도 계속 남을 수 있다. 이러한 특성과 관련된 개념이 Unit Root이며, 단위근이 존재하는 시계열은 안정적인 평균 수준으로 쉽게 돌아오지 않아 일반적으로 정상성을 만족하지 않는다.

### 4.2 ADF Test

ADF Test(Augmented Dickey-Fuller Test)는 시계열에 단위근이 존재하는지를 검정한다.

- **귀무가설 $H_0$**: 단위근이 존재한다. 즉, 정상성을 만족한다고 보기 어렵다.
- **대립가설 $H_1$**: 단위근이 존재하지 않는다. 즉, 정상성을 만족한다고 볼 근거가 있다.

유의수준을 0.05로 설정했을 때의 해석은 다음과 같다.

| p-value | 판단 | 해석 |
|---|---|---|
| `< 0.05` | 귀무가설 기각 | 단위근이 없다는 근거가 있으며 ADF 기준으로 정상성을 만족한다고 판단 |
| `≥ 0.05` | 귀무가설을 기각하지 못함 | 단위근이 없다고 보기 어려우며 ADF 기준으로 정상성을 판단하기 어려움 |

```python
from statsmodels.tsa.stattools import adfuller

result = adfuller(data["users"].dropna())

print("ADF Statistic:", result[0])
print("p-value:", result[1])
print("Critical Values:", result[4])
```

예를 들어 p-value가 0.81이라면 0.05보다 크므로 귀무가설을 기각하지 못한다. 따라서 해당 원본 시계열은 ADF Test를 기준으로 정상성을 만족한다고 보기 어렵다.

### 4.3 차분(Differencing)

차분은 현재 시점의 값에서 이전 시점의 값을 빼 시점 사이의 변화량을 구하는 방법이다.

$$
\Delta y_t = y_t-y_{t-1}
$$

- 차분 전: 각 시점의 수준(Level)
- 차분 후: 이전 시점 대비 변화(Change)

차분은 시계열의 수준 변화나 Trend의 영향을 줄여 데이터를 더 안정적인 형태로 만드는 데 활용할 수 있다.

```python
# 1차 차분
data["users_diff"] = data["users"].diff()

# 첫 번째 값은 이전 값이 없어 NaN이므로 제거 후 검정
diff_series = data["users_diff"].dropna()
result_diff = adfuller(diff_series)

print("ADF Statistic:", result_diff[0])
print("p-value:", result_diff[1])
```

차분을 했다는 사실만으로 정상성이 확보되었다고 결론 내리면 안 된다. 차분한 데이터의 그래프와 ADF Test 결과를 다시 확인해야 한다.

### 4.4 정상성 진단 절차

1. 날짜 자료형, 시간 순서, Frequency를 확인한다.
2. 원본 시계열을 시각화한다.
3. Trend, Seasonality, 변동 크기, 이동평균을 확인한다.
4. ADF Test를 실행한다.
5. 정상성을 만족하기 어렵다면 차분 등 필요한 변환을 적용한다.
6. 변환된 시계열을 다시 시각화한다.
7. ADF Test를 재실행해 정상성을 확인한다.

ADF Test의 p-value 하나만 보는 것이 아니라 **패턴 확인 → 통계적 진단 → 변환 → 재진단**의 전체 과정을 거치는 것이 중요하다.

| Autocorrelation | 현재 값과 과거 값이 관련되는가? | Lag별 상관관계 확인 |
| Trend | 장기적으로 증가·감소하는가? | 원본 그래프, 이동평균, 분해 |
| Seasonality | 일정한 주기로 반복되는가? | 주기 비교, 시계열 분해 |
| Residual | 주요 패턴으로 설명하고 무엇이 남는가? | 시계열 분해 결과 |
| Stationarity | 통계적 특성이 시간에 따라 안정적인가? | 시각화, 이동평균, ADF Test |
| Unit Root | 충격의 영향이 지속되는가? | ADF Test |
| Differencing | 수준 대신 변화량을 보면 안정적인가? | `diff()` 적용 후 재진단 |

## 핵심 정리

1. 시계열 데이터에서는 값뿐 아니라 시간, 순서, Frequency가 중요하다.
2. 현재 값과 과거 값의 관계를 자기상관이라고 한다.
3. 시계열에는 Trend, Seasonality, Residual이 동시에 포함될 수 있다.
4. 덧셈 시계열 분해에서는 `Observed = Trend + Seasonal + Residual` 관계를 사용한다.
5. 정상성은 평균, 분산, 동일 Lag의 관계가 시간에 따라 안정적으로 유지되는 성질이다.
6. 그래프와 이동평균은 정상성을 직관적으로 확인하는 방법이며, ADF Test와 함께 판단해야 한다.
7. ADF Test에서 p-value가 유의수준보다 작으면 단위근이 존재한다는 귀무가설을 기각한다.
8. 차분은 수준 데이터를 변화량 데이터로 바꾸지만, 적용 후 정상성을 반드시 다시 확인해야 한다.

## 오늘의 한 문장

> 시계열 분석은 값의 크기만 보는 것이 아니라 시간적 순서와 반복 구조를 이해하고, 과거의 패턴을 미래에 활용할 수 있도록 정상성을 진단하고 필요한 변환을 수행하는 과정이다.
