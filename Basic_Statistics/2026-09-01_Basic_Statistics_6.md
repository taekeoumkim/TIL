## 1. 표본평균의 표본분포

모집단 전체를 조사하기 어려울 때는 일부를 표본으로 뽑아 모집단의 특성을 추정한다. 그러나 같은 모집단에서 같은 수의 데이터를 뽑더라도 어떤 데이터가 선택되는지에 따라 표본평균은 달라진다.

예를 들어 카페 고객 20명을 여러 번 표본으로 뽑으면 평균 주문 금액은 다음처럼 매번 다를 수 있다.

- 첫 번째 표본평균: 15,200원
- 두 번째 표본평균: 14,700원
- 세 번째 표본평균: 15,500원

이처럼 **같은 모집단에서 같은 크기의 표본을 반복 추출하고, 각 표본에서 계산한 통계량들이 이루는 확률분포**를 표본분포라고 한다. 평균을 계산했다면 표본평균의 표본분포, 비율을 계산했다면 표본비율의 표본분포가 된다.

### 혼동하기 쉬운 세 가지 분포

| 구분 | 의미 | 관찰 대상 |
|---|---|---|
| 모집단 분포 | 모집단에 속한 개별 값들의 분포 | 전체 고객의 주문 금액 |
| 표본의 분포 | 한 번 추출한 표본 안의 개별 값들의 분포 | 선택된 고객 20명의 주문 금액 |
| 표본평균의 표본분포 | 반복 추출한 각 표본의 평균들이 이루는 분포 | 여러 번 계산한 평균 주문 금액 |

### 표본평균 분포의 성질

모평균을 \(\mu\), 모분산을 \(\sigma^2\), 표본 크기를 \(n\)이라고 하면 독립적으로 추출한 표본평균 \(\bar{X}\)은 다음 성질을 가진다.

$$
E(\bar{X}) = \mu
$$

$$
Var(\bar{X}) = \frac{\sigma^2}{n}
$$

$$
SD(\bar{X}) = \frac{\sigma}{\sqrt{n}}
$$

즉, 표본평균의 기댓값은 모평균과 같고, 표본 크기가 커질수록 표본평균들은 모평균 주변에 더 조밀하게 모인다.

### Python으로 반복 표본 추출하기

```python
import numpy as np

np.random.seed(42)

# 평균 15,000원, 표준편차 3,000원인 고객 주문 금액 모집단
population = np.random.normal(15000, 3000, 10000)
sample_means = []

# 20명씩 복원추출하여 평균을 구하는 작업을 1,000번 반복
for _ in range(1000):
    sample = np.random.choice(population, size=20, replace=True)
    sample_means.append(np.mean(sample))

print(f"모집단 평균: {np.mean(population):.0f}원")
print(f"표본평균들의 평균: {np.mean(sample_means):.0f}원")
```

각 표본평균은 조금씩 다르지만, 반복 횟수가 많아지면 표본평균들의 평균은 모평균에 가까워진다. 여기서 `replace=True`는 한 번 뽑힌 값도 다시 선택될 수 있는 복원추출을 뜻한다.

## 2. 중심극한정리(Central Limit Theorem)

현실의 데이터는 항상 정규분포를 따르지 않는다. 예를 들어 배달 시간은 대부분 짧지만 교통 체증이나 주문 폭주로 일부 값이 매우 커져 오른쪽으로 치우칠 수 있다.

중심극한정리에 따르면 모집단의 분포가 정규분포가 아니더라도 일정한 조건에서 표본 크기 \(n\)이 충분히 커지면 표본평균의 분포는 정규분포에 가까워진다.

$$
\bar{X} \approx N\left(\mu, \frac{\sigma^2}{n}\right)
$$

따라서 표본평균의 분포는 다음과 같이 근사할 수 있다.

- 평균: \(\mu\)
- 분산: \(\sigma^2/n\)
- 표준편차: \(\sigma/\sqrt{n}\)

### 반드시 구분할 점

중심극한정리는 **표본 안의 개별 데이터나 모집단 자체가 정규분포로 변한다는 뜻이 아니다.** 반복해서 얻은 **표본평균들의 분포**가 정규분포에 가까워진다는 뜻이다.

`n >= 30`은 자주 사용하는 경험적 기준일 뿐 절대적인 규칙은 아니다. 모집단이 심하게 치우쳤거나 극단값이 많으면 더 큰 표본이 필요할 수 있다. 또한 일반적인 중심극한정리에는 표본의 독립성과 모집단의 유한한 분산 같은 조건이 필요하다.

### 치우친 모집단으로 CLT 확인하기

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# 오른쪽으로 치우친 배달 시간 모집단
population = np.random.exponential(scale=20, size=10000)
sample_means = []

for _ in range(1000):
    sample = np.random.choice(population, size=30, replace=True)
    sample_means.append(np.mean(sample))

fig, axes = plt.subplots(1, 2, figsize=(11, 4))

axes[0].hist(population, bins=50, color="skyblue", edgecolor="black")
axes[0].set_title("모집단 분포")
axes[0].set_xlabel("배달 시간")
axes[0].set_ylabel("빈도")

axes[1].hist(sample_means, bins=30, color="salmon", edgecolor="black")
axes[1].set_title("표본평균의 분포 (n=30)")
axes[1].set_xlabel("평균 배달 시간")
axes[1].set_ylabel("빈도")

plt.tight_layout()
plt.show()
```

왼쪽의 모집단은 오른쪽 꼬리가 길지만, 오른쪽의 표본평균 분포는 종 모양에 가까워지는 것을 확인할 수 있다.

### 표본 크기에 따른 변화 비교

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(20)
population = np.random.exponential(scale=10, size=10000)
sample_sizes = [1, 5, 30, 100]

fig, axes = plt.subplots(2, 2, figsize=(10, 7))

for ax, n in zip(axes.flat, sample_sizes):
    means = [
        np.mean(np.random.choice(population, size=n, replace=True))
        for _ in range(1000)
    ]
    ax.hist(means, bins=30, edgecolor="black")
    ax.set_title(f"표본평균의 분포 (n={n})")

plt.tight_layout()
plt.show()
```

표본 크기가 커질수록 두 가지 변화가 나타난다.

1. 표본평균의 분포가 정규분포에 가까워진다.
2. 표본평균의 분포가 더 좁아져 모평균 근처에 모인다.

## 3. 표준오차(Standard Error)

표준오차는 반복해서 얻은 표본평균들이 얼마나 퍼져 있는지를 나타내는 값, 즉 **표본평균의 표준편차**이다.

$$
SE = \frac{\sigma}{\sqrt{n}}
$$

- \(\sigma\): 모집단의 표준편차
- \(n\): 표본 크기

모표준편차 \(\sigma\)를 모를 때는 표본표준편차 \(s\)를 이용해 표준오차를 추정한다.

$$
\widehat{SE} = \frac{s}{\sqrt{n}}
$$

### 표준편차와 표준오차 비교

| 구분 | 표준편차(SD) | 표준오차(SE) |
|---|---|---|
| 무엇의 퍼짐인가? | 개별 관측값 | 반복 추출한 표본통계량 |
| 무엇을 설명하는가? | 데이터의 변동성 | 추정량의 불확실성·정밀도 |
| 표본 크기와의 관계 | 표본 크기가 커진다고 자동으로 감소하지 않음 | \(n\)이 커질수록 감소 |

표준오차가 작다는 것은 표본을 다시 뽑아도 표본평균이 크게 달라지지 않는다는 뜻이다. 따라서 모평균을 더 정밀하게 추정할 수 있다. 다만 표준오차가 작다고 해서 편향된 표본이나 잘못된 조사 설계가 자동으로 해결되는 것은 아니다.

### 표본 크기와 표준오차의 관계

```python
import numpy as np

sigma = 12
sample_sizes = [10, 25, 100, 400]

for n in sample_sizes:
    se = sigma / np.sqrt(n)
    print(f"표본 크기 {n:3d}명 -> 표준오차 {se:.2f}")
```

실행 결과:

```text
표본 크기  10명 -> 표준오차 3.79
표본 크기  25명 -> 표준오차 2.40
표본 크기 100명 -> 표준오차 1.20
표본 크기 400명 -> 표준오차 0.60
```

표준오차는 \(1/\sqrt{n}\)에 비례하므로 다음 관계가 성립한다.

- 표본 크기를 4배로 늘리면 표준오차는 절반이 된다.
- 표본 크기를 100배로 늘리면 표준오차는 1/10이 된다.
- 표준오차를 절반으로 줄이려면 표본을 2배가 아니라 4배로 늘려야 한다.

## 4. 추론통계의 토대

실제로는 표본을 수천 번 뽑기보다 하나의 표본만 관측하는 경우가 많다. 표본분포의 이론적 성질을 알고 있으면 하나의 표본평균을 이용해 다음과 같은 추론을 할 수 있다.

- 모평균 추정
- 신뢰구간 계산
- 가설검정
- 추정값의 불확실성 평가

전체 흐름은 다음과 같이 이해할 수 있다.

```text
모집단에서 표본 추출
        ↓
표본평균 계산
        ↓
표본분포와 표준오차를 이용해 변동성 파악
        ↓
모평균에 대한 추론
```

중심극한정리 덕분에 모집단의 정확한 분포를 모르더라도 조건이 충족되고 표본이 충분히 크다면 표본평균의 분포를 정규분포로 근사할 수 있다. 이것이 신뢰구간과 가설검정을 가능하게 하는 핵심 기반이다.

## 5. 코딩 테스트 사전 학습: BFS

BFS(Breadth-First Search, 너비 우선 탐색)는 시작점에서 가까운 노드부터 차례로 탐색하는 알고리즘이다. 먼저 들어온 데이터를 먼저 꺼내는 Queue를 사용하며, Python에서는 `collections.deque`의 `append()`와 `popleft()`를 활용한다.

가중치가 없는 그래프에서는 BFS가 이동 횟수 0인 노드, 1인 노드, 2인 노드 순서로 탐색하므로 목표 노드를 처음 발견했을 때의 거리가 최소 이동 횟수가 된다.

### 최소 이동 횟수 구하기

```python
from collections import deque


def solution(graph, start, target):
    queue = deque([(start, 0)])
    visited = {start}

    while queue:
        current, distance = queue.popleft()

        if current == target:
            return distance

        for next_node in graph[current]:
            if next_node not in visited:
                visited.add(next_node)
                queue.append((next_node, distance + 1))


graph = {
    1: [2, 3],
    2: [1, 4],
    3: [1],
    4: [2],
}

print(solution(graph, 1, 4))  # 2
```

### BFS 핵심

- Queue에 현재 노드와 이동 횟수를 함께 저장한다.
- 같은 노드를 반복 탐색하지 않도록 `visited`를 사용한다.
- 새 노드를 Queue에 넣는 순간 방문 처리해야 중복 삽입을 막을 수 있다.
- 일반 그래프의 BFS 시간 복잡도는 인접 리스트 기준 \(O(V + E)\)이다.
- 최소 이동 횟수를 보장하는 것은 모든 간선의 가중치가 같거나 없는 경우이다.

## 6. 오늘 배운 내용 정리

1. 표본분포는 같은 크기의 표본을 반복 추출할 때 통계량들이 이루는 확률분포이다.
2. 표본평균의 기댓값은 모평균과 같다.
3. 표본평균의 표준편차를 표준오차라고 하며, \(SE=\sigma/\sqrt{n}\)이다.
4. 표본 크기가 커질수록 표준오차가 작아져 추정의 정밀도가 높아진다.
5. 중심극한정리는 조건이 충족될 때 표본 크기가 커질수록 표본평균의 분포가 정규분포에 가까워진다는 정리이다.
6. 정규분포에 가까워지는 대상은 원자료가 아니라 표본평균의 분포이다.
7. BFS는 Queue와 방문 기록을 사용해 가까운 노드부터 탐색하며, 가중치가 없는 그래프의 최단 이동 횟수를 구할 수 있다.

## 7. 느낀 점

표본 하나의 평균이 모집단 평균과 항상 같지는 않지만, 표본평균의 반복적인 변동에는 일정한 규칙이 있다는 점이 인상적이었다. 중심극한정리를 통해 모집단이 정규분포가 아니더라도 표본평균을 이용한 통계적 추론이 가능해지는 이유를 이해할 수 있었다.

또한 단순히 표본 수가 많으면 좋다고 생각했는데, 표준오차가 \(1/\sqrt{n}\)의 비율로 감소한다는 것을 통해 정밀도를 높이기 위해 필요한 표본 수가 생각보다 빠르게 증가한다는 사실도 알게 되었다. 앞으로 통계 결과를 볼 때 평균만 확인하지 않고 표본 크기, 표준오차, 표본추출 방법까지 함께 살펴봐야겠다.
