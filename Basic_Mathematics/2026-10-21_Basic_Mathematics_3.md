## 1. 선형 변환과 아핀 변환

선형 변환(Linear Transformation)은 **벡터의 덧셈과 스칼라 곱을 보존하는 변환**이다. 입력을 행 벡터로 표현하면 행렬곱으로 다음과 같이 나타낸다.

$$
T(\mathbf{x})=\mathbf{x}W
$$

열 벡터를 사용하는 표기에서는 행렬을 왼쪽에 둔다. 같은 변환을 두 표기로 나타낼 때에는 행렬의 전치 관계도 함께 맞춰야 한다.

### 선형성의 두 조건

$$
T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v})
$$

$$
T(c\mathbf{u})=cT(\mathbf{u})
$$

각각 덧셈 보존과 스칼라 곱 보존을 뜻한다. 선형 변환은 항상 $T(\mathbf{0})=\mathbf{0}$을 만족한다.

예를 들어 입력이 $[3,2]$이고 변환 행렬이 다음과 같다면 각 성분을 2배, 3배로 바꾼다.

$$
W=\begin{bmatrix}2&0\\0&3\end{bmatrix},\qquad
[3,2]W=[6,6]
$$

행렬에 따라 벡터의 크기와 방향을 바꾸거나, 회전시키거나, 다른 차원의 벡터로 변환할 수도 있다.

### 편향을 더하면 아핀 변환

아핀 변환(Affine Transformation)은 선형 변환 결과에 편향을 더한다.

$$
f(\mathbf{x})=\mathbf{x}W+\mathbf{b}
$$

편향이 $[1,-2]$라면 출력은 $[6,6]+[1,-2]=[7,4]$이다.

```python
import numpy as np

x = np.array([3, 2])
W_scale = np.array([[2, 0], [0, 3]])
b_shift = np.array([1, -2])

print(x @ W_scale)             # [6 6]
print(x @ W_scale + b_shift)   # [7 4]
```

| 구분 | 선형 변환 | 아핀 변환 |
| --- | --- | --- |
| 수식 | $\mathbf{x}W$ | $\mathbf{x}W+\mathbf{b}$ |
| 주요 연산 | 행렬곱 | 행렬곱과 편향 덧셈 |
| 0벡터 입력 | 0벡터 출력 | 편향 벡터 출력 |
| 원점 보존 | 항상 보존 | 편향이 0일 때 보존 |

**편향이 0이 아닌 아핀 변환은 선형 변환이 아니다.** 편향이 0이면 선형 변환과 같아진다. 원점 보존은 선형 변환의 필수 성질이지만, 그것만으로 선형성을 보장하지는 않는다.

## 2. 가중치와 편향의 역할

출력이 하나인 모델의 점수는 다음과 같이 계산할 수 있다.

$$
z=\sum_{i=1}^{d}x_iw_i+b=\mathbf{x}\cdot\mathbf{w}+b
$$

| 구분 | 가중치(Weight) | 편향(Bias) |
| --- | --- | --- |
| 적용 방식 | 입력값에 곱함 | 가중합에 더함 |
| 역할 | 특성의 기여 방향과 정도를 조절 | 출력의 기준점을 조절 |
| 입력에 따른 기여 | 입력값에 따라 달라짐 | 같은 출력에 일정한 값을 추가 |
| 학습 | 학습 중 조정되는 파라미터 | 학습 중 조정되는 파라미터 |

### 가중치의 부호와 크기

다른 입력을 고정한 아핀 연산에서 특정 입력을 증가시키면 다음과 같은 변화가 나타난다.

- 가중치가 양수: 해당 출력 점수가 증가한다.
- 가중치가 음수: 해당 출력 점수가 감소한다.
- 가중치가 0: 해당 입력은 그 출력의 가중합에 직접 기여하지 않는다.

단, **가중치의 절댓값만으로 특성 중요도를 단정할 수 없다.** 입력의 단위와 스케일에 따라 실제 기여량이 달라지기 때문이다. 이 해석은 해당 가중합에 대한 것이며, 여러 레이어와 활성화 함수를 거친 최종 출력의 영향은 더 복잡할 수 있다.

### 편향은 출력의 기준점

입력이 모두 0이면 가중합은 0이므로 출력 점수는 편향과 같다. 선형 회귀의 절편과 같은 역할이다. 다만 실제 데이터에서 입력이 0인 상황이 의미가 있는지는 따로 판단해야 한다.

같은 출력의 편향을 3만큼 높이면 모든 데이터의 **활성화 전 점수**가 3씩 증가한다. 가중치를 바꾸면 입력값에 따라 점수 변화량이 달라진다.

```python
X_compare = np.array([[3, 2], [5, 1]])
w_compare = np.array([1, 4])

print(X_compare @ w_compare + 2)  # [13 11]
print(X_compare @ w_compare + 5)  # [16 14]
```

### 여러 출력의 파라미터와 Shape

입력 특성이 $d$개이고 출력 뉴런이 $m$개인 완전연결 레이어에서는 다음과 같이 배치한다.

| 대상 | Shape | 의미 |
| --- | --- | --- |
| 입력 $X$ | `(n, d)` | 데이터 $n$개, 입력 특성 $d$개 |
| 가중치 $W$ | `(d, m)` | 입력 특성과 각 뉴런의 연결 |
| 편향 $\mathbf{b}$ | `(m,)` | 뉴런마다 하나의 편향 |
| 출력 $Z$ | `(n, m)` | 데이터별 뉴런 출력 |

$$
Z=XW+\mathbf{b}
$$

이 배치에서 $W$의 각 열은 뉴런 하나의 가중치이다. 편향은 브로드캐스팅을 통해 모든 데이터 행에 동일하게 더해진다.

편향을 포함한 전체 학습 파라미터 개수는 $dm+m$개이다. 예를 들어 입력 2개, 출력 3개이면 가중치 6개와 편향 3개로 총 9개이다.

## 3. 뉴런과 활성화 함수

뉴런은 입력에 가중치를 적용하고 편향을 더한 뒤, 필요한 활성화 함수를 적용하여 출력을 계산하는 기본 단위이다.

$$
z=\mathbf{x}\cdot\mathbf{w}+b,\qquad a=f(z)
$$

예를 들어 입력 $[3,2]$, 가중치 $[2,-1]$, 편향 3이면 다음과 같다.

$$
z=3\times2+2\times(-1)+3=7
$$

이후 선택한 활성화 함수에 따라 최종 출력이 결정된다.

### ReLU

ReLU(Rectified Linear Unit)는 양수를 그대로 출력하고 0 이하를 0으로 바꾼다.

$$
\mathrm{ReLU}(z)=\max(0,z)
$$

| 입력 | -3 | -1 | 0 | 2 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ReLU 출력 | 0 | 0 | 0 | 2 | 5 |

```python
def relu(z):
    return np.maximum(0, z)

print(relu(np.array([-3, -1, 0, 2, 5])))  # [0 0 0 2 5]
```

벡터나 행렬에도 원소별로 적용되며 Shape는 유지된다. 앞의 뉴런에서 $z=7$이므로 ReLU 출력도 7이다.

## 4. 비선형 활성화 함수가 필요한 이유

활성화 함수 없이 아핀 변환만 두 번 연결하면 다음과 같다.

$$
\mathbf{h}=\mathbf{x}W_1+\mathbf{b}_1
$$

$$
\mathbf{y}=\mathbf{h}W_2+\mathbf{b}_2
=\mathbf{x}(W_1W_2)+(\mathbf{b}_1W_2+\mathbf{b}_2)
$$

새 가중치를 $W_1W_2$, 새 편향을 $\mathbf{b}_1W_2+\mathbf{b}_2$로 두면 **전체가 하나의 아핀 변환으로 합쳐진다.** 레이어를 늘리는 것만으로 비선형 관계를 표현할 수는 없다.

반면 레이어 사이에 ReLU와 같은 비선형 활성화 함수를 넣으면 전체를 일반적으로 하나의 아핀 변환으로 합칠 수 없다.

예를 들어 $f(x)=\mathrm{ReLU}(x-2)$는 $x\leq2$에서 0이고, $x>2$에서는 $x-2$이다. 입력 구간에 따라 다른 형태의 관계를 만든다.

## 5. 여러 뉴런의 연산을 행렬로 계산하기

입력 $[3,2]$를 뉴런 2개에 전달한다고 하자.

$$
W_1=\begin{bmatrix}1&-2\\2&1\end{bmatrix},\qquad
\mathbf{b}_1=[-4,1]
$$

| 뉴런 | 가중합과 편향 | 활성화 전 점수 | ReLU 출력 |
| --- | --- | ---: | ---: |
| 1 | $3\times1+2\times2-4$ | 3 | 3 |
| 2 | $3\times(-2)+2\times1+1$ | -3 | 0 |

따라서 활성화 전 벡터는 $[3,-3]$, 활성화 후 벡터는 $[3,0]$이다.

여러 고객의 데이터를 행으로 쌓으면 같은 연산을 한 번에 수행할 수 있다.

```python
X = np.array([
    [3, 2],
    [1, 4],
    [0, 2],
])
W1 = np.array([
    [1, -2],
    [2,  1],
])
b1 = np.array([-4, 1])

Z1 = X @ W1 + b1
H = relu(Z1)

print(Z1)
# [[ 3 -3]
#  [ 5  3]
#  [ 0  3]]

print(H)
# [[3 0]
#  [5 3]
#  [0 3]]

print(H.shape)  # (3, 2)
```

데이터 개수는 3개로 유지되고 각 데이터가 뉴런 2개의 출력으로 표현된다. 레이어의 뉴런 수가 다음 레이어에 전달할 특성 개수가 된다.

## 6. 순전파로 최종 출력 계산하기

순전파(Forward Propagation)는 입력이 각 레이어를 순서대로 통과하여 최종 출력에 도달하는 계산 과정이다.

은닉층에는 ReLU를 적용하고, 출력층에서는 하나의 점수를 계산하는 구조를 사용하자.

$$
Z_1=XW_1+\mathbf{b}_1,\qquad H=\mathrm{ReLU}(Z_1)
$$

$$
Y=HW_2+\mathbf{b}_2
$$

```python
W2 = np.array([
    [2],
    [-1],
])
b2 = np.array([1])

Y = H @ W2 + b2

print(Y)
# [[ 7]
#  [ 8]
#  [-2]]

print(Y.shape)  # (3, 1)
```

| 단계 | Shape | 의미 |
| --- | --- | --- |
| 입력 $X$ | `(3, 2)` | 고객 3명, 특성 2개 |
| 은닉층 가중치 $W_1$ | `(2, 2)` | 입력 2개를 뉴런 2개에 연결 |
| 은닉층 출력 $H$ | `(3, 2)` | 고객별 새로운 표현 2개 |
| 출력층 가중치 $W_2$ | `(2, 1)` | 은닉층 출력 2개를 점수 1개에 연결 |
| 최종 출력 $Y$ | `(3, 1)` | 고객마다 점수 1개 |

고객 A의 출력은 $3\times2+0\times(-1)+1=7$이다. 고객별 최종 점수는 각각 7, 8, -2이다.

이 예시의 출력층에는 활성화 함수를 적용하지 않았다. 출력층의 함수는 해결하려는 문제에 따라 선택하며, **이 점수들을 곧바로 구매 확률로 해석할 수는 없다.**

단일 고객을 NumPy 1차원 배열 `(2,)`로 넣으면 이 구조의 최종 출력은 `(1,)`이다. 고객 한 명을 2차원 배열 `(1, 2)`로 넣으면 최종 출력은 `(1, 1)`이므로 배치 축의 유무를 구분해야 한다.

## 7. 순전파와 학습의 차이

순전파는 **주어진 파라미터로 출력을 계산하는 과정**이다. 순전파만으로 가중치와 편향이 바뀌지는 않는다.

학습에서는 다음 과정을 반복한다.

1. 순전파로 예측값을 계산한다.
2. 예측값과 정답을 비교하여 손실을 계산한다.
3. 역전파로 파라미터에 대한 손실의 기울기를 계산한다.
4. 경사하강법 등의 최적화 방법으로 가중치와 편향을 업데이트한다.

파라미터 학습의 핵심은 예측에 사용하는 가중치와 편향을 조정하는 것이다. 입력 전처리나 특성 선택은 이와 구분되는 데이터 처리 과정이다.

## 핵심 정리

- 선형 변환은 덧셈과 스칼라 곱을 보존하고, 아핀 변환은 그 결과에 편향을 더한다.
- 가중치는 입력의 기여를 조절하고 편향은 활성화 전 출력의 기준점을 이동시킨다.
- 여러 뉴런의 계산은 행렬곱과 편향 덧셈으로 묶을 수 있다.
- 비선형 활성화 함수 없이 아핀 변환만 쌓으면 하나의 아핀 변환으로 합쳐진다.
- 레이어 출력의 Shape는 데이터 개수와 해당 레이어의 뉴런 수로 결정된다.
- 순전파는 예측 계산이며, 학습에는 손실 계산과 기울기를 이용한 파라미터 업데이트가 추가로 필요하다.
