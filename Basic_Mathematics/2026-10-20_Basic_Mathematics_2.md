## 1. 벡터 내적의 계산과 의미

벡터 내적(Dot Product)은 **두 벡터에서 같은 위치의 원소끼리 곱한 뒤 모두 더하는 연산**이다. 여러 입력 특성에 서로 다른 가중치를 적용하여 하나의 점수를 계산할 때 사용할 수 있다.

### 내적의 계산

두 벡터가 다음과 같다고 하자.

$$
\mathbf{a}=[2,3],\qquad \mathbf{b}=[4,5]
$$

대응하는 원소를 곱한 후 더하면 내적을 구할 수 있다.

$$
\mathbf{a}\cdot\mathbf{b}=2\times4+3\times5=8+15=23
$$

일반적으로 원소가 $n$개인 두 벡터의 내적은 다음과 같다.

$$
\mathbf{a}\cdot\mathbf{b}
=\sum_{i=1}^{n}a_i b_i
=a_1b_1+a_2b_2+\cdots+a_nb_n
$$

내적의 결과는 벡터가 아니라 **하나의 숫자인 스칼라**이다.

```python
import numpy as np

a = np.array([2, 3])
b = np.array([4, 5])

print(np.dot(a, b))  # 23
print(a @ b)         # 23
```

두 입력이 1차원 NumPy 배열이면 `np.dot(a, b)`와 `a @ b`로 내적을 계산할 수 있다.

### 원소별 곱과 구분하기

```python
print(a * b)  # [ 8 15]
print(a @ b)  # 23
```

| 연산 | 계산 방식 | 결과 |
| --- | --- | --- |
| `a * b` | 대응하는 원소끼리 곱함 | 원소별 곱을 담은 배열 |
| `a @ b` | 대응하는 원소끼리 곱한 후 합산 | 스칼라 |

내적은 원소별 곱에서 계산이 끝나는 것이 아니라, **곱한 결과를 모두 더하는 과정까지 포함한다.**

## 2. 벡터 내적의 차원 조건

일반적인 벡터 내적은 **두 벡터의 원소 개수가 같아야** 계산할 수 있다.

$$
[1,2,3]\cdot[4,5,6]
=1\times4+2\times5+3\times6=32
$$

반면 `[1, 2]`와 `[3, 4, 5]`는 원소 개수가 달라 각 위치를 일대일로 대응시킬 수 없다.

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(a.shape)       # (3,)
print(b.shape)       # (3,)
print(np.dot(a, b))  # 32
```

1차원 배열에서는 두 배열의 `shape`가 같은지 확인하면 원소 개수의 일치 여부를 판단할 수 있다. 길이가 다른 1차원 배열에 `np.dot()`을 적용하면 오류가 발생한다.

모델의 입력 특성과 가중치를 연결할 때에는 개수뿐 아니라 **특성의 순서도 일치해야 한다.** 첫 번째 특성에는 첫 번째 가중치가 적용되기 때문이다.

## 3. 벡터 내적의 기하학적 의미

내적은 계산식 외에도 두 벡터의 길이와 방향 관계로 설명할 수 있다.

$$
\mathbf{a}\cdot\mathbf{b}
=\|\mathbf{a}\|_2\|\mathbf{b}\|_2\cos\theta
$$

- $\|\mathbf{a}\|_2$, $\|\mathbf{b}\|_2$: 각 벡터의 L2 노름, 즉 길이
- $\theta$: 두 벡터 사이의 각도
- $\cos\theta$: 사이각에 대한 코사인 값

벡터의 L2 노름은 각 원소를 제곱하여 더한 값에 제곱근을 취해 계산한다.

$$
\|\mathbf{a}\|_2=\sqrt{a_1^2+a_2^2+\cdots+a_n^2}
$$

### 내적의 부호와 방향 관계

**두 벡터가 모두 0벡터가 아닐 때** 다음과 같이 해석할 수 있다.

| 내적 결과 | 사이각 | 방향 관계 |
| --- | --- | --- |
| 양수 | $0^\circ\leq\theta<90^\circ$ | 예각을 이룸 |
| 0 | $\theta=90^\circ$ | 서로 수직 |
| 음수 | $90^\circ<\theta\leq180^\circ$ | 둔각 또는 정반대 방향 |

예를 들어 $\mathbf{a}=[1,0]$을 기준으로 비교하면 다음과 같다.

| 비교 벡터 $\mathbf{b}$ | 내적 | 사이각 | 해석 |
| --- | ---: | --- | --- |
| $[2,0]$ | 2 | $0^\circ$ | 같은 방향 |
| $[0,2]$ | 0 | $90^\circ$ | 수직 |
| $[-2,0]$ | -2 | $180^\circ$ | 반대 방향 |

내적에는 방향뿐 아니라 **벡터의 크기도 영향을 준다.** 따라서 내적 값이 더 크다는 이유만으로 두 벡터의 방향이 더 비슷하다고 판단할 수 없다.

## 4. 코사인 유사도

코사인 유사도(Cosine Similarity)는 내적을 두 벡터 길이의 곱으로 나누어, 크기에 따른 영향을 제거하고 방향의 유사도를 비교한다.

$$
\operatorname{cosine\_similarity}(\mathbf{a},\mathbf{b})
=\frac{\mathbf{a}\cdot\mathbf{b}}
{\|\mathbf{a}\|_2\|\mathbf{b}\|_2}
=\cos\theta
$$

| 값 | 의미 |
| ---: | --- |
| 1 | 같은 방향 |
| 0 | 서로 수직 |
| -1 | 반대 방향 |

코사인 유사도는 $-1$부터 $1$ 사이의 값을 갖는다.

### 크기가 달라도 방향은 같을 수 있다

$$
\mathbf{a}=[3,4],\qquad\mathbf{b}=[6,8]
$$

$$
\mathbf{a}\cdot\mathbf{b}=3\times6+4\times8=50
$$

$$
\|\mathbf{a}\|_2=5,\qquad\|\mathbf{b}\|_2=10
$$

따라서 코사인 유사도는 다음과 같다.

$$
\frac{50}{5\times10}=1
$$

$\mathbf{b}$는 $\mathbf{a}$의 두 배이므로 길이는 다르지만 방향은 같다.

```python
a = np.array([3, 4])
b = np.array([6, 8])

dot_product = np.dot(a, b)
norm_a = np.linalg.norm(a)
norm_b = np.linalg.norm(b)

cosine_similarity = dot_product / (norm_a * norm_b)
print(cosine_similarity)  # 1.0
```

### 활용과 주의할 점

문장이나 문서를 숫자 벡터로 표현한 임베딩(Embedding)의 유사도를 비교할 때 사용할 수 있다. 벡터의 크기보다 방향 관계가 중요한 상황에 적합하다.

- 0벡터의 길이는 0이므로 코사인 유사도를 정의할 수 없다.
- 유사도 값의 의미는 데이터를 어떤 방식으로 벡터화했는지에 따라 달라진다.
- 코사인 유사도가 1이라는 것은 방향이 같다는 뜻이며, 두 벡터의 모든 원소가 같다는 뜻은 아니다.

## 5. 머신러닝에서 내적을 이용한 가중합 계산

고객의 방문 횟수와 장바구니 추가 횟수로 구매 관심도 점수를 계산한다고 하자.

| 고객 | 방문 횟수 | 장바구니 추가 횟수 |
| --- | ---: | ---: |
| A | 3 | 2 |
| B | 5 | 1 |
| C | 2 | 4 |

방문 횟수의 가중치를 2, 장바구니 추가 횟수의 가중치를 4로 정하면 가중치 벡터는 $\mathbf{w}=[2,4]$이다.

고객 한 명의 점수는 입력 벡터와 가중치 벡터의 내적으로 표현한다.

$$
\text{score}=\mathbf{x}\cdot\mathbf{w}
$$

| 고객 | 입력 벡터 | 계산 | 점수 |
| --- | --- | --- | ---: |
| A | $[3,2]$ | $3\times2+2\times4$ | 14 |
| B | $[5,1]$ | $5\times2+1\times4$ | 14 |
| C | $[2,4]$ | $2\times2+4\times4$ | 20 |

```python
w = np.array([2, 4])
x_a = np.array([3, 2])
x_b = np.array([5, 1])
x_c = np.array([2, 4])

print(x_a @ w)  # 14
print(x_b @ w)  # 14
print(x_c @ w)  # 20
```

고객 A와 B는 서로 다른 입력을 가졌지만 같은 점수를 얻는다. **서로 다른 입력 데이터라도 가중합의 결과는 같을 수 있다.** 따라서 같은 출력 점수만으로 입력 특성이 같다고 해석할 수 없다.

또한 이 점수는 가중합의 결과이며 구매 확률 자체를 의미하지 않는다. 실제 모델은 내적 결과에 편향을 더하거나 활성화 함수를 적용할 수 있다.

$$
z=\mathbf{x}\cdot\mathbf{w}+b
$$

입력 특성이 많아져도 대응하는 특성과 가중치를 곱한 뒤 합산한다는 원리는 같다. 여러 고객의 입력 벡터를 행렬로 묶으면 행렬곱을 이용해 여러 고객의 점수를 한 번에 계산하는 방식으로 연결할 수 있다.

## 핵심 정리

- 내적은 대응하는 원소를 곱한 후 모두 더하는 연산이며 결과는 스칼라이다.
- 일반적인 벡터 내적은 두 벡터의 원소 개수가 같아야 한다.
- 내적은 벡터의 크기와 사이각의 영향을 함께 받는다.
- 0벡터가 아닌 두 벡터의 내적이 0이면 서로 수직이다.
- 코사인 유사도는 크기에 따른 영향을 제거하고 방향 관계를 비교한다.
- 입력 특성과 가중치의 내적으로 모델의 가중합을 계산할 수 있다.
- 가중합이 같더라도 입력이 같다고 할 수 없고, 계산 점수를 곧바로 확률로 해석해서도 안 된다.

## 오늘의 한 문장

> 내적은 여러 특성을 하나의 점수로 결합하는 연산이자, 벡터의 크기와 방향 관계를 함께 보여 주는 연산이다.
