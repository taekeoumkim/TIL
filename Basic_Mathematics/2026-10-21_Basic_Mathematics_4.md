## 1. 예측하려는 대상에 따라 문제를 구분하기

같은 입력 데이터를 사용하더라도 **무엇을 예측하는지에 따라 모델의 출력과 그 의미가 달라진다.**

고객의 방문 횟수와 장바구니 추가 횟수로 구매 금액을 예측할 수도 있고, 구매 여부를 예측할 수도 있다.

| 예측 문제 | 문제 유형 | 출력 예시 |
| --- | --- | --- |
| 고객 구매 금액 예측 | 회귀 | 15,000원 |
| 고객 구매 여부 예측 | 이진 분류 | 구매 클래스의 예측 확률 0.7 |
| 상품 카테고리 예측 | 다중 클래스 분류 | 의류 0.7, 식품 0.2, 가전 0.1 |

모델을 설계할 때에는 입력 데이터뿐 아니라 **타깃의 의미, 출력값의 형태, 최종 판단 방법**을 함께 정해야 한다.

## 2. 회귀 모델의 예측

회귀(Regression)는 입력 데이터로부터 연속적인 수치 값을 예측하는 문제이다. 출력은 하나 또는 여러 개의 수치로 표현할 수 있다.

| 문제 | 입력 특성 예시 | 예측값 예시 |
| --- | --- | --- |
| 주택 가격 예측 | 면적, 위치, 건축 연도 | 350,000,000원 |
| 상품 판매량 예측 | 가격, 광고비, 과거 판매량 | 125.6개 |
| 고객 구매 금액 예측 | 방문 횟수, 장바구니 추가 횟수 | 15,000원 |
| 배송 소요 시간 예측 | 배송 거리, 주문량, 교통 상황 | 35.5분 |

### 아핀 변환으로 예측값 계산하기

간단한 선형 회귀 모델에서는 입력 특성과 가중치의 내적에 편향을 더해 예측값을 계산한다.

$$
\hat{y}=\mathbf{x}\cdot\mathbf{w}+b
$$

- $\mathbf{x}$: 입력 특성 벡터
- $\mathbf{w}$: 가중치 벡터
- $b$: 편향
- $\hat{y}$: 모델의 예측값

고객 A의 방문 횟수가 4회이고 장바구니 추가 횟수가 2회라고 하자.

$$
\mathbf{x}=[4,2],\qquad \mathbf{w}=[1000,3000],\qquad b=5000
$$

$$
\hat{y}=4\times1000+2\times3000+5000=15000
$$

```python
import numpy as np

x = np.array([4, 2])
w_reg = np.array([1000, 3000])
b_reg = 5000

y_pred = x @ w_reg + b_reg
print(y_pred)  # 15000
```

이 가중치와 편향은 계산 과정을 이해하기 위해 설정한 예시 값이다.

### 실제값과 예측값의 차이

실제 구매 금액이 12,000원이라면 예측 오차는 다음과 같다.

$$
\hat{y}-y=15000-12000=3000
$$

모델이 실제 금액보다 3,000원 높게 예측한 것이다. 학습에서는 예측값과 실제값의 차이를 바탕으로 손실을 계산하고 파라미터를 조정한다.

**단순 선형 회귀는 출력 범위를 자동으로 제한하지 않는다.** 구매 금액처럼 음수가 될 수 없는 대상을 예측하더라도 모델의 계산 결과로 음수가 나올 수 있으므로, 출력의 의미와 허용 범위를 함께 확인해야 한다.

## 3. 분류 모델의 예측

분류(Classification)는 입력 데이터를 바탕으로 미리 정의한 클래스 또는 범주를 예측하는 문제이다.

| 문제 | 클래스 예시 |
| --- | --- |
| 고객 구매 여부 | 구매 / 미구매 |
| 이메일 스팸 분류 | 스팸 / 정상 |
| 고객 이탈 예측 | 이탈 / 유지 |
| 상품 카테고리 분류 | 의류 / 식품 / 가전 |

분류 모델도 내부적으로는 숫자를 계산한다. 일반적으로 점수 또는 확률을 계산한 뒤, 이를 바탕으로 최종 클래스를 결정한다.

### 이진 분류

이진 분류(Binary Classification)는 두 클래스 중 하나를 예측하는 문제이다.

구매 여부를 예측한다면 다음과 같이 정의할 수 있다.

- 클래스 0: 구매하지 않음
- 클래스 1: 구매함

| 고객 | 구매 클래스의 예측 확률 | 실제 구매 여부 |
| --- | ---: | ---: |
| A | 0.7 | 1 |
| B | 0.2 | 0 |
| C | 0.9 | 1 |

확률 0.7은 모델이 구매 클래스에 70%의 확률을 부여했다는 뜻이다. 최종 클래스를 결정할 때에는 이 확률을 임계값(Threshold)과 비교할 수 있다.

다만 **모델의 예측 확률이 실제 발생 빈도와 정확히 일치하는지는 별도의 검증이 필요하다.** 높은 예측 확률이 정답을 보장하는 것은 아니다.

### 다중 클래스 분류

다중 클래스 분류(Multiclass Classification)는 세 개 이상의 상호 배타적인 클래스 중 하나를 예측하는 문제이다.

| 클래스 번호 | 카테고리 | 예측 확률 |
| ---: | --- | ---: |
| 0 | 의류 | 0.7 |
| 1 | 식품 | 0.2 |
| 2 | 가전 | 0.1 |

상호 배타적인 클래스의 확률을 모델링할 때에는 각 확률이 0과 1 사이이며 전체 합은 1이다.

$$
0.7+0.2+0.1=1
$$

가장 높은 확률을 가진 클래스를 선택하는 방식이라면 의류를 예측한다. 이처럼 가장 큰 값의 위치를 선택하는 연산을 Argmax라고 한다.

하나의 데이터가 여러 클래스에 동시에 속할 수 있는 **다중 레이블 분류(Multilabel Classification)**는 다중 클래스 분류와 구분해야 한다.

## 4. 점수와 예측 확률 구분하기

분류 모델이 확률로 변환하기 전에 계산한 값을 점수(Score) 또는 로짓(Logit)이라고 한다.

$$
z=\mathbf{x}\cdot\mathbf{w}+b
$$

다음 입력과 파라미터를 사용해 보자.

$$
\mathbf{x}=[4,2],\qquad\mathbf{w}=[0.3,0.8],\qquad b=-2
$$

$$
z=4\times0.3+2\times0.8-2=0.8
$$

```python
w_cls = np.array([0.3, 0.8])
b_cls = -2

z = x @ w_cls + b_cls
print(round(float(z), 1))  # 0.8
```

**점수 0.8은 구매 확률 80%를 의미하지 않는다.** 점수는 음수이거나 1보다 클 수도 있으며, 우연히 0과 1 사이에 있더라도 그 자체로 확률이 되는 것은 아니다.

### 점수를 확률 형태로 변환하기

| 함수 | 입력 | 출력 | 대표적인 활용 |
| --- | --- | --- | --- |
| Sigmoid | 하나의 점수 | 0과 1 사이의 값 | 이진 분류의 한 클래스 확률 모델링 |
| Softmax | 여러 클래스의 점수 | 합이 1인 확률 형태의 값들 | 다중 클래스 분류의 클래스별 확률 모델링 |

점수 0.8에 Sigmoid를 적용하면 약 0.69가 된다.

$$
\operatorname{Sigmoid}(0.8)\approx0.69
$$

```python
purchase_probability = 1 / (1 + np.exp(-z))
print(round(float(purchase_probability), 2))  # 0.69
```

즉, 모델의 점수는 0.8이지만 변환 후 구매 클래스에 부여하는 확률은 약 69%이다.

### 점수, 확률, 클래스는 서로 다른 단계

| 단계 | 의미 | 예시 |
| --- | --- | --- |
| 점수 계산 | 입력에 가중치와 편향을 적용한 결과 | 로짓 0.8 |
| 확률 출력 | 점수를 확률 형태로 변환한 결과 | 구매 확률 약 0.69 |
| 클래스 결정 | 확률에 판단 기준을 적용한 결과 | 구매 또는 미구매 |

Sigmoid와 Softmax는 확률 형태의 출력을 만드는 역할을 한다. Threshold와 Argmax는 출력값을 바탕으로 최종 클래스를 결정하는 역할을 한다.

## 5. 회귀와 분류의 출력 비교

| 구분 | 회귀 | 분류 |
| --- | --- | --- |
| 예측 목표 | 실제 수치에 가까운 값 예측 | 올바른 클래스 구분 |
| 타깃 예시 | 구매 금액 12,000원 | 구매 여부 1 |
| 모델 출력 예시 | 예측 구매 금액 15,000원 | 구매 확률 약 0.69 |
| 출력 해석 | 금액, 시간 등 타깃의 단위로 해석 | 점수, 확률, 최종 클래스를 구분하여 해석 |
| 주요 확인 사항 | 실제값과의 차이, 출력 범위 | 클래스 정의, 확률의 의미, 판단 기준 |

회귀와 분류는 모두 수치 연산을 사용한다. 따라서 출력이 숫자라는 사실만으로 문제 유형을 구분할 수 없다. **예측 대상이 수치 자체인지, 미리 정의한 범주인지**를 기준으로 판단해야 한다.

## 핵심 정리

- 같은 입력 특성을 사용하더라도 타깃에 따라 회귀 또는 분류 문제가 된다.
- 회귀는 연속적인 수치를 예측하고, 분류는 미리 정의한 클래스를 구분한다.
- 이진 분류는 두 클래스 중 하나를, 다중 클래스 분류는 여러 상호 배타적인 클래스 중 하나를 예측한다.
- 분류 모델의 점수는 예측 확률과 다르다.
- Sigmoid와 Softmax는 점수를 확률 형태로 변환하는 데 사용한다.
- Threshold와 Argmax는 최종 클래스를 결정하는 데 사용한다.
- 예측 확률과 실제 발생 빈도의 일치 여부는 별도로 검증해야 한다.

## 오늘의 한 문장

> 모델의 출력을 이해하려면 계산된 숫자뿐 아니라, 그 숫자가 수치 예측값인지 점수인지 확률인지까지 구분해야 한다.
