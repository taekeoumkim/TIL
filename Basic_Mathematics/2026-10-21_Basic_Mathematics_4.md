## 1. 회귀와 분류의 예측 방식

같은 고객의 방문 횟수와 장바구니 추가 횟수를 입력하더라도 예측 목표에 따라 출력의 의미가 달라진다.

| 구분 | 회귀 | 이진 분류 | 다중 클래스 분류 |
| --- | --- | --- | --- |
| 목표 | 연속적인 수치 예측 | 두 클래스 중 하나 선택 | 여러 상호 배타적인 클래스 중 하나 선택 |
| 예시 | 구매 금액 | 구매 / 미구매 | 의류 / 식품 / 가전 |
| 출력 예시 | 15,000원 | 구매 확률 0.7 | 클래스별 확률 `[0.7, 0.2, 0.1]` |
| 최종 판단 | 예측 수치 사용 | 임계값 적용 | 최댓값의 클래스 선택 |

**분류 모델도 숫자를 계산하지만, 예측 대상은 범주이다.** 출력이 숫자라는 이유만으로 회귀라고 판단하면 안 된다.

### 회귀 예측

단순 선형 회귀에서는 아핀 변환으로 예측값을 계산한다.

$$
\hat y=\mathbf{x}\cdot\mathbf{w}+b
$$

입력 $[4,2]$, 가중치 $[1000,3000]$, 편향 5000이면 다음과 같다.

$$
\hat y=4\times1000+2\times3000+5000=15000
$$

실제 구매 금액이 12,000원이면 예측값에서 실제값을 뺀 오차는 3,000원이다. 학습에서는 예측과 정답으로 손실을 계산하여 파라미터를 조정한다.

단순 선형 회귀는 출력 범위를 자동으로 제한하지 않는다. 금액처럼 음수가 될 수 없는 대상을 예측해도 음수 출력이 나올 수 있다.

### 점수와 확률 구분

분류 모델이 확률 변환 전에 계산하는 점수를 로짓(Logit)이라고 한다.

$$
z=\mathbf{x}\cdot\mathbf{w}+b
$$

입력 $[4,2]$, 가중치 $[0.3,0.8]$, 편향 $-2$이면 $z=0.8$이다. **이 값은 구매 확률 80%를 의미하지 않는다.** 점수는 음수이거나 1보다 클 수도 있다.

분류 예측에서는 점수 계산, 확률 변환, 최종 클래스 결정을 구분해야 한다.

## 2. Sigmoid로 이진 분류 확률 계산하기

Sigmoid는 하나의 점수를 0과 1 사이의 값으로 변환한다.

$$
\sigma(z)=\frac{1}{1+e^{-z}}
$$

| 점수 $z$ | Sigmoid 출력 |
| ---: | ---: |
| -2 | 약 0.119 |
| 0 | 0.5 |
| 0.8 | 약 0.690 |
| 2 | 약 0.881 |

- 점수가 커지면 출력 확률도 커진다.
- 점수 0은 확률 0.5로 변환된다.
- 구매 클래스 확률이 $p$이면 미구매 클래스 확률은 $1-p$이다.

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

logits_binary = np.array([2.0, -1.0, 0.0])
p_binary = sigmoid(logits_binary)

print(np.round(p_binary, 3))  # [0.881 0.269 0.5  ]
```

이 구현은 기본 계산 원리를 보여 준다. 매우 큰 절댓값의 로짓을 다루는 실제 구현에서는 수치적으로 안정적인 연산도 고려해야 한다.

Sigmoid 출력이 0과 1 사이라는 사실만으로 실제 발생 확률을 정확히 예측한다고 보장되지는 않는다. 학습 데이터, 모델의 적합성과 확률 보정(Calibration) 등을 통해 검증해야 한다.

## 3. Softmax로 다중 클래스 확률 계산하기

Softmax는 여러 클래스의 점수를 합이 1인 확률 분포로 변환한다.

$$
p_i=\frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}}
$$

각 점수에 지수 함수를 적용한 뒤 전체 지수값의 합으로 나눈다. 유한한 점수와 클래스가 둘 이상인 수학적 계산에서는 각 확률이 0보다 크고 1보다 작다.

### 계산 예시

점수가 $[2,1,0]$이면 지수값은 약 $[7.389,2.718,1]$이고 합은 약 11.107이다.

| 클래스 | 점수 | Softmax 확률 |
| --- | ---: | ---: |
| 의류 | 2 | 약 0.665 |
| 식품 | 1 | 약 0.245 |
| 가전 | 0 | 약 0.090 |

확률의 합은 1이며 가장 큰 점수의 클래스가 가장 큰 확률을 갖는다.

### 최댓값을 빼서 안정적으로 계산하기

Softmax는 모든 점수에 같은 상수를 더하거나 빼도 결과가 같다. 지수값의 분자와 분모에 같은 배율이 적용되어 상쇄되기 때문이다.

따라서 `[2, 1, 0]`과 `[0, -1, -2]`는 같은 결과를 만든다. 각 점수에서 최댓값을 빼면 큰 양수의 지수 계산에서 발생하는 오버플로를 줄일 수 있다.

```python
def softmax(z):
    shifted = z - np.max(z, axis=-1, keepdims=True)
    exp_z = np.exp(shifted)
    return exp_z / np.sum(exp_z, axis=-1, keepdims=True)

scores_one = np.array([2.0, 1.0, 0.0])
print(np.round(softmax(scores_one), 3))  # [0.665 0.245 0.09 ]
```

이 함수는 마지막 축을 클래스 축으로 가정한다. 1차원 벡터와 `(데이터 개수, 클래스 개수)` 형태의 2차원 배열에 모두 사용할 수 있다.

### 여러 데이터의 확률 계산

```python
Z = np.array([
    [2, 1, 0],
    [0, 2, 1],
    [1, 0, 3],
])
P = softmax(Z)

print(np.round(P, 3))
# [[0.665 0.245 0.09 ]
#  [0.09  0.665 0.245]
#  [0.114 0.042 0.844]]

print(P.sum(axis=1))  # [1. 1. 1.]
```

각 행이 데이터 하나이므로 **행마다 독립적으로 정규화해야 한다.** 2차원 배열에서 `axis=1`은 클래스 축에 대한 연산이다. `keepdims=True`는 합계와 최댓값의 축을 유지하여 각 행에 올바르게 브로드캐스팅하도록 한다.

전체 배열의 모든 지수값을 하나의 합으로 나누면 데이터별 확률 분포가 되지 않는다.

### Sigmoid와 Softmax 선택

| 구분 | Sigmoid | Softmax |
| --- | --- | --- |
| 대표 활용 | 이진 분류 | 다중 클래스 분류 |
| 입력 | 한 클래스의 로짓 | 클래스별 로짓 벡터 |
| 출력 | 한 클래스의 확률 | 합이 1인 클래스별 확률 |
| 다중 출력 해석 | 각 출력을 개별 이진 예측으로 처리 가능 | 클래스들이 서로 경쟁 |

여러 레이블이 동시에 참일 수 있는 다중 레이블 분류에서는 클래스별 Sigmoid를 사용할 수 있다. 여러 클래스 중 정확히 하나를 선택하는 다중 클래스 분류와 구분한다.

## 4. Threshold로 이진 클래스 결정하기

임계값(Threshold)은 예측 확률을 최종 클래스로 바꾸는 기준이다.

- $p\geq t$이면 클래스 1
- $p<t$이면 클래스 0

0.5는 기본적인 선택이지만 모든 문제에 고정적으로 적용해야 하는 값은 아니다.

```python
purchase_prob = np.array([0.85, 0.30, 0.65, 0.45])
pred_05 = (purchase_prob >= 0.5).astype(int)
pred_07 = (purchase_prob >= 0.7).astype(int)

print(pred_05)  # [1 0 1 0]
print(pred_07)  # [1 0 0 0]
```

확률이 같아도 임계값이 바뀌면 최종 클래스는 달라진다. 이때 모델의 확률 출력이나 파라미터를 바꾸는 것은 아니며, 결정 규칙을 바꾸는 것이다.

### 임계값과 오분류

| 실제 클래스 | 예측 클래스 | 구분 |
| ---: | ---: | --- |
| 1 | 1 | TP: 양성을 양성으로 예측 |
| 0 | 0 | TN: 음성을 음성으로 예측 |
| 0 | 1 | FP: 음성을 양성으로 오분류 |
| 1 | 0 | FN: 양성을 음성으로 오분류 |

**같은 데이터에서 모델의 출력 확률을 고정하고 임계값만 바꾸면** 다음 관계가 성립한다.

| 임계값 변화 | 양성 예측 수 | FP | FN |
| --- | --- | --- | --- |
| 높임 | 감소 또는 유지 | 감소 또는 유지 | 증가 또는 유지 |
| 낮춤 | 증가 또는 유지 | 증가 또는 유지 | 감소 또는 유지 |

임계값을 높인다고 정확도가 반드시 좋아지지는 않는다. 사기 탐지에서는 실제 사기를 놓치는 FN의 비용이 클 수 있고, 고비용 프로모션에서는 잘못 선정한 FP도 중요할 수 있다. 검증 데이터 성능과 업무의 오류 비용을 함께 고려하여 선택한다.

### Sigmoid와 로짓 기준

Sigmoid는 단조 증가하고 $\sigma(0)=0.5$이므로 다음 두 규칙은 같다.

$$
\sigma(z)\geq0.5\quad\Longleftrightarrow\quad z\geq0
$$

최종 클래스만 필요하고 임계값이 0.5라면 로짓의 부호로 결정할 수 있다. 확률 임계값이 0.5가 아니라면 로짓에 그대로 0을 적용하면 안 되며, 그 확률에 대응하는 로짓 기준이 필요하다.

## 5. Argmax로 다중 클래스 결정하기

Argmax는 가장 큰 값을 만드는 입력을 찾는 연산이다. NumPy 배열에서는 **최댓값 자체가 아니라 최댓값의 인덱스**를 반환한다.

```python
classes = np.array(["의류", "식품", "가전"])
prob_one = np.array([0.2, 0.6, 0.2])
index = np.argmax(prob_one)

print(index)           # 1
print(classes[index])  # 식품
```

클래스 인덱스와 실제 이름의 대응 관계를 유지해야 한다. 최댓값이 여러 개이면 NumPy의 `argmax()`는 지정한 축에서 처음 나타난 위치를 반환한다.

### Softmax는 최댓값의 위치를 유지한다

지수 함수는 단조 증가하고 모든 클래스가 같은 분모로 나누어지므로, 수학적으로 로짓의 최대 위치와 Softmax 확률의 최대 위치는 같다.

$$
\arg\max_i z_i=\arg\max_i p_i
$$

최종 클래스만 필요하면 로짓에 바로 Argmax를 적용할 수 있다. 클래스별 확률을 확인하려면 Softmax를 사용한다.

### 여러 데이터에서는 클래스 축 지정

```python
pred_indices = np.argmax(P, axis=1)
pred_classes = classes[pred_indices]

print(pred_indices)  # [0 1 2]
print(pred_classes)  # ['의류' '식품' '가전']
```

출력이 `(데이터 개수, 클래스 개수)`라면 `axis=1`로 각 데이터의 클래스를 선택한다. `axis=0`은 각 클래스에서 가장 큰 값을 가진 데이터의 위치를 찾으므로 목적이 다르다. 축을 생략하면 배열 전체를 펼친 기준의 인덱스를 반환한다.

### 선택된 클래스와 신뢰성은 다르다

확률이 `[0.36, 0.34, 0.30]`이면 Argmax는 첫 번째 클래스를 선택한다. 하지만 다른 클래스와의 차이가 작으므로 확실한 구분이라고 단정할 수 없다.

최고 확률의 크기, 두 상위 확률의 차이, 확률 보정 상태와 실제 정답의 일치 여부를 함께 확인할 수 있다. **Argmax는 선택 규칙이며 정답이나 신뢰성을 보장하지 않는다.**

## 6. 전체 예측 흐름과 Shape

고객 3명에게 입력 특성이 2개씩 있는 경우를 계산해 보자. 아래 파라미터는 계산을 위한 예시 값이다.

```python
X = np.array([[4, 2], [2, 0], [6, 3]])

# 회귀: 수치 예측
w_reg = np.array([1000, 3000])
y_reg = X @ w_reg + 5000
print(y_reg)  # [15000  7000 20000]

# 이진 분류: 점수 → 확률 → 클래스
w_binary = np.array([0.3, 0.8])
z_binary = X @ w_binary - 2
prob_binary = sigmoid(z_binary)
class_binary = (prob_binary >= 0.5).astype(int)
print(np.round(z_binary, 1))  # [ 0.8 -1.4  2.2]
print(class_binary)          # [1 0 1]

# 다중 클래스 분류: 클래스별 점수 → 확률 → 클래스
W_multi = np.array([[1, 0, -1], [0, 1, 2]])
z_multi = X @ W_multi
prob_multi = softmax(z_multi)
class_multi = np.argmax(prob_multi, axis=1)

print(z_multi.shape)         # (3, 3)
print(prob_multi.shape)      # (3, 3)
print(class_multi.shape)     # (3,)
```

| 출력 | Shape | 의미 |
| --- | --- | --- |
| 회귀 예측값 | `(3,)` | 고객별 수치 1개 |
| 이진 분류 로짓·확률 | `(3,)` | 고객별 값 1개 |
| 다중 클래스 로짓·확률 | `(3, 3)` | 고객별 클래스 3개의 값 |
| 다중 클래스 최종 예측 | `(3,)` | 고객별 클래스 인덱스 1개 |

회귀 예측값과 이진 분류 로짓의 Shape가 같아도 의미는 다르다. 값의 구조뿐 아니라 예측 대상과 변환 과정을 함께 확인해야 한다.

## 핵심 정리

- 회귀는 수치를, 분류는 클래스를 예측하며 점수·확률·최종 클래스는 구분해야 한다.
- Sigmoid는 이진 분류 확률을, Softmax는 상호 배타적인 클래스의 확률 분포를 모델링한다.
- Softmax는 각 데이터의 클래스 축을 기준으로 계산하고, 최댓값을 빼서 수치적 안정성을 높인다.
- Threshold는 양성과 음성을 나누는 기준이며 오류 비용에 따라 조정할 수 있다.
- Argmax는 가장 높은 값의 인덱스를 반환하고, 여러 데이터에서는 축 설정이 중요하다.
- 확률 형태의 출력과 최댓값 선택만으로 예측의 정확성이나 확률의 신뢰성을 보장할 수는 없다.

## 오늘의 한 문장

> 모델의 점수를 확률로 변환하는 과정과, 확률을 최종 행동이나 클래스로 바꾸는 결정 규칙은 서로 구분해서 설계해야 한다.
