## 1. 스칼라, 벡터, 행렬의 정의

데이터는 표현하려는 값의 개수와 구조에 따라 스칼라, 벡터, 행렬로 나타낼 수 있다.

| 구분 | 의미 | 표현 예시 | 활용 |
| --- | --- | --- | --- |
| 스칼라(Scalar) | 하나의 숫자 | $x=5$ | 방문 횟수, 예측 확률, 손실 값 |
| 벡터(Vector) | 숫자를 순서대로 나열한 객체 | $\mathbf{x}=[5,2]$ | 고객 한 명의 특성, 가중치 |
| 행렬(Matrix) | 숫자를 행과 열로 배열한 객체 | $3\times2$ 형태의 데이터 | 전체 입력 데이터, 여러 출력의 가중치 |

### 스칼라: 개별 값 표현

고객 A의 방문 횟수가 5회라면 $x=5$라는 스칼라로 표현한다. 상품 가격, 모델의 예측 확률, 손실 값도 각각 하나의 숫자로 나타낼 수 있다.

스칼라는 관측된 값뿐 아니라 계산 결과를 나타내는 데에도 쓰인다.

### 벡터: 여러 값을 순서대로 표현

고객 A의 방문 횟수가 5회이고 장바구니 추가 횟수가 2회라면 다음과 같이 표현한다.

$$
\mathbf{x}_A=[5,2]
$$

- 첫 번째 원소: 방문 횟수 5
- 두 번째 원소: 장바구니 추가 횟수 2

벡터에서는 **원소의 순서와 의미를 일관되게 유지해야 한다.** 특성 순서가 바뀌면 같은 숫자를 사용하더라도 모델에 전달되는 의미가 달라진다.

벡터를 가로로 배열하면 행 벡터, 세로로 배열하면 열 벡터가 된다.

$$
\text{행 벡터}:\begin{bmatrix}5&2\end{bmatrix},\qquad
\text{열 벡터}:\begin{bmatrix}5\\2\end{bmatrix}
$$

두 표현은 같은 원소를 갖지만 각각 $1\times2$, $2\times1$ 형태이므로 행렬 연산에서는 구분한다.

### 행렬: 여러 데이터 표현

| 고객 | 방문 횟수 | 장바구니 추가 횟수 |
| --- | ---: | ---: |
| A | 5 | 2 |
| B | 3 | 1 |
| C | 8 | 4 |

고객별 벡터를 행으로 쌓으면 다음 행렬이 된다.

$$
X=\begin{bmatrix}5&2\\3&1\\8&4\end{bmatrix}
$$

- 행(Row): 고객 한 명의 데이터
- 열(Column): 방문 횟수, 장바구니 추가 횟수와 같은 특성

행렬의 원소 $X_{ij}$에서 $i$는 행, $j$는 열을 뜻한다. 수학적 표기에서는 위치를 1부터 세므로 $X_{21}=3$, $X_{32}=4$이다.

NumPy의 인덱스는 0부터 시작하므로 같은 값은 각각 `X[1, 0]`, `X[2, 1]`로 접근한다.

## 2. 데이터와 모델 파라미터의 벡터·행렬 표현

지도학습에서는 입력 데이터, 정답 데이터, 모델이 학습하는 파라미터를 구분해야 한다.

| 기호 | 표현 | 역할 |
| --- | --- | --- |
| $X$ | 입력 행렬 | 여러 데이터의 입력 특성을 저장 |
| $\mathbf{y}$ | 타깃 벡터 | 각 데이터에 대응하는 실제 정답을 저장 |
| $\mathbf{w}$ | 가중치 벡터 | 하나의 출력을 계산할 때 특성별 기여를 조절 |
| $W$ | 가중치 행렬 | 여러 출력에 필요한 가중치를 저장 |
| $b$ | 스칼라 또는 벡터 | 가중합에 더해 출력을 조정 |

### 입력 행렬과 타깃 벡터

입력 특성을 방문 횟수와 장바구니 추가 횟수로 정하고, 구매하면 1, 구매하지 않으면 0으로 정답을 표현한다.

```python
import numpy as np

X = np.array([
    [5, 2],  # 고객 A
    [3, 1],  # 고객 B
    [8, 4],  # 고객 C
])
y = np.array([1, 0, 1])

print(X.shape)  # (3, 2)
print(y.shape)  # (3,)
```

**`X`의 각 행과 `y`의 각 원소는 같은 데이터에 대응해야 한다.** 예를 들어 `X[1]`은 고객 B의 특성이고 `y[1]`은 고객 B의 실제 구매 여부이다. 데이터 순서를 바꿀 때에도 입력과 정답의 대응 관계를 유지해야 한다.

### 가중치와 편향

방문 횟수의 가중치를 2, 장바구니 추가 횟수의 가중치를 3, 편향을 1로 두면 출력 점수는 다음과 같다.

$$
\text{score}=w_1x_1+w_2x_2+b
$$

고객 A의 입력값을 대입하면 다음 결과를 얻는다.

$$
\text{score}=2\times5+3\times2+1=17
$$

가중치는 벡터 $\mathbf{w}=[2,3]$, 편향은 스칼라 $b=1$로 표현한다.

```python
x_a = np.array([5, 2])
w = np.array([2, 3])
b = 1

score = np.dot(x_a, w) + b
print(score)  # 17
```

- 가중치: 각 입력 특성이 출력 점수에 미치는 영향을 조절한다.
- 편향: 입력의 가중합에 일정한 값을 더한다.
- 학습: 예측값과 실제 정답의 차이를 줄이도록 가중치와 편향을 조정하는 과정이다.

**17은 가중합으로 계산한 점수이며 구매 확률이 아니다.** 이진 분류에서 확률을 표현하려면 시그모이드와 같은 추가 변환을 사용할 수 있다.

### 여러 출력의 가중치 행렬

입력 특성 2개로 구매 관심도와 고객 활동이라는 두 점수를 계산한다면, 출력마다 서로 다른 가중치를 둘 수 있다.

| 입력 특성 | 구매 관심도 가중치 | 고객 활동 가중치 |
| --- | ---: | ---: |
| 방문 횟수 | 2 | 1 |
| 장바구니 추가 횟수 | 3 | 4 |

$$
W=\begin{bmatrix}2&1\\3&4\end{bmatrix}
$$

이 배치에서는 각 행이 입력 특성에, 각 열이 출력에 대응한다. 첫 번째 열은 구매 관심도, 두 번째 열은 고객 활동 점수의 가중치이다.

여러 출력에 필요한 파라미터를 행렬로 묶으면 데이터와 모델의 구조를 체계적으로 표현할 수 있다. 신경망의 레이어에서도 가중치 행렬과 편향을 학습 가능한 파라미터로 사용한다.

## 3. 벡터와 행렬의 차원 및 Shape

### 벡터의 차원

벡터의 차원은 **벡터를 구성하는 원소의 개수**를 뜻한다.

| 벡터 | 원소 개수 | 수학적 차원 |
| --- | ---: | --- |
| $[5,2]$ | 2 | 2차원 벡터 |
| $[5,2,10000]$ | 3 | 3차원 벡터 |
| $[1,2,3,4,5]$ | 5 | 5차원 벡터 |

특성 벡터에서는 원소 개수가 하나의 데이터가 가진 특성 개수에 해당한다. 다만 벡터의 모든 원소가 반드시 서로 다른 종류의 특성을 의미해야 하는 것은 아니다.

### 행렬의 크기

행이 $m$개이고 열이 $n$개이면 $m\times n$ 행렬이며 전체 원소 개수는 $mn$개이다.

입력 행렬에서 각 행을 데이터, 각 열을 특성으로 두면 다음과 같이 해석한다.

$$
X\in\mathbb{R}^{n\times d}
$$

- $n$: 데이터 개수(Samples)
- $d$: 각 데이터의 특성 개수(Features)

고객 3명에게 특성이 2개씩 있으면 $3\times2$ 행렬이고, 고객 100명에게 특성이 5개씩 있으면 $100\times5$ 행렬이다.

### Shape와 ndim

`shape`는 각 축의 길이를 나타내고, `ndim`은 배열의 축 개수를 나타낸다.

```python
X = np.array([
    [5, 2],
    [3, 1],
    [8, 4],
])

print(X.shape)  # (3, 2): 행 3개, 열 2개
print(X.ndim)   # 2: 축 2개
print(X.size)   # 6: 전체 원소 6개
```

| 데이터 개수 | 특성 개수 | 입력 행렬의 shape |
| ---: | ---: | --- |
| 3 | 2 | `(3, 2)` |
| 100 | 2 | `(100, 2)` |
| 100 | 5 | `(100, 5)` |
| 1000 | 10 | `(1000, 10)` |

### 수학적 차원과 배열의 차원 수 구분

```python
x = np.array([5, 2, 10])
row = np.array([[5, 2, 10]])
column = np.array([[5], [2], [10]])

print(x.ndim, x.shape)            # 1 (3,)
print(row.ndim, row.shape)        # 2 (1, 3)
print(column.ndim, column.shape)  # 2 (3, 1)
```

| 배열 | 원소 개수 | ndim | shape | 구조 |
| --- | ---: | ---: | --- | --- |
| `x` | 3 | 1 | `(3,)` | 하나의 축을 가진 배열 |
| `row` | 3 | 2 | `(1, 3)` | 행 벡터 형태의 배열 |
| `column` | 3 | 2 | `(3, 1)` | 열 벡터 형태의 배열 |

`[5, 2, 10]`은 원소가 3개이므로 수학적으로 3차원 벡터이다. 하지만 `np.array([5, 2, 10])`은 축이 하나이므로 NumPy에서는 1차원 배열이다.

`(3,)`은 원소가 하나인 튜플로 표현한 shape이다. `(1, 3)`이나 `(3, 1)`과 구분해야 하며, NumPy의 1차원 배열 자체에는 행과 열의 구분이 없다.

데이터와 파라미터를 다룰 때에는 값뿐 아니라 **각 축의 의미와 shape**도 확인해야 한다. 같은 원소를 담고 있어도 배열 구조가 다르면 연산에서 다르게 취급될 수 있다.

## 핵심 정리

- 스칼라는 하나의 값, 벡터는 순서가 있는 여러 값, 행렬은 행과 열로 구성된 값의 구조이다.
- 여러 데이터의 특성은 입력 행렬 $X$, 각 데이터의 실제 정답은 타깃 벡터 $\mathbf{y}$로 표현한다.
- 가중치와 편향은 모델이 학습을 통해 조정하는 파라미터이다.
- 가중합으로 계산한 출력 점수를 확률로 해석하지 않는다.
- 벡터의 차원은 원소 개수이고, NumPy의 `ndim`은 축 개수이다.
- `shape`를 확인할 때 각 축이 데이터, 특성, 출력 중 무엇을 의미하는지 함께 파악한다.
