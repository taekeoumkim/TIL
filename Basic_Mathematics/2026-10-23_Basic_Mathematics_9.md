## 1. 경사하강법과 파라미터 업데이트

역전파로 각 파라미터의 Gradient를 계산했다면, 다음으로 그 값을 이용해 가중치와 편향을 변경해야 한다.

경사하강법(Gradient Descent)은 **현재 파라미터에서 손실의 Gradient를 계산하고, 그 반대 방향으로 파라미터를 반복해서 업데이트하는 최적화 방법**이다.

$$
\boldsymbol\theta_{t+1}
=\boldsymbol\theta_t
-\alpha\nabla L(\boldsymbol\theta_t)
$$

| 기호 | 의미 |
| --- | --- |
| $\boldsymbol\theta_t$ | 현재 단계의 파라미터 |
| $\nabla L(\boldsymbol\theta_t)$ | 현재 파라미터에서 계산한 손실의 Gradient |
| $\alpha$ | 학습률(Learning Rate), 일반적으로 양수 |
| $\boldsymbol\theta_{t+1}$ | 업데이트된 파라미터 |

하나의 가중치에 대해서는 다음과 같이 표현한다.

$$
w_{\mathrm{new}}
=w_{\mathrm{old}}-\alpha\frac{dL}{dw}
$$

### Gradient의 부호와 업데이트 방향

| 현재 Gradient | 기본 경사하강법의 업데이트 |
| --- | --- |
| 음수 | 파라미터 증가 |
| 양수 | 파라미터 감소 |
| 0 | 해당 파라미터의 변경 없음 |

예를 들어 $L(w)=(w-5)^2$이면 도함수는 $2(w-5)$이다. $w=3$에서 기울기는 $-4$이며, 학습률이 0.1이면 다음과 같다.

$$
w_{\mathrm{new}}=3-0.1\times(-4)=3.4
$$

기울기가 음수일 때는 음수를 빼므로 가중치가 증가한다. 다만 Gradient는 현재 지점 주변의 변화율이므로, 이동 폭이 지나치게 크면 손실이 증가할 수도 있다.

### 역전파와 경사하강법 구분하기

| 구분 | 역전파 | 경사하강법 |
| --- | --- | --- |
| 목적 | 각 파라미터의 Gradient 계산 | 계산한 Gradient로 파라미터 변경 |
| 주요 원리 | Chain Rule | Gradient의 반대 방향으로 업데이트 |
| 결과 | 파라미터별 기울기 | 새로운 가중치와 편향 |

모델 학습에서는 순전파, 손실 계산, 역전파, 파라미터 업데이트를 반복한다.

## 2. 가중치와 편향의 반복 학습

입력값이 $x=2$, 실제 정답이 $y=10$인 회귀 모델을 생각해 보자.

$$
\hat y=wx+b,\qquad L=(y-\hat y)^2
$$

초기 파라미터는 $w=3$, $b=1$이고, 학습률은 $\alpha=0.05$로 설정한다.

### 첫 번째 업데이트

현재 예측값과 손실은 다음과 같다.

$$
\hat y=3\times2+1=7,\qquad L=(10-7)^2=9
$$

제곱오차의 Gradient를 계산한다.

$$
\frac{\partial L}{\partial w}=2(\hat y-y)x=-12
$$

$$
\frac{\partial L}{\partial b}=2(\hat y-y)=-6
$$

두 Gradient를 **모두 업데이트 전의 동일한 파라미터에서 계산한 뒤** 가중치와 편향을 변경한다.

$$
w_{\mathrm{new}}=3-0.05\times(-12)=3.6
$$

$$
b_{\mathrm{new}}=1-0.05\times(-6)=1.3
$$

새로운 예측값은 $3.6\times2+1.3=8.5$이고, 손실은 $(10-8.5)^2=2.25$이다.

### 새로운 지점에서 Gradient 다시 계산하기

업데이트된 파라미터에서 다시 계산하면 다음과 같다.

$$
\frac{\partial L}{\partial w}=2(8.5-10)\times2=-6,\qquad
\frac{\partial L}{\partial b}=2(8.5-10)=-3
$$

따라서 두 번째 업데이트 후에는 $w=3.9$, $b=1.45$가 된다.

| 업데이트 횟수 | 가중치 $w$ | 편향 $b$ | 예측값 $\hat y$ | 손실 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 3.0000 | 1.0000 | 7.0000 | 9.0000 |
| 1 | 3.6000 | 1.3000 | 8.5000 | 2.2500 |
| 2 | 3.9000 | 1.4500 | 9.2500 | 0.5625 |
| 3 | 4.0500 | 1.5250 | 9.6250 | 0.1406 |

**처음 계산한 Gradient를 계속 사용하는 것이 아니라, 매번 현재 파라미터에서 다시 계산해야 한다.**

### NumPy로 반복 학습 구현하기

```python
import numpy as np

x, y = 2.0, 10.0
theta = np.array([3.0, 1.0])  # [가중치, 편향]
learning_rate = 0.05
n_updates = 5

for step in range(n_updates + 1):
    w, b = theta
    y_pred = w * x + b
    loss = (y - y_pred) ** 2

    print(
        f"Step {step}: w={w:.4f}, b={b:.4f}, "
        f"Loss={loss:.4f}"
    )

    if step < n_updates:
        grad = np.array([
            2 * (y_pred - y) * x,
            2 * (y_pred - y),
        ])
        theta = theta - learning_rate * grad

# Step 0: w=3.0000, b=1.0000, Loss=9.0000
# Step 1: w=3.6000, b=1.3000, Loss=2.2500
# Step 2: w=3.9000, b=1.4500, Loss=0.5625
# Step 3: w=4.0500, b=1.5250, Loss=0.1406
# Step 4: w=4.1250, b=1.5625, Loss=0.0352
# Step 5: w=4.1625, b=1.5813, Loss=0.0088
```

Step 0은 초기 상태이고, 이후 다섯 번 업데이트한 결과를 출력한다.

이 예제는 데이터가 하나이므로 $2w+b=10$을 만족하는 모든 파라미터 조합에서 손실이 0이다. **손실을 최소화하는 파라미터가 항상 하나로 정해지는 것은 아니다.**

## 3. 학습률과 학습 안정성

학습률은 Gradient를 이용한 파라미터 변경 크기를 조절한다. 하나의 가중치에 대한 실제 변화량은 다음과 같다.

$$
\Delta w=-\alpha\frac{dL}{dw}
$$

따라서 업데이트 크기는 학습률뿐 아니라 **Gradient의 크기에도 영향**을 받는다.

### 학습률에 따른 한 번의 업데이트 비교

이번 비교에서는 편향이 없는 별도의 모델 $\hat y=2w$를 사용한다.

$$
L(w)=(10-2w)^2,\qquad
\frac{dL}{dw}=8w-40
$$

초기 가중치는 $w=3$이고, 초기 손실은 16, Gradient는 $-16$이다. 이 함수는 $w=5$에서 최솟값 0을 가진다.

| 학습률 $\alpha$ | 가중치 변화량 | 업데이트 후 $w$ | 업데이트 후 손실 | 해석 |
| --- | ---: | ---: | ---: | --- |
| 0.01 | +0.16 | 3.16 | 13.5424 | 작은 폭으로 감소 |
| 0.05 | +0.80 | 3.80 | 5.7600 | 손실 감소 |
| 0.20 | +3.20 | 6.20 | 5.7600 | 최솟값을 지나친 뒤에도 손실 감소 |
| 0.25 | +4.00 | 7.00 | 16.0000 | 손실 유지 |
| 0.30 | +4.80 | 7.80 | 31.3600 | 손실 증가 |

학습률 0.05가 이 예제에서 잘 작동한다고 해서 모든 모델에 적절한 값이라는 뜻은 아니다. 적절한 학습률은 손실 함수, 데이터의 스케일, 모델 구조 등에 따라 달라진다.

### 오버슈팅, 진동과 발산

| 개념 | 의미 | 이 예제에서의 모습 |
| --- | --- | --- |
| 오버슈팅(Overshooting) | 업데이트가 최솟값을 지나 반대편으로 이동 | $\alpha=0.2$에서 $w=3$이 $6.2$로 이동 |
| 진동(Oscillation) | 최솟값 주변을 반복해서 오감 | $\alpha=0.25$에서 $w$가 3과 7을 반복 |
| 발산(Divergence) | 안정적인 값에 가까워지지 않고 변화 폭이나 손실이 커짐 | $\alpha=0.3$에서 손실 증가 |

**오버슈팅이 발생했다고 해서 반드시 손실이 증가하거나 학습이 실패하는 것은 아니다.** 학습률 0.2에서는 최솟값의 양쪽을 오가면서도 손실이 감소한다.

반면 학습률 0.25에서는 가중치가 3과 7을 반복하며 손실이 16에 머문다. 손실값이 일정하더라도 파라미터는 수렴하지 않을 수 있다는 예시이다.

### 여러 번 업데이트했을 때의 손실

| 학습률 | 초기 손실 | 1회 후 | 2회 후 | 3회 후 |
| --- | ---: | ---: | ---: | ---: |
| 0.01 | 16.0000 | 13.5424 | 11.4623 | 9.7017 |
| 0.05 | 16.0000 | 5.7600 | 2.0736 | 0.7465 |
| 0.20 | 16.0000 | 5.7600 | 2.0736 | 0.7465 |
| 0.25 | 16.0000 | 16.0000 | 16.0000 | 16.0000 |
| 0.30 | 16.0000 | 31.3600 | 61.4656 | 120.4726 |

학습률 0.05와 0.2의 손실은 같지만 가중치의 이동 경로는 다르다. 0.05에서는 최솟값의 한쪽에서 접근하고, 0.2에서는 양쪽을 번갈아 이동한다.

```python
import numpy as np

def loss_fn(w):
    return (10 - 2 * w) ** 2

def gradient_fn(w):
    return 8 * w - 40

learning_rates = [0.01, 0.05, 0.2, 0.25, 0.3]

for lr in learning_rates:
    w = 3.0
    losses = [loss_fn(w)]

    for _ in range(3):
        grad = gradient_fn(w)
        w = w - lr * grad
        losses.append(loss_fn(w))

    print(lr, np.round(losses, 4))

# 0.01 [16.     13.5424 11.4623  9.7017]
# 0.05 [16.      5.76    2.0736  0.7465]
# 0.2  [16.      5.76    2.0736  0.7465]
# 0.25 [16. 16. 16. 16.]
# 0.3  [ 16.      31.36    61.4656 120.4726]
```

같은 초기값과 손실 함수에서도 학습률에 따라 결과가 달라진다. 학습률의 적절성은 한 번의 업데이트보다 **반복 학습에서 나타나는 전체 변화 추세**를 보고 판단해야 한다.

## 4. Gradient 계산에 사용하는 데이터의 범위

학습 데이터가 여러 개이면 한 번의 업데이트에 전체 데이터를 사용할지, 일부 데이터만 사용할지 결정해야 한다.

예를 들어 다음 데이터에 모델 $\hat y=wx$를 학습한다고 하자.

| 데이터 | 입력 $x$ | 실제값 $y$ |
| --- | ---: | ---: |
| A | 1 | 2 |
| B | 2 | 4 |
| C | 3 | 6 |
| D | 4 | 8 |

전체 데이터의 평균제곱오차와 Gradient는 다음과 같다.

$$
L(w)=\frac1n\sum_{i=1}^{n}(y_i-wx_i)^2
$$

$$
\frac{dL}{dw}
=\frac2n\sum_{i=1}^{n}(wx_i-y_i)x_i
$$

### 경사하강법의 세 가지 방식

| 방식 | 한 번의 Gradient 계산에 사용하는 데이터 | 업데이트 시점 | 특징 |
| --- | --- | --- | --- |
| Batch GD | 전체 학습 데이터 | 전체 Gradient 계산 후 | 한 번의 업데이트에 많은 계산이 필요할 수 있음 |
| SGD | 데이터 하나 | 데이터 하나 처리 후 | 업데이트가 잦고 데이터별 Gradient 변동이 클 수 있음 |
| Mini-Batch GD | 작은 데이터 묶음 | 각 묶음 처리 후 | 여러 데이터를 묶어 효율적으로 계산 가능 |

여기서 Batch Size는 한 번의 Gradient 계산에 사용하는 데이터 개수이다. SGD는 샘플 하나씩 업데이트하는 의미로 구분했다.

동일한 파라미터에서 평균 손실의 Gradient는 개별 Gradient의 평균이다. 다만 SGD나 Mini-Batch GD에서는 **중간 업데이트로 파라미터가 달라지므로**, 다음 데이터의 Gradient도 새로운 파라미터에서 계산한다.

## 5. Batch·SGD·Mini-Batch 비교

앞의 데이터 4개에 대해 초기 가중치 $w=0$, 학습률 $\alpha=0.01$을 사용하고 데이터 순서를 A, B, C, D로 고정한다.

### Batch Gradient Descent

$w=0$에서 데이터별 제곱오차의 Gradient는 다음과 같다.

| 데이터 | 개별 Gradient $2(wx-y)x$ |
| --- | ---: |
| A | -4 |
| B | -16 |
| C | -36 |
| D | -64 |

전체 평균 Gradient와 업데이트 결과는 다음과 같다.

$$
g=\frac{-4-16-36-64}{4}=-30
$$

$$
w_{\mathrm{new}}=0-0.01\times(-30)=0.3
$$

### SGD와 Mini-Batch GD

SGD는 데이터 하나를 사용할 때마다 업데이트한다. 같은 데이터를 한 번씩 사용하는 동안 가중치는 다음과 같이 바뀐다.

| 처리한 데이터 | 업데이트 후 $w$ |
| --- | ---: |
| A | 0.0400 |
| B | 0.1968 |
| C | 0.5214 |
| D | 0.9945 |

Batch Size를 2로 설정하면 Mini-Batch는 A·B와 C·D로 나뉜다.

| Mini-Batch | 현재 $w$에서의 평균 Gradient | 업데이트 후 $w$ |
| --- | ---: | ---: |
| A·B | -10.0 | 0.100 |
| C·D | -47.5 | 0.575 |

두 번째 Mini-Batch는 첫 번째 업데이트 후의 가중치 0.1을 사용한다.

### 한 번씩 전체 데이터를 사용한 결과

| 구분 | Batch GD | SGD | Mini-Batch GD |
| --- | ---: | ---: | ---: |
| 전체 데이터 수 | 4 | 4 | 4 |
| Batch Size | 4 | 1 | 2 |
| 업데이트 횟수 | 1 | 4 | 2 |
| 마지막 가중치 $w$ | 0.3000 | 0.9945 | 0.5750 |

세 방식은 같은 초기값과 학습률을 사용했지만 업데이트 횟수와 Gradient를 계산하는 지점이 다르다. **이 결과만으로 특정 방식이 항상 더 좋다고 판단할 수는 없다.**

### NumPy 구현

```python
import numpy as np

X = np.array([1.0, 2.0, 3.0, 4.0])
y = np.array([2.0, 4.0, 6.0, 8.0])

initial_w = 0.0
learning_rate = 0.01

def batch_gradient(X_batch, y_batch, w):
    y_pred = w * X_batch
    return np.mean(2 * (y_pred - y_batch) * X_batch)

def train_one_epoch(batch_size):
    w = initial_w

    for start in range(0, len(X), batch_size):
        X_batch = X[start:start + batch_size]
        y_batch = y[start:start + batch_size]

        grad = batch_gradient(X_batch, y_batch, w)
        w = w - learning_rate * grad

    return w

print(round(train_one_epoch(4), 4))  # 0.3
print(round(train_one_epoch(1), 4))  # 0.9945
print(round(train_one_epoch(2), 4))  # 0.575
```

계산을 비교하기 위해 데이터 순서를 고정한 예제이다. 실제 SGD와 Mini-Batch 학습에서는 데이터 순서의 영향을 줄이기 위해 Epoch마다 데이터를 섞는 Shuffling을 자주 사용한다.

시계열처럼 순서가 중요한 데이터는 문제의 특성과 학습 데이터 구성에 맞게 처리해야 한다.

## 6. Epoch과 Iteration

Epoch과 Iteration은 학습의 반복 단위를 나타내지만 의미가 다르다.

| 용어 | 의미 |
| --- | --- |
| Epoch | 전체 학습 데이터를 한 번 사용하는 단위 |
| Iteration | 하나의 Batch에 대해 Gradient를 계산하고 한 번 업데이트하는 단계 |
| Batch Size | 한 번의 Gradient 계산에 사용하는 데이터 수 |

마지막에 남은 데이터까지 사용하고 Batch마다 한 번씩 업데이트한다면 다음과 같다.

$$
\text{1 Epoch당 Iteration 수}
=\left\lceil\frac{N}{B}\right\rceil
$$

$N$은 전체 데이터 수이고, $B$는 Batch Size이며, $\lceil\cdot\rceil$은 올림이다.

전체 데이터가 1,000개이면 다음과 같다.

| Batch Size | 1 Epoch당 Iteration |
| ---: | ---: |
| 1 | 1,000 |
| 10 | 100 |
| 100 | 10 |
| 128 | 8 |
| 1,000 | 1 |

Batch Size가 128이면 일곱 묶음의 896개를 처리한 뒤, 남은 104개를 마지막 묶음으로 사용한다. 따라서 업데이트는 총 8번이다.

이 조건에서 10 Epoch을 학습하면 총 Iteration은 $10\times8=80$번이다. 마지막에 남은 불완전한 Batch를 버리는 설정에서는 계산이 달라진다.

**같은 Epoch 수라고 해서 파라미터 업데이트 횟수까지 같은 것은 아니다.**

## 7. 수렴의 의미와 한계

수렴(Convergence)은 반복 학습을 통해 손실이나 파라미터가 특정 값에 가까워지는 현상이다.

다음 손실 함수에서 초기 가중치를 1, 학습률을 0.1로 설정한다.

$$
L(w)=(w-5)^2,\qquad \frac{dL}{dw}=2(w-5)
$$

첫 번째 업데이트는 다음과 같다.

$$
w_{\mathrm{new}}=1-0.1\times(-8)=1.8
$$

업데이트를 반복하면 다음과 같다.

| 업데이트 횟수 | 가중치 $w$ | 손실 |
| --- | ---: | ---: |
| 0 | 1.0000 | 16.0000 |
| 1 | 1.8000 | 10.2400 |
| 2 | 2.4400 | 6.5536 |
| 3 | 2.9520 | 4.1943 |
| 4 | 3.3616 | 2.6844 |

가중치는 최적값 5에, 손실은 0에 가까워진다.

하지만 실제 모델에서 손실이 안정되거나 감소 폭이 작아졌다는 사실만으로 다음을 보장할 수는 없다.

- 파라미터 자체도 한 값에 수렴했다는 것
- 전역 최솟값에 도달했다는 것
- 새로운 데이터에 대한 예측 성능이 충분하다는 것

특히 앞서 학습률 0.25의 예제에서는 손실이 일정했지만 파라미터는 계속 진동했다. **손실값의 변화와 파라미터의 변화를 구분해서 해석해야 한다.**

## 8. 실제 학습에서 확인할 사항

| 관찰한 현상 | 가능한 해석 | 확인할 내용 |
| --- | --- | --- |
| 손실이 매우 천천히 감소 | 학습률이 너무 작을 가능성 | 학습률과 Gradient 크기 |
| 손실이 안정적으로 감소 | 학습이 진행되고 있을 가능성 | 학습 추세와 검증 성능 |
| 손실이 크게 진동 | 학습률이 크거나 Batch별 Gradient 변동이 클 가능성 | 학습률과 Batch 구성 |
| 손실이 급격히 증가 | 학습 불안정 또는 발산 가능성 | 학습률, Gradient, 데이터 스케일 등 |
| 손실 감소 폭이 작아짐 | 수렴 또는 학습 정체 가능성 | 추가 학습 시 변화와 검증 성능 |

손실 변화만으로 원인을 단정할 수는 없다. 데이터 스케일, 파라미터 초기화, 활성화 함수와 최적화 알고리즘 등도 영향을 준다.

SGD나 Mini-Batch GD는 사용한 데이터에 따라 Gradient가 달라지므로, 개별 업데이트마다 전체 학습 손실이 반드시 감소하지는 않는다. Batch 손실의 단기 변동과 Epoch 단위의 전체적인 추세를 함께 살펴야 한다.

또한 **학습 손실 감소와 검증 성능 개선은 같은 의미가 아니다.** 학습 데이터의 손실뿐 아니라 검증 데이터의 손실과 목적에 맞는 평가 지표도 확인해야 한다.

## 핵심 정리

- 경사하강법은 현재 Gradient의 반대 방향으로 파라미터를 반복해서 업데이트한다.
- 여러 파라미터의 Gradient는 동일한 현재 지점에서 계산하며, 업데이트 후에는 새 Gradient를 구한다.
- 실제 변경 크기는 학습률과 Gradient의 크기에 함께 영향을 받는다.
- 큰 학습률은 오버슈팅·진동·발산을 일으킬 수 있지만, 오버슈팅 자체가 반드시 손실 증가를 뜻하지는 않는다.
- Batch GD·SGD·Mini-Batch GD는 한 번의 Gradient 계산에 사용하는 데이터 수와 업데이트 빈도가 다르다.
- Epoch은 전체 데이터를 한 번 사용하는 단위이고, Iteration은 한 번의 업데이트 단계이다.
- 손실이 안정되었다고 해서 파라미터의 수렴, 전역 최적해, 새로운 데이터의 성능까지 보장되지는 않는다.

## 오늘의 한 문장

> 경사하강법은 현재 파라미터에서 계산한 Gradient로 업데이트를 반복하는 과정이며, 학습률과 Batch 구성을 조절하고 손실의 추세와 검증 성능을 함께 확인해야 한다.
