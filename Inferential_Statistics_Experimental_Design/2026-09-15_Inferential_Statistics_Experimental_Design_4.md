## 1. t-검정이란?

t-검정(t-test)은 평균의 차이가 통계적으로 유의한지 확인할 때 사용하는 대표적인 가설검정 방법이다.

두 집단의 표본 평균이 다르다고 해서 모집단 평균에도 반드시 차이가 있다고 결론 내릴 수는 없다. 표본 평균은 표본을 어떻게 추출했는지에 따라 우연히 달라질 수 있기 때문이다.

t-검정은 다음 두 요소를 함께 고려한다.

- 관찰한 평균의 차이
- 표본 데이터의 변동성 및 표준오차

평균 차이가 크고 데이터의 변동성이 작을수록 평균 차이가 우연으로 발생했다고 보기 어려워진다.

```text
관찰된 평균 차이
    ÷
평균 차이의 불확실성(표준오차)
    ↓
t 통계량
    ↓
t분포를 이용해 p-value 계산
    ↓
p-value와 유의수준 비교
```

---

## 2. t 통계량과 t분포

t 통계량(t-statistic)은 관찰된 평균 차이가 표준오차에 비해 얼마나 큰지를 나타내는 값이다.

개념적으로는 다음과 같이 이해할 수 있다.

$$
t = \frac{\text{관찰된 평균 차이}}{\text{평균 차이의 표준오차}}
$$

t 통계량의 절댓값이 크다는 것은 평균 차이가 데이터의 변동성에 비해 크다는 의미이다. 다만 실제 판단에서는 t 통계량만 보는 것이 아니라, t분포를 이용해 계산된 p-value를 유의수준과 비교한다.

t분포(t-distribution)는 정규분포와 비슷한 형태를 가지며, 모집단의 분산을 알지 못한 상태에서 표본을 이용해 평균의 차이를 검정할 때 사용한다.

### t분포의 특징

- 평균을 중심으로 좌우 대칭인 형태이다.
- 정규분포보다 꼬리가 두꺼워 작은 표본에서의 불확실성을 반영한다.
- 자유도가 커질수록 정규분포에 가까워진다.
- t 통계량과 자유도를 이용해 p-value를 계산한다.

Python 통계 라이브러리가 t 통계량과 p-value를 계산하므로 수식을 직접 계산하는 것보다 분석 상황에 맞는 검정법을 선택하고 결과를 올바르게 해석하는 것이 더 중요하다.

## 3. t-검정의 공통 가설검정 절차

사용하는 t-검정의 종류가 달라도 기본적인 분석 흐름은 동일하다.

1. 분석 질문을 정의한다.
2. 귀무가설과 대립가설을 설정한다.
3. 데이터 구조에 맞는 t-검정을 선택한다.
4. 검정에 필요한 가정을 확인한다.
5. t 통계량과 p-value를 계산한다.
6. p-value를 유의수준과 비교한다.
7. 통계적 결론을 분석 맥락에 맞게 해석한다.

유의수준을 0.05로 설정한 양측검정의 판단 기준은 다음과 같다.

| 조건 | 판단 | 해석 |
|---|---|---|
| `p-value < 0.05` | 귀무가설 기각 | 평균에 차이가 있다고 볼 통계적 근거가 있음 |
| `p-value >= 0.05` | 귀무가설을 기각하지 못함 | 평균 차이를 주장할 통계적 근거가 부족함 |

p-value가 유의수준 이상이라는 결과는 두 평균이 완전히 같다는 증명이 아니다. 현재 표본만으로 차이를 발견하지 못했다는 의미이다.

## 4. 분석 상황에 따른 t-검정 선택

| 분석 상황 | 검정 방법 | Python 함수 |
|---|---|---|
| 하나의 표본 평균과 특정 기준값 비교 | 단일표본 t-검정 | `stats.ttest_1samp()` |
| 서로 다른 두 집단의 평균 비교 | 독립표본 t-검정 | `stats.ttest_ind()` |
| 같은 대상의 두 측정값 평균 비교 | 대응표본 t-검정 | `stats.ttest_rel()` |

```text
하나의 집단과 기준값 비교인가?
    └─ 예 → 단일표본 t-검정

두 평균을 비교하는가?
    ├─ 서로 다른 대상 → 독립표본 t-검정
    └─ 같은 대상의 두 측정 → 대응표본 t-검정
```

## 5. 단일표본 t-검정

단일표본 t-검정(One-sample t-test)은 하나의 표본 평균을 특정 기준값과 비교할 때 사용한다.

### 분석 예시

고객센터에서 최근 문의 10건의 응답시간을 이용하여 평균 응답시간이 목표인 10분과 다른지 확인한다.

```python
response_times = [11, 12, 10, 13, 12, 11, 14, 10, 12, 13]
```

가설은 다음과 같이 설정한다.

$$
H_0: \mu = 10
$$

$$
H_1: \mu \neq 10
$$

- 귀무가설: 평균 응답시간은 10분과 차이가 없다.
- 대립가설: 평균 응답시간은 10분과 차이가 있다.

### Python 코드

```python
from scipy import stats

response_times = [11, 12, 10, 13, 12, 11, 14, 10, 12, 13]

t_stat, p_value = stats.ttest_1samp(
    response_times,
    popmean=10,
)

print(f"t 통계량: {t_stat:.3f}")
print(f"p-value: {p_value:.3f}")
```

실행 결과:

```text
t 통계량: 4.323
p-value: 0.002
```

```text
p-value = 0.002 < 0.05
→ 귀무가설 기각
```

따라서 평균 응답시간이 기준인 10분과 다르다고 볼 통계적 근거가 있다.

### 주요 인자

```python
stats.ttest_1samp(data, popmean=reference_value)
```

| 인자 | 의미 |
|---|---|
| `data` | 분석할 하나의 표본 |
| `popmean` | 비교하려는 모집단 평균의 기준값 |

## 6. 독립표본 t-검정

독립표본 t-검정(Independent samples t-test)은 서로 다른 대상으로 구성된 두 집단의 평균을 비교할 때 사용한다.

### 분석 예시

쇼핑몰에서 서로 다른 고객에게 광고 A와 광고 B를 보여주고 구매금액의 평균을 비교한다.

```python
group_a = [42, 38, 45, 40, 43, 39, 41, 44, 37, 42]
group_b = [50, 47, 52, 48, 51, 46, 49, 53, 48, 50]
```

가설은 다음과 같다.

$$
H_0: \mu_A = \mu_B
$$

$$
H_1: \mu_A \neq \mu_B
$$

- 귀무가설: 두 광고 그룹의 평균 구매금액에는 차이가 없다.
- 대립가설: 두 광고 그룹의 평균 구매금액에는 차이가 있다.

### Python 코드

```python
from scipy import stats

group_a = [42, 38, 45, 40, 43, 39, 41, 44, 37, 42]
group_b = [50, 47, 52, 48, 51, 46, 49, 53, 48, 50]

t_stat, p_value = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False,
)

print(f"t 통계량: {t_stat:.3f}")
print(f"p-value: {p_value:.3f}")
```

`equal_var=False`는 두 집단의 분산이 같다고 가정하지 않는 Welch's t-test를 사용한다는 의미이다.

### 사용할 수 있는 상황

- 광고 A를 본 고객과 광고 B를 본 고객
- 서울 지점 고객과 부산 지점 고객
- 신규 고객과 기존 고객

두 집단이 서로 다른 대상으로 구성되었는지 확인하는 것이 중요하다.

---

## 7. Student's t-test와 Welch's t-test

독립표본 t-검정은 두 집단의 분산을 같다고 가정하는지에 따라 구분할 수 있다.

| 구분 | Student's t-test | Welch's t-test |
|---|---|---|
| 분산 전제 | 두 집단의 분산이 같음 | 두 집단의 분산이 달라도 됨 |
| 자유도 | $n_1+n_2-2$ | 분산과 표본 크기에 따라 보정 |
| SciPy 설정 | `equal_var=True` | `equal_var=False` |
| 적합한 상황 | 등분산 가정이 적절한 경우 | 분산이 다르거나 확신하기 어려운 경우 |

```python
# 등분산을 가정하는 Student's t-test
stats.ttest_ind(group_a, group_b, equal_var=True)

# 등분산을 가정하지 않는 Welch's t-test
stats.ttest_ind(group_a, group_b, equal_var=False)
```

두 방법은 자유도 계산 방식 등이 다르지만, 결과 해석의 기본 원리는 같다. 계산된 p-value를 유의수준과 비교하여 귀무가설의 기각 여부를 판단한다.

## 8. 대응표본 t-검정

대응표본 t-검정(Paired samples t-test)은 같은 대상을 두 번 측정한 값의 평균 차이를 비교할 때 사용한다.

### 분석 예시

업무 자동화 도구를 도입하기 전과 후에 같은 직원 10명의 작업시간을 측정한다.

```python
before = [52, 48, 55, 50, 47, 53, 51, 49, 54, 50]
after = [45, 44, 48, 46, 43, 47, 45, 44, 49, 46]
```

가설은 다음과 같이 설정한다.

$$
H_0: \mu_d = 0
$$

$$
H_1: \mu_d \neq 0
$$

$\mu_d$는 각 대상의 도입 전후 차이의 평균이다.

- 귀무가설: 도입 전후의 평균 작업시간에는 차이가 없다.
- 대립가설: 도입 전후의 평균 작업시간에는 차이가 있다.

### Python 코드

```python
from scipy import stats

before = [52, 48, 55, 50, 47, 53, 51, 49, 54, 50]
after = [45, 44, 48, 46, 43, 47, 45, 44, 49, 46]

t_stat, p_value = stats.ttest_rel(before, after)

print(f"t 통계량: {t_stat:.3f}")
print(f"p-value: {p_value:.3f}")
```

p-value가 0.05보다 작다면 귀무가설을 기각하고, 도입 전후의 평균 작업시간이 다르다고 볼 통계적 근거가 있다고 해석한다.

### 사용할 수 있는 상황

- 같은 사람의 교육 전 점수와 교육 후 점수
- 같은 사람의 운동 전 체중과 운동 후 체중
- 같은 고객의 서비스 변경 전 만족도와 변경 후 만족도

## 9. 대응표본에서 짝 연결이 중요한 이유

대응표본 t-검정은 각 대상의 두 측정값 차이를 분석한다. 따라서 두 배열에서 같은 위치의 값이 같은 대상의 관측값이어야 한다.

| 대상 | 도입 전 | 도입 후 | 전후 차이 |
|---|---:|---:|---:|
| 직원 1 | 52 | 45 | 7 |
| 직원 2 | 48 | 44 | 4 |
| 직원 3 | 55 | 48 | 7 |

```text
직원 1: 도입 전 52분 ↔ 도입 후 45분
직원 2: 도입 전 48분 ↔ 도입 후 44분
직원 3: 도입 전 55분 ↔ 도입 후 48분
```

짝이 잘못 연결되거나 두 시점의 관측값 수가 다르면 올바른 대응표본 분석을 수행할 수 없다. 전후 데이터를 결합할 때 대상 식별자를 기준으로 정렬과 누락 여부를 확인해야 한다.

## 10. 독립표본과 대응표본 비교

| 구분 | 독립표본 t-검정 | 대응표본 t-검정 |
|---|---|---|
| 표본 관계 | 서로 다른 두 집단 | 같은 대상의 두 측정값 |
| 분석 대상 | 두 집단의 평균 차이 | 각 쌍의 차이값 평균 |
| 예시 | A 광고 고객 vs B 광고 고객 | 같은 고객의 이벤트 전후 구매금액 |
| SciPy 함수 | `stats.ttest_ind()` | `stats.ttest_rel()` |
| 핵심 확인 | 그룹 간 독립성 | 각 관측값의 올바른 짝 연결 |

```text
서로 다른 사람들로 구성된 A/B 그룹
→ 독립표본 t-검정

같은 사람을 두 번 측정한 전후 데이터
→ 대응표본 t-검정
```

## 11. t-검정의 주요 가정

t-검정은 데이터 구조와 검정 유형에 따라 다음 가정을 확인해야 한다.

### 독립성

관측값이 서로 독립이어야 한다. 한 관측값이 다른 관측값에 영향을 주거나 같은 대상을 중복해서 독립 표본처럼 처리하면 가정이 위반될 수 있다.

- 독립표본 t-검정: 두 그룹의 대상이 서로 달라야 한다.
- 대응표본 t-검정: 서로 다른 쌍은 독립이어야 하며, 한 쌍 내부의 두 값은 의도적으로 연결된다.

독립성은 통계 검정만으로 확인하기보다 데이터 수집과 실험 설계를 통해 판단해야 한다.

### 정규성

t-검정에서 확인하는 정규성은 검정 구조에 따라 달라진다.

- 단일표본 t-검정: 표본 값의 분포
- 독립표본 t-검정: 각 그룹 값의 분포
- 대응표본 t-검정: 각 쌍의 차이값 분포

히스토그램이나 Q-Q plot으로 분포와 극단값을 확인할 수 있고, 필요하면 정규성 검정을 참고할 수 있다. 표본 크기와 데이터의 치우침 정도도 함께 고려해야 한다.

### 등분산성

등분산성은 독립표본 Student's t-test에서 두 집단의 분산이 같다고 보는 가정이다.

- 등분산 가정이 적절하면 `equal_var=True`를 사용할 수 있다.
- 두 그룹의 분산이 다르거나 확신하기 어렵다면 `equal_var=False`로 Welch's t-test를 고려할 수 있다.
- 단일표본과 대응표본 t-검정에는 두 독립 그룹의 등분산 가정을 적용하지 않는다.

### 측정 수준과 이상치

t-검정은 평균을 비교하므로 분석값이 수치형이어야 한다. 또한 평균과 표준편차는 극단값의 영향을 받기 때문에 이상치가 결과를 과도하게 좌우하는지 확인해야 한다.

## 12. t-검정 가정 점검 순서

```text
분석 질문 정의
    ↓
단일·독립·대응 구조 구분
    ↓
데이터 수집 과정에서 독립성 확인
    ↓
분포와 이상치 시각화
    ↓
검정 구조에 맞는 정규성 확인
    ↓
독립표본이면 등분산성 검토
    ↓
Student 또는 Welch 방식 선택
    ↓
검정 실행 및 결과 해석
```

가정이 적절하지 않다고 해서 무조건 분석을 중단하는 것은 아니다. 문제가 되는 가정을 확인한 뒤 Welch's t-test처럼 해당 가정을 완화한 방법이나 비모수적 대안을 검토할 수 있다.

---

## 13. 결과 해석 예시

가설검정 결과는 검정 방법, 가설, 유의수준, 통계량, p-value, 결론을 함께 작성한다.

> 평균 응답시간이 기준인 10분과 다른지 확인하기 위해 양측 단일표본 t-검정을 수행했다. 유의수준은 0.05로 설정했다. 검정 결과 t 통계량은 4.323, p-value는 0.002였다. p-value가 유의수준보다 작으므로 평균 응답시간이 10분이라는 귀무가설을 기각했다. 따라서 평균 응답시간이 기준인 10분과 다르다고 볼 통계적 근거가 있다.

통계적 유의성을 확인한 뒤에는 평균 차이와 효과 크기가 실제 업무에서 의미 있는지도 함께 판단해야 한다.

## 핵심 용어 정리

| 용어 | 의미 |
|---|---|
| t-검정 | 평균의 차이가 통계적으로 유의한지 확인하는 검정 방법 |
| t 통계량 | 평균 차이를 표준오차와 비교한 통계량 |
| t분포 | 표본으로 평균 차이를 검정할 때 사용하는 확률분포 |
| 자유도 | t분포의 형태를 결정하는 정보량과 관련된 값 |
| 단일표본 t-검정 | 하나의 표본 평균과 기준값을 비교하는 검정 |
| 독립표본 t-검정 | 서로 다른 두 집단의 평균을 비교하는 검정 |
| 대응표본 t-검정 | 같은 대상의 두 측정값 평균을 비교하는 검정 |
| Student's t-test | 두 독립 집단의 등분산을 가정하는 t-검정 |
| Welch's t-test | 두 독립 집단의 등분산을 가정하지 않는 t-검정 |
| 독립성 | 관측값이 서로 영향을 주지 않는다는 가정 |
| 정규성 | 분석 대상 분포가 정규분포에서 크게 벗어나지 않는다는 가정 |
| 등분산성 | 비교하는 두 독립 집단의 분산이 같다는 가정 |

## 오늘 배운 내용 정리

- t-검정은 평균의 차이가 통계적으로 유의한지 확인하는 방법이다.
- t 통계량은 평균 차이와 데이터의 변동성을 함께 고려하여 계산한다.
- 하나의 표본 평균과 기준값은 단일표본 t-검정으로 비교한다.
- 서로 다른 두 집단의 평균은 독립표본 t-검정으로 비교한다.
- 같은 대상의 전후 평균은 대응표본 t-검정으로 비교한다.
- 독립표본에서 등분산을 가정하기 어렵다면 Welch's t-test를 고려할 수 있다.
- 대응표본에서는 같은 대상의 두 값이 정확하게 짝을 이루어야 한다.
- t-검정 전에는 독립성, 정규성, 등분산성, 이상치 등 관련 가정을 확인해야 한다.
- 검정 결과는 p-value와 유의수준을 비교하여 해석하되, 효과 크기와 실질적 의미도 함께 고려해야 한다.

## 한 문장 정리

> t-검정은 데이터가 단일표본·독립표본·대응표본 중 어떤 구조인지 구분하고 관련 가정을 확인한 뒤, 평균 차이를 표준오차와 비교하여 통계적 유의성을 판단하는 방법이다.
