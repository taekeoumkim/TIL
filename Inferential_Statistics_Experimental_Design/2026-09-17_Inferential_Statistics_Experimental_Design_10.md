## 학습 목표

- 필요 표본을 서비스 트래픽과 연결하여 예상 실험 기간을 산정할 수 있다.

## 1. 표본 크기를 미리 계산해야 하는 이유

A/B 테스트를 설계할 때는 실험에 몇 명의 사용자가 필요한지 사전에 결정해야 한다.

- 표본이 너무 적으면 실제 효과가 있어도 발견하지 못할 수 있다.
- 표본이 지나치게 많으면 실험 기간과 비용이 불필요하게 증가한다.
- 결과를 보면서 임의로 실험을 연장하거나 조기에 종료하면 판단 오류가 커질 수 있다.

따라서 표본 크기는 감으로 정하는 것이 아니라 **유의수준, 검정력, 효과 크기 또는 MDE**를 기준으로 계산해야 한다.

---

## 2. 검정력 분석의 네 가지 요소

검정력 분석(Power Analysis)은 다음 네 요소 사이의 관계를 다룬다. 이 가운데 세 요소를 정하면 나머지 하나를 계산할 수 있다.

| 요소 | 기호 | 의미 | 일반적인 설정 |
|---|---:|---|---:|
| 유의수준 | $\alpha$ | 실제 효과가 없는데 있다고 판단할 확률인 1종 오류의 허용 수준 | 0.05 |
| 검정력 | $1-\beta$ | 실제 효과가 있을 때 이를 발견할 확률 | 0.80 |
| 효과 크기 | - | 두 그룹 사이에서 탐지하려는 차이의 크기 | 실험에 따라 결정 |
| 표본 크기 | $n$ | 각 그룹에 필요한 관측치 수 | 계산 대상 |

### 2.1 유의수준

유의수준은 실제로 차이가 없는데 차이가 있다고 잘못 판단하는 위험을 어느 정도 허용할지 나타낸다. 일반적으로 `0.05`를 사용하며, 이는 1종 오류를 5% 수준으로 제한하겠다는 의미다.

### 2.2 검정력

검정력은 실제 효과가 존재할 때 통계적 검정이 그 효과를 발견할 확률이다.

검정력이 0.80이라면 설정한 크기 이상의 실제 효과가 있을 때 이를 약 80%의 확률로 탐지하도록 실험을 설계한다는 뜻이다. 반대로 실제 효과를 놓치는 2종 오류 확률 $\beta$는 0.20이다.

### 2.3 효과 크기

효과 크기는 두 집단의 차이가 얼마나 큰지를 표준화하거나, 전환율의 차이처럼 분석 대상에 맞는 형태로 표현한 값이다.

- 평균 비교: Cohen's $d$ 등의 표준화 효과 크기
- 비율 비교: 두 전환율을 변환한 비율 효과 크기

### 2.4 표본 크기

표본 크기는 설정한 유의수준과 검정력으로 목표 효과를 탐지하기 위해 필요한 관측치 수다. 두 그룹을 같은 비율로 배정한다면 전체 표본은 그룹당 표본의 약 2배가 된다.

## 3. 검정력과 표본 크기의 관계

쇼핑몰의 할인 쿠폰이 평균 구매 금액에 영향을 주는지 독립된 두 그룹으로 검정한다고 가정한다.

- 유의수준: 0.05
- 효과 크기: Cohen's $d=0.2$
- 양측검정

다른 조건을 유지한 채 검정력만 변경하면 필요한 표본은 다음과 같이 달라진다.

| 검정력 | 그룹당 필요 표본 |
|---:|---:|
| 0.80 | 약 393명 |
| 0.90 | 약 526명 |

검정력을 높이면 실제 효과를 놓칠 가능성은 감소하지만, 더 많은 표본이 필요하다.

> 검정력 증가 → 효과 발견 가능성 증가 → 필요 표본 증가 → 실험 비용과 기간 증가

검정력을 무조건 높게 설정하는 것이 항상 최선은 아니다. 실무에서는 탐지 능력과 비용 사이의 타협점으로 0.80을 자주 사용한다.

### 평균 차이 실험의 표본 크기 계산

```python
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()

n_80 = analysis.solve_power(
    effect_size=0.2,
    alpha=0.05,
    power=0.80,
    alternative="two-sided",
)

n_90 = analysis.solve_power(
    effect_size=0.2,
    alpha=0.05,
    power=0.90,
    alternative="two-sided",
)

print("검정력 80%일 때 그룹당 표본:", round(n_80))
print("검정력 90%일 때 그룹당 표본:", round(n_90))
```

`TTestIndPower`는 서로 독립적인 두 그룹의 평균 차이를 검정하는 실험에 사용할 수 있다.

## 4. MDE의 의미

MDE(Minimum Detectable Effect)는 **실험에서 탐지하고자 하는 최소 효과 크기**다.

현재 구매 전환율이 10%인 서비스에서 다음 기준을 비교할 수 있다.

| 기준 | 현재 전환율 | 목표 전환율 | MDE |
|---|---:|---:|---:|
| A | 10% | 11% | 1%p |
| B | 10% | 10.5% | 0.5%p |

기준 B는 더 작은 개선까지 탐지하겠다는 의미다. 그러나 작은 효과는 표본의 우연한 변동과 구분하기 어려우므로 훨씬 많은 표본이 필요하다.

유의수준 0.05와 검정력 0.80을 적용했을 때 자료의 계산 결과는 다음과 같다.

| MDE | 그룹당 필요 표본 |
|---:|---:|
| 1%p | 약 14,744명 |
| 0.5%p | 약 57,763명 |

MDE를 절반으로 낮추자 필요한 표본은 약 네 배로 증가했다.

> MDE 감소 → 더 작은 차이까지 탐지 → 필요 표본 증가

### 퍼센트와 퍼센트포인트의 구분

전환율이 10%에서 11%로 증가한 경우:

- 절대 변화: `11% - 10% = 1%p`
- 상대 변화율: `(11% - 10%) / 10% = 10%`

MDE를 정의할 때는 절대 차이인지 상대 변화인지 명확히 표시해야 한다. 자료의 예시는 전환율의 절대 차이인 퍼센트포인트(%p)를 사용한다.

## 5. MDE는 비즈니스가 결정한다

MDE는 통계 프로그램이 자동으로 정해 주는 값이 아니다. **어느 정도의 개선부터 기능 개발과 운영 비용을 감수할 가치가 있는지**를 먼저 판단해야 한다.

예를 들어 새 결제 화면을 개발하고 운영하려면 전환율이 최소 1%p 증가해야 수익성이 있다고 판단했다면, 1%p를 MDE 후보로 설정할 수 있다. 통계 분석은 이 효과를 주어진 확률로 탐지하려면 표본이 얼마나 필요한지를 계산한다.

### MDE 설정 시 고려할 사항

- 기능 개발 및 운영 비용
- 효과가 발생했을 때 기대되는 추가 수익
- 현재 지표의 기준값
- 확보 가능한 사용자 트래픽
- 허용할 수 있는 실험 기간
- 탐지하지 못해도 무시할 수 있는 변화의 범위

MDE를 크게 설정하면 필요한 표본은 줄지만, 작지만 의미 있는 개선을 놓칠 수 있다. 반대로 지나치게 작게 설정하면 현실적으로 확보하기 어려운 표본이 요구될 수 있다.

## 6. 전환율 실험의 표본 크기 계산

전환율과 같은 두 비율을 비교할 때는 먼저 `proportion_effectsize()`로 두 비율의 차이를 효과 크기로 변환한 뒤, `NormalIndPower().solve_power()`로 표본 크기를 계산할 수 있다.

### 예시 조건

- 현재 결제 전환율: 15%
- 목표 결제 전환율: 17%
- MDE: 2%p
- 유의수준: 0.05
- 검정력: 0.80
- 검정 방향: 양측검정

```python
from statsmodels.stats.power import NormalIndPower
from statsmodels.stats.proportion import proportion_effectsize

current_rate = 0.15
target_rate = 0.17

# 두 비율의 차이를 statsmodels에서 사용할 효과 크기로 변환
effect_size = proportion_effectsize(current_rate, target_rate)

analysis = NormalIndPower()

n_per_group = analysis.solve_power(
    effect_size=effect_size,
    alpha=0.05,
    power=0.80,
    alternative="two-sided",
)

n_per_group = round(abs(n_per_group))
total_sample = n_per_group * 2

print("효과 크기:", round(effect_size, 4))
print("그룹당 필요 표본:", n_per_group, "명")
print("전체 필요 표본:", total_sample, "명")
```

`solve_power()`의 결과는 기본적으로 **그룹당 필요한 표본 수**로 해석한다. A와 B 그룹을 동일한 비율로 배정한다면 전체 필요 표본은 이 값의 약 2배다.

### 함수 선택 정리

| 비교 대상 | 효과 크기 | 검정력 분석 도구 |
|---|---|---|
| 두 독립 집단의 평균 | Cohen's $d$ 등 | `TTestIndPower` |
| 두 독립 집단의 비율 | `proportion_effectsize()` | `NormalIndPower` |

---

## 7. `solve_power()`의 활용

검정력 분석의 네 요소 가운데 하나를 비워 두면 `solve_power()`가 나머지 조건을 이용해 해당 값을 계산한다.

### 필요한 표본 크기 계산

```python
n = analysis.solve_power(
    effect_size=effect_size,
    nobs1=None,
    alpha=0.05,
    power=0.80,
    ratio=1.0,
    alternative="two-sided",
)
```

### 주어진 표본으로 얻을 수 있는 검정력 계산

```python
power = analysis.solve_power(
    effect_size=effect_size,
    nobs1=5000,
    alpha=0.05,
    power=None,
    ratio=1.0,
    alternative="two-sided",
)
```

트래픽이 제한되어 표본 크기를 늘릴 수 없다면, 확보 가능한 표본으로 어느 정도의 검정력을 얻는지 역으로 확인할 수 있다.

## 8. 표본 크기를 실험 기간으로 변환하기

표본 크기를 계산한 뒤에는 실제 서비스 트래픽으로 해당 표본을 모으는 데 얼마나 걸리는지 확인해야 한다.

### 예시 조건

- A 그룹 필요 표본: 20,000명
- B 그룹 필요 표본: 20,000명
- 전체 필요 표본: 40,000명
- 하루 실험 대상 사용자: 5,000명
- 그룹 배정 비율: 1:1

하루에 각 그룹으로 유입되는 사용자는 약 2,500명이므로 예상 기간은 다음과 같다.

$$
\text{예상 기간}
=\left\lceil\frac{20{,}000}{2{,}500}\right\rceil
=8\text{일}
$$

```python
import math

sample_per_group = 20_000
daily_total_traffic = 5_000
daily_traffic_per_group = daily_total_traffic / 2

days = math.ceil(sample_per_group / daily_traffic_per_group)

print("그룹당 하루 트래픽:", daily_traffic_per_group)
print("예상 실험 기간:", days, "일")
```

### 일반적인 기간 산정식

그룹을 동일한 비율로 배정하는 경우:

$$
\text{예상 실험 기간}
=\left\lceil
\frac{\text{그룹당 필요 표본}}
{\text{하루 전체 대상 트래픽}/\text{그룹 수}}
\right\rceil
$$

계산상 필요한 일수 외에도 요일별 행동 차이와 사용자 행동 주기를 고려해야 한다. 표본이 빨리 모이더라도 특정 요일에만 실험이 집중되지 않도록 기간을 설계하는 것이 중요하다.

## 9. 이탈과 데이터 누락을 고려한 보정

실제 실험에서는 모든 배정 사용자의 데이터가 정상적으로 분석에 포함되지 않을 수 있다.

- 실험 도중 사용자 이탈
- 로그 수집 실패
- 분석 조건에 따른 제외
- 중복 또는 비정상 데이터 제거

따라서 계산된 최소 표본에 여유분을 추가할 수 있다. 예상 유효 데이터 비율이 $r$이라면 모집 목표 표본은 다음과 같이 보정할 수 있다.

$$
\text{모집 목표 표본}
=\left\lceil
\frac{\text{분석에 필요한 표본}}{r}
\right\rceil
$$

예를 들어 분석에 10,000명이 필요하고 5%의 데이터 손실을 예상한다면 유효 비율은 0.95이므로 약 10,527명을 모집 대상으로 잡을 수 있다.

## 10. 요소 간 트레이드오프

| 조건 변화 | 필요한 표본의 변화 | 의미 |
|---|---:|---|
| 검정력 증가 | 증가 | 실제 효과를 놓칠 확률 감소 |
| 유의수준 감소 | 증가 | 거짓 양성을 더 엄격하게 통제 |
| MDE 감소 | 크게 증가 | 더 작은 효과까지 탐지 |
| 기준 지표의 변동성 증가 | 증가 | 신호와 잡음을 구분하기 어려워짐 |
| 사용 가능한 표본 증가 | 검정력 증가 | 같은 효과를 발견할 가능성 증가 |

실험 설계는 한 요소만 최대화하는 과정이 아니다. 탐지하고 싶은 최소 효과, 오류 허용 수준, 트래픽, 비용, 실험 기간을 함께 고려해 현실적인 조합을 선택해야 한다.

## 핵심 용어 정리

| 용어 | 의미 |
|---|---|
| 검정력(Power) | 실제 효과가 있을 때 이를 발견할 확률 |
| 1종 오류 | 실제 효과가 없는데 있다고 판단하는 오류 |
| 2종 오류 | 실제 효과가 있는데 없다고 판단하는 오류 |
| 효과 크기 | 집단 간 차이의 크기를 분석 가능한 형태로 표현한 값 |
| MDE | 실험에서 탐지하려는 최소 효과 크기 |
| 그룹당 표본 | 각 실험 조건에 필요한 관측치 수 |
| 전체 표본 | 모든 실험 그룹의 표본을 합한 수 |
| 양측검정 | 효과가 증가하거나 감소하는 두 방향을 모두 검정하는 방식 |

---

## 오늘의 정리

1. 검정력 분석은 유의수준, 검정력, 효과 크기, 표본 크기의 연결 관계를 이용해 실험 규모를 설계하는 방법이다.
2. 다른 조건이 같다면 검정력을 높이거나 MDE를 작게 설정할수록 더 많은 표본이 필요하다.
3. MDE는 통계 도구가 정하는 값이 아니라, 비용과 기대 편익을 고려하여 비즈니스가 먼저 결정해야 하는 최소 개선 수준이다.
4. 평균 비교에는 `TTestIndPower`, 전환율과 같은 비율 비교에는 `proportion_effectsize()`와 `NormalIndPower`를 사용할 수 있다.
5. 계산된 표본은 일반적으로 그룹당 표본이며, 실제 운영에서는 전체 트래픽, 배정 비율, 데이터 손실을 반영해야 한다.
6. 필요 표본을 일일 대상 트래픽으로 나누면 예상 실험 기간을 구할 수 있지만, 요일 효과와 행동 주기도 함께 고려해야 한다.

> **한 문장 요약:** 좋은 A/B 테스트는 비즈니스적으로 의미 있는 MDE와 목표 검정력을 먼저 정하고, 이를 탐지할 수 있는 표본과 현실적인 실험 기간을 사전에 계산하여 설계한다.
