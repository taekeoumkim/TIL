# 2026-09-16 단순선형회귀 이론

## 학습 목표

- 하나의 독립변수와 하나의 종속변수 사이의 관계를 선형식으로 표현할 수 있다.
- 단순선형회귀 모델의 절편과 회귀계수를 분석 맥락에 맞게 해석할 수 있다.
- `scikit-learn`으로 단순선형회귀 모델을 학습하고 예측값을 계산할 수 있다.
- SST, SSE와 결정계수($R^2$)의 관계를 설명할 수 있다.
- 잔차의 의미와 부호를 해석할 수 있다.
- 잔차 그래프를 이용해 선형모델의 적합성을 평가할 수 있다.

## 1. 상관분석에서 회귀분석으로

피어슨 상관계수는 두 연속형 변수 사이의 선형 관계가 어느 방향으로, 어느 정도 강하게 나타나는지를 보여준다. 단순선형회귀(Simple Linear Regression)는 여기서 한 단계 더 나아가 두 변수의 관계를 하나의 직선식으로 표현한다.

예를 들어 광고비와 매출의 관계를 회귀모델로 나타내면 다음 질문에 답할 수 있다.

> 광고비가 1단위 달라질 때 매출은 평균적으로 얼마나 달라지는가?

단순선형회귀의 전체 분석 흐름은 다음과 같다.

```text
독립변수와 종속변수 설정
    ↓
산점도로 선형 관계 확인
    ↓
단순선형회귀 모델 학습
    ↓
절편과 회귀계수 해석
    ↓
예측값 계산
    ↓
결정계수(R²)로 설명력 확인
    ↓
잔차 분포로 적합성 확인
    ↓
회귀계수·R²·잔차를 종합하여 평가
```

---

## 2. 독립변수와 종속변수

단순선형회귀에서는 두 변수의 역할을 구분한다.

| 구분 | 기호 | 의미 | 광고비와 매출 예시 |
|---|---|---|---|
| 독립변수 | $X$ | 종속변수를 설명하는 데 사용하는 변수 | 광고비 |
| 종속변수 | $y$ | 설명하거나 예측하려는 결과 변수 | 매출 |

다음과 같은 관계를 분석할 수 있다.

```text
광고비(X) → 매출(y)
공부시간(X) → 시험점수(y)
사용시간(X) → 배터리 소모량(y)
```

화살표는 모델에서 설명변수와 결과변수의 역할을 나타낼 뿐, 그 자체로 인과관계가 증명되었다는 뜻은 아니다.

---

## 3. 단순선형회귀식

단순선형회귀는 두 변수의 관계를 하나의 직선으로 표현한다.

모집단의 관계는 다음과 같이 나타낼 수 있다.

$$
y=\beta_0+\beta_1X+\epsilon
$$

- $\beta_0$: 절편
- $\beta_1$: 회귀계수 또는 기울기
- $\epsilon$: 직선으로 설명되지 않는 오차

표본 데이터로 추정한 예측식은 다음과 같다.

$$
\hat{y}=b_0+b_1X
$$

- $\hat{y}$: 모델의 예측값
- $b_0$: 추정한 절편
- $b_1$: 추정한 회귀계수

직선의 위치는 절편으로, 방향과 기울어진 정도는 회귀계수로 결정된다.

---

## 4. 절편 해석

절편(Intercept)은 독립변수 $X$가 0일 때 모델이 예측하는 종속변수 $y$의 값이다.

$$
X=0 \Rightarrow \hat{y}=b_0
$$

광고비를 독립변수, 매출을 종속변수로 사용한다면 절편은 광고비가 0일 때 모델이 예측하는 매출이다.

다만 다음 상황에서는 절편의 실제 의미가 제한적일 수 있다.

- 관측 데이터에 $X=0$이 포함되지 않은 경우
- $X=0$이 현실적으로 불가능한 경우
- 관측 범위에서 멀리 떨어진 값으로 외삽해야 하는 경우

따라서 절편은 수학적으로 필요한 회귀식의 구성 요소이지만, 항상 비즈니스적으로 의미 있는 값은 아니다.

---

## 5. 회귀계수 해석

회귀계수(Coefficient)는 독립변수가 1단위 달라질 때 종속변수가 평균적으로 얼마나 달라지는 선형 관계로 추정되는지를 나타낸다.

예를 들어 회귀계수가 1.4라면 다음과 같이 해석할 수 있다.

> 현재 데이터에서 광고비가 1단위 높을 때 매출은 평균적으로 약 1.4단위 높아지는 선형 관계로 추정된다.

### 회귀계수의 부호

| 회귀계수 | 관계의 방향 | 해석 |
|---:|---|---|
| $b_1>0$ | 양의 선형 관계 | $X$가 높을수록 $y$도 높아지는 경향 |
| $b_1<0$ | 음의 선형 관계 | $X$가 높을수록 $y$는 낮아지는 경향 |
| $b_1\approx0$ | 뚜렷한 선형 변화가 작음 | $X$의 변화에 따른 $y$의 평균 변화가 작음 |

회귀계수의 크기는 반드시 변수의 단위와 함께 해석해야 한다.

```text
광고비 단위: 만원
매출 단위: 만원
회귀계수: 1.4

→ 광고비가 1만원 높을 때 매출은 평균적으로 약 1.4만원 높아지는 관계
```

회귀계수가 양수나 음수라는 사실만으로 독립변수가 종속변수의 원인이라고 판단할 수는 없다.

---

## 6. scikit-learn으로 모델 구축하기

광고비와 매출 데이터로 단순선형회귀 모델을 만든다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression

ad_cost = np.array([10, 20, 30, 40, 50, 60, 70, 80])
sales = np.array([105, 120, 135, 145, 165, 175, 190, 205])

X = ad_cost.reshape(-1, 1)
y = sales

model = LinearRegression()
model.fit(X, y)

print("절편:", model.intercept_)
print("회귀계수:", model.coef_[0])
```

### X를 2차원으로 바꾸는 이유

`scikit-learn`의 입력 변수 `X`는 일반적으로 다음 형태를 가진 2차원 배열이어야 한다.

```text
(관측값 수, 특성 수)
```

단순선형회귀는 특성이 하나이므로 `reshape(-1, 1)`을 사용해 1차원 배열을 하나의 열을 가진 2차원 배열로 변환한다.

```python
print(ad_cost.shape)  # (8,)
print(X.shape)        # (8, 1)
```

| 속성 | 의미 |
|---|---|
| `model.intercept_` | 학습된 절편 $b_0$ |
| `model.coef_[0]` | 학습된 회귀계수 $b_1$ |

## 7. 회귀선과 최소제곱법

각 데이터 점을 완전히 통과하는 하나의 직선이 항상 존재하는 것은 아니다. 회귀모델은 실제값과 예측값의 차이를 가능한 한 작게 만드는 직선을 찾는다.

각 관측값의 오차를 잔차라고 한다.

$$
e_i=y_i-\hat{y}_i
$$

양수와 음수 잔차를 단순히 더하면 서로 상쇄될 수 있으므로 잔차를 제곱하여 합한다.

$$
SSE=\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

최소제곱법은 이 잔차제곱합(SSE)이 최소가 되도록 절편과 회귀계수를 추정하는 방법이다.

```text
여러 후보 직선
    ↓
각 직선의 예측값 계산
    ↓
실제값과 예측값의 잔차 계산
    ↓
잔차를 제곱하여 합산
    ↓
SSE가 가장 작은 직선 선택
```

---

## 8. 예측값 계산

학습한 모델의 `predict()` 메서드로 각 독립변수에 대응하는 종속변수의 예측값을 계산할 수 있다.

```python
y_pred = model.predict(X)

print("실제값:", y)
print("예측값:", y_pred)
```

새로운 광고비의 매출을 예측할 때도 입력을 2차원 형태로 전달한다.

```python
new_ad_cost = np.array([[90]])
predicted_sales = model.predict(new_ad_cost)

print("예측 매출:", predicted_sales[0])
```

모델의 예측값은 회귀선 위의 값이며 실제값과 완전히 같지 않을 수 있다.

```text
실제 매출: 165
예측 매출: 160
차이: 5
```

관측 범위를 크게 벗어난 값의 예측은 기존 선형 관계가 계속 유지된다고 가정하는 외삽이므로 주의해야 한다.

---

## 9. 데이터의 전체 변동: SST

SST(Total Sum of Squares)는 실제값들이 종속변수의 평균에서 얼마나 떨어져 있는지를 나타낸다.

$$
SST=\sum_{i=1}^{n}(y_i-\bar{y})^2
$$

- $y_i$: 실제값
- $\bar{y}$: 실제값의 평균

SST는 회귀모델을 사용하기 전 종속변수 데이터가 원래 가지고 있는 전체 변동의 크기이다.

```text
실제값과 평균의 차이
    ↓
각 차이를 제곱
    ↓
모두 합산
    ↓
SST = 데이터의 전체 변동
```

---

## 10. 모델이 설명하지 못한 변동: SSE

SSE(Sum of Squared Errors)는 실제값과 모델의 예측값 사이의 차이를 제곱하여 모두 더한 값이다.

$$
SSE=\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

SSE는 회귀모델을 적용하고도 설명하지 못하고 남아 있는 변동을 나타낸다.

```text
실제값과 예측값의 차이
    ↓
각 차이를 제곱
    ↓
모두 합산
    ↓
SSE = 모델이 설명하지 못한 변동
```

같은 데이터에서 SSE가 작을수록 회귀선의 예측값이 실제값에 더 가깝다.

---

## 11. 결정계수 R²

결정계수(Coefficient of Determination, $R^2$)는 종속변수의 전체 변동 중에서 회귀모델이 설명하는 정도를 나타내는 지표이다.

$$
R^2=1-\frac{SSE}{SST}
$$

예를 들어 SST가 100이고 SSE가 20이면 다음과 같다.

$$
R^2=1-\frac{20}{100}=0.8
$$

전체 변동 100 중 모델이 설명하지 못한 변동이 20이므로 모델이 현재 데이터의 종속변수 변동 중 약 80%를 설명한다고 해석한다.

```text
전체 변동(SST)
    ↓
설명하지 못한 변동(SSE)을 제외
    ↓
모델이 설명한 비율(R²)
```

---

## 12. Python에서 R² 확인하기

학습에 사용한 데이터에서 `model.score()`로 결정계수를 확인할 수 있다.

```python
r2 = model.score(X, y)
print("결정계수(R²):", r2)
```

예를 들어 결과가 다음과 같다고 가정한다.

```text
결정계수(R²): 0.99
```

이는 현재 데이터에서 매출의 변동 중 약 99%를 광고비를 사용한 선형회귀 모델이 설명한다는 의미이다.

다만 $R^2$가 높다는 사실만으로 다음 내용을 결론 내릴 수는 없다.

```text
R²가 높다 ≠ 두 변수 사이에 인과관계가 있다
R²가 높다 ≠ 선형회귀 모델이 모든 측면에서 적절하다
R²가 높다 ≠ 새로운 데이터에서도 같은 성능을 보장한다
```

따라서 $R^2$와 함께 회귀계수, 잔차 분포, 데이터의 범위와 분석 목적을 확인해야 한다.

## 13. 잔차

잔차(Residual)는 각 관측값의 실제값과 모델 예측값의 차이이다.

$$
e_i=y_i-\hat{y}_i
$$

```python
y_pred = model.predict(X)
residuals = y - y_pred

print("실제값:", y)
print("예측값:", y_pred)
print("잔차:", residuals)
```

예를 들어 실제 매출이 165이고 예측값이 160이라면 잔차는 5이다.

| 잔차 | 의미 |
|---:|---|
| 잔차 $>0$ | 실제값이 예측값보다 큼: 모델이 작게 예측 |
| 잔차 $<0$ | 실제값이 예측값보다 작음: 모델이 크게 예측 |
| 잔차 $\approx0$ | 실제값과 예측값이 비슷함 |

SSE는 각 잔차를 제곱하여 모두 더한 값이다.

---

## 14. 잔차 그래프

각 잔차를 개별적으로 보는 것뿐 아니라 잔차 전체가 어떤 형태로 분포하는지를 확인해야 한다.

```python
import matplotlib.pyplot as plt

plt.scatter(X.flatten(), residuals)
plt.axhline(0, color="red", linestyle="--")
plt.xlabel("Ad Cost")
plt.ylabel("Residual")
plt.title("Residual Plot")
plt.show()
```

### 비교적 적절한 잔차 패턴

잔차가 0을 중심으로 뚜렷한 규칙 없이 흩어져 있으면 선형모델이 관계를 비교적 적절하게 표현한다고 볼 수 있다.

```text
잔차가 0 주변에 무작위로 분포
→ 선형모델이 놓친 뚜렷한 구조가 적어 보임
```

### 문제가 의심되는 잔차 패턴

| 잔차 패턴 | 의심할 수 있는 문제 |
|---|---|
| 곡선 형태 | 실제 관계가 비선형일 가능성 |
| X가 커질수록 잔차 폭 증가 | 오차 분산이 일정하지 않을 가능성 |
| 특정 점이 매우 멀리 떨어짐 | 이상치 또는 영향력이 큰 관측값 가능성 |
| 잔차가 한쪽으로 치우침 | 모델의 체계적인 과대·과소 예측 가능성 |

$R^2$가 높아도 잔차에 일정한 패턴이 나타나면 현재 선형모델이 데이터에 존재하는 관계를 충분히 표현하지 못할 수 있다.

## 15. 모델 시각화

실제 데이터와 회귀선을 함께 표시하면 모델이 관계를 어떻게 표현하는지 확인할 수 있다.

```python
import matplotlib.pyplot as plt

plt.scatter(ad_cost, sales, label="Actual")
plt.plot(ad_cost, y_pred, color="red", label="Regression Line")
plt.xlabel("Ad Cost")
plt.ylabel("Sales")
plt.title("Simple Linear Regression")

```

시각화에서는 다음을 확인한다.

- 데이터가 대체로 직선 형태를 따르는가?
- 회귀선이 데이터의 중심을 지나가는가?
- 일부 관측값이 회귀선에서 매우 멀리 떨어져 있는가?
- 독립변수 범위에 따라 오차의 크기가 달라지는가?

## 16. 회귀계수·R²·잔차의 역할

| 평가 요소 | 답하는 질문 |
|---|---|
| 회귀계수 | $X$가 1단위 달라질 때 $y$는 평균적으로 얼마나 달라지는가? |
| 결정계수($R^2$) | 모델이 종속변수의 전체 변동을 얼마나 설명하는가? |
| 잔차 | 실제값과 예측값의 차이가 어떤 형태로 나타나는가? |

세 요소는 서로 다른 정보를 제공하므로 하나만 보고 모델을 평가해서는 안 된다.

```text
회귀계수: 관계의 방향과 크기
    +
R²: 모델의 설명력
    +
잔차: 선형모델이 놓친 패턴
    ↓
모델의 종합 평가
```

## 17. 분석 절차 체크리스트

### 분석 전

- [ ] 독립변수와 종속변수의 역할을 명확히 정했다.
- [ ] 두 변수가 수치형인지 확인했다.
- [ ] 산점도로 선형 관계와 이상치를 확인했다.
- [ ] 변수의 단위와 관측 범위를 확인했다.

### 모델 구축

- [ ] `X`를 `(관측값 수, 1)` 형태의 2차원 배열로 만들었다.
- [ ] `LinearRegression().fit(X, y)`로 모델을 학습했다.
- [ ] 절편과 회귀계수를 단위와 함께 해석했다.
- [ ] 회귀계수를 인과효과로 단정하지 않았다.

### 모델 평가

- [ ] 실제값과 예측값을 비교했다.
- [ ] $R^2$로 현재 데이터의 설명력을 확인했다.
- [ ] 잔차를 계산하고 잔차 그래프를 확인했다.
- [ ] 곡선, 분산 변화, 이상치 등의 잔차 패턴을 확인했다.
- [ ] 관측 범위 밖의 예측을 신중하게 해석했다.

## 핵심 용어 정리

| 용어 | 의미 |
|---|---|
| 단순선형회귀 | 하나의 독립변수와 하나의 종속변수 관계를 직선으로 표현하는 방법 |
| 독립변수 | 종속변수를 설명하는 데 사용하는 변수 |
| 종속변수 | 설명하거나 예측하려는 결과 변수 |
| 절편 | 독립변수가 0일 때 모델이 예측하는 종속변수 값 |
| 회귀계수 | 독립변수 1단위 변화에 따른 종속변수의 평균적인 변화량 |
| 예측값 | 회귀식에 독립변수를 입력하여 모델이 계산한 값 |
| 잔차 | 실제값에서 예측값을 뺀 차이 |
| SST | 종속변수의 실제값이 평균에서 벗어난 전체 변동 |
| SSE | 실제값과 예측값의 차이를 제곱해 합한 설명되지 않은 변동 |
| 결정계수($R^2$) | 종속변수의 전체 변동 중 모델이 설명하는 비율 |
| 최소제곱법 | SSE가 최소가 되도록 회귀계수를 추정하는 방법 |

## 오늘 배운 내용 정리

- 단순선형회귀는 하나의 독립변수와 하나의 종속변수 관계를 직선으로 표현한다.
- 절편은 $X=0$일 때의 예측값이며, 실제 의미가 제한적일 수 있다.
- 회귀계수는 $X$가 1단위 달라질 때 $y$가 평균적으로 얼마나 달라지는지를 나타낸다.
- 회귀계수는 변수의 단위와 함께 해석해야 하며 인과관계를 의미하지 않는다.
- `scikit-learn`의 입력 변수 `X`는 2차원 배열로 구성해야 한다.
- SST는 종속변수의 전체 변동이고 SSE는 모델이 설명하지 못한 변동이다.
- $R^2=1-SSE/SST$이며 모델이 종속변수의 변동을 설명하는 정도를 나타낸다.
- $R^2$가 높더라도 모델이 모든 측면에서 적절하다고 단정할 수 없다.
- 잔차는 실제값과 예측값의 차이이며, 0을 중심으로 패턴 없이 분포하는지 확인한다.
- 회귀계수, $R^2$, 잔차 분포를 함께 확인해야 모델의 설명력과 적합성을 평가할 수 있다.

## 한 문장 정리

> 단순선형회귀는 하나의 독립변수와 종속변수의 관계를 직선으로 추정하고, 회귀계수로 관계를 해석한 뒤 결정계수와 잔차 분포를 함께 확인하여 모델의 설명력과 적합성을 평가하는 방법이다.
