## 1. 세 집단 이상의 평균 비교

t-검정은 하나의 표본 평균을 기준값과 비교하거나 두 집단의 평균을 비교할 때 사용할 수 있다. 그러나 비교하려는 집단이 세 개 이상이라면 두 집단씩 t-검정을 반복하기보다 여러 집단의 평균을 한 번에 비교하는 분산분석(ANOVA)을 사용할 수 있다.

예를 들어 교육 방식 A, B, C의 평균 성적을 비교하기 위해 두 집단씩 t-검정을 수행하면 다음 세 번의 검정이 필요하다.

```text
A와 B 비교
A와 C 비교
B와 C 비교
```

집단 수가 늘어나면 비교 횟수도 빠르게 증가한다. $k$개 집단의 모든 쌍을 비교하는 횟수는 다음과 같다.

$$
\frac{k(k-1)}{2}
$$

여러 번의 가설검정을 반복하면 전체적으로 제1종 오류가 발생할 가능성이 커질 수 있다. 실제로는 평균 차이가 없는데 우연히 하나 이상의 비교에서 유의한 결과가 나올 위험이 증가하는 것이다.

```text
세 집단 이상의 평균 비교
    ↓
쌍별 t-검정을 반복하지 않음
    ↓
ANOVA로 모든 평균을 한 번에 비교
    ↓
유의한 경우에만 사후 검정 수행
```

---

## 2. 일원배치 분산분석

일원배치 분산분석(One-way ANOVA)은 하나의 범주형 기준으로 나눈 세 집단 이상의 평균에 차이가 있는지 확인하는 방법이다.

### 사용할 수 있는 상황

- 교육 방식 A·B·C의 평균 성적 비교
- 매장 A·B·C의 평균 대기시간 비교
- 요금제 A·B·C의 평균 데이터 사용량 비교
- 세 가지 광고 유형별 평균 구매금액 비교

여기서 `일원(One-way)`은 집단을 나누는 요인이 하나라는 의미이다.

| 구성 요소 | 교육 방식 예시 |
|---|---|
| 독립변수 | 교육 방식 |
| 독립변수의 수준 | A, B, C |
| 종속변수 | 시험 성적 |
| 분석 목적 | 교육 방식별 평균 성적 비교 |

---

## 3. ANOVA의 가설

세 집단 A, B, C의 평균을 비교할 때 가설은 다음과 같이 설정한다.

$$
H_0: \mu_A = \mu_B = \mu_C
$$

$$
H_1: \text{적어도 하나의 집단 평균은 다르다}
$$

- 귀무가설($H_0$): 모든 집단의 평균이 같다.
- 대립가설($H_1$): 적어도 하나의 집단 평균이 다르다.

대립가설은 “모든 집단의 평균이 서로 다르다”는 의미가 아니다. 한 집단만 다른 경우에도 귀무가설은 성립하지 않는다.

```text
ANOVA 유의
→ 모든 평균이 같다는 가설을 유지하기 어려움
→ 적어도 하나의 평균이 다름
→ 어느 집단이 다른지는 아직 알 수 없음
```

---

## 4. scipy로 일원배치 ANOVA 수행하기

세 가지 교육 방식에 따른 수강생의 시험 성적을 비교한다.

```python
from scipy import stats

group_a = [72, 75, 78, 74, 76]
group_b = [80, 82, 79, 83, 81]
group_c = [85, 88, 84, 87, 86]

f_stat, p_value = stats.f_oneway(
    group_a,
    group_b,
    group_c,
)

print(f"F 통계량: {f_stat:.3f}")
print(f"p-value: {p_value:.3f}")
```

`stats.f_oneway()`에는 비교할 각 집단의 데이터를 인자로 전달한다. 함수는 F 통계량과 p-value를 반환한다.

```python
f_stat, p_value = stats.f_oneway(group_1, group_2, group_3, ...)
```

### 판단 기준

| 조건 | 판단 | 의미 |
|---|---|---|
| `p-value < α` | 귀무가설 기각 | 적어도 하나의 집단 평균이 다르다고 볼 근거가 있음 |
| `p-value >= α` | 귀무가설을 기각하지 못함 | 집단 평균의 차이를 주장할 근거가 부족함 |

유의수준을 0.05로 설정했을 때 p-value가 0.05보다 작으면 모든 교육 방식의 평균 성적이 같다는 귀무가설을 기각한다.

## 5. ANOVA의 기본 원리

ANOVA는 여러 집단의 평균 차이를 판단하기 위해 집단 간 변동과 집단 내 변동을 비교한다.

### 집단 간 변동

집단 간 변동(Between-group variation)은 각 집단의 평균이 전체 평균에서 얼마나 떨어져 있는지를 나타낸다.

```text
집단 평균들이 서로 멀리 떨어져 있음
→ 집단 간 변동이 큼
→ 집단에 따라 평균이 다를 가능성이 커짐
```

### 집단 내 변동

집단 내 변동(Within-group variation)은 같은 집단 안에서 관측값들이 얼마나 퍼져 있는지를 나타낸다.

```text
같은 집단 안의 값들이 넓게 퍼져 있음
→ 집단 내 변동이 큼
→ 개인차 또는 잡음이 큼
```

| 변동 원천 | 의미 | 값이 클 때 나타내는 것 |
|---|---|---|
| 집단 간 변동(Between) | 집단 평균이 전체 평균에서 벗어난 정도 | 집단별 평균 차이가 큼 |
| 집단 내 변동(Within) | 각 집단 안에서 데이터가 흩어진 정도 | 같은 집단 안의 개인차·잡음이 큼 |

ANOVA는 단순히 표본 평균만 비교하지 않고, 관찰된 평균 차이가 각 집단 내부의 데이터 변동에 비해 충분히 큰지를 평가한다.

---

## 6. F 통계량

F 통계량(F-statistic)은 집단 간 변동을 집단 내 변동과 비교한 값이다.

$$
F = \frac{\text{집단 간 변동}}{\text{집단 내 변동}}
$$

보다 구체적으로는 두 변동을 각각의 자유도로 나눈 평균제곱(Mean Square)의 비율을 사용한다.

$$
F = \frac{MS_{between}}{MS_{within}}
$$

### F 통계량의 직관

```text
집단 평균 차이 큼
+
각 집단 내부 데이터는 비교적 모여 있음
    ↓
집단 간 변동이 집단 내 변동보다 큼
    ↓
F 통계량이 커지는 경향
    ↓
귀무가설과 잘 맞지 않을 가능성 증가
```

반대로 집단 평균의 차이가 작거나 각 집단 안의 데이터가 매우 넓게 퍼져 있다면 F 통계량은 상대적으로 작아질 수 있다.

F 통계량이 크다고 무조건 귀무가설을 기각하는 것은 아니다. F 통계량과 자유도를 바탕으로 계산된 p-value를 유의수준과 비교하여 최종 판단을 내려야 한다.

## 7. ANOVA 결과 해석

세 매장 A, B, C의 평균 고객 대기시간을 비교한다고 가정한다.

```python
from scipy import stats

store_a = [8, 10, 9, 11, 8, 9, 10, 9]
store_b = [12, 13, 11, 14, 12, 13, 12, 14]
store_c = [9, 8, 10, 7, 9, 8, 9, 10]

f_stat, p_value = stats.f_oneway(
    store_a,
    store_b,
    store_c,
)

print(f"F 통계량: {f_stat:.3f}")
print(f"p-value: {p_value:.3f}")
```

결과를 해석할 때는 다음 순서를 따른다.

1. 분석 질문과 집단을 설명한다.
2. 귀무가설과 대립가설을 설정한다.
3. 유의수준을 정한다.
4. F 통계량과 p-value를 확인한다.
5. p-value와 유의수준을 비교한다.
6. 귀무가설 기각 여부를 결정한다.
7. 유의하다면 사후 검정의 필요성을 판단한다.

### 결과 문장 예시

> 세 매장의 평균 고객 대기시간을 비교하기 위해 일원배치 분산분석을 수행했다. 유의수준 0.05에서 p-value가 0.05보다 작으므로 모든 매장의 평균 대기시간이 같다는 귀무가설을 기각했다. 따라서 적어도 하나의 매장 평균 대기시간이 다르다고 볼 통계적 근거가 있다. 다만 어느 매장 사이에 차이가 있는지는 사후 검정을 통해 추가로 확인해야 한다.

## 8. ANOVA 결과만으로 알 수 없는 것

ANOVA가 유의하면 다음 사실은 알 수 있다.

```text
적어도 하나의 집단 평균이 다르다.
```

그러나 다음 질문에는 답할 수 없다.

```text
A와 B가 다른가?
A와 C가 다른가?
B와 C가 다른가?
```

즉, F 통계량과 ANOVA의 p-value는 전체 평균이 모두 같은지에 대한 검정 결과이며, 차이가 발생한 구체적인 집단 쌍을 알려주지 않는다.

| ANOVA로 판단 가능 | ANOVA만으로 판단 불가능 |
|---|---|
| 모든 집단의 평균이 같은지 | 정확히 어느 집단끼리 다른지 |
| 적어도 하나의 평균 차이가 있는지 | 각 집단 쌍의 차이 방향과 유의성 |

구체적인 집단 쌍의 차이를 확인하려면 사후 검정이 필요하다.

---

## 9. 사후 검정이 필요한 이유

사후 검정(Post-hoc test)은 ANOVA에서 유의한 결과가 나온 후, 구체적으로 어떤 집단 사이에 유의한 차이가 있는지 확인하는 추가 분석이다.

```text
ANOVA 수행
    ↓
p-value < α 인가?
    ├─ 아니요 → 집단 평균 차이를 주장할 근거 부족
    └─ 예 → 적어도 하나의 평균이 다름
                ↓
              사후 검정
                ↓
              차이가 있는 집단 쌍 확인
```

ANOVA 후 단순한 t-검정을 여러 번 수행하면 다중 비교로 인한 제1종 오류 문제가 다시 발생할 수 있다. 사후 검정은 여러 쌍을 비교하는 과정에서 이러한 오류를 통제하도록 설계된다.

대표적인 사후 검정 방법 중 하나가 Tukey HSD(Honestly Significant Difference)이다.

---

## 10. Tukey HSD 사후 검정

세 가지 요금제 A, B, C를 사용하는 고객의 월평균 데이터 사용량을 비교한다고 가정한다.

```python
plan_a = [12, 14, 13, 15, 11, 14, 13, 12]
plan_b = [18, 20, 19, 21, 17, 20, 18, 19]
plan_c = [13, 15, 14, 16, 12, 15, 14, 13]
```

### 1단계: ANOVA 수행

```python
from scipy import stats

f_stat, p_value = stats.f_oneway(
    plan_a,
    plan_b,
    plan_c,
)

print(f"F 통계량: {f_stat:.3f}")
print(f"p-value: {p_value:.3f}")
```

p-value가 0.05보다 작다면 적어도 하나의 요금제에서 평균 사용량이 다르다고 판단하고 사후 검정을 진행한다.

### 2단계: Tukey HSD 수행

```python
from statsmodels.stats.multicomp import pairwise_tukeyhsd

values = plan_a + plan_b + plan_c

groups = (
    ["A"] * len(plan_a)
    + ["B"] * len(plan_b)
    + ["C"] * len(plan_c)
)

result = pairwise_tukeyhsd(
    endog=values,
    groups=groups,
    alpha=0.05,
)

print(result)
```

### 주요 인자

| 인자 | 의미 |
|---|---|
| `endog` | 분석할 모든 관측값을 하나로 합친 배열 |
| `groups` | 각 관측값이 속한 집단의 레이블 |
| `alpha` | 다중 비교에서 사용할 유의수준 |

`values`와 `groups`는 길이가 같아야 하며, 각 값과 집단 레이블의 순서가 정확히 대응해야 한다.

## 11. Tukey HSD 결과 해석

예시 결과는 다음과 같이 요약할 수 있다.

```text
A - B → reject = True
A - C → reject = False
B - C → reject = True
```

| 비교 집단 | `reject` | 해석 |
|---|---:|---|
| A와 B | `True` | 두 집단의 평균 차이가 통계적으로 유의함 |
| A와 C | `False` | 두 집단의 평균 차이를 주장할 근거가 부족함 |
| B와 C | `True` | 두 집단의 평균 차이가 통계적으로 유의함 |

따라서 요금제 B의 평균 사용량은 A 및 C와 유의한 차이가 있지만, A와 C 사이의 차이는 통계적으로 유의하지 않다고 해석할 수 있다.

`reject=False`는 두 집단의 평균이 완전히 같다는 뜻이 아니다. 현재 데이터와 설정한 유의수준에서 두 집단의 평균 차이를 통계적으로 확인할 근거가 부족하다는 의미이다.

## 12. ANOVA와 사후 검정의 역할 비교

| 구분 | ANOVA | 사후 검정 |
|---|---|---|
| 분석 목적 | 전체 집단 평균이 모두 같은지 확인 | 차이가 있는 구체적인 집단 쌍 확인 |
| 귀무가설 | 모든 집단 평균이 같음 | 비교하는 두 집단의 평균이 같음 |
| 주요 결과 | F 통계량, p-value | 집단별 평균 차이, 보정된 p-value, `reject` 등 |
| 수행 시점 | 먼저 수행 | ANOVA가 유의한 뒤 수행 |
| 대표 함수 | `stats.f_oneway()` | `pairwise_tukeyhsd()` |

```text
ANOVA: 전체 차이가 존재하는가?
사후 검정: 구체적으로 어디에서 차이가 발생했는가?
```

## 13. ANOVA 적용 전 확인할 사항

일원배치 ANOVA를 적용할 때는 분석 설계와 데이터 특성을 확인해야 한다.

- 종속변수는 평균을 비교할 수 있는 수치형 데이터인가?
- 집단을 나누는 요인은 하나인가?
- 비교하는 집단은 서로 독립적인가?
- 각 집단의 분포가 정규성 가정에서 크게 벗어나지 않는가?
- 집단별 분산이 비슷한가?
- 극단값이 결과를 과도하게 좌우하지 않는가?

일원배치 ANOVA의 대표적인 가정은 독립성, 정규성, 등분산성이다. 가정이 적절하지 않다면 데이터 구조와 분석 목적에 맞는 다른 방법을 검토해야 한다.

## 14. 분석 절차 체크리스트

### 분석 설계

- [ ] 비교할 집단이 세 개 이상인지 확인했다.
- [ ] 하나의 요인으로 구분된 독립 집단인지 확인했다.
- [ ] 종속변수가 수치형인지 확인했다.
- [ ] 귀무가설과 대립가설을 설정했다.
- [ ] 유의수준을 분석 전에 결정했다.

### ANOVA

- [ ] 집단별 분포와 이상치를 확인했다.
- [ ] 독립성, 정규성, 등분산성을 검토했다.
- [ ] `stats.f_oneway()`로 F 통계량과 p-value를 계산했다.
- [ ] p-value를 유의수준과 비교했다.
- [ ] “적어도 하나의 평균이 다르다”는 범위로 결론을 작성했다.

### 사후 검정

- [ ] ANOVA가 유의한 경우에 사후 검정을 수행했다.
- [ ] 관측값과 집단 레이블이 정확히 대응하는지 확인했다.
- [ ] Tukey HSD 결과에서 각 집단 쌍의 `reject` 값을 확인했다.
- [ ] 유의한 집단 쌍과 유의하지 않은 집단 쌍을 구분했다.
- [ ] 통계적 유의성과 실제 차이의 크기를 함께 해석했다.

## 핵심 용어 정리

| 용어 | 의미 |
|---|---|
| ANOVA | 세 집단 이상의 평균을 한 번에 비교하는 분산분석 |
| 일원배치 ANOVA | 하나의 요인으로 나눈 세 집단 이상의 평균을 비교하는 방법 |
| 집단 간 변동 | 각 집단 평균이 전체 평균에서 벗어난 정도 |
| 집단 내 변동 | 같은 집단 안에서 관측값이 퍼진 정도 |
| F 통계량 | 집단 간 변동을 집단 내 변동과 비교한 값 |
| 다중 비교 | 여러 집단 쌍을 동시에 또는 반복하여 비교하는 것 |
| 사후 검정 | ANOVA 후 차이가 발생한 구체적인 집단 쌍을 확인하는 검정 |
| Tukey HSD | 모든 집단 쌍을 비교하면서 다중 비교 오류를 통제하는 사후 검정 |
| `reject=True` | 해당 집단 쌍의 평균이 같다는 귀무가설을 기각 |
| `reject=False` | 해당 집단 쌍의 평균 차이를 주장할 근거가 부족함 |

## 오늘 배운 내용 정리

- 세 집단 이상의 평균을 비교할 때 일원배치 ANOVA를 사용할 수 있다.
- 여러 집단을 쌍별 t-검정으로 반복 비교하면 전체 제1종 오류가 커질 수 있다.
- ANOVA의 귀무가설은 모든 집단의 평균이 같다는 것이다.
- 대립가설은 적어도 하나의 집단 평균이 다르다는 것이며, 모든 평균이 서로 다르다는 뜻은 아니다.
- F 통계량은 집단 간 변동을 집단 내 변동과 비교한다.
- ANOVA에서는 F 통계량으로 계산한 p-value를 유의수준과 비교해 판단한다.
- 유의한 ANOVA 결과는 적어도 하나의 평균이 다르다는 사실만 알려준다.
- 차이가 발생한 구체적인 집단 쌍은 Tukey HSD 같은 사후 검정으로 확인한다.
- 사후 검정의 `reject=True`는 해당 두 집단의 평균 차이가 통계적으로 유의하다는 의미이다.
- 통계적 유의성을 확인한 뒤에는 평균 차이와 효과 크기의 실질적 의미도 함께 검토해야 한다.

## 한 문장 정리

> ANOVA는 집단 간 변동과 집단 내 변동을 비교해 세 집단 이상의 전체 평균 차이를 검정하고, 유의한 결과가 나오면 사후 검정으로 차이가 발생한 구체적인 집단 쌍을 찾는 방법이다.
