## 1. 두 범주형 변수의 관계 확인

t-검정과 ANOVA는 수치형 데이터의 평균 차이를 확인할 때 사용한다. 반면 다음과 같이 두 범주형 변수 사이에 관계가 있는지를 확인하려면 카이제곱 독립성 검정을 사용할 수 있다.

- 회원 등급과 쿠폰 사용 여부
- 이용 기기와 유료회원 가입 여부
- 성별과 상품 선택 여부
- 고객 연령대와 구독 서비스 이용 여부

예를 들어 골드 회원의 쿠폰 사용 비율이 일반 회원보다 높아 보인다고 해도, 표에서 보이는 차이만으로 두 변수가 실제로 관련되어 있다고 결론 내릴 수는 없다. 표본의 우연한 변동으로 차이가 나타났을 수도 있기 때문이다.

```text
두 범주형 변수 선택
    ↓
교차표로 조합별 빈도 확인
    ↓
두 변수가 독립일 때의 기대빈도 계산
    ↓
관측빈도와 기대빈도 비교
    ↓
카이제곱 통계량과 p-value 계산
    ↓
두 변수의 관계 해석
```

## 2. 교차표

교차표(Cross Table 또는 Contingency Table)는 범주형 변수 두 개를 행과 열에 배치하여 각 범주 조합에 해당하는 데이터의 빈도를 정리한 표이다.

쇼핑몰의 회원 등급과 쿠폰 사용 여부를 집계한 결과가 다음과 같다고 가정한다.

| 회원 등급 | 쿠폰 사용 | 쿠폰 미사용 | 행 합계 |
|---|---:|---:|---:|
| 일반 | 20 | 40 | 60 |
| 실버 | 30 | 30 | 60 |
| 골드 | 45 | 15 | 60 |
| 열 합계 | 95 | 85 | 180 |

교차표를 통해 다음과 같은 분포를 확인할 수 있다.

- 일반 회원은 쿠폰 미사용 고객이 더 많다.
- 실버 회원은 쿠폰 사용과 미사용 빈도가 같다.
- 골드 회원은 쿠폰 사용 고객이 더 많다.

하지만 이러한 패턴이 통계적으로 유의한 관계인지 판단하려면 카이제곱 독립성 검정이 필요하다.

---

## 3. 원본 데이터에서 교차표 만들기

원본 데이터가 고객별 행으로 구성되어 있다면 `pandas.crosstab()`으로 교차표를 만들 수 있다.

```python
import pandas as pd

df = pd.DataFrame({
    "membership": ["일반", "일반", "실버", "골드", "골드", "골드"],
    "coupon_used": ["미사용", "사용", "사용", "사용", "사용", "미사용"],
})

table = pd.crosstab(
    df["membership"],
    df["coupon_used"],
)

print(table)
```

이미 집계된 빈도 데이터가 있다면 2차원 리스트나 NumPy 배열을 직접 사용할 수 있다.

```python
table = [
    [20, 40],
    [30, 30],
    [45, 15],
]
```

교차표의 각 셀에는 평균이나 비율이 아니라 해당 범주 조합에서 관찰된 개수가 들어가야 한다.

## 4. 카이제곱 독립성 검정

카이제곱 독립성 검정(Chi-square Test of Independence)은 두 범주형 변수가 서로 독립인지, 통계적인 관계가 있는지 확인하는 방법이다.

### 가설 설정

- 귀무가설($H_0$): 두 범주형 변수는 서로 독립이다.
- 대립가설($H_1$): 두 범주형 변수는 서로 관련되어 있다.

회원 등급과 쿠폰 사용 여부를 분석한다면 다음과 같이 표현할 수 있다.

```text
H₀: 회원 등급과 쿠폰 사용 여부는 서로 독립이다.
H₁: 회원 등급과 쿠폰 사용 여부는 서로 관련이 있다.
```

여기서 독립이라는 것은 한 변수의 범주에 따라 다른 변수의 분포가 체계적으로 달라지지 않는다는 의미이다.

---

## 5. SciPy로 카이제곱 독립성 검정 수행하기

```python
from scipy import stats

table = [
    [20, 40],
    [30, 30],
    [45, 15],
]

chi2, p_value, dof, expected = stats.chi2_contingency(table)

print(f"카이제곱 통계량: {chi2:.3f}")
print(f"p-value: {p_value:.3f}")
print(f"자유도: {dof}")
print("기대빈도:")
print(expected)
```

`chi2_contingency()`는 네 가지 값을 반환한다.

| 반환값 | 의미 |
|---|---|
| `chi2` | 관측빈도와 기대빈도의 차이를 요약한 카이제곱 통계량 |
| `p_value` | 귀무가설 아래 현재 이상의 차이가 나타날 확률 |
| `dof` | 검정에 사용되는 자유도 |
| `expected` | 두 변수가 독립일 때 예상되는 각 셀의 기대빈도 |

### 판단 기준

| 조건 | 판단 | 해석 |
|---|---|---|
| `p-value < α` | 귀무가설 기각 | 두 변수 사이에 관계가 있다고 볼 통계적 근거가 있음 |
| `p-value >= α` | 귀무가설을 기각하지 못함 | 두 변수의 관계를 주장할 통계적 근거가 부족함 |

유의수준이 0.05이고 p-value가 0.05보다 작다면 회원 등급과 쿠폰 사용 여부가 독립이라는 귀무가설을 기각한다.

## 6. 관측빈도

관측빈도(Observed Frequency)는 실제 데이터에서 관찰된 각 범주 조합의 빈도이다.

위 교차표에서는 다음 값들이 관측빈도이다.

```text
일반 × 쿠폰 사용: 20
일반 × 쿠폰 미사용: 40
실버 × 쿠폰 사용: 30
실버 × 쿠폰 미사용: 30
골드 × 쿠폰 사용: 45
골드 × 쿠폰 미사용: 15
```

관측빈도는 표본 데이터에서 실제로 확인한 값이며, 카이제곱 검정은 이를 기대빈도와 비교한다.

---

## 7. 기대빈도

기대빈도(Expected Frequency)는 두 변수가 서로 독립이라고 가정했을 때 각 셀에서 예상되는 빈도이다.

각 셀의 기대빈도는 행 합계와 열 합계를 이용해 계산한다.

$$
E_{ij} = \frac{(i\text{번째 행 합계})\times(j\text{번째 열 합계})}{\text{전체 합계}}
$$

예를 들어 일반 회원이면서 쿠폰을 사용하는 셀의 기대빈도는 다음과 같다.

$$
E = \frac{60\times95}{180} \approx 31.67
$$

실제 관측빈도는 20인데 독립을 가정한 기대빈도는 약 31.67이다. 이러한 차이를 모든 셀에 대해 종합하여 카이제곱 통계량을 계산한다.

```text
관측빈도: 실제 데이터에 나타난 빈도
기대빈도: 두 변수가 독립일 때 예상되는 빈도
```

회원 등급과 쿠폰 사용 여부가 관련이 없다면 각 회원 등급의 쿠폰 사용 비율은 전체 쿠폰 사용 비율과 크게 다르지 않을 것으로 예상할 수 있다. 실제 분포가 이러한 기대에서 크게 벗어나면 두 변수가 독립적이지 않을 가능성을 생각할 수 있다.

---

## 8. 카이제곱 통계량

카이제곱 통계량($\chi^2$)은 관측빈도와 기대빈도의 차이를 모든 셀에 대해 합산한 값이다.

$$
\chi^2 = \sum \frac{(O-E)^2}{E}
$$

- $O$: 관측빈도(Observed Frequency)
- $E$: 기대빈도(Expected Frequency)

각 셀에서 관측빈도와 기대빈도의 차이를 제곱한 뒤 기대빈도로 나누므로 차이의 방향보다 차이의 크기가 반영된다.

```text
관측빈도와 기대빈도가 비슷함
→ χ² 통계량이 작아지는 경향

관측빈도와 기대빈도의 차이가 큼
→ χ² 통계량이 커지는 경향
```

카이제곱 통계량이 클수록 두 변수가 독립이라는 가정으로 현재 교차표의 패턴을 설명하기 어려워지는 경향이 있다. 실제 결론은 카이제곱 통계량과 자유도로 계산한 p-value를 유의수준과 비교하여 내린다.

---

## 9. 자유도

행의 범주 수가 $r$, 열의 범주 수가 $c$일 때 카이제곱 독립성 검정의 자유도는 다음과 같다.

$$
dof=(r-1)(c-1)
$$

회원 등급 3개와 쿠폰 사용 여부 2개로 구성된 $3\times2$ 교차표의 자유도는 다음과 같다.

$$
dof=(3-1)(2-1)=2
$$

자유도는 카이제곱 통계량을 p-value로 변환할 때 사용되는 카이제곱 분포의 형태를 결정한다.

---

## 10. 관측빈도와 기대빈도의 관계

카이제곱 독립성 검정의 전체 흐름은 다음과 같다.

```text
교차표의 관측빈도 확인
    ↓
두 변수가 독립이라고 가정
    ↓
행 합계와 열 합계로 기대빈도 계산
    ↓
각 셀의 관측빈도와 기대빈도 비교
    ↓
차이를 χ² 통계량으로 합산
    ↓
자유도를 반영하여 p-value 계산
    ↓
p-value와 유의수준 비교
```

세부 계산을 직접 수행하는 것보다 관측빈도와 기대빈도의 차이가 카이제곱 통계량으로 연결되고, 최종적으로 p-value를 이용해 판단한다는 논리를 이해하는 것이 중요하다.

## 11. 카이제곱 독립성 검정의 주요 가정

검정 결과를 해석하기 전에 데이터와 기대빈도가 카이제곱 독립성 검정에 적절한지 확인해야 한다.

### 빈도 데이터 사용

교차표에는 각 범주 조합에 해당하는 관측 개수가 들어가야 한다.

```text
적절함: 모바일·가입 조합의 고객 수 50명
부적절함: 모바일 고객의 가입 비율 62.5%
부적절함: 모바일 고객의 평균 결제금액
```

비율로 교차표를 시각화할 수는 있지만, 검정에는 원래의 빈도를 사용해야 한다.

### 관측값의 독립성

각 관측값은 서로 독립이어야 한다. 일반적으로 한 대상은 교차표의 한 셀에 한 번만 집계되어야 한다.

동일한 고객을 여러 번 중복 집계하거나 같은 고객의 반복 측정을 서로 독립적인 관측값처럼 처리하면 독립성 가정이 적절하지 않을 수 있다.

### 충분한 기대빈도

기대빈도가 지나치게 작은 셀이 많으면 카이제곱 근사를 이용한 p-value가 부정확해질 수 있다. 실무에서는 기대빈도 5를 기준으로 각 셀을 점검하는 경우가 많다.

```python
_, _, _, expected = stats.chi2_contingency(table)

print(expected)
print("기대빈도 5 미만 셀 수:", (expected < 5).sum())
```

기대빈도가 작은 셀이 많다면 범주를 합치는 것이 분석 목적에 적절한지 검토하거나, 데이터 구조에 맞는 다른 검정 방법을 고려해야 한다.

## 12. 분석 예시: 이용 기기와 유료회원 가입 여부

서비스 이용 기기와 유료회원 가입 여부의 관계를 확인한다.

| 이용 기기 | 가입 | 미가입 |
|---|---:|---:|
| 모바일 | 50 | 30 |
| PC | 35 | 45 |
| 태블릿 | 20 | 30 |

두 변수 모두 범주형이므로 카이제곱 독립성 검정을 고려할 수 있다.

### 가설

```text
H₀: 이용 기기와 유료회원 가입 여부는 서로 독립이다.
H₁: 이용 기기와 유료회원 가입 여부는 서로 관련이 있다.
```

### Python 코드

```python
from scipy import stats

table = [
    [50, 30],
    [35, 45],
    [20, 30],
]

chi2, p_value, dof, expected = stats.chi2_contingency(table)

print(f"카이제곱 통계량: {chi2:.3f}")
print(f"p-value: {p_value:.3f}")
print(f"자유도: {dof}")
print("기대빈도:")
print(expected)
```

### 결과 해석 순서

1. 교차표가 두 범주형 변수의 빈도로 구성되었는지 확인한다.
2. 관측값이 서로 독립인지 확인한다.
3. 기대빈도가 지나치게 작은 셀이 많지 않은지 확인한다.
4. p-value와 사전에 정한 유의수준을 비교한다.
5. 귀무가설의 기각 여부를 결정한다.
6. 실제 데이터의 비율과 분포를 함께 확인한다.

## 13. 결과 문장 작성하기

### 귀무가설을 기각한 경우

> 이용 기기와 유료회원 가입 여부의 관계를 확인하기 위해 카이제곱 독립성 검정을 수행했다. 유의수준 0.05에서 p-value가 0.05보다 작으므로 두 변수가 서로 독립이라는 귀무가설을 기각했다. 따라서 이용 기기와 유료회원 가입 여부 사이에 관계가 있다고 볼 통계적 근거가 있다.

### 귀무가설을 기각하지 못한 경우

> p-value가 유의수준 0.05 이상이므로 이용 기기와 유료회원 가입 여부가 서로 독립이라는 귀무가설을 기각하지 못했다. 현재 데이터만으로 두 변수 사이에 관계가 있다고 주장할 통계적 근거가 부족하다.

귀무가설을 기각하지 못했다고 해서 두 변수가 완전히 독립임을 증명한 것은 아니다. 표본 수와 기대빈도, 검정력 등을 함께 고려해야 한다.

## 14. 해석할 때 주의할 점

카이제곱 독립성 검정의 유의한 결과는 두 변수 사이에 통계적인 연관성이 있음을 의미한다. 다음과 같은 의미로 해석하면 안 된다.

- 한 변수가 다른 변수의 원인이라고 단정할 수 없다.
- 관계의 강도가 크다고 바로 판단할 수 없다.
- 어떤 셀이 전체 차이에 가장 크게 기여했는지 p-value만으로 알 수 없다.
- 표본이 크면 작은 분포 차이도 유의하게 나타날 수 있다.

따라서 검정 후에는 행 또는 열 비율을 함께 살펴보고, 어떤 범주에서 분포 차이가 나타나는지 확인해야 한다.

```python
import pandas as pd

table_df = pd.DataFrame(
    table,
    index=["모바일", "PC", "태블릿"],
    columns=["가입", "미가입"],
)

row_ratio = table_df.div(table_df.sum(axis=1), axis=0)
print(row_ratio)
```

카이제곱 검정은 관계의 존재 여부를 판단하고, 비율 분석은 관계가 어떤 형태로 나타나는지 설명하는 데 도움을 준다.

## 15. 분석 절차 체크리스트

### 분석 설계

- [ ] 분석할 두 변수가 모두 범주형인지 확인했다.
- [ ] 귀무가설과 대립가설을 설정했다.
- [ ] 유의수준을 분석 전에 정했다.

### 데이터 확인

- [ ] 교차표에 비율이나 평균이 아닌 빈도를 입력했다.
- [ ] 한 대상이 중복 집계되지 않았는지 확인했다.
- [ ] 행과 열 범주가 분석 질문과 일치하는지 확인했다.
- [ ] 기대빈도가 지나치게 작은 셀이 많지 않은지 확인했다.

### 검정과 해석

- [ ] 카이제곱 통계량, p-value, 자유도, 기대빈도를 확인했다.
- [ ] p-value를 유의수준과 비교했다.
- [ ] 기각 여부를 “관계가 있다” 또는 “관계를 주장할 근거가 부족하다”로 표현했다.
- [ ] 유의한 관계를 인과관계로 해석하지 않았다.
- [ ] 행·열 비율을 함께 확인하여 관계의 패턴을 설명했다.

## 오늘 배운 내용 정리

- 교차표는 두 범주형 변수의 조합별 빈도를 보여준다.
- 표에서 차이가 보이는 것만으로 두 변수가 관련되어 있다고 결론 내릴 수 없다.
- 카이제곱 독립성 검정의 귀무가설은 두 변수가 서로 독립이라는 것이다.
- 관측빈도는 실제 빈도이고 기대빈도는 두 변수가 독립일 때 예상되는 빈도이다.
- 관측빈도와 기대빈도의 차이가 클수록 카이제곱 통계량이 커지는 경향이 있다.
- 최종 결론은 카이제곱 통계량으로 계산한 p-value를 유의수준과 비교해 내린다.
- 교차표에는 평균이나 비율이 아닌 빈도 데이터를 사용해야 한다.
- 관측값의 독립성과 기대빈도가 지나치게 작지 않은지를 확인해야 한다.
- 유의한 관계는 인과관계를 의미하지 않으며, 비율을 함께 확인해 관계의 형태를 설명해야 한다.

## 한 문장 정리

> 카이제곱 독립성 검정은 두 범주형 변수의 교차표에서 실제 관측빈도와 독립을 가정한 기대빈도를 비교하여 두 변수 사이에 통계적인 관계가 있는지 판단하는 방법이다.
