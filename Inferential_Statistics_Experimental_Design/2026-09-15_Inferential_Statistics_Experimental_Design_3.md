## 1. 분석 목적과 데이터 특성 확인

같은 데이터셋을 사용하더라도 무엇을 비교하거나 확인하려는지에 따라 적절한 검정 방법이 달라진다. 따라서 검정 기법을 먼저 선택하는 것이 아니라 분석 질문과 데이터 구조를 먼저 확인해야 한다.

쇼핑몰 데이터에서 생각할 수 있는 분석 질문은 다음과 같다.

| 분석 질문 | 데이터 특성 | 핵심 구조 |
|---|---|---|
| 남성 고객과 여성 고객의 평균 구매금액이 다른가? | 연속형 | 서로 다른 두 그룹 비교 |
| 이벤트 참여 고객의 전후 구매금액이 다른가? | 연속형 | 같은 대상의 두 시점 비교 |
| 일반·실버·골드 회원의 평균 구매금액이 다른가? | 연속형 | 서로 다른 세 그룹 비교 |
| 멤버십 등급과 재구매 여부에 관계가 있는가? | 범주형 | 두 범주형 변수의 관계 확인 |

모두 가설검정을 사용할 수 있는 질문이지만 변수의 유형, 그룹 수, 관측값 사이의 관계가 서로 다르다. 그러므로 하나의 검정법을 모든 상황에 적용해서는 안 된다.

### 검정법을 선택하기 전에 확인할 네 가지

1. 무엇의 차이 또는 관계를 확인하려는가?
2. 분석할 데이터는 연속형인가, 범주형인가?
3. 비교할 그룹은 몇 개인가?
4. 그룹이 서로 독립적인가, 같은 대상을 반복 측정한 대응 데이터인가?

```text
분석 목적 확인
    ↓
데이터 유형 확인
    ↓
비교 그룹 수 확인
    ↓
독립 표본인지 대응 표본인지 확인
    ↓
검정 가정 확인
    ↓
적절한 검정 방법 선택
```

## 2. 분석 목적 확인하기

첫 번째 단계는 분석 질문이 평균이나 분포의 차이를 확인하려는 것인지, 변수 사이의 관계를 확인하려는 것인지 구분하는 것이다.

| 분석 목적 | 질문 예시 |
|---|---|
| 한 집단과 기준값 비교 | 신규 화면 적용 후 평균 구매금액이 기존 평균과 다른가? |
| 두 집단의 평균 비교 | A 지역과 B 지역 고객의 평균 구매금액이 다른가? |
| 동일 대상의 전후 비교 | 이벤트 전후 같은 고객의 구매금액이 달라졌는가? |
| 세 집단 이상의 평균 비교 | 멤버십 등급별 평균 구매금액이 다른가? |
| 범주형 변수 간 관계 확인 | 멤버십 등급과 재구매 여부가 관련되어 있는가? |

분석 목적을 구체적으로 작성하면 귀무가설과 대립가설, 검정 방향, 필요한 검정법을 자연스럽게 좁힐 수 있다.

---

## 3. 데이터 유형 확인하기

분석 대상 변수의 형태는 검정 방법을 결정하는 핵심 기준이다.

### 연속형 데이터

연속형 데이터는 일정 범위에서 수치로 측정되는 값이다.

- 구매금액
- 배송 시간
- 걸음 수
- 시험 점수

연속형 데이터에서는 평균이나 분포의 차이를 비교하는 검정을 고려할 수 있다.

### 범주형 데이터

범주형 데이터는 대상을 특정 그룹이나 상태로 구분하는 값이다.

- 회원 등급: 일반·실버·골드
- 재구매 여부: 예·아니요
- 고객 유형: 신규·기존

두 범주형 변수 사이의 관계를 확인할 때는 각 조합의 빈도를 바탕으로 검정하는 방법을 고려한다.

| 데이터 조합 | 주로 확인하는 내용 |
|---|---|
| 연속형 변수와 기준값 | 표본 평균이 기준과 다른지 |
| 연속형 변수와 범주형 그룹 | 그룹별 평균이 다른지 |
| 범주형 변수와 범주형 변수 | 두 범주형 변수에 관계가 있는지 |

---

## 4. 비교하는 그룹 수 확인하기

연속형 데이터의 평균을 비교하더라도 그룹 수에 따라 검정 방법이 달라진다.

| 그룹 수 | 분석 예시 | 고려할 검정 구조 |
|---:|---|---|
| 1개 | 신규 시스템의 평균 배송 시간과 기존 기준 3일 비교 | 단일 집단과 기준값 비교 |
| 2개 | A 지역과 B 지역의 평균 구매금액 비교 | 두 집단 평균 비교 |
| 3개 이상 | 일반·실버·골드 회원의 평균 구매금액 비교 | 세 집단 이상 평균 비교 |

세 그룹 이상을 여러 번의 두 집단 검정으로 나누어 비교하면 제1종 오류가 누적될 수 있다. 따라서 먼저 전체 그룹 사이에 평균 차이가 있는지 확인하는 검정을 고려해야 한다.

---

## 5. 독립 표본과 대응 표본 구분하기

두 그룹을 비교한다는 이유만으로 같은 검정 방법을 사용할 수는 없다. 관측값 사이의 관계를 확인해야 한다.

### 독립 표본

한 그룹의 관측값이 다른 그룹의 관측값과 직접 연결되지 않는 데이터이다.

```text
A 지역 고객의 구매금액
vs
B 지역 고객의 구매금액
```

서로 다른 고객으로 구성된 A/B 그룹, 남성 고객과 여성 고객, 신규 고객과 기존 고객 비교 등이 이에 해당한다.

### 대응 표본

같은 대상을 두 번 측정했거나 관측값이 쌍으로 연결된 데이터이다.

```text
같은 고객의 이벤트 참여 전 구매금액
vs
같은 고객의 이벤트 참여 후 구매금액
```

동일 사용자의 프로그램 참여 전후 걸음 수, 동일 학생의 교육 전후 점수 등은 대응 표본이다.

| 구분 | 독립 표본 | 대응 표본 |
|---|---|---|
| 대상 | 서로 다른 대상 | 같은 대상 또는 연결된 쌍 |
| 관측값 관계 | 서로 독립 | 서로 대응됨 |
| 예시 | A 고객군과 B 고객군 | 같은 고객의 전후 구매금액 |
| 분석의 초점 | 두 그룹의 평균 차이 | 각 대상의 전후 차이 |

대응 데이터에서는 각 대상의 두 측정값을 서로 연결해서 분석해야 한다. 대응 관계를 무시하고 독립 표본처럼 처리하면 데이터 구조에 맞지 않는 분석이 될 수 있다.

## 6. 검정 방법의 가정 확인하기

통계적 검정 방법은 데이터를 비교하기 위해 몇 가지 조건을 전제로 한다. 이러한 조건을 검정의 가정(Assumption)이라고 한다.

같은 연속형 데이터의 평균을 비교하더라도 실제 분포는 다를 수 있다.

```python
import numpy as np

group_a = np.array([48, 52, 50, 55, 47, 51, 49, 53, 46, 54])
group_b = np.array([45, 48, 50, 52, 47, 49, 51, 55, 120, 180])

print("A 지역 평균:", group_a.mean())
print("B 지역 평균:", group_b.mean())
```

A 지역의 값은 비교적 비슷한 범위에 모여 있지만, B 지역에는 120과 180처럼 다른 값보다 매우 큰 값이 포함되어 있다.

```text
A 지역: 값들이 비교적 비슷한 범위에 분포
B 지역: 일부 큰 값으로 인해 한쪽으로 치우친 분포
```

이처럼 분석 목적과 변수 유형이 같아도 분포, 이상치, 그룹별 변동성이 다를 수 있으므로 검정에 필요한 가정을 확인해야 한다.

## 7. 정규성

정규성(Normality)은 분석 대상 데이터의 분포가 정규분포에서 크게 벗어나지 않는지를 확인하는 가정이다.

정규성을 확인할 때는 다음과 같은 데이터 특징을 살펴볼 수 있다.

- 분포가 한쪽으로 크게 치우쳐 있는가?
- 극단적으로 크거나 작은 값이 포함되어 있는가?
- 평균 주변에 값이 비교적 대칭적으로 분포하는가?
- 표본 크기는 충분한가?

시각적으로는 히스토그램이나 Q-Q plot을 활용할 수 있고, 필요하다면 정규성 검정을 함께 사용할 수 있다. 다만 하나의 결과만 기계적으로 적용하기보다 데이터의 분포와 표본 크기를 함께 고려해야 한다.

## 8. 등분산성

등분산성(Homogeneity of Variance)은 비교하는 그룹들의 분산이 비슷하다는 가정이다.

```text
A 그룹의 값이 퍼진 정도 ≈ B 그룹의 값이 퍼진 정도
→ 등분산 가정을 고려할 수 있음

A 그룹의 값이 퍼진 정도와 B 그룹의 값이 퍼진 정도가 크게 다름
→ 등분산 가정이 적절한지 재검토
```

두 독립 그룹의 평균을 비교할 때 등분산성을 가정하기 어렵다면 등분산을 요구하지 않는 Welch's t-test를 고려할 수 있다.

```python
from scipy import stats

t_stat, p_value = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False,  # Welch's t-test
)
```

`equal_var=False`는 두 그룹의 분산이 같다고 가정하지 않는 설정이다.

## 9. 가정이 적절하지 않을 때의 판단

검정 가정이 충족되지 않는다고 해서 항상 분석을 중단해야 하는 것은 아니다. 또한 가정 하나가 적절하지 않다고 무조건 비모수검정을 선택하는 것도 아니다.

```text
검정 가정 확인
    ↓
어떤 가정이 문제가 되는지 파악
    ↓
해당 가정을 요구하지 않는 설정 또는 검정법 검토
    ↓
데이터 변환이나 비모수검정 등 대안 검토
    ↓
선택한 방법과 근거를 결과에 기록
```

고려할 수 있는 대응은 다음과 같다.

- 등분산성이 적절하지 않다면 Welch's t-test 사용을 검토한다.
- 분포 가정을 적용하기 어렵다면 특정 분포에 대한 가정이 상대적으로 적은 비모수검정을 검토한다.
- 이상치가 분석 결과를 과도하게 좌우하는지 확인한다.
- 데이터 변환이 분석 목적과 해석에 적절한지 검토한다.
- 표본 수와 그룹별 데이터 구조를 함께 고려한다.

핵심은 가정 충족 여부를 단순한 통과·실패로 처리하는 것이 아니라, 어떤 가정이 왜 문제가 되는지 확인하고 그에 맞는 방법을 선택하는 것이다.

## 10. 데이터 특성에 따른 검정 기법 선택

분석 상황별 대표적인 검정 방법은 다음과 같이 정리할 수 있다.

| 분석 목적 | 데이터 유형 | 그룹 구조 | 대표적인 검정 방법 |
|---|---|---|---|
| 표본 평균과 기준값 비교 | 연속형 | 한 집단 | 단일표본 t-test |
| 서로 다른 두 집단의 평균 비교 | 연속형 | 독립된 두 집단 | 독립표본 t-test 또는 Welch's t-test |
| 같은 대상의 전후 평균 비교 | 연속형 | 대응된 두 측정 | 대응표본 t-test |
| 서로 다른 세 집단 이상의 평균 비교 | 연속형 | 독립된 세 집단 이상 | 일원분산분석(One-way ANOVA) |
| 두 범주형 변수의 관계 확인 | 범주형 | 빈도 자료 | 카이제곱 독립성 검정 |

이 표는 대표적인 선택 방향을 보여준다. 실제 검정 전에는 각 방법에 필요한 가정이 데이터에 적절한지 확인해야 한다.

### 상황별 가설의 예

#### 서로 다른 두 그룹의 평균 비교

```text
질문: A 지역과 B 지역 고객의 평균 구매금액이 다른가?

H₀: 두 지역의 평균 구매금액은 같다.
H₁: 두 지역의 평균 구매금액은 다르다.

데이터: 연속형
그룹 수: 2개
관계: 독립
검정 후보: 독립표본 t-test 또는 Welch's t-test
```

#### 같은 대상의 전후 평균 비교

```text
질문: 이벤트 전후 같은 고객의 평균 구매금액이 다른가?

H₀: 이벤트 전후 평균 구매금액의 차이는 0이다.
H₁: 이벤트 전후 평균 구매금액의 차이는 0이 아니다.

데이터: 연속형
그룹 수: 두 시점
관계: 대응
검정 후보: 대응표본 t-test
```

#### 세 그룹 이상의 평균 비교

```text
질문: 일반·실버·골드 회원의 평균 구매금액이 다른가?

H₀: 모든 회원 등급의 평균 구매금액은 같다.
H₁: 적어도 한 등급의 평균 구매금액은 다르다.

데이터: 연속형
그룹 수: 3개
관계: 독립
검정 후보: 일원분산분석
```

#### 두 범주형 변수의 관계 확인

```text
질문: 회원 등급과 재구매 여부에 관계가 있는가?

H₀: 회원 등급과 재구매 여부는 서로 독립이다.
H₁: 회원 등급과 재구매 여부는 서로 관련되어 있다.

데이터: 두 범주형 변수
검정 후보: 카이제곱 독립성 검정
```

## 11. 검정 방법 선택 순서

다음 순서로 질문하면 적절한 검정 방법을 단계적으로 좁힐 수 있다.

### 1단계: 무엇을 확인하려는가?

- 평균의 차이인가?
- 범주형 변수 사이의 관계인가?

### 2단계: 데이터는 어떤 유형인가?

- 연속형인가?
- 범주형인가?

### 3단계: 몇 개의 그룹을 비교하는가?

- 한 집단과 기준값을 비교하는가?
- 두 그룹인가?
- 세 그룹 이상인가?

### 4단계: 관측값은 어떤 관계인가?

- 서로 다른 독립된 대상인가?
- 같은 대상을 반복 측정한 대응 데이터인가?

### 5단계: 검정 가정은 적절한가?

- 분포가 정규성 가정에서 크게 벗어나지 않는가?
- 비교 그룹의 분산이 비슷한가?
- 이상치나 강한 치우침이 결과를 좌우하지 않는가?

### 6단계: 검정 방법을 선택한다

검정법을 선택한 뒤에도 유의수준, 검정 방향, 효과 크기와 실제 분석 목적을 함께 고려해야 한다.

---

## 12. 검정 선택 체크리스트

- [ ] 분석 질문을 차이 또는 관계의 형태로 명확히 작성했다.
- [ ] 종속변수의 데이터 유형을 확인했다.
- [ ] 비교하는 그룹의 수를 확인했다.
- [ ] 독립 표본과 대응 표본을 구분했다.
- [ ] 데이터의 분포와 이상치를 확인했다.
- [ ] 정규성과 등분산성 등 필요한 가정을 검토했다.
- [ ] 가정이 적절하지 않을 때 사용할 대안을 검토했다.
- [ ] 선택한 검정 방법과 선택 근거를 기록했다.
- [ ] p-value뿐 아니라 효과 크기와 실제 의미도 함께 해석할 준비를 했다.

## 핵심 용어 정리

| 용어 | 의미 |
|---|---|
| 연속형 데이터 | 구매금액이나 배송 시간처럼 수치로 측정되는 데이터 |
| 범주형 데이터 | 회원 등급이나 재구매 여부처럼 범주로 구분되는 데이터 |
| 독립 표본 | 서로 다른 대상으로 구성되어 관측값이 직접 연결되지 않은 표본 |
| 대응 표본 | 같은 대상의 반복 측정처럼 관측값이 쌍으로 연결된 표본 |
| 검정의 가정 | 통계적 검정법을 적용할 때 전제하는 데이터 조건 |
| 정규성 | 데이터 분포가 정규분포에서 크게 벗어나지 않는다는 가정 |
| 등분산성 | 비교하는 그룹의 분산이 비슷하다는 가정 |
| Welch's t-test | 두 독립 집단의 등분산을 가정하지 않는 평균 비교 방법 |
| 비모수검정 | 특정 분포에 대한 가정을 상대적으로 적게 사용하는 검정 방법 |
| 일원분산분석 | 서로 다른 세 집단 이상의 평균 차이를 검정하는 방법 |
| 카이제곱 독립성 검정 | 두 범주형 변수의 관계를 검정하는 방법 |

## 오늘 배운 내용 정리

- 검정 방법은 분석 목적과 데이터의 구조를 확인한 뒤 선택해야 한다.
- 연속형과 범주형 데이터는 확인하려는 내용과 사용할 검정 방법이 다르다.
- 두 그룹 비교에서도 서로 다른 대상이면 독립 표본, 같은 대상의 전후 측정이면 대응 표본이다.
- 평균 비교 검정에서는 데이터의 분포와 정규성·등분산성 등의 가정을 확인해야 한다.
- 등분산 가정이 적절하지 않은 독립된 두 그룹은 Welch's t-test를 고려할 수 있다.
- 가정이 적절하지 않다고 분석을 바로 중단하거나 무조건 비모수검정을 선택하는 것은 아니다.
- 무엇을 확인하는지, 데이터 유형, 그룹 수, 데이터 관계, 검정 가정의 순서로 검정법을 좁혀간다.
- 선택한 검정 방법과 그 근거를 분석 결과에 명확하게 기록해야 한다.

## 한 문장 정리

> 적절한 가설검정은 검정법 이름에서 시작하는 것이 아니라 분석 목적, 데이터 유형, 그룹 수, 독립·대응 관계와 검정 가정을 차례로 확인하는 것에서 시작한다.
