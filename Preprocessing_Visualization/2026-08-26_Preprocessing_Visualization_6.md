# 1. 데이터 정제가 필요한 이유

현실에서 수집되는 데이터는 항상 깨끗하지 않다.

예를 들어 설문 응답이 비어 있거나, 같은 거래가 두 번 기록되거나,
근무시간이나 연봉처럼 숫자가 잘못 입력될 수 있다. 이러한 문제를 확인하지
않고 분석하면 통계 결과가 왜곡되고 잘못된 의사결정으로 이어질 수 있다.

오늘 배운 대표적인 데이터 정제 요소는 다음 세 가지이다.

  정제 요소                     의미
  ----------------------------- -----------------------------------------
  결측치(Missing Value)         값이 있어야 할 위치에 값이 없는 상태
  중복 데이터(Duplicate Data)   동일한 정보가 두 번 이상 기록된 상태
  이상치(Outlier)               전체적인 데이터 분포에서 크게 벗어난 값

------------------------------------------------------------------------

# 2. 완전탐색(Brute Force)

완전탐색은 **가능한 경우를 하나씩 모두 확인하면서 조건을 만족하는 답을
찾는 방법**이다.

예를 들어 숫자 리스트에서 서로 다른 두 숫자를 선택하여 합이 10이 되는
경우를 찾을 수 있다.

``` python
numbers = [2, 4, 6, 7]

for i in range(len(numbers)):
    for j in range(i + 1, len(numbers)):
        if numbers[i] + numbers[j] == 10:
            print(numbers[i], numbers[j])
```

결과:

``` text
4 6
```

`j`를 `i + 1`부터 시작하면 같은 원소를 두 번 선택하지 않고 `(2, 4)`,
`(4, 2)`처럼 동일한 조합을 중복 확인하는 것도 피할 수 있다.

# 3. 결측치(Missing Value)

결측치는 **데이터셋에서 값이 존재해야 할 위치에 값이 없는 상태**이다.

Pandas에서는 대표적으로 `NaN`, `None` 등으로 나타날 수 있으며 숫자형과
문자형 데이터 모두에서 발생할 수 있다.

``` python
import pandas as pd

survey = pd.DataFrame({
    "customer": ["민수", "지수", "현우", "서연"],
    "age": [25, 42, 31, 55],
    "satisfaction": [5, None, 4, None]
})
```

## isna()로 결측치 확인

``` python
survey["satisfaction"].isna()
```

`isna()`는 결측치인 위치를 `True`, 값이 존재하는 위치를 `False`로
표시한다.

``` text
False → 값이 존재
True  → 결측치
```

컬럼별 결측치 개수를 확인하려면 다음과 같이 작성한다.

``` python
df.isna().sum()
```

특정 컬럼의 결측치 개수:

``` python
df["customer_rating"].isna().sum()
```

결측치가 많은 컬럼부터 정렬:

``` python
df.isna().sum().sort_values(ascending=False)
```

결측치가 있는 행만 선택:

``` python
missing_rows = df[
    df["customer_rating"].isna()
]
```

`isna()`의 결과가 Boolean Series이기 때문에 불리언 인덱싱의 조건으로
사용할 수 있다.

------------------------------------------------------------------------

# 4. 결측치를 발견했다고 바로 처리하면 안 된다

결측치를 찾았다고 바로 삭제하거나 평균으로 채우는 것이 정답은 아니다.

먼저 다음을 확인해야 한다.

``` text
결측치가 얼마나 많은가?
왜 결측치가 발생했는가?
수치형인가 범주형인가?
데이터에 이상치가 존재하는가?
삭제했을 때 중요한 정보가 사라지지 않는가?
```

즉, **결측치를 발견하는 것과 처리 방법을 결정하는 것은 별개의
과정**이다.

------------------------------------------------------------------------

# 5. 중복 데이터(Duplicate Data)

중복 데이터는 동일한 정보가 데이터셋에 두 번 이상 기록된 상태이다.

중복은 완전히 동일한 행뿐 아니라 일부 컬럼이 같은 부분 중복 형태로도
나타날 수 있다.

Pandas에서는 `duplicated()`로 중복 여부를 확인한다.

``` python
df.duplicated()
```

중복된 행의 개수:

``` python
df.duplicated().sum()
```

중복된 행만 조회:

``` python
duplicate_rows = df[
    df.duplicated()
]
```

## 중복처럼 보여도 실제 중복이 아닐 수 있다

같은 고객이 같은 상품을 여러 번 구매했다면 고객과 상품 컬럼은 같더라도
서로 다른 실제 주문일 수 있다.

따라서 중복 여부를 판단할 때는

> **어떤 컬럼을 기준으로 동일한 데이터라고 판단할 것인가?**

를 먼저 정해야 한다.

중복 데이터를 무조건 제거하지 않고 데이터의 맥락과 비즈니스 규칙을
확인해야 한다.

중복은 ETL 파이프라인 오류, 시스템 통합 오류, 재시도 로직 오류, 수동
입력 실수 등으로 발생할 수 있다.

------------------------------------------------------------------------

# 6. 이상치(Outlier)

이상치는 **전체적인 데이터 분포에서 크게 벗어난 값**이다.

예를 들어 직원들의 하루 근무시간이 다음과 같다고 하자.

``` python
work_hours = [8, 7, 9, 8, 80]
```

대부분 7\~9시간인데 하나의 값만 80시간이다.

이 값 때문에 평균이 22.4시간까지 증가하여 일반적인 근무시간을 제대로
나타내지 못할 수 있다.

``` python
work["work_hours"].describe()
```

`describe()`의 평균, 중앙값, 최댓값 등의 통계량을 비교하면 극단적인 값을
발견하는 데 도움을 받을 수 있다.

## 이상치의 유형

이상치를 발견했다고 무조건 삭제해서는 안 된다.

``` text
입력 오류
측정 오류
진짜 이상치
```

### 입력 오류

실제 값이 8시간인데 80시간으로 잘못 입력된 경우이다. 올바른 값을 확인할
수 있다면 수정해야 한다.

### 측정 오류

센서나 데이터 수집 과정에서 잘못된 값이 기록된 경우이다. 데이터가 생성된
과정을 확인해야 한다.

### 진짜 이상치

실제로 발생한 극단적인 값일 수 있다. 이런 값은 오히려 중요한 분석 대상이
될 수도 있다.

따라서 이상치를 발견하면 **입력 오류인지, 측정 오류인지, 실제 값인지
먼저 확인**해야 한다.

------------------------------------------------------------------------

# 7. 결측치 처리 방법 4가지

오늘 학습한 대표적인 결측치 처리 방법은 다음 네 가지이다.

  -----------------------------------------------------------------------
  방법              핵심 원리         적합한 상황       주의사항
  ----------------- ----------------- ----------------- -----------------
  행 삭제           결측치가 있는 행  결측 비율이 낮고  데이터 손실 가능
                    제거              무작위로 발생     

  평균 대체         해당 컬럼         수치형, 이상치가  이상치에 민감,
                    평균으로 채움     거의 없고         분산 감소
                                      정규분포에 가까움 

  중앙값 대체       해당 컬럼         수치형, 이상치가  분산 감소 가능
                    중앙값으로 채움   있거나 분포가     
                                      치우침            

  최빈값 대체       가장 자주         범주형 데이터     특정 값 쏠림 심화
                    등장하는 값으로                     가능
                    채움                                
  -----------------------------------------------------------------------

핵심은 **모든 결측치를 같은 방법으로 처리하지 않고 데이터의 종류와
분포를 고려하는 것**이다.

------------------------------------------------------------------------

# 8. 행 삭제 - dropna()

결측치가 매우 적고 무작위로 발생했다면 행 삭제를 고려할 수 있다.

``` python
df_dropped = df.dropna()
```

기본적으로 결측치가 하나라도 있는 행을 제거한다.

특정 컬럼만 기준으로 삭제할 수도 있다.

``` python
df = df.dropna(
    subset=["부서"]
)
```

이는 `부서` 컬럼에 결측치가 있는 행만 제거한다.

다만 결측치가 많은 상황에서 무작정 삭제하면 데이터가 크게 줄어들고, 특정
패턴의 데이터가 제거되면서 편향이 생길 수 있다.

------------------------------------------------------------------------

# 9. 평균 대체(Mean Imputation)

이상치가 거의 없고 분포가 비교적 대칭적인 수치형 데이터라면 평균 대체를
고려할 수 있다.

``` python
df["나이"] = df["나이"].fillna(
    df["나이"].mean()
)
```

평균은 이상치에 민감하기 때문에 극단적인 값이 존재한다면 평균 자체가
왜곡될 수 있다.

------------------------------------------------------------------------

# 10. 중앙값 대체(Median Imputation)

이상치가 있거나 분포가 치우친 수치형 데이터에서는 중앙값 대체를 고려할
수 있다.

``` python
df["구매금액"] = df["구매금액"].fillna(
    df["구매금액"].median()
)
```

평균과 중앙값의 핵심 차이는 **이상치 민감도**이다.

``` text
이상치가 없고 분포가 대칭적
→ 평균 고려

이상치가 있거나 분포가 치우침
→ 중앙값 고려
```

------------------------------------------------------------------------

# 11. 최빈값 대체(Mode Imputation)

범주형 데이터는 최빈값으로 결측치를 채우는 방법을 고려할 수 있다.

``` python
df["회원등급"] = df["회원등급"].fillna(
    df["회원등급"].mode()[0]
)
```

`mode()`는 최빈값을 Series 형태로 반환할 수 있으므로 첫 번째 최빈값을
사용하려면 `[0]`으로 꺼낸다.

``` python
df["회원등급"].mode()[0]
```

다만 최빈값으로 여러 결측치를 채우면 특정 범주의 비율이 더 커지는 쏠림
현상이 심화될 수 있다.

------------------------------------------------------------------------

# 12. fillna()

`fillna()`는 결측치를 특정 값이나 통계값으로 채우는 Pandas 메서드이다.

``` python
# 평균
df["나이"] = df["나이"].fillna(
    df["나이"].mean()
)

# 중앙값
df["점수"] = df["점수"].fillna(
    df["점수"].median()
)

# 최빈값
df["지역"] = df["지역"].fillna(
    df["지역"].mode()[0]
)
```

학습자료에서는 앞/뒤 값으로 채우는 `ffill`, `bfill` 방식도 제공한다고
설명했다.

------------------------------------------------------------------------

# 13. dropna()와 fillna()를 함께 사용할 수 있다

하나의 DataFrame에서도 컬럼의 특성에 따라 서로 다른 방법을 사용할 수
있다.

예를 들어 직원 데이터에서 근속연수는 중앙값으로 채우고 부서가 없는 행은
삭제할 수 있다.

``` python
df["근속연수"] = df["근속연수"].fillna(
    df["근속연수"].median()
)

df = df.dropna(
    subset=["부서"]
)
```

즉, `dropna()`와 `fillna()` 중 하나만 선택해야 하는 것이 아니다.

------------------------------------------------------------------------

# 14. 결측치 처리 방법을 선택하는 과정

결측치를 발견했을 때 다음과 같은 흐름으로 생각할 수 있다.

``` text
결측치 발견
    ↓
결측치가 얼마나 많은가?
    ↓
왜 발생했는가?
    ↓
데이터 타입은 무엇인가?
    ↓
수치형 / 범주형 확인
    ↓
이상치나 치우친 분포가 있는가?
    ↓
적절한 처리 방법 선택
```

간단히 정리하면:

``` text
결측치가 매우 적고 무작위
→ 행 삭제 고려

수치형 + 이상치 거의 없음
→ 평균 대체 고려

수치형 + 큰 이상치 또는 치우친 분포
→ 중앙값 대체 고려

범주형
→ 최빈값 대체 고려
```

하지만 실제 업무에서는 데이터의 모양만 보는 것이 아니라 결측치가 **수집
오류나 ETL 문제로 발생한 것은 아닌지 원인을 확인**해야 한다.

파이프라인 오류가 원인이라면 값을 대체하기 전에 원인을 수정하는 것이
우선이다.

------------------------------------------------------------------------

# 15. 결측치 처리에도 한계가 있다

`dropna()`로 결측치를 모두 삭제하면 데이터 손실과 편향 문제가 발생할 수
있다.

반대로 `fillna()`로 평균·중앙값·최빈값을 채우는 것도 모든 결측치를
동일한 값으로 바꾸기 때문에 변수 간 관계를 무시하거나 분산을 왜곡할 수
있다.

따라서 결측치 처리는 단순히 `NaN`을 없애는 것이 아니라 **데이터 특성과
분석 목적에 맞는 방법을 선택하는 과정**이다.

------------------------------------------------------------------------

# 16. 처리 방법의 판단 근거 기록

전처리에서는 **무엇을 했는지뿐 아니라 왜 그렇게 했는지** 기록하는 것이
중요하다.

``` python
# [결측치 처리 근거]
# 나이: 이상치가 없고 값의 분포가 크게 치우치지 않음
# → 평균 대체
df["나이"] = df["나이"].fillna(
    df["나이"].mean()
)

# 구매금액: 큰 금액의 이상치가 존재함
# → 중앙값 대체
df["구매금액"] = df["구매금액"].fillna(
    df["구매금액"].median()
)

# 회원등급: 범주형 데이터이며 '일반'이 가장 많이 등장함
# → 최빈값 대체
df["회원등급"] = df["회원등급"].fillna(
    df["회원등급"].mode()[0]
)
```

이렇게 근거를 남기면 다른 사람이 코드를 보더라도 왜 해당 처리 방법을
선택했는지 이해할 수 있다.

------------------------------------------------------------------------

# 17. 오늘의 핵심 코드

``` python
import pandas as pd

df = pd.read_csv("data.csv")

# 결측치 확인
df.isna()
df.isna().sum()
df["customer_rating"].isna().sum()

# 결측치 개수를 내림차순 정렬
df.isna().sum().sort_values(ascending=False)

# 결측치가 있는 행
df[df["customer_rating"].isna()]

# 중복 확인
df.duplicated()
df.duplicated().sum()

# 중복 행
df[df.duplicated()]

# 분포 확인
df["value"].describe()

# 결측치가 있는 행 삭제
df.dropna()

# 특정 컬럼을 기준으로 행 삭제
df.dropna(subset=["부서"])

# 평균 대체
df["나이"] = df["나이"].fillna(
    df["나이"].mean()
)

# 중앙값 대체
df["구매금액"] = df["구매금액"].fillna(
    df["구매금액"].median()
)

# 최빈값 대체
df["회원등급"] = df["회원등급"].fillna(
    df["회원등급"].mode()[0]
)
```

# 18. 오늘 배운 내용 정리

### 데이터 정제의 세 가지 핵심 요소

``` text
결측치
→ 값이 있어야 할 위치에 값이 없음

중복 데이터
→ 동일한 정보가 두 번 이상 기록됨

이상치
→ 전체 데이터 분포에서 크게 벗어난 값
```

### 결측치 처리

``` text
행 삭제
평균 대체
중앙값 대체
최빈값 대체
```

### 중요한 판단 기준

-   데이터의 종류와 분포를 먼저 확인한다.
-   평균은 이상치의 영향을 많이 받고 중앙값은 상대적으로 적게 받는다.
-   범주형 데이터는 최빈값 대체를 고려할 수 있다.
-   중복처럼 보이는 데이터도 실제로 다른 사건일 수 있다.
-   이상치를 발견해도 무조건 제거하지 않는다.
-   결측치가 파이프라인 오류에서 발생했다면 대체보다 원인 수정이
    우선이다.
-   처리 코드에는 **왜 해당 방법을 선택했는지 근거를 남긴다.**

# 19. 오늘의 핵심 한 줄

> **데이터 정제는 결측치·중복·이상치를 기계적으로 제거하는 것이 아니라,
> 데이터가 왜 그렇게 기록되었는지 확인하고 데이터의 특성에 맞는 처리
> 방법을 근거와 함께 선택하는 과정이다.**

------------------------------------------------------------------------

# 20. 느낀 점

오늘은 데이터 분석에서 전처리와 정제가 왜 중요한지 조금 더 구체적으로
이해할 수 있었다.

이전에는 결측치가 있으면 `dropna()`로 삭제하거나 `fillna()`로 값을
채우면 된다고 단순하게 생각하기 쉬웠는데, 실제로는 **어떤 값을 어떤
방법으로 처리할지 판단하는 과정이 더 중요하다**는 것을 배웠다.

특히 평균과 중앙값의 차이가 기억에 남았다. 평균은 이상치에 영향을 많이
받기 때문에 데이터에 극단적인 값이 있다면 결측치를 평균으로 채우는 것이
오히려 데이터의 특성을 왜곡할 수 있다. 따라서 수치형 데이터라고 무조건
평균을 사용하는 것이 아니라 분포와 이상치를 먼저 확인해야 한다.

중복 데이터도 같은 고객과 상품이 여러 번 나타난다는 이유만으로 제거하면
안 된다는 점이 중요했다. 실제로 같은 고객이 같은 상품을 여러 번 구매한
것일 수도 있기 때문에 데이터가 의미하는 사건과 비즈니스 기준을 함께
확인해야 한다.

또한 이상치를 발견했을 때 바로 삭제해서는 안 된다는 점도 기억해야겠다.
극단적인 값이 입력 오류나 측정 오류일 수도 있지만 실제로 발생한 중요한
값일 수도 있기 때문이다.

앞으로 데이터를 전처리할 때는 단순히

``` text
결측치 발견 → 삭제
중복 발견 → 제거
이상치 발견 → 제거
```

처럼 처리하지 않고,

``` text
왜 이런 값이 생겼는가?
실제로 잘못된 데이터인가?
제거하면 어떤 정보가 사라지는가?
왜 이 처리 방법을 선택했는가?
```

를 먼저 생각해야겠다.

그리고 전처리 코드에는 결과만 남기는 것이 아니라 **처리 방법을 선택한
이유까지 주석으로 기록하는 습관**을 들여야겠다.
