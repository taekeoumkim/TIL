## 1. 이상치를 발견하면 무조건 제거해야 할까?

이상치를 발견하면 가장 먼저 떠올리기 쉬운 방법은 제거이다.

하지만 이상치는 항상 잘못된 데이터라는 뜻은 아니다.

예를 들어 일반적인 주문 금액이 대부분 2만~4만 원인데 30만 원짜리 주문이 하나 있다고 하자.

이 값은

- 잘못 입력된 값일 수도 있고
- 실제 고액 주문일 수도 있다.

따라서 이상치를 처리할 때는 먼저

> **이 값이 정말 잘못된 데이터인지 확인하는 과정**

이 필요하다.

오늘은 이상치를 탐지하는 대표적인 방법 두 가지와 처리 전략 세 가지를 학습했다.

```text
이상치 탐지
→ IQR
→ Z-score

이상치 처리
→ 제거
→ Winsorizing
→ 보존
```

---

## 2. IQR 방법

IQR은 **Interquartile Range**, 즉 사분위 범위를 의미한다.

IQR은 데이터의 가운데 50% 범위를 이용해 이상치를 찾는다.

```text
Q1 = 제1사분위수 = 하위 25%
Q3 = 제3사분위수 = 하위 75%
IQR = Q3 - Q1
```

일반적으로 이상치 후보의 경계는 다음과 같이 정한다.

```text
하한값 = Q1 - 1.5 × IQR
상한값 = Q3 + 1.5 × IQR
```

따라서

```text
값 < 하한값
또는
값 > 상한값
```

이면 이상치 후보로 판단한다.

---

## 3. IQR 예제

```python
import pandas as pd

df = pd.DataFrame({
    "주문금액": [
        20000, 22000, 25000, 27000, 30000,
        32000, 35000, 38000, 40000, 300000
    ]
})
```

Q1과 Q3를 계산한다.

```python
Q1 = df["주문금액"].quantile(0.25)
Q3 = df["주문금액"].quantile(0.75)
```

IQR을 계산한다.

```python
IQR = Q3 - Q1
```

하한값과 상한값을 구한다.

```python
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
```

이상치 후보를 찾는다.

```python
outliers = df[
    (df["주문금액"] < lower_bound)
    |
    (df["주문금액"] > upper_bound)
]
```

학습자료의 예제에서는 정상 범위가 약

```text
5,000원 ~ 57,000원
```

으로 계산되었고, `300000`은 상한값을 초과하기 때문에 이상치 후보로 탐지되었다.

하지만 이 값이 실제 고액 주문이라면 삭제하면 안 된다.

---

## 4. IQR의 핵심 원리

IQR은 데이터의 가운데 50%를 기준으로 계산한다.

```text
Q1 -------- Median -------- Q3
|<--------- IQR ---------->|
```

이상치 경계:

```text
Q1 - 1.5 × IQR
Q3 + 1.5 × IQR
```

IQR의 장점은 극단적인 값 자체를 기준 계산에 직접 사용하지 않기 때문에 **이상치의 영향을 비교적 적게 받는다는 점**이다.

따라서 분포가 비대칭이거나 이상치가 이미 존재하는 데이터에서도 활용하기 좋다.

## 5. quantile()

Pandas에서는 `quantile()`을 이용해 사분위수를 계산할 수 있다.

```python
df["value"].quantile(0.25)
```

→ Q1

```python
df["value"].quantile(0.75)
```

→ Q3

예:

```python
Q1 = df["revenue"].quantile(0.25)
Q3 = df["revenue"].quantile(0.75)

IQR = Q3 - Q1
```

```python
Q1 = df["revenue"].quantile(0.25)
Q3 = df["revenue"].quantile(0.75)

IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers = df[

    |
    (df["revenue"] > upper_bound)
]
```

이후 이상치 개수와 필요한 컬럼만 확인할 수 있다.

```python
print(len(outliers))

print(
    outliers[
        ["order_id", "product_category", "revenue"]
    ]
)
```

## 7. Z-score 방법

Z-score는 각 값이 **평균에서 표준편차 몇 배만큼 떨어져 있는지**를 나타낸다.

공식은 다음과 같다.

```text
Z-score = (값 - 평균) / 표준편차
```

일반적으로

```text
|z| > 3
```

이면 이상치 후보로 판단한다.

즉, 평균에서 표준편차 3배 이상 떨어진 값을 찾는 방식이다.

---

## 8. Z-score 예제

고객센터 상담시간이 다음과 같다고 하자.

```python
import pandas as pd
import numpy as np
from scipy import stats

df = pd.DataFrame({
    "상담시간": [
        8, 9, 10, 11, 10, 9, 12, 10, 11, 9,
        10, 8, 11, 10, 9, 12, 10, 11, 9, 10,
        8, 10, 11, 9, 10, 12, 9, 11, 10, 60
    ]
})
```

Z-score를 계산한다.

```python
z_scores = np.abs(
    stats.zscore(df["상담시간"])
)
```

절댓값이 3보다 큰 값만 선택한다.

```python
outliers = df[
    z_scores > 3
]
```

학습자료의 예제에서는 `60분`이 이상치 후보로 탐지되었다.

---

## 9. 왜 절댓값을 사용할까?

Z-score는 평균보다 작은 값이면 음수가 되고, 큰 값이면 양수가 된다.

예:

```text
평균보다 매우 작음 → z = -3.5
평균보다 매우 큼 → z = 4.2
```

이상치 여부에서는 방향보다 **평균에서 얼마나 멀리 떨어져 있는가**가 중요하기 때문에 절댓값을 사용한다.

```python
np.abs(z_scores)
```

따라서 기준은

```python
np.abs(z_scores) > 3
```

이 된다.

---

## 10. Z-score가 적합한 상황

Z-score는 평균과 표준편차를 이용한다.

따라서 데이터가 평균을 중심으로 비교적 대칭적이고 **정규분포에 가까운 경우**에 활용하기 좋다.

정규분포에서는 약 99.7%의 값이

```text
평균 ± 3 × 표준편차
```

안에 존재한다고 볼 수 있다.

그래서 그 범위를 크게 벗어난 값을 이상치 후보로 판단한다.

---

## 11. Z-score의 주의점

Z-score는 평균과 표준편차를 사용하기 때문에 극단적인 이상치 자체가 평균과 표준편차를 왜곡할 수 있다.

즉,

```text
극단적인 이상치 존재
↓
평균 변화
↓
표준편차 변화
↓
Z-score 계산에도 영향
```

이 발생할 수 있다.

따라서 분포가 비대칭이거나 이미 큰 이상치가 존재한다면 IQR이 더 적합할 수 있다.

---

## 12. IQR과 Z-score 비교

| 구분 | IQR | Z-score |
|---|---|---|
| 분포 가정 | 없음 | 정규분포 가정 |
| 기준 | Q1, Q3, IQR | 평균, 표준편차 |
| 이상치 영향 | 비교적 강함 | 비교적 약함 |
| 적합 상황 | 비대칭 분포, 이상치 존재 | 정규분포에 가까움 |

정리하면 다음과 같다.

```text
데이터 분포가 비대칭이거나
이상치가 의심됨
→ IQR

데이터가 정규분포에 가까움
→ Z-score
```

학습자료에서는 먼저 IQR로 이상치를 탐지하고, 데이터가 정규적이라고 판단되는 경우 Z-score를 추가로 활용하는 방식도 제시했다.

## 13. 이상치 탐지와 이상치 처리는 다르다

이상치 탐지 알고리즘이 특정 값을 이상치라고 표시했다고 해서 곧바로 삭제해야 하는 것은 아니다.

```text
이상치 탐지
≠
잘못된 데이터 확정
```

탐지는 단지

> **다른 값들과 비교했을 때 주의해서 확인할 필요가 있는 값**

을 찾아주는 과정이다.

따라서 이상치가 발견되면 원본 데이터와 비즈니스 맥락을 확인해야 한다.

---

## 14. 이상치 처리 전략

학습자료에서는 이상치 처리 방법을 세 가지로 설명했다.

```text
1. 제거(Removal)
2. Winsorizing
3. 보존(Keep)
```

이 세 가지 중 어떤 전략을 선택할지는 이상치가 왜 발생했는지에 따라 달라진다.

---

## 15. 이상치 제거

입력 오류가 확실한 경우에는 해당 데이터를 제거할 수 있다.

예를 들어 상품 가격이 일반적으로 1만~2만 원인데 어떤 값이 실수로 `1,000,000원`으로 입력되었고, 실제 값도 확인할 수 없다면 제거를 고려할 수 있다.

IQR 범위 안의 데이터만 남기는 방식:

```python
df_drop = df[
    (df["가격"] >= lower_bound)
    &
    (df["가격"] <= upper_bound)
]
```

하지만 실제 고가 상품일 가능성이 있다면 제거하면 안 된다.

---

## 16. Winsorizing

Winsorizing은 이상치를 삭제하지 않고 **경계값으로 제한하는 방법**이다.

예를 들어 상한값보다 큰 값은 상한값으로 바꾸고, 하한값보다 작은 값은 하한값으로 바꾼다.

```text
값 < lower_bound
→ lower_bound로 변경

값 > upper_bound
→ upper_bound로 변경
```

Pandas에서는 `clip()`을 이용하면 구현할 수 있다.

```python
df["가격_winsorized"] = df["가격"].clip(
    lower=lower_bound,
    upper=upper_bound
)
```

장점은 데이터 행 자체를 삭제하지 않고 극단적인 값의 영향을 줄일 수 있다는 것이다.

---

## 17. 이상치 보존

이상치가 실제 의미 있는 데이터라면 그대로 유지해야 한다.

예를 들어

```text
VIP 고객의 실제 대량 주문
실제 고가 상품
특수 이벤트로 발생한 높은 매출
매우 긴 실제 상담
```

처럼 현실에서 실제로 발생한 값이라면 분석에서 중요한 정보일 수 있다.

이 경우 이상치를 제거하면 오히려 중요한 패턴을 잃을 수 있다.

---

## 18. 처리 전략 선택 기준

```text
이상치 발견
    ↓
실제 오류인가?
    ↓
YES → 제거 또는 수정 고려

NO
    ↓
극단적인 값의 영향만 줄이고 싶은가?
    ↓
YES → Winsorizing 고려

NO
    ↓
실제로 중요한 값인가?
    ↓
YES → 보존
```

즉, 이상치 처리에서 가장 중요한 것은 **왜 그 값이 존재하는지 판단하는 것**이다.

---

## 19. 이상치 처리 전 체크할 것

이상치를 발견하면 다음과 같은 질문을 해볼 수 있다.

```text
입력 오류인가?
측정 오류인가?
실제 발생한 값인가?
비즈니스적으로 가능한 값인가?
원본 데이터에서 확인할 수 있는가?
삭제하면 중요한 정보가 사라지는가?
모델이나 통계량에 얼마나 영향을 주는가?
```

## 20. 오늘의 핵심 코드

```python
import pandas as pd
import numpy as np
from scipy import stats

# -------------------------
# IQR
# -------------------------

Q1 = df["revenue"].quantile(0.25)
Q3 = df["revenue"].quantile(0.75)

IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers_iqr = df[
    (df["revenue"] < lower_bound)
    |
    (df["revenue"] > upper_bound)
]

# -------------------------
# Z-score
# -------------------------

z_scores = np.abs(
    stats.zscore(df["avg_order_value"])
)

outliers_z = df[
    z_scores > 3
]

# -------------------------
# 이상치 제거
# -------------------------

df_drop = df[
    (df["revenue"] >= lower_bound)
    &
    (df["revenue"] <= upper_bound)
]

# -------------------------
# Winsorizing
# -------------------------

df["revenue_winsorized"] = df["revenue"].clip(
    lower=lower_bound,
    upper=upper_bound
)
```

## 21. 오늘 배운 내용 정리

### IQR

```text
Q1 = 25% 지점
Q3 = 75% 지점
IQR = Q3 - Q1
```

이상치 후보:

```text
Q1 - 1.5 × IQR 미만
또는
Q3 + 1.5 × IQR 초과
```

특징:

- 분포 가정이 필요하지 않음
- 이상치에 비교적 강함
- 비대칭 데이터에서도 활용 가능

---

### Z-score

```text
Z = (값 - 평균) / 표준편차
```

일반적인 이상치 후보 기준:

```text
|z| > 3
```

특징:

- 평균과 표준편차 사용
- 정규분포에 가까운 데이터에 적합
- 극단적인 이상치가 평균과 표준편차에 영향을 줄 수 있음

---

### 이상치 처리 전략

```text
제거
→ 명확한 오류일 때

Winsorizing
→ 데이터는 유지하면서 극단적인 영향만 제한할 때

보존
→ 실제 의미 있는 값일 때
```

## 22. 오늘의 핵심 한 줄

> **이상치 처리는 이상치를 찾는 것보다, 그 값이 왜 존재하는지 판단한 뒤 제거·Winsorizing·보존 중 적절한 전략을 선택하는 것이 더 중요하다.**

---

## 23. 느낀 점

오늘은 이상치를 단순히 "평균에서 많이 벗어난 값"으로 보고 삭제하는 것이 아니라, **탐지와 판단, 처리를 구분해야 한다**는 점을 배웠다.

특히 IQR과 Z-score는 둘 다 이상치를 탐지하는 방법이지만 사용하는 기준과 적합한 상황이 다르다는 점이 중요했다. IQR은 사분위수를 이용하기 때문에 극단적인 값의 영향을 비교적 적게 받고 분포가 비대칭인 데이터에도 활용할 수 있다. 반면 Z-score는 평균과 표준편차를 이용하기 때문에 데이터가 정규분포에 가까울 때 더 적합하다.

또한 이상치로 탐지되었다고 해서 그 값이 반드시 잘못된 값은 아니라는 점이 기억에 남았다. 30만 원짜리 주문이나 매우 긴 상담시간이 실제로 발생한 값이라면 오히려 분석에서 중요한 정보가 될 수 있다.

이상치 처리 전략에서도 무조건 삭제하는 것만 있는 것이 아니라 Winsorizing처럼 데이터 개수는 유지하면서 극단적인 영향만 줄이는 방법이 있다는 것을 알게 되었다.

앞으로 이상치를 발견하면 바로 삭제하지 않고 다음 순서로 생각해야겠다.

```text
이상치 탐지
→ 실제 오류인지 확인
→ 데이터 분포와 비즈니스 의미 확인
→ 제거 / Winsorizing / 보존 선택
```
