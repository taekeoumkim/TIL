## 1. 데이터 시각화란?

데이터 시각화는 데이터를 그래프나 차트로 표현하여 사람이 데이터의 특징을 직관적으로 이해할 수 있도록 돕는 작업이다.

수많은 행으로 이루어진 데이터를 숫자만으로 살펴보면 패턴, 추세, 이상치를 발견하기 어렵다. 시각화를 이용하면 데이터가 어디에 몰려 있는지, 시간에 따라 어떻게 변하는지, 값 사이에 어떤 관계가 있는지를 한눈에 확인할 수 있다.

그러나 시각화는 단순히 보기 좋은 그래프를 만드는 작업이 아니다. 잘못된 차트를 사용하거나 축의 범위를 부적절하게 설정하면 데이터가 전달하는 메시지를 왜곡할 수 있다. 따라서 차트를 그리기 전에 **무엇을 확인하거나 전달하려는지** 먼저 정해야 한다.

---

## 2. 데이터 시각화의 세 가지 목적

### 패턴 발견

탐색적 데이터 분석(EDA) 과정에서 데이터에 숨겨진 규칙, 구조, 추세와 이상한 움직임을 찾는 것이 목적이다.

예를 들어 월별 매출 그래프를 살펴보며 특정 월에 매출이 감소한 뒤 다시 증가하는 패턴을 발견할 수 있다.

### 의사결정 지원

데이터의 비교·분석 결과를 근거로 어떤 행동을 선택할지 판단하도록 돕는 것이 목적이다.

예를 들어 4월 이후 매출이 증가했다면 해당 기간의 마케팅 활동을 분석하고, 효과가 확인된 전략을 확대할지 결정할 수 있다.

### 효과적인 커뮤니케이션

분석을 통해 발견한 결과나 핵심 메시지를 이해관계자에게 명확하게 전달하는 것이 목적이다.

탐색을 위한 그래프는 여러 변수와 정보를 함께 보여줄 수 있지만, 발표용 그래프는 전달하려는 핵심 메시지가 바로 보이도록 단순하게 구성하는 것이 좋다.

### 월별 매출 시각화 예시

```python
import pandas as pd
import matplotlib.pyplot as plt

sales = pd.DataFrame({
    "month": ["1월", "2월", "3월", "4월", "5월"],
    "sales": [120, 125, 118, 150, 170]
})

plt.plot(sales["month"], sales["sales"], marker="o")
plt.xlabel("Month")
plt.ylabel("Sales")
plt.title("Monthly Sales")
plt.show()
```

같은 그래프라도 목적에 따라 다음과 같이 해석할 수 있다.

- 패턴 발견: 3월에 매출이 잠시 감소한 뒤 크게 증가했다.
- 의사결정 지원: 4월 이후 증가 원인을 분석하여 관련 전략의 확대 여부를 판단한다.
- 커뮤니케이션: 최근 매출이 상승하고 있다는 메시지를 전달한다.

## 3. 차트 선택을 위한 두 가지 질문

차트를 선택할 때는 다음 두 질문에 순서대로 답한다.

### Q1. 변수가 몇 개인가?

- 단변량: 변수 1개
- 이변량: 변수 2개
- 다변량: 변수 3개 이상

### Q2. 무엇을 보여주고 싶은가?

- 분포: 값들이 어느 구간에 얼마나 퍼져 있는가?
- 관계: 두 변수 사이에 어떤 관계가 있는가?
- 비교: 집단이나 항목 사이에 어떤 차이가 있는가?
- 추세: 시간의 흐름에 따라 값이 어떻게 변하는가?
- 구성비: 전체에서 각 항목이 차지하는 비율은 얼마인가?

변수의 개수와 전달 목적이 만나는 지점에서 적합한 차트를 선택한다.

### 차트 선택 매트릭스

| 목적 | 단변량 | 이변량 | 다변량 |
|---|---|---|---|
| 분포 | 히스토그램, KDE | 그룹별 박스플롯 | 바이올린 플롯 |
| 관계 | - | 산점도 | 산점도 행렬 |
| 비교 | 막대그래프 | 그룹 막대그래프 | 히트맵 |
| 추세 | 선 그래프 | 복수 선 그래프 | - |
| 구성비 | 파이차트, 도넛 차트 | 누적 막대그래프 | - |

예를 들어 카페의 시간대별 주문량은 `시간대`와 `주문량`이라는 두 변수를 사용하고, 시간에 따른 변화를 보여주는 것이 목적이다. 따라서 이변량·추세에 해당하는 선 그래프가 적합하다.

```python
import matplotlib.pyplot as plt

hours = [9, 10, 11, 12, 13, 14]
orders = [12, 18, 25, 48, 42, 30]

plt.plot(hours, orders, marker="o")
plt.xlabel("Hour")
plt.ylabel("Orders")
plt.title("Orders by Hour")
plt.show()
```

그래프를 통해 주문량이 오전부터 증가하여 12시에 가장 많아지고, 이후 감소하는 추세를 확인할 수 있다.

## 4. 흔한 시각화 오류

### Y축 범위를 잘라 차이를 과장하는 경우

A 지점의 매출이 98억 원이고 B 지점의 매출이 100억 원이라면 실제 차이는 2억 원이다. 그러나 막대그래프의 Y축을 90부터 시작하면 두 값의 차이가 실제보다 훨씬 크게 보일 수 있다.

```python
stores = ["A", "B"]
sales = [98, 100]

plt.bar(stores, sales)
plt.ylim(90, 101)
plt.show()
```

막대의 길이로 크기를 비교하는 그래프는 일반적으로 Y축을 0부터 시작해야 차이를 정직하게 보여줄 수 있다. 축을 생략하거나 범위를 조정해야 한다면 그 사실을 명확히 표시해야 한다.

### 파이차트를 지나치게 사용하는 경우

파이차트는 전체에 대한 구성비를 보여주는 데 사용할 수 있지만, 항목이 많거나 비율이 비슷하면 각도를 정확하게 비교하기 어렵다. 이때는 길이를 비교하기 쉬운 막대그래프가 더 적합하다.

### 목적보다 디자인을 먼저 선택하는 경우

화려한 색상, 3D 효과와 장식 요소가 많으면 핵심 데이터보다 디자인에 시선이 분산될 수 있다. 시각화에서는 전달할 메시지를 먼저 정하고, 그 메시지를 이해하는 데 필요한 요소만 사용하는 것이 중요하다.

## 5. 데이터 분포를 확인해야 하는 이유

데이터 분석 초기에는 값들이 어디에 몰려 있는지, 한쪽으로 치우쳐 있는지, 극단적으로 크거나 작은 값이 있는지 확인해야 한다. 분포를 이해해야 결측치와 이상치 처리, 데이터 변환, 모델 선택 등 다음 분석 방향을 적절하게 결정할 수 있다.

분포를 확인하는 대표적인 차트에는 히스토그램, KDE, 박스플롯이 있다. 세 차트는 같은 데이터를 서로 다른 관점에서 보여준다.

---

## 6. 히스토그램

히스토그램은 연속형 수치 데이터를 일정한 구간인 `bin`으로 나누고, 각 구간에 포함된 데이터의 빈도를 막대로 표현하는 차트이다.

- X축: 데이터 값의 범위
- Y축: 각 구간에 포함된 데이터의 개수
- 막대 사이: 연속된 구간을 나타내므로 일반적으로 간격이 없음

```python
import matplotlib.pyplot as plt

purchase_amounts = [
    12000, 15000, 18000, 22000, 25000,
    27000, 30000, 32000, 35000, 38000,
    42000, 45000, 47000, 50000, 52000,
    55000, 58000, 62000, 70000, 85000
]

plt.hist(purchase_amounts, bins=5, edgecolor="white")
plt.xlabel("구매 금액")
plt.ylabel("고객 수")
plt.title("고객 구매 금액 분포")
plt.show()
```

### `bins`의 영향

`bins`는 전체 데이터 범위를 몇 개의 구간으로 나눌지 지정하는 값이다.

| `bins` 설정 | 특징 |
|---|---|
| 너무 적음 | 분포가 지나치게 단순해져 세부 패턴이 사라질 수 있음 |
| 적절함 | 전체 모양과 세부 패턴을 균형 있게 확인할 수 있음 |
| 너무 많음 | 막대가 지나치게 세분화되어 노이즈가 많아 보일 수 있음 |

Matplotlib의 기본값은 10이며 `bins="auto"`도 사용할 수 있다. 모든 데이터에 공통으로 적용되는 하나의 정답은 없으므로 여러 값을 시도하여 중요한 패턴이 잘 드러나는 값을 선택해야 한다.

### 결측치를 제외한 히스토그램

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("customer_order_summary.csv")

plt.hist(df["avg_order_value"].dropna(), bins=15)
plt.title("Average Order Value Distribution")
plt.show()
```

`dropna()`를 사용하면 해당 열의 결측치를 제외한 값으로 그래프를 그릴 수 있다.

## 7. KDE

KDE(Kernel Density Estimation, 커널 밀도 추정)는 데이터의 분포를 부드러운 연속 곡선으로 추정하는 방법이다. 각 데이터 포인트 주변에 작은 커널을 배치하고 이를 합하여 전체 분포의 형태를 나타낸다.

히스토그램이 구간별 실제 빈도를 보여준다면 KDE는 값들이 어느 위치에 상대적으로 밀집되어 있는지를 보여준다. 여러 그룹의 전반적인 분포 모양을 한 그래프에서 비교할 때 유용하다.

```python
import seaborn as sns
import matplotlib.pyplot as plt

store_a = [20, 22, 23, 25, 25, 27, 28, 30, 31, 33, 35, 36, 38, 40, 42]
store_b = [30, 32, 34, 35, 37, 38, 40, 42, 43, 45, 47, 48, 50, 52, 55]

sns.kdeplot(store_a, label="A 매장", fill=True)
sns.kdeplot(store_b, label="B 매장", fill=True)
plt.xlabel("체류 시간(분)")
plt.ylabel("밀도")
plt.title("매장별 고객 체류 시간 분포")
plt.legend()
plt.show()
```

B 매장의 곡선이 A 매장의 곡선보다 오른쪽에 위치한다면 B 매장 고객의 체류 시간이 전반적으로 더 길다고 해석할 수 있다.

### KDE 해석 시 주의점

- Y축은 실제 데이터의 개수가 아니라 **확률 밀도**를 나타낸다.
- 곡선이 높다는 것은 그 주변에 데이터가 상대적으로 많이 분포한다는 의미이다.
- 부드럽게 추정한 곡선이므로 실제 데이터에 없는 구간까지 이어져 보일 수 있다.

## 8. 박스플롯

박스플롯은 데이터의 중심, 퍼짐 정도와 잠재적 이상치를 한눈에 확인하는 차트이다.

| 구성 요소 | 의미 |
|---|---|
| 박스 하단 | 제1사분위수(Q1, 25%) |
| 박스 내부의 선 | 중앙값(Q2, 50%) |
| 박스 상단 | 제3사분위수(Q3, 75%) |
| 박스 높이 | IQR = Q3 - Q1, 데이터의 중간 50% 범위 |
| 수염 | 일반적으로 Q1 - 1.5 × IQR부터 Q3 + 1.5 × IQR 범위 안의 값까지 표시 |
| 수염 바깥의 점 | IQR 기준으로 탐지된 잠재적 이상치 |

```python
import matplotlib.pyplot as plt

work_times = [
    20, 21, 22, 23, 23, 24, 24, 25, 25, 26,
    26, 27, 27, 28, 29, 30, 31, 32, 65, 72
]

plt.boxplot(work_times)
plt.ylabel("처리 시간(분)")
plt.title("업무 처리 시간 박스플롯")
plt.show()
```

이 그래프에서는 대부분의 작업 시간이 모여 있는 범위와 중앙값을 확인할 수 있으며, 65분과 72분은 수염 바깥의 점으로 표시될 수 있다.

### IQR과 이상치

IQR(Interquartile Range)은 데이터의 중간 50%가 차지하는 범위이다.

```text
IQR = Q3 - Q1
하한 기준 = Q1 - 1.5 × IQR
상한 기준 = Q3 + 1.5 × IQR
```

1.5 × IQR은 통계학자 존 튜키가 제안한 경험적 기준이다. 이 기준 밖의 값은 잠재적 이상치로 표시되지만, 반드시 오류 데이터라는 의미는 아니다. 실제로 발생한 의미 있는 극단값일 수 있으므로 분석 목적과 원본 데이터를 확인한 뒤 유지, 변환 또는 제거 여부를 판단해야 한다.

### 두 그룹의 박스플롯 비교

```python
online_days = online_df["delivery_days"].dropna()
offline_days = offline_df["delivery_days"].dropna()

plt.boxplot(
    [online_days, offline_days],
    tick_labels=["Online", "Offline"]
)
plt.ylabel("Delivery Days")
plt.title("Delivery Days by Channel")
plt.show()
```

하나의 그래프에 여러 그룹을 표시하면 중앙값, 데이터의 퍼짐 정도와 잠재적 이상치의 차이를 비교할 수 있다.

## 9. 히스토그램, KDE, 박스플롯 비교

| 차트 | 중점적으로 보여주는 정보 | 장점 | 주의점 |
|---|---|---|---|
| 히스토그램 | 구간별 빈도 | 어느 범위에 데이터가 많이 몰렸는지 직관적으로 확인 가능 | `bins`에 따라 모양이 달라짐 |
| KDE | 부드럽게 추정한 전체 분포 형태 | 여러 그룹의 분포 모양을 겹쳐 비교하기 좋음 | Y축은 실제 개수가 아닌 밀도임 |
| 박스플롯 | 중앙값, IQR, 잠재적 이상치 | 중심·퍼짐·이상치를 간결하게 비교 가능 | 세부적인 분포 모양은 알기 어려움 |

같은 데이터라도 질문에 따라 차트를 다르게 선택해야 한다.

- 어느 구간에 값이 많이 존재하는가? → 히스토그램
- 여러 집단의 전체적인 분포 모양이 어떻게 다른가? → KDE
- 중앙값과 퍼짐 정도, 잠재적 이상치를 빠르게 비교하고 싶은가? → 박스플롯

필요하다면 세 차트를 함께 사용하여 한 차트만으로는 확인하기 어려운 정보를 보완할 수 있다.

## 10. Matplotlib 한글 폰트 설정

Matplotlib의 기본 폰트가 한글을 지원하지 않으면 제목과 축 이름이 네모로 표시될 수 있다. 운영체제에 맞는 한글 폰트를 지정해야 한다.

```python
import matplotlib.pyplot as plt
import platform

if platform.system() == "Windows":
    plt.rcParams["font.family"] = "Malgun Gothic"
elif platform.system() == "Darwin":
    plt.rcParams["font.family"] = "AppleGothic"

plt.rcParams["axes.unicode_minus"] = False
```

`axes.unicode_minus = False`는 그래프의 마이너스 기호가 깨지는 현상을 방지한다.

## 11. 오늘 배운 내용 정리

### 시각화의 목적

- 패턴 발견: 데이터 속의 구조, 추세와 이상치를 탐색한다.
- 의사결정 지원: 분석 결과를 근거로 행동을 선택하도록 돕는다.
- 커뮤니케이션: 핵심 메시지를 이해관계자에게 명확하게 전달한다.

### 차트 선택 순서

```text
변수의 개수 확인
    ↓
전달 목적 확인
    ↓
목적에 맞는 차트 선택
    ↓
축·범례·색상 등을 점검하여 왜곡 없이 표현
```

### 분포 차트

- `plt.hist()` → 연속형 데이터를 구간별 빈도로 표현
- `sns.kdeplot()` → 전체 분포를 부드러운 밀도 곡선으로 표현
- `plt.boxplot()` → 중앙값, IQR과 잠재적 이상치를 표현
- `dropna()` → 결측치를 제외하고 시각화할 때 사용
- `bins` → 히스토그램의 구간 개수를 조정
- `fill=True` → KDE 곡선 아래 영역을 색으로 채움
- `plt.legend()` → 여러 그룹의 범례를 표시

## 12. 느낀 점

오늘은 그래프를 그리는 방법보다 먼저 **왜 이 그래프를 그리는지 생각하는 과정**이 중요하다는 것을 배웠다. 같은 데이터라도 패턴을 탐색할 때와 다른 사람에게 결과를 설명할 때 필요한 그래프의 형태가 달라질 수 있기 때문이다.

특히 차트를 선택할 때 변수의 개수만 보는 것이 아니라 분포, 관계, 비교, 추세, 구성비 중 무엇을 보여주려는지 함께 판단해야 한다는 점이 인상적이었다. 앞으로는 익숙한 차트를 바로 사용하는 대신, 분석 질문과 차트가 실제로 일치하는지 먼저 확인해야겠다.

또한 히스토그램, KDE, 박스플롯은 모두 분포를 보여주지만 강조하는 정보가 다르다는 것을 알게 되었다. 히스토그램에서는 구간별 빈도, KDE에서는 전체적인 분포 모양, 박스플롯에서는 중앙값과 이상치를 확인할 수 있었다. 하나의 차트만 보고 결론을 내리기보다 여러 시각화를 함께 비교하여 데이터를 더 정확하게 해석하는 연습을 해야겠다.

마지막으로 박스플롯에서 이상치로 표시된 값을 무조건 삭제해서는 안 된다는 점을 기억해야겠다. 그 값이 입력 오류인지 실제로 발생한 의미 있는 극단값인지 확인한 뒤 분석 목적에 맞게 처리하는 습관을 기르고 싶다.
