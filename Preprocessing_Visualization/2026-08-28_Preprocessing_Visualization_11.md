## 1. 통계란?

통계(Statistics)는 데이터를 수집·정리·분석하여 의미를 찾고, 그 결과를 실제 의사결정에 활용하는 학문이다. 단순히 숫자를 계산하는 것이 아니라 데이터를 통해 현실을 이해하고 판단하는 전체 과정을 포함한다.

일상에서도 통계는 다양하게 사용된다.

- 여론조사: 일부 사람에게 질문하여 전체 유권자의 의견을 추정한다.
- 평균 연봉: 여러 사람의 연봉을 하나의 대표값으로 요약한다.
- 배송 예상 시간: 과거 배송 데이터를 분석하여 새로운 주문의 도착 시간을 예상한다.
- 마케팅 분석: 캠페인이 고객의 클릭이나 구매에 효과가 있었는지 판단한다.

### 평균 배송 시간 계산

쇼핑몰은 모든 주문의 배송 시간을 미리 정확하게 알 수 없다. 대신 과거 배송 시간을 이용해 평균적인 소요 시간을 계산하고 이를 새로운 주문의 예상 배송 시간에 활용할 수 있다.

```python
delivery_hours = [20, 24, 22, 26, 23]

average_hours = sum(delivery_hours) / len(delivery_hours)

print("평균 배송 시간:", average_hours, "시간")
```

결과:

```text
평균 배송 시간: 23.0 시간
```

이처럼 통계값은 데이터의 특징을 간단하게 요약하고 실제 상황을 판단하는 근거가 된다.

## 2. 기술통계와 추론통계

통계는 크게 기술통계와 추론통계로 나눌 수 있다.

### 기술통계

기술통계(Descriptive Statistics)는 **현재 가지고 있는 데이터를 요약하고 설명하는 방법**이다.

예를 들어 고객 100명의 만족도를 조사하여 평균이 4.2점이었다면 다음 문장은 기술통계에 해당한다.

> 조사에 참여한 고객 100명의 평균 만족도는 4.2점이다.

실제로 수집한 100명의 데이터만 설명하고 있기 때문이다.

대표적인 기술통계 방법은 다음과 같다.

- 중심경향치: 평균, 중앙값, 최빈값
- 산포도: 분산, 표준편차
- 위치 통계량: 백분위수, 사분위수
- 시각화: 히스토그램, 박스플롯

### 추론통계

추론통계(Inferential Statistics)는 **일부 표본 데이터를 이용하여 더 큰 모집단의 특성을 추론하는 방법**이다.

같은 만족도 조사 결과를 보고 다음과 같이 말한다면 추론통계에 해당한다.

> 조사에 참여한 고객의 반응을 보면 전체 고객도 높은 만족도를 보일 것으로 예상된다.

실제로 조사한 고객을 넘어 전체 고객에 관한 결론을 내리고 있기 때문이다.

대표적인 추론통계 방법에는 신뢰구간, 가설검정, 회귀분석 등이 있다.

### 기술통계와 추론통계 비교

| 구분 | 기술통계 | 추론통계 |
|---|---|---|
| 목적 | 수집한 데이터의 요약과 설명 | 모집단에 대한 결론 도출 |
| 데이터 범위 | 현재 가지고 있는 데이터 | 표본에서 모집단으로 일반화 |
| 주요 방법 | 평균, 중앙값, 표준편차, 시각화 | 신뢰구간, 가설검정, 회귀분석 |
| 예시 | 지난달 매출 평균은 500만 원이다 | 광고가 전체 고객의 매출에 효과가 있을 것이다 |

같은 데이터라도 질문에 따라 관점이 달라진다.

```text
수집한 고객 100명의 평균 만족도는 4.2점이다.
→ 기술통계

표본 결과를 바탕으로 전체 고객의 만족도도 높을 것이라고 예상한다.
→ 추론통계
```

### 추론통계가 필요한 이유

현실에서는 모집단 전체를 조사하기 어렵거나 비용이 지나치게 많이 들 수 있다. 전 국민의 소득, 모든 고객의 만족도, 전 세계 사용자의 클릭 패턴 등을 전부 조사하는 것은 현실적이지 않다.

따라서 모집단에서 일부를 표본으로 뽑아 분석하고, 그 결과를 바탕으로 모집단의 특성을 추론한다.

## 3. 모집단과 표본

### 모집단

모집단(Population)은 분석을 통해 궁극적으로 알고 싶은 대상 전체이다.

예를 들어 배달 앱 회사가 전체 사용자 100만 명의 평균 주문 금액을 알고 싶다면 100만 명의 전체 사용자가 모집단이다.

### 표본

표본(Sample)은 모집단에서 실제 조사나 분석을 위해 선택한 일부이다.

전체 사용자 100만 명 중 1,000명의 주문 금액을 조사했다면 이 1,000명이 표본이다.

```python
all_users = [
    "사용자1",
    "사용자2",
    "사용자3",
    "사용자4",
    "사용자5"
]

sample_users = all_users[:2]

print("모집단:", all_users)
print("표본:", sample_users)
```

결과:

```text
모집단: ['사용자1', '사용자2', '사용자3', '사용자4', '사용자5']
표본: ['사용자1', '사용자2']
```

### 대표성 있는 표본의 중요성

표본을 이용해 모집단을 정확하게 추론하려면 표본이 모집단의 특성을 잘 반영해야 한다.

예를 들어 쇼핑몰 전체 고객의 만족도를 조사하면서 VIP 고객만 표본으로 선택하면 조사 결과가 전체 고객의 의견을 대표하지 못할 수 있다. 이러한 문제를 표본 편향이라고 한다.

표본의 크기가 크더라도 특정 집단만 포함되어 있다면 결과가 편향될 수 있다. 따라서 표본의 크기뿐 아니라 **어떤 방식으로 표본을 추출했는지**가 중요하다.

## 4. 통계 분석의 기본 흐름

통계 분석은 바로 계산이나 모델링부터 시작하는 것이 아니라 단계적으로 진행한다.

```text
문제 정의
    ↓
데이터 수집 및 표본 설계
    ↓
EDA와 데이터 품질 점검
    ↓
기술통계로 데이터 요약
    ↓
필요한 경우 추론통계 적용
    ↓
결과 해석 및 의사결정
```

예를 들어 쇼핑몰 매출 감소 원인을 분석한다면 먼저 결측치, 이상치와 자료형을 확인한다. 이후 평균, 중앙값, 표준편차와 시각화를 이용해 데이터를 요약하고, 필요하면 가설검정이나 회귀분석을 통해 원인에 관한 근거를 검토한다.

## 5. 중심경향치란?

중심경향치는 데이터가 전체적으로 어느 값을 중심으로 모여 있는지 나타내는 대표값이다.

대표적인 중심경향치는 다음 세 가지이다.

- 평균(Mean): 모든 값을 더한 뒤 개수로 나눈 값
- 중앙값(Median): 데이터를 정렬했을 때 가운데에 위치한 값
- 최빈값(Mode): 데이터에서 가장 자주 등장한 값

세 지표는 모두 데이터를 하나의 값으로 요약하지만 특징이 다르다. 데이터의 유형, 분포와 이상치 유무에 따라 적절한 대표값을 선택해야 한다.

---

## 6. 산술평균

산술평균(Arithmetic Mean)은 모든 값을 더한 뒤 데이터의 개수로 나눈 값이다.

$$
\bar{x}=\frac{x_1+x_2+\cdots+x_n}{n}
$$

```python
import pandas as pd

ratings = pd.Series([4, 5, 3, 4, 5])

print(ratings.mean())
```

결과:

```text
4.2
```

모든 관측값을 계산에 사용하기 때문에 데이터 전체의 정보를 반영한다. 반면 극단적으로 크거나 작은 값의 영향도 크게 받는다.

```python
scores = pd.Series([70, 75, 80, 85, 200])

print(scores.mean())
```

결과:

```text
102.0
```

대부분의 점수는 70점에서 85점 사이이지만 이상치인 200점이 평균을 102점까지 끌어올렸다. 따라서 평균을 사용할 때는 이상치와 분포의 형태를 함께 확인해야 한다.

---

## 7. 가중평균

가중평균(Weighted Mean)은 모든 값을 동일하게 반영하지 않고, 각 값에 서로 다른 중요도나 비중인 가중치를 적용한 평균이다.

$$
\bar{x}_w=\frac{\sum_{i=1}^{n}w_ix_i}{\sum_{i=1}^{n}w_i}
$$

```python
import numpy as np

scores = [80, 90]
weights = [0.4, 0.6]

weighted_mean = np.average(scores, weights=weights)

print(weighted_mean)
```

결과:

```text
86.0
```

중간고사 80점을 40%, 기말고사 90점을 60% 반영한 결과이다.

### 가중평균을 사용하는 경우

- 중간고사와 기말고사의 반영 비율이 다를 때
- 학점 수가 다른 과목의 전체 평점을 계산할 때
- 자산별 투자 비중을 반영해 포트폴리오 수익률을 계산할 때
- 집단별 응답자 수를 반영해 설문 결과를 통합할 때

모든 값의 중요도가 같다면 산술평균을 사용하고, 각 값의 비중이 다르면 가중평균을 사용한다.

## 8. Pandas와 NumPy 자료형 변환

Pandas와 NumPy의 기능을 함께 사용하려면 `Series`나 `DataFrame`을 NumPy 배열로 변환하거나, 배열을 다시 Pandas 객체로 변환할 수 있다.

### Series와 NumPy 배열 변환

```python
import pandas as pd
import numpy as np

scores = pd.Series([70, 80, 90])

# Series → NumPy array
scores_array = scores.to_numpy()

# NumPy array → Series
scores_series = pd.Series(scores_array)

print(scores_array)
print(scores_series)
```

### DataFrame과 2차원 배열 변환

```python
df = pd.DataFrame({
    "score": [70, 80, 90],
    "hours": [2, 3, 5]
})

# DataFrame → NumPy array
data_array = df.to_numpy()

# NumPy array → DataFrame
new_df = pd.DataFrame(
    data_array,
    columns=["score", "hours"]
)
```

## 9. 중앙값

중앙값(Median)은 데이터를 크기순으로 정렬했을 때 가운데에 위치하는 값이다.

- 데이터 개수가 홀수이면 가운데 값을 사용한다.
- 데이터 개수가 짝수이면 가운데 두 값의 평균을 사용한다.

```python
import pandas as pd

salaries = pd.Series([
    3200, 3500, 3700, 4000, 4200, 4500, 15000
])

print("평균:", salaries.mean())
print("중앙값:", salaries.median())
```

결과:

```text
평균: 5414.285714285715
중앙값: 4000.0
```

대부분의 직원은 3,200만 원에서 4,500만 원 사이의 연봉을 받지만 한 명의 연봉은 1억 5천만 원이다. 이 값 때문에 평균은 크게 증가하지만 중앙값은 정렬된 데이터의 가운데 값인 4,000만 원이다.

```text
3200  3500  3700  [4000]  4200  4500  15000
                     ↑
                   중앙값
```

연봉, 주택 가격, 구매 금액처럼 극단적으로 큰 값이 나타나기 쉬운 데이터에서는 중앙값이 일반적인 수준을 더 잘 나타낼 수 있다.

### 평균과 중앙값 비교

| 데이터 상태 | 평균 | 중앙값 | 적합한 대표값 |
|---|---|---|---|
| 대칭이고 이상치가 거의 없음 | 전체 값을 잘 반영 | 평균과 비슷함 | 평균 |
| 큰 이상치가 존재함 | 위쪽으로 크게 변함 | 영향이 비교적 작음 | 중앙값 |
| 작은 이상치가 존재함 | 아래쪽으로 크게 변함 | 영향이 비교적 작음 | 중앙값 |

중앙값이 이상치의 영향을 **전혀 받지 않는 것**은 아니지만 평균보다 훨씬 덜 민감하다.

## 10. 최빈값

최빈값(Mode)은 데이터에서 가장 자주 등장한 값이다.

결제 방법이나 상품 카테고리처럼 숫자로 평균을 계산할 수 없는 범주형 데이터의 대표적인 값을 찾을 때 유용하다.

```python
import pandas as pd

payment_methods = pd.Series([
    "카드",
    "간편결제",
    "카드",
    "계좌이체",
    "카드",
    "간편결제"
])

print(payment_methods.mode())
```

결과:

```text
0    카드
dtype: object
```

`카드`가 세 번으로 가장 자주 등장하므로 최빈값이다.

### 최빈값이 여러 개인 경우

최빈값은 반드시 하나만 존재하지 않는다.

```python
sizes = pd.Series([260, 265, 265, 270, 270, 275])

print(sizes.mode())
```

결과:

```text
0    265
1    270
dtype: int64
```

265와 270이 각각 두 번씩 등장하므로 두 값 모두 최빈값이다. 두 개 이상의 값이 가장 높은 빈도를 가지는 분포를 이봉 또는 다봉 분포라고 한다.

`mode()`는 여러 값을 반환할 수 있으므로 결과가 `Series` 형태라는 점도 주의해야 한다. 첫 번째 최빈값만 필요하다면 `series.mode().iloc[0]`처럼 가져올 수 있지만, 다른 최빈값이 사라질 수 있다는 점을 고려해야 한다.

### 수치형 데이터의 최빈값

수치형 데이터에도 최빈값을 사용할 수 있다. 다만 연속형 데이터는 같은 값이 반복될 가능성이 낮아 최빈값의 의미가 작을 수 있다. 신발 사이즈처럼 정해진 값이 반복되는 이산형 수치 데이터에서는 최빈값이 유용하다.

## 11. 데이터 유형에 따른 대표값 선택

| 데이터 유형 | 예시 | 사용할 수 있는 대표값 |
|---|---|---|
| 명목형 | 결제 수단, 상품 카테고리 | 최빈값 |
| 순서형 | 만족도 등급, 회원 등급 | 중앙값, 최빈값 |
| 수치형 | 매출, 연봉, 배송 시간 | 평균, 중앙값, 최빈값 |

수치형 데이터라고 항상 평균을 사용해야 하는 것은 아니다. 데이터의 분포가 치우쳐 있거나 이상치가 존재한다면 중앙값을 함께 확인해야 한다.

## 12. 왜도

왜도(Skewness)는 데이터 분포가 좌우 대칭에서 어느 방향으로 얼마나 치우쳐 있는지 나타내는 값이다.

- 왜도 ≈ 0: 좌우가 대체로 대칭인 분포
- 왜도 > 0: 오른쪽 꼬리가 긴 양의 왜도
- 왜도 < 0: 왼쪽 꼬리가 긴 음의 왜도

```python
import pandas as pd

purchase_amounts = pd.Series([
    3, 4, 4, 5, 5, 6, 7, 8, 30, 50
])

print("평균:", purchase_amounts.mean())
print("중앙값:", purchase_amounts.median())
print("왜도:", purchase_amounts.skew())
```

결과:

```text
평균: 12.2
중앙값: 5.5
왜도: 2.2768099586398025
```

대부분의 고객은 3만 원에서 8만 원 정도를 구매했지만 일부 고객의 구매 금액은 30만 원과 50만 원이다. 큰 값이 오른쪽 꼬리를 길게 만들고 평균을 12.2만 원까지 끌어올렸다.

### 왜도와 평균·중앙값의 관계

| 왜도 | 분포 형태 | 일반적인 관계 | 대표값 선택 |
|---|---|---|---|
| 약 0 | 대칭 | 평균 ≈ 중앙값 | 평균 사용 가능 |
| 양수 | 오른쪽 꼬리가 김 | 평균 > 중앙값 | 중앙값도 함께 확인 |
| 음수 | 왼쪽 꼬리가 김 | 평균 < 중앙값 | 중앙값도 함께 확인 |

왜도의 부호만으로 대표값을 기계적으로 결정하기보다 히스토그램, 박스플롯, 이상치와 분석 목적을 함께 확인해야 한다.

### 왜도가 나타나는 실제 데이터

- 연봉: 소수의 고액 연봉자가 평균을 끌어올린다.
- 이커머스 구매 금액: 일부 VIP 고객의 큰 지출로 오른쪽 꼬리가 길어진다.
- 서버 응답 시간: 일부 지연 요청 때문에 양의 왜도가 나타날 수 있다.
- 병원 재원 기간: 일부 장기 입원 환자가 평균 재원 기간을 늘린다.

서버 응답 시간처럼 긴 지연이 중요한 데이터는 평균이나 중앙값뿐 아니라 P95, P99와 같은 높은 백분위수도 확인한다.

## 13. 백분위수와 사분위수

백분위수(Percentile)는 데이터를 작은 값부터 정렬했을 때 특정 비율의 데이터가 그 값 이하에 위치하도록 나누는 기준이다.

예를 들어 P90은 전체 데이터의 약 90%가 해당 값 이하에 있다는 의미이다.

사분위수(Quartile)는 데이터를 네 부분으로 나누는 백분위수이다.

- Q1: 제1사분위수, 25번째 백분위수
- Q2: 제2사분위수, 50번째 백분위수이며 중앙값과 같음
- Q3: 제3사분위수, 75번째 백분위수

```python
import numpy as np

delivery_hours = [20, 22, 24, 25, 26, 28, 30, 32, 36, 40]

p90 = np.percentile(delivery_hours, 90)
q1 = np.percentile(delivery_hours, 25)
q2 = np.percentile(delivery_hours, 50)
q3 = np.percentile(delivery_hours, 75)

print("P90:", p90)
print("Q1:", q1)
print("Q2:", q2)
print("Q3:", q3)
```

백분위수는 고객의 상위 구매 금액 기준, 시험 점수의 위치, 배송 지연 기준과 서비스 응답 시간의 SLA 등을 설정할 때 활용할 수 있다.

NumPy나 Pandas의 계산 방식에 따라 데이터 사이의 위치를 보간하는 방법이 다를 수 있으므로, 도구나 옵션이 달라지면 결과에 작은 차이가 생길 수 있다.

## 14. 평균·중앙값·최빈값 비교

| 대표값 | 계산 또는 기준 | 장점 | 한계 | 적합한 상황 |
|---|---|---|---|---|
| 평균 | 모든 값의 합 ÷ 개수 | 모든 값을 반영 | 이상치에 민감 | 대칭적인 수치형 데이터 |
| 중앙값 | 정렬했을 때 가운데 값 | 이상치에 비교적 강함 | 모든 값의 크기를 직접 반영하지 않음 | 치우친 수치형·순서형 데이터 |
| 최빈값 | 가장 자주 등장한 값 | 범주형 데이터에도 사용 가능 | 없거나 여러 개일 수 있음 | 결제 수단, 상품 종류, 이산형 데이터 |

대표값 선택 흐름은 다음과 같이 정리할 수 있다.

```text
데이터가 범주형인가?
    ├─ 예 → 최빈값 확인
    └─ 아니요 → 수치형 데이터
                 ↓
           이상치나 왜도가 큰가?
              ├─ 예 → 중앙값 중심으로 확인
              └─ 아니요 → 평균 사용 가능

※ 실제 분석에서는 평균과 중앙값을 함께 비교하는 것이 좋다.
```

## 15. 오늘 배운 내용 정리

### 통계의 기본 개념

- 통계는 데이터를 수집·정리·분석하여 의사결정에 활용하는 방법이다.
- 기술통계는 현재 가지고 있는 데이터를 요약하고 설명한다.
- 추론통계는 표본을 이용하여 모집단의 특성을 추론한다.
- 모집단은 알고 싶은 대상 전체이고, 표본은 실제 분석을 위해 선택한 일부이다.
- 표본을 이용한 추론에서는 표본의 대표성이 중요하다.

### 중심경향치

- `Series.mean()` → 산술평균 계산
- `np.average(values, weights=...)` → 가중평균 계산
- `Series.median()` → 중앙값 계산
- `Series.mode()` → 최빈값을 `Series`로 반환
- `Series.skew()` → 분포의 왜도 계산
- `np.percentile(data, q)` → q번째 백분위수 계산

### 대표값 선택

- 대칭적이고 이상치가 적은 수치형 데이터 → 평균
- 이상치가 있거나 치우친 수치형 데이터 → 중앙값도 함께 확인
- 범주형 또는 반복되는 이산형 데이터 → 최빈값
- 값마다 중요도가 다른 데이터 → 가중평균

## 16. 느낀 점

오늘은 통계가 단순히 평균을 계산하는 과목이 아니라, 데이터를 통해 현실을 이해하고 의사결정을 내리는 방법이라는 것을 배웠다. 현재 데이터를 설명하는 기술통계와 일부 데이터를 통해 전체를 판단하는 추론통계의 차이도 알게 되었다.

특히 표본의 크기만 크면 되는 것이 아니라 모집단을 잘 대표하도록 추출해야 한다는 점이 중요하다고 느꼈다. 앞으로 설문이나 사용자 데이터를 볼 때 분석 대상 전체가 누구인지, 실제 데이터는 어떤 방식으로 수집되었는지 먼저 확인해야겠다.

평균은 가장 익숙한 대표값이지만 이상치의 영향을 크게 받을 수 있다는 점도 다시 확인했다. 연봉이나 구매 금액처럼 일부 큰 값이 존재하는 데이터에서는 평균만 보면 일반적인 수준을 잘못 판단할 수 있으므로 중앙값과 왜도를 함께 살펴봐야 한다.

또한 결제 방법이나 상품 카테고리처럼 숫자가 아닌 데이터에서는 평균이 아니라 최빈값이 적합하다는 것을 배웠다. 앞으로는 대표값을 습관적으로 선택하지 않고 데이터의 유형, 분포, 이상치와 분석 목적을 먼저 확인한 뒤 가장 적절한 지표를 사용해야겠다.
