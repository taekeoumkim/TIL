# TIL | 2026-11-19 — 이미지 전처리·데이터 증강과 누수 방지

정상 제품과 불량 제품을 분류하는 사례를 통해 이미지의 크기와 픽셀 값을 모델 입력에 맞추는 방법을 배웠다. 같은 제품의 사진을 어느 데이터셋에 배치하는지, 이미지 변환 후에도 결함과 라벨이 일치하는지가 평가 결과에 영향을 준다.

## 1. 이미지 전처리와 데이터 증강

| 작업 | 적용 방법 | 확인할 점 |
| --- | --- | --- |
| 크기 조정 | Resize로 목표 크기에 맞추거나 Crop·Padding을 조합한다. | 직접 변환하면 종횡비가 달라질 수 있다. 자르기는 가장자리 정보를 잃을 수 있고, 여백 추가는 원본 영역을 보존하지만 입력에 여백을 만든다. |
| 픽셀 값 변환 | 일반적인 8비트 RGB 픽셀을 실수형으로 바꾸고 255로 나눈다. | 0~255가 0~1로 바뀐다. 필요한 경우 채널별 평균·표준편차로 추가 정규화한다. |
| 데이터 증강 | 좌우 반전, 회전, 밝기 변경, 무작위 자르기를 적용한다. | 실제 환경에서 가능한 변화인지, 변환 후에도 라벨과 핵심 특징이 유지되는지 확인한다. |

평균과 표준편차를 이용한 변환은 `(픽셀 값 - 평균) / 표준편차`로 계산한다. 예를 들어 0~1 값에 평균과 표준편차를 모두 0.5로 적용하면 범위가 -1~1이 된다. 사전학습 모델을 쓸 때는 해당 가중치의 권장 크기, 채널, 자료형, 정규화 기준을 확인한다.

상품 종류 분류에는 전체 형태가 중요할 수 있고, 표면 결함 분류에는 작은 흠집과 위치 정보가 중요할 수 있다. 불량 제품 사진에서 균열이 있는 영역을 잘라내면 변환된 이미지와 `불량` 라벨이 어긋날 수 있다. 방향이 정답에 영향을 주는 데이터에서는 반전과 회전의 범위를 확인하고, 색상 분류에서는 밝기 변경이 색상 구분에 미치는 영향을 살핀다.

## 2. 데이터셋 분할과 데이터 누수

| 데이터셋 | 역할 |
| --- | --- |
| Train | 모델 가중치를 학습한다. |
| Validation | 모델과 하이퍼파라미터를 선택하고 전처리 변경의 효과를 비교한다. |
| Test | 선택을 마친 모델의 일반화 성능을 최종 평가한다. |

분할 비율은 데이터 규모와 평가 목적에 따라 정한다. 정상 900장과 불량 100장을 70:15:15로 층화 분할하는 예에서는 불량 이미지가 각각 70장, 15장, 15장 들어간다. **층화 분할(Stratified Split)**은 클래스 비율을 유지하는 데 쓰인다. 동일한 제품을 여러 각도에서 촬영했다면 **그룹 분할**로 제품 ID가 같은 사진을 한 데이터셋에 배치한다.

제품 A의 정면 사진이 Train에 있고 측면 사진이 Test에 있으면, 평가 결과에 학습 중 접한 제품의 특징이 반영될 수 있다. 같은 이미지의 중복이나 원본과 증강본이 서로 다른 데이터셋에 섞이는 경우도 누수의 원인이 된다. 원본의 중복과 제품 ID를 확인하고 분할한 뒤, 학습 데이터에 증강을 적용한다.

### 그룹 분할에서 확인할 것

학습자료의 예시는 제품 10개에 사진이 두 장씩 있다. `GroupShuffleSplit`으로 제품 2개를 Test에 먼저 배정하고, 남은 8개 중 25%인 2개를 Validation에 배정하면 Train에는 6개가 남는다. 사진 수로는 각각 Train 12장, Validation 4장, Test 4장이다.

`test_size`는 그룹 수를 기준으로 적용된다. 제품마다 사진 수가 다르면 이미지 비율은 달라질 수 있다. 분할 후에는 제품 ID 집합끼리 교집합이 없는지 검사하고, 데이터셋별 이미지 수와 클래스 분포도 확인한다. 그룹 분할의 클래스 비율은 별도로 확인해야 한다.

## 3. 학습용·평가용 전처리 구성

Train에는 모델이 요구하는 기본 전처리와 라벨을 보존하는 무작위 증강을 적용한다. Validation과 Test는 일관된 조건에서 성능을 비교할 수 있도록 크기 조정과 정규화 등을 고정한다. 정규화 통계를 직접 구할 때는 Train의 평균과 표준편차를 계산해 세 데이터셋에 동일하게 적용한다.

```python
from torchvision import transforms

resize = transforms.Resize((224, 224))
to_tensor = transforms.ToTensor()
normalize = transforms.Normalize(mean=[0.5] * 3, std=[0.5] * 3)

train_transform = transforms.Compose([
    resize,
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.ColorJitter(brightness=0.2),
    to_tensor,
    normalize,
])

eval_transform = transforms.Compose([
    resize,
    to_tensor,
    normalize,
])
```

학습용 예시에서 두 파이프라인 모두 RGB 이미지 한 장을 `(3, 224, 224)` 텐서로 변환한다. `ToTensor()`가 일반적인 8비트 RGB 픽셀을 0~1 범위로 조정한 뒤 `Normalize()`가 예시 통계를 적용한다. 변환이 끝나면 크기·채널·자료형·값 범위를 확인하고, 샘플 이미지를 보면서 결함이 남아 있는지 확인한다. 전처리를 변경했을 때의 효과는 동일한 Validation 데이터에서 비교한다.

## 배운 점

새로운 제품에 대한 성능을 평가하려면 사진 한 장보다 **제품 하나**를 분할 단위로 삼는 편이 평가 목적에 맞다. 전처리에서는 최종 텐서 크기가 같더라도, 잘려 나간 결함이나 바뀐 방향 때문에 라벨의 근거가 달라질 수 있다는 점을 배웠다.
