상품 이미지의 임베딩을 K-Means로 묶고, 군집 중심에 가까운 대표 이미지를 선택하는 방법을 배웠다. 군집별 실제 이미지와 메타데이터를 함께 살펴 공통적인 시각적 특징을 해석하는 과정까지 학습했다.

## 1. 이미지 군집화와 K-Means

이미지 군집화는 정답 라벨 없이 유사한 특징의 이미지를 그룹화하는 비지도학습이다. 이미지 분류가 정의된 클래스를 예측하는 데 쓰인다면 군집화는 데이터의 형태·색상·촬영 방식 등에 나타나는 패턴을 탐색한다.

```text
원본 이미지 → 동일한 특징 추출 모델 → 임베딩
→ K-Means → 이미지별 군집 번호 → 실제 이미지 해석
```

ResNet18로 이미지 1,000장의 특징을 추출하면 임베딩 Shape는 `(1000, 512)`가 될 수 있다. K-Means는 각 이미지의 벡터를 입력받아 군집 번호 1,000개를 반환한다.

### K-Means의 반복 과정

1. 군집 수 K를 정하고 중심 벡터들을 초기화한다.
2. 각 임베딩을 가장 가까운 중심에 할당한다.
3. 군집 내 벡터의 평균으로 중심을 갱신한다.
4. 할당과 갱신을 반복한다.

K-Means는 유클리드 거리를 기반으로 동작한다. 결과 번호 0, 1, 2는 그룹 식별자이며 실제 상품명은 구성 이미지를 보고 해석한다. 임베딩 모델이 배경이나 색상을 강하게 반영하면 상품 종류가 섞인 군집이 형성될 수 있다.

K를 늘리면 그룹이 더 세분화될 수 있다. 분석 목적, 군집별 구성 이미지, Silhouette Score 등의 지표를 함께 살펴 적절한 값을 선택한다.

## 2. 군집 중심과 대표 이미지

군집 중심(Centroid)은 해당 군집 벡터들의 평균이다. 실제 이미지 중 중심까지의 거리가 가장 짧은 이미지를 대표 사례로 선택할 수 있다.

```text
군집별 중심 확인 → 소속 이미지와 중심의 거리 계산
→ 가장 가까운 이미지 선택 → 다른 구성 이미지와 비교
```

다음은 학습자료의 가상 2차원 임베딩으로 군집화와 대표 사례 선택을 연결한 예시다.

```python
import numpy as np
import pandas as pd
from sklearn.cluster import KMeans

images = ["운동화 A", "운동화 B", "운동화 C", "가방 A", "가방 B", "가방 C"]
embeddings = np.array([
    [1.0, 1.0], [1.2, 0.9], [0.9, 1.1],
    [5.0, 5.0], [5.2, 4.9], [4.9, 5.1],
])

model = KMeans(n_clusters=2, random_state=42, n_init=10)
clusters = model.fit_predict(embeddings)

assigned_centers = model.cluster_centers_[clusters]
distances = np.linalg.norm(embeddings - assigned_centers, axis=1)

result = pd.DataFrame({
    "image": images,
    "cluster": clusters,
    "distance": distances,
})

representatives = (
    result.sort_values("distance")
    .groupby("cluster")
    .head(1)
)

print(result)
print(representatives)
```

| 기능 | 역할 |
| --- | --- |
| `fit_predict()` | 중심을 학습하고 이미지별 군집 번호 반환 |
| `cluster_centers_` | 군집별 중심 벡터 |
| `cluster_centers_[clusters]` | 각 이미지에 대응하는 소속 군집 중심 |
| `np.linalg.norm(..., axis=1)` | 각 이미지 벡터와 중심의 거리 |
| `groupby("cluster").head(1)` | 거리순 정렬 결과에서 군집별 첫 행 선택 |

이 예시는 운동화와 가방 벡터가 각각 가까이 배치되도록 만든 데이터다. 실제 분석에서는 모델이 생성한 임베딩과 원본 파일 경로를 연결한다. 군집 번호가 어느 상품 그룹에 해당하는지는 실행 결과에서 확인한다.

대표 이미지와 함께 중심에서 먼 이미지도 살펴본다. 중심 근처에서는 평균적인 패턴을, 먼 사례에서는 군집 내부의 다양성이나 부적절한 포함 가능성을 확인할 수 있다.

## 3. 시각적 패턴과 군집 프로파일링

| 확인 항목 | 질문 |
| --- | --- |
| 형태 | 비슷한 물체 형태가 반복되는가? |
| 색상 | 특정 색상이 집중되는가? |
| 질감 | 재질이나 표면 패턴이 비슷한가? |
| 촬영 방식 | 배경·각도·구도가 유사한가? |
| 공통 객체 | 같은 종류의 물체가 많이 나타나는가? |

군집 프로파일링은 군집별 이미지 수·비율, 대표 이미지, 공통 특징과 다른 군집과의 차이를 요약하는 과정이다. 대표 한 장과 여러 구성 이미지를 비교하고 상품 카테고리, 촬영 방식 등 별도로 확인한 메타데이터의 분포도 활용한다.

```python
# df에는 image, cluster, photo_type 컬럼이 있다고 가정
cluster_counts = df.groupby("cluster").size()
cluster_ratios = cluster_counts / len(df)
photo_counts = pd.crosstab(df["cluster"], df["photo_type"])

print(cluster_counts)
print(cluster_ratios)
print(photo_counts)
```

이 집계는 비어 있지 않은 결과 테이블을 가정한다. 촬영 방식은 실제 이미지를 확인해 기록한 정보를 연결한다. 흰색 배경 이미지가 특정 군집에 많다면 배경과 관련된 특징이 반영됐을 가능성을 검토할 수 있다.

## 4. 도메인 인사이트와 추가 검증

| 단계 | 예시 |
| --- | --- |
| 관찰 | 한 군집에는 흰색 배경 이미지가, 다른 군집에는 착용 장면이 많음 |
| 해석 | 임베딩이 촬영 방식의 특징을 반영했을 가능성 |
| 업무 활용 | 상품 이미지 구성의 다양성과 부족한 촬영 유형 검토 |
| 추가 검증 | 카테고리·촬영 방식 분포 확인, 필요한 경우 사용자 행동 데이터와 연계 |

제조에서는 표면 질감과 결함 형태, 의료에서는 영상의 형태와 촬영 특성, 스포츠에서는 자세와 경기 장면 등의 분포를 탐색할 수 있다. 군집의 업무상 의미는 실제 이미지와 관련 정보를 확인해 부여한다.

특정 군집에 불량 제품이 많아도 전체 구성원의 품질을 개별적으로 확인해야 한다. 촬영 방식과 구매 전환율의 관계를 알고 싶다면 별도 행동 데이터와 검증이 필요하다.

## 배운 점

군집 크기와 대표 이미지 한 장만으로는 어떤 기준으로 묶였는지 충분히 알기 어렵다. 중심에 가까운 사례와 먼 사례를 함께 확인하고 메타데이터 분포를 비교하면, 상품 종류를 모았는지 촬영 배경을 모았는지를 구체적으로 해석할 수 있다.
