# TIL | 2026-11-24 — VLM과 이미지·텍스트 기반 분석

상품 사진의 색상과 형태를 설명하는 사례를 통해 VLM의 역할을 배웠다. 이미지 분류·객체 탐지·세그멘테이션과 필요한 출력이 어떻게 다른지 비교하고, 이미지에서 확인할 수 있는 정보를 질문과 연결하는 방법을 살펴봤다.

## 1. VLM의 개념과 활용

VLM(Vision-Language Model)은 이미지와 텍스트의 정보를 함께 처리하는 모델이다. 서로 다른 형태의 데이터를 함께 활용하는 방식을 멀티모달이라고 한다. 이번 학습에서는 이미지와 질문을 받아 자연어 답변을 생성하는 VLM을 중심으로 다뤘다.

```text
이미지 + 텍스트 질문·지시 → VLM → 설명·질문 응답·속성 추출
```

| 분석 방식 | 입력 | 주요 출력 |
| --- | --- | --- |
| 이미지 분류 | 이미지 | 학습된 클래스별 점수 |
| 객체 탐지 | 이미지 | 객체별 Class와 Bounding Box |
| 세그멘테이션 | 이미지 | 픽셀별 클래스 또는 객체 Mask |
| 자연어 응답형 VLM | 이미지와 텍스트 | 이미지 설명·질문 답변·추출 정보 |

VLM은 이미지와 텍스트의 관계를 학습하는 다양한 구조를 포함한다. 구체적인 기능과 입출력 형식은 사용하는 모델에 따라 확인한다.

## 2. 이미지 설명과 시각적 질문 응답

| 작업 | 요청 예시 | 결과에 담을 내용 |
| --- | --- | --- |
| 이미지 설명(Image Captioning) | 보이는 내용을 두 문장 이내로 설명 | 주요 대상과 장면 |
| 시각적 질문 응답(VQA) | 상품의 주요 색상은 무엇인가? | 질문에 해당하는 시각적 정보 |
| 속성 추출 | 종류·색상·외형을 항목별로 정리 | 지정된 속성 |
| 이미지 비교 | 여러 이미지의 공통점과 차이 설명 | 확인되는 시각적 차이 |

같은 운동화 사진에 색상을 물으면 색상 정보를, 외형을 물으면 발목 높이나 장식을 중심으로 요청할 수 있다. 작은 물체의 개수나 미세한 결함처럼 정밀도가 필요한 항목은 실제 이미지와 대조해 검증한다.

## 3. 프롬프트의 분석 범위 정하기

프롬프트에는 분석 대상, 작업, 출력 항목과 길이, 불확실한 정보의 처리 기준을 포함한다.

> 상품 이미지에서 직접 확인할 수 있는 상품 종류, 주요 색상, 외형적 특징을 각각 정리해 주세요. 이미지로 확정하기 어려운 항목은 “확인 불가”로 표시해 주세요.

다음은 흰색 운동화와 검은색 장식이 실제로 보인다고 가정한 기대 결과다.

| 항목 | 기대 출력 예시 |
| --- | --- |
| 상품 종류 | 운동화 |
| 주요 색상 | 흰색 |
| 외형적 특징 | 낮은 발목 높이, 검은색 장식 |
| 실제 소재 | 확인 불가 |

색상과 외형은 사진에서 관찰할 수 있다. 소재를 확정하려면 상품 정보 등이 필요할 수 있고, 정확한 가격과 판매량은 별도 자료가 필요하다. 응답에 관찰 근거가 있는지 확인하고 불확실한 항목의 처리가 일관적인지 살핀다.

여러 이미지에서 같은 항목을 추출하면 결과를 테이블로 정리하기 쉽다. JSON 등으로 구조화할 때도 필드 누락·값의 일관성과 이미지에 대한 사실 일치를 각각 검사한다.

## 4. 모델 선택과 결과 평가

| 필요한 결과 | 우선 검토할 접근 |
| --- | --- |
| 정해진 상품 범주 | 이미지 분류 |
| 객체의 사각형 위치 | 객체 탐지 |
| 개별 객체의 픽셀 영역 | Instance Segmentation |
| 상품 외형의 자연어 설명 | VLM |
| 이미지별 다양한 질문 응답 | VLM |

태스크 전용 모델은 클래스·Box·Mask를 정답 라벨과 비교한다. VLM 응답은 이미지와 대조하여 잘못된 설명, 근거 없는 추측, 중요한 속성 누락 등을 확인한다.

학습 데이터와 도메인 차이, 확보 가능한 라벨, 처리량과 추론 속도, 실행 환경과 비용도 모델 선택에 반영한다. 전용 CV 모델을 새 문제로 학습할 때는 태스크에 맞는 정답 데이터가 필요하다. 사전학습 VLM을 추가 학습 없이 활용하는 경우에도 실제 데이터에서 정확성과 출력 일관성을 평가한다.

## 5. CV 모델과 VLM을 연결하기

상품 위치와 설명이 모두 필요한 경우 다음과 같은 흐름을 구성할 수 있다.

```text
입력 이미지 → 객체 탐지 → 상품 영역 추출
→ VLM에 영역과 질문 전달 → 특징 설명 → 결과 검증
```

탐지 단계는 위치를 제공하고 VLM은 추출된 영역의 시각적 특징을 설명한다. 잘못된 Box나 불완전한 영역이 전달되면 후속 설명에도 영향을 주므로 탐지 영역과 최종 답변을 함께 검토한다.

## 배운 점

이미지에 대해 질문을 바꾸면 추출할 정보도 바꿀 수 있다는 점을 배웠다. 상품 외형을 설명할 때는 이미지에 보이는 근거를 확인하고, 정밀한 위치나 영역이 필요한 작업에서는 해당 출력에 맞는 모델과 평가 기준을 선택해야 한다.
