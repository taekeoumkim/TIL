# TIL | 2026-11-20 — 객체 탐지와 세그멘테이션

물류센터의 상품 상자와 제조 현장의 결함 이미지를 예로 들어 이미지 분류, 객체 탐지, 세그멘테이션의 출력과 학습 라벨을 비교했다. 객체 탐지 결과의 좌표·클래스·신뢰도를 해석하고 필요한 정보의 상세 수준에 맞춰 태스크를 선택하는 방법을 배웠다.

## 1. 태스크별 출력과 정답 데이터

| 태스크 | 필요한 출력 | 학습 라벨 | 활용 예시 |
| --- | --- | --- | --- |
| 이미지 분류 | 이미지 전체의 클래스별 점수 | 이미지별 클래스 | 정상·불량 판단 |
| 객체 탐지 | 객체별 Class, Bounding Box, Confidence | 객체별 클래스와 사각형 좌표 | 결함 위치와 상품 개수 확인 |
| 세그멘테이션 | 픽셀별 클래스 또는 객체 영역 Mask | 픽셀별 클래스나 객체 Mask | 균열·조직의 형태와 영역 구분 |

분류는 이미지 전체의 범주를 판단한다. 객체 탐지는 여러 물체의 위치와 종류를 각각 예측하며, 세그멘테이션은 픽셀 단위의 영역을 표현한다. 같은 CNN 특징 추출 구조를 활용할 수 있어도 출력과 필요한 라벨은 달라진다.

### Semantic과 Instance Segmentation

| 방식 | 상자 세 개가 있는 이미지의 표현 |
| --- | --- |
| Semantic Segmentation | 모든 상자 픽셀을 같은 상자 클래스로 표시 |
| Instance Segmentation | 같은 종류의 상자도 각 객체의 영역을 구분 |

개별 객체의 형태나 면적이 필요하면 Instance Segmentation을 고려한다. 픽셀 단위 라벨을 구축하는 작업량도 태스크 선택에 함께 반영한다.

## 2. Bounding Box 좌표 해석

일반적인 이미지 좌표계는 왼쪽 위가 원점이며 x는 오른쪽, y는 아래로 증가한다.

| 좌표 형식 | 구성 |
| --- | --- |
| XYXY | 왼쪽 위와 오른쪽 아래의 `(x1, y1, x2, y2)` |
| XYWH | 시작 위치와 크기를 나타내는 `(x, y, width, height)` |

XYXY 좌표 `(50, 80, 210, 240)`의 너비와 높이는 각각 `210-50=160`, `240-80=160`이다. XYWH로는 `(50, 80, 160, 160)`이다.

모델이나 라이브러리에 따라 좌표 형식과 단위가 달라질 수 있고, 이미지 크기로 나눈 0~1 좌표를 사용하기도 한다. 결과를 그리거나 크기를 계산하기 전에 형식과 단위를 확인한다.

## 3. Class와 Confidence 해석

**Class**는 검출한 객체의 종류다. 클래스 인덱스는 모델이 학습한 클래스 이름과 연결해야 한다. 서비스에서 필요한 상자·팔레트·결함 종류가 학습 클래스에 포함되어 있는지 확인한다.

**Confidence**는 검출에 부여한 신뢰도 점수이며 모델별 계산 방식에 따라 의미가 달라질 수 있다. 실제 정답과의 비교를 통해 점수와 검출 정확성의 관계를 평가한다. 클래스가 맞아도 Box가 물체의 일부만 포함할 수 있으므로 위치의 적절성도 함께 검토한다.

### Threshold로 결과 선택

| 기준 변경 | 검토할 영향 |
| --- | --- |
| 기준을 높임 | 낮은 신뢰도 검출을 줄이지만 실제 객체를 놓칠 수 있음 |
| 기준을 낮춤 | 더 많은 객체 후보를 포함하지만 오검출이 늘 수 있음 |

다음은 학습자료의 가상 탐지 결과를 필터링하는 예시다.

```python
detections = [
    {"class": "상자", "bbox": (50, 80, 210, 240), "confidence": 0.92},
    {"class": "상자", "bbox": (260, 100, 420, 290), "confidence": 0.78},
    {"class": "팔레트", "bbox": (10, 15, 600, 450), "confidence": 0.32},
]

threshold = 0.5

for detection in detections:
    if detection["confidence"] < threshold:
        continue

    x1, y1, x2, y2 = detection["bbox"]
    width = x2 - x1
    height = y2 - y1
    print(detection["class"], detection["confidence"], width, height)
```

기준을 통과하는 상자 두 개의 너비·높이는 각각 160 × 160, 160 × 190이다. 이 코드는 미리 준비한 결과의 해석을 보여 준다. 실제 적용 기준은 검증 데이터와 객체를 놓쳤을 때의 영향을 함께 보고 정한다.

같은 객체에 Box가 여러 개 생기면 NMS(Non-Maximum Suppression) 등의 후처리로 중복 검출을 정리할 수 있다. 정답 Box와의 겹침을 나타내는 IoU와 탐지 성능 지표는 이후 학습에서 다룬다.

## 4. 대표 모델의 역할

| 모델 | 태스크 | 처리 흐름과 출력 |
| --- | --- | --- |
| ResNet | 이미지 분류 | 잔차 연결을 활용한 특징 추출 후 클래스별 점수 출력 |
| Faster R-CNN | 객체 탐지 | 특징 추출 → 객체 후보 영역 생성 → 클래스·Box·Confidence 예측 |
| Mask R-CNN | Instance Segmentation | 객체 탐지에 객체별 Mask 예측을 더해 영역까지 출력 |

Faster R-CNN은 결함의 종류와 사각형 위치를 확인하는 데 활용할 수 있다. Mask R-CNN은 개별 균열이나 물체의 픽셀 영역을 구분하므로 형태와 면적 분석에 활용할 수 있다.

## 5. 모델 선택 기준과 배운 점

정상·불량 판정만 필요한지, 결함 위치가 필요한지, 결함의 형태까지 필요한지를 먼저 정의한다. 그다음 클래스 라벨, Box, Mask 중 확보할 수 있는 정답 데이터를 확인하고 실제 이미지에서 성능·추론 속도·연산 비용을 비교한다.

이번 학습으로 불량 여부와 불량 위치, 불량 면적이 각각 다른 출력 요구사항이라는 점을 이해했다. 위치가 필요한 작업에 이미지별 라벨만 준비했다면 Box 라벨 구축을 검토해야 하고, 개별 결함의 영역이 필요하면 객체별 Mask를 준비해야 한다.
