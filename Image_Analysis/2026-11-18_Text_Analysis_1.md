# TIL | 2026-11-18 — 이미지의 픽셀·채널과 모델 입력

제품 표면의 흠집을 탐지하는 사례를 통해 이미지 해상도가 세부 정보와 처리 부담에 어떤 영향을 주는지 배웠다. 이미지가 모델에 들어가기까지 픽셀 값, 채널 순서, 자료형이 어떻게 표현되는지도 살펴봤다.

## 1. 픽셀과 해상도

픽셀은 디지털 이미지를 구성하는 기본 단위다. 일반적인 8비트 흑백 이미지에서 각 픽셀은 밝기를 나타내는 `uint8` 값 하나를 가진다. 0은 검정, 128은 중간 밝기의 회색, 255는 흰색이다. 이 범위는 8비트 표현을 기준으로 한다.

```python
import numpy as np

gray = np.array([
    [0, 64, 128, 255],
    [0, 128, 192, 255],
    [0, 64, 128, 255],
], dtype=np.uint8)

print(gray.shape)  # (3, 4)
print(gray.dtype)  # uint8
print(gray[1, 2])  # 192, 두 번째 행의 세 번째 열
```

이미지 크기는 보통 **가로 × 세로**로 표기하고, NumPy의 흑백 배열은 **(세로, 가로)** 순서로 표현한다. 예를 들어 640 × 480 이미지는 배열에서 `(480, 640)`이다. 정사각형 이미지에서는 두 값이 같아 순서 오류를 알아차리기 어려울 수 있다.

| 해상도 | 전체 픽셀 수 |
| --- | ---: |
| 32 × 32 | 1,024 |
| 224 × 224 | 50,176 |
| 1024 × 1024 | 1,048,576 |

1024 × 1024는 32 × 32보다 한 변에 픽셀이 32배 많아 전체 픽셀 수는 1,024배다. 같은 채널 수와 자료형을 사용하면 처리할 입력 데이터도 그만큼 늘어난다. 실제 연산량은 모델 구조에도 영향을 받는다.

제품 전체의 형태를 구분하는 작업은 작은 이미지에서도 가능할 수 있지만, 미세한 흠집은 축소 과정에서 사라질 수 있다. 흐릿한 이미지를 확대하면 픽셀 수는 늘어도 원본에 담긴 세부 정보는 그대로다.

## 2. 채널과 텐서의 차원 순서

흑백 이미지는 픽셀마다 밝기 값 하나를 저장한다. RGB 이미지는 빨강·초록·파랑의 강도를 세 값으로 저장한다. 예를 들어 8비트 RGB에서 빨강은 `[255, 0, 0]`, 흰색은 `[255, 255, 255]`다.

| 표현 | 차원 순서 | 예시 |
| --- | --- | --- |
| NumPy 흑백 이미지 한 장 | `(H, W)` | `(224, 224)` |
| 일반적인 NumPy RGB 이미지 한 장 | `(H, W, C)` | `(224, 224, 3)` |
| PyTorch CNN 입력에 쓰는 이미지 한 장 | `(C, H, W)` | `(3, 224, 224)` |
| 일반적인 PyTorch CNN 배치 입력 | `(N, C, H, W)` | `(8, 3, 224, 224)` |

`N`은 한 번에 처리하는 이미지 수, `C`는 채널 수, `H`와 `W`는 세로와 가로 픽셀 수다.

```python
import numpy as np
import torch

rgb = np.array([
    [[255, 0, 0], [0, 255, 0], [0, 0, 255]],
    [[255, 255, 255], [0, 0, 0], [255, 255, 0]],
], dtype=np.uint8)

tensor = torch.from_numpy(rgb)     # (2, 3, 3), HWC
tensor = tensor.permute(2, 0, 1)   # (3, 2, 3), CHW
batch = tensor.unsqueeze(0)        # (1, 3, 2, 3), NCHW
```

`permute(2, 0, 1)`은 채널 축을 앞으로 옮기고 `unsqueeze(0)`은 배치 축을 추가한다. 픽셀 값과 자료형은 이 과정에서 그대로 유지된다. RGB 입력을 요구하는 모델에 흑백 이미지를 넣으려면 밝기 채널을 세 번 복제해 형태를 맞출 수 있다. 세 채널에는 동일한 밝기 값이 들어간다.

## 3. 입력 크기와 종횡비

가로 640, 세로 480인 이미지를 224 × 224 입력으로 바꿀 때는 어떤 정보가 중요한지에 따라 크기 조정 방식을 선택한다.

| 방법 | 결과와 주의점 |
| --- | --- |
| 직접 크기 조정 | 목표 크기에 바로 맞춘다. 4:3 이미지를 정사각형으로 바꾸면 물체 형태가 왜곡될 수 있다. |
| 비율을 유지한 뒤 자르기 | 형태의 비율을 유지한다. 가장자리를 자르면 그곳에 있던 물체나 결함을 놓칠 수 있다. |
| 비율을 유지한 뒤 여백 추가 | 원본 영역 전체를 유지한다. 목표 크기에 맞추기 위해 여백이 들어간다. |

## 4. 자료형과 정규화

`uint8` 픽셀을 부동소수점으로 변환한 뒤 255로 나누면 값의 범위가 0~1로 바뀐다. 예를 들어 128은 약 0.502가 된다. 일부 사전학습 모델은 여기에 채널별 평균을 빼고 표준편차로 나누는 정규화까지 요구한다. 입력 자료형과 값의 범위는 사용하려는 모델의 전처리 기준에 맞춘다.

학습자료에서는 ResNet18의 가중치에 연결된 전처리로 입력을 준비했다.

```python
from PIL import Image
from torchvision.models import ResNet18_Weights

image = Image.new("RGB", (640, 480), color=(120, 170, 200))
preprocess = ResNet18_Weights.DEFAULT.transforms()
batch = preprocess(image).unsqueeze(0)

print(image.size)   # (640, 480)
print(batch.shape)  # torch.Size([1, 3, 224, 224])
print(batch.dtype)  # torch.float32
```

이 예시는 크기 조정, 자르기, 텐서 변환, 정규화가 끝난 입력의 형태를 확인한다. 학습·검증·테스트에서도 모델이 요구하는 기본 채널 구성과 정규화 기준을 일관되게 적용한다.

## 배운 점

가장자리의 흠집이 탐지 대상이라면 모델이 요구하는 Shape를 맞춘 뒤에도 잘라낸 영역과 축소된 이미지에서 결함이 남아 있는지 확인해야 한다. 입력 전처리를 점검할 때는 크기, 채널 순서, 자료형, 픽셀 값의 범위와 함께 분석에 필요한 특징이 실제로 보존됐는지도 살핀다.
