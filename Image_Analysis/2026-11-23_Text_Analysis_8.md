# TIL | 2026-11-23 — 이미지 임베딩과 유사도 분석

상품 이미지를 벡터로 표현하여 비슷한 디자인을 검색하거나 이미지들을 군집화하는 방법을 배웠다. 사전학습 ResNet18의 분류기 이전 특징을 추출하고, 벡터 간 코사인 유사도와 유클리드 거리로 관계를 비교하는 과정을 살펴봤다.

## 1. 이미지 임베딩과 특징 벡터

이미지 임베딩은 모델이 추출한 시각적 특징을 여러 숫자로 표현한 벡터다. 일반적인 CNN 분류 모델에서는 분류기 이전의 특징 벡터를 활용할 수 있다.

| 표현 방식 | 생성 과정 | 활용 |
| --- | --- | --- |
| 픽셀 벡터 | 이미지의 픽셀을 일렬로 나열 | 원본 픽셀 값 표현 |
| 모델 기반 임베딩 | 학습된 특징 추출 모델에 이미지 입력 | 유사도 분석·검색·군집화 |
| 분류 출력 | 특징 벡터를 분류기에 전달 | 클래스별 점수와 범주 예측 |

224 × 224 RGB 이미지를 펼치면 150,528개 값이 된다. 모델 기반 임베딩의 차원은 특징 추출 구조에 따라 정해지며, ResNet18의 최종 분류기 이전 벡터는 512차원이다.

이미지 N장을 D차원으로 표현하면 배열 Shape는 `(N, D)`다. 각 행은 이미지 하나에 대응한다. 각 차원의 조합에 시각적 특징이 담기므로 개별 숫자 하나를 특정 색상이나 모양과 바로 연결해 해석하기는 어렵다.

## 2. 코사인 유사도와 유클리드 거리

| 방법 | 계산 기준 | 결과 해석 |
| --- | --- | --- |
| 코사인 유사도 | 내적을 두 벡터 크기의 곱으로 나눔 | 클수록 방향이 유사 |
| 유클리드 거리 | 차원별 차이의 제곱합에 제곱근 적용 | 작을수록 벡터가 가까움 |

```text
cosine(A, B) = dot(A, B) / (norm(A) × norm(B))
distance(A, B) = sqrt(sum((A - B)²))
```

코사인 유사도는 0이 아닌 벡터에서 -1~1 범위를 갖는다. 유클리드 거리는 0 이상이며 벡터의 크기에도 영향을 받는다. 예를 들어 `[1, 1]`과 `[2, 2]`는 코사인 유사도가 1이고 거리는 약 1.414다.

학습자료의 가상 벡터에서 운동화 A는 `[1, 0]`, 운동화 B는 `[0.8, 0.6]`, 가방 C는 `[0, 1]`이다.

| 비교 | 코사인 유사도 | 유클리드 거리 |
| --- | ---: | ---: |
| A와 B | 0.80 | 약 0.632 |
| A와 C | 0.00 | 약 1.414 |

```python
import numpy as np

query = np.array([1.0, 0.0])
candidates = {
    "운동화 B": np.array([0.8, 0.6]),
    "가방 C": np.array([0.0, 1.0]),
}

for name, vector in candidates.items():
    cosine = np.dot(query, vector) / (
        np.linalg.norm(query) * np.linalg.norm(vector)
    )
    distance = np.linalg.norm(query - vector)
    print(name, round(cosine, 3), round(distance, 3))
```

위 벡터들은 영벡터가 아닌 계산 예시다. 실제 구현에서는 영벡터의 처리 기준을 정한다. 모든 비교 벡터를 길이 1로 정규화하면 코사인 유사도 내림차순과 유클리드 거리 오름차순은 같은 순위를 제공한다. 정규화 여부와 모델의 특징에 맞춰 비교 방법을 선택한다.

## 3. ResNet18로 특징 추출하기

```text
이미지 → 권장 전처리 → CNN 특징 추출 → 512차원 벡터
→ 유사도 계산 또는 군집화 → 실제 이미지 검토
```

ResNet18의 최종 `Linear(512, 1000)` 분류기를 `nn.Identity()`로 대체하면 입력받은 512차원 특징을 그대로 반환한다.

```python
import torch
from torch import nn
from PIL import Image
from torchvision.models import resnet18, ResNet18_Weights

weights = ResNet18_Weights.DEFAULT
model = resnet18(weights=weights)
model.fc = nn.Identity()
model.eval()

images = [
    Image.new("RGB", (224, 224), color=color)
    for color in ["red", "blue", "green"]
]
preprocess = weights.transforms()
batch = torch.stack([preprocess(image) for image in images])

with torch.inference_mode():
    embeddings = model(batch)

print(batch.shape)       # torch.Size([3, 3, 224, 224])
print(embeddings.shape)  # torch.Size([3, 512])
```

단색 이미지를 사용하는 이 예시는 배치와 벡터의 구조를 확인한다. 가중치를 처음 불러올 때 다운로드가 필요할 수 있다. 실제 상품 검색의 적합성을 확인하려면 상품 사진으로 벡터를 만들고 결과를 검토한다.

| 기능 | 역할 |
| --- | --- |
| `weights.transforms()` | 사전학습 가중치에 맞는 전처리 |
| `nn.Identity()` | 분류기를 특징 벡터 반환용으로 대체 |
| `model.eval()` | 평가 모드 설정 |
| `torch.stack()` | 전처리한 이미지들을 배치로 구성 |
| `torch.inference_mode()` | 기울기 기록 등 학습용 처리를 줄여 특징 추출 |

## 4. 검색과 군집 결과 해석

같은 특징 추출기로 상품 1,000장을 처리하면 `(1000, 512)` 임베딩을 구성할 수 있다. 기준 이미지와 후보들의 유사도를 비교해 순위를 정하거나, 가까운 벡터끼리 군집화한다.

결과를 해석할 때는 사용한 모델과 전처리, 거리 계산 방법을 확인하고 실제 이미지가 목적에 맞는 특징을 공유하는지 살핀다. 모델이 상품 형태보다 배경색·구도·표면 패턴을 강하게 반영하면 다른 상품이 가까워질 수 있다. 같은 상품도 촬영 각도나 조명에 따라 달라질 수 있다.

일반 사물로 학습한 모델의 특징이 특수 제조·의료 이미지에 적합한지도 실제 결과에서 검토한다. 임베딩 차원 수와 함께 검색·군집의 적합성을 확인한다.

## 배운 점

분류 모델의 마지막 출력을 바꾸면 클래스 점수 대신 특징 벡터를 분석에 사용할 수 있다는 점을 배웠다. 검색 결과가 비슷한 상품을 모았는지, 비슷한 배경만 모았는지를 실제 이미지에서 확인해야 분석 목적에 맞는 임베딩인지 판단할 수 있다.
