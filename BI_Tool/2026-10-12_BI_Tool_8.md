# 2026-10-12 Tableau 파라미터 활용

## 1. 사용자가 분석 기준을 바꾸는 파라미터

**Parameter(파라미터)**는 사용자가 변경할 수 있는 하나의 입력값이다. 분석할 지표, 목표값과 상위 항목 수처럼 분석의 기준을 조절하는 데 활용한다.

지역별 성과 대시보드에서 매출 대신 이익을 보거나, 목표 매출을 100만 원에서 150만 원으로 바꾸고 싶을 수 있다. 파라미터를 활용하면 담당자가 계산식을 매번 수정하지 않아도 사용자가 기준을 선택할 수 있다.

단, 파라미터는 입력값을 저장하는 역할이다. **계산된 필드나 필터 등의 분석 로직에 연결해야 결과가 달라진다.**

---

## 2. 파라미터의 데이터 유형과 허용 값

| 데이터 유형 | 활용 예시 |
|---|---|
| Integer | 상위 항목 수 5, 10, 20 |
| Float | 목표 이익률이나 할인율 |
| String | 매출, 이익, 수량 선택 |
| Boolean | 분석 옵션의 사용 여부 |
| Date / Date & Time | 분석 기준 날짜 |

사용자가 입력할 수 있는 값도 목적에 맞게 제한할 수 있다.

| 허용 값 | 의미 | 예시 |
|---|---|---|
| All | 값을 직접 입력 | 임의의 목표 금액 |
| List | 정해진 목록에서 선택 | 매출 / 이익 / 수량 |
| Range | 지정한 범위에서 선택 | 최소·최대 목표값과 간격 |

허용 값 옵션은 자료형에 따라 다르다. 문자열에는 Range를 사용할 수 없다. Top N처럼 개수를 나타내는 값은 정수형으로 만들고, 유효한 양수만 입력하도록 구성하는 것이 자연스럽다.

---

## 3. Parameter Control과 분석 로직

파라미터를 만든 뒤 **Parameter Control**을 표시하면 사용자가 값을 직접 변경할 수 있다.

동작은 다음 순서로 이어진다.

1. 사용자가 컨트롤에서 값을 선택한다.
2. 현재 파라미터 값이 변경된다.
3. 연결된 계산식이나 필터가 새 값을 사용한다.
4. 계산 결과와 뷰가 갱신된다.

컨트롤만 표시하고 계산에 연결하지 않으면 선택값은 바뀌어도 차트는 그대로일 수 있다. 화면이 바뀌지 않는다면 파라미터를 참조하는 로직이 실제 뷰에 사용되는지 확인한다.

---

## 4. Parameter와 Filter의 차이

| 관점 | Parameter | Filter |
|---|---|---|
| 주요 역할 | 분석에 사용할 입력값 제공 | 표시할 데이터 범위 제어 |
| 값의 기준 | 사용자가 정의한 값도 사용 | 필드 값과 조건 |
| 단독 변경 | 반드시 뷰가 바뀌지는 않음 | 조건에 맞는 데이터로 범위 변경 |
| 활용 | 지표, 목표값, Top N 선택 | 지역, 기간, 카테고리 선택 |

서울 데이터만 남기려면 Filter가 직접적이다. 매출과 이익 중 무엇을 볼지 바꾸려면 Parameter와 계산된 필드를 연결한다.

파라미터를 계산식과 필터에 연결하여 데이터 범위를 바꿀 수도 있다. 이는 파라미터 자체가 데이터를 제거하는 것이 아니라, 그 값을 사용하는 필터가 범위를 제한하는 것이다.

---

## 5. 지표 선택: 같은 차트에서 매출·이익·수량 전환

문자열 파라미터 [지표 선택]에 매출, 이익, 수량을 목록으로 제공한다. 다음 계산된 필드는 선택값에 맞는 집계값을 반환한다.

```text
CASE [지표 선택]
WHEN '매출' THEN SUM([Sales])
WHEN '이익' THEN SUM([Profit])
WHEN '수량' THEN SUM([Quantity])
END
```

| 선택값 | 반환되는 지표 |
|---|---|
| 매출 | SUM([Sales]) |
| 이익 | SUM([Profit]) |
| 수량 | SUM([Quantity]) |

만든 필드를 차트의 측정값으로 사용하면 하나의 뷰에서 지표를 전환할 수 있다. 계산식의 분기 결과는 집계 수준과 자료형이 일관되어야 한다.

지표가 달라지면 단위도 달라진다. 매출과 이익은 금액이고 수량은 개수이므로 제목, 축 이름, 레이블과 Tooltip도 선택한 지표에 맞는지 확인한다.

---

## 6. 목표 기준 변경: 같은 값도 판단이 달라진다

숫자형 파라미터 [목표 매출]을 만들고 목표 달성 여부를 계산한다.

```text
IF SUM([Sales]) >= [목표 매출] THEN '목표 달성'
ELSE '목표 미달'
END
```

실제 매출이 180만 원이면 다음처럼 판단이 달라진다.

| 목표 매출 | 결과 |
|---|---|
| 150만 원 | 목표 달성 |
| 200만 원 | 목표 미달 |

데이터는 그대로지만 판단 기준이 바뀐다. 결과를 Color나 Label에 사용하면 목표 충족 여부를 표시할 수 있다.

SUM([Sales])의 범위는 현재 뷰의 집계 수준에 따라 달라진다. 지역별 목표인지 전체 목표인지, 어떤 기간의 목표인지 먼저 정의해야 한다.

또한 하나의 목표 파라미터는 현재 선택한 하나의 값을 제공한다. 지역마다 서로 다른 목표가 필요하면 별도의 목표 데이터와 연결하는 방식도 고려해야 한다.

---

## 7. Top N: 표시할 상위 항목 수 변경

정수형 파라미터 [Top N]을 만들고 5, 10, 20 등의 값을 제공할 수 있다.

지역이나 상품의 Top N 필터에서 상위 항목 수를 이 파라미터와 연결하고, 순위를 정할 집계 지표를 지정한다.

| 파라미터 값 | 표시 목적 |
|---|---|
| 5 | 상위 5개 항목 |
| 10 | 상위 10개 항목 |
| 20 | 상위 20개 항목 |

파라미터만 만든 것으로는 상위 항목이 선택되지 않는다. Top N 설정이 해당 값을 실제로 사용해야 한다.

추가로 다음을 확인한다.

- 매출, 이익 등 어떤 지표를 기준으로 상위를 정하는가?
- 특정 지역이나 기간 안에서 상위 항목을 구하는가?
- 필터의 실행 순서가 의도한 범위와 일치하는가?
- 지표 선택을 바꿀 때 Top N의 기준도 함께 바뀌어야 하는가?

상위 항목 수와 순위 기준은 별개의 설정이다. 차트만 이익으로 바뀌고 필터는 매출 기준으로 남으면 의도와 다른 분석이 될 수 있다.

---

## 8. Parameter Action: 마크 선택을 입력으로 사용

**Parameter Action**은 차트의 마크를 선택하는 동작 등을 파라미터 입력에 연결하는 기능이다.

사용자가 컨트롤에서 직접 입력하는 것에 더해, 선택한 마크의 값을 파라미터로 전달하여 다른 계산이나 뷰에서 활용할 수 있다.

이때 어떤 마크의 어떤 값이 전달되는지, 파라미터 자료형과 맞는지, 선택을 해제했을 때 어떤 값을 유지할지 정의해야 한다.

Action도 파라미터의 입력 경로를 만드는 것이다. 최종 결과를 바꾸려면 해당 파라미터가 분석 로직에 연결되어 있어야 한다.

---

## 9. 동적 분석 설계 흐름

| 사용자 요구 | 연결할 기능 |
|---|---|
| 특정 지역만 보기 | Filter |
| 특정 기간만 보기 | Filter |
| 분석 지표 바꾸기 | Parameter + Calculated Field |
| 목표 기준 바꾸기 | Parameter + Calculated Field |
| 상위 항목 수 바꾸기 | Parameter + Top N 설정 |
| 마크를 선택하여 기준값 전달 | Parameter Action + 연결된 계산 |

설계는 다음 순서로 진행한다.

1. 사용자가 무엇을 변경하려는지 정한다.
2. 파라미터의 자료형, 허용 값과 기본값을 정의한다.
3. 계산된 필드나 필터에 연결한다.
4. 계산 결과를 뷰에 사용한다.
5. Parameter Control 또는 Action으로 입력을 제공한다.
6. 선택값을 바꾸면서 결과를 검증한다.
7. 제목, 단위와 표시되는 범위도 함께 점검한다.

입력값을 많게 만드는 것보다 사용자가 목적에 맞게 분석 기준을 바꾸고 결과의 의미를 이해할 수 있게 만드는 것이 중요하다.

---

## 10. 핵심 정리

- 파라미터는 사용자가 변경할 수 있는 하나의 입력값이다.
- 자료형과 허용 값을 분석 목적에 맞게 지정한다.
- Parameter Control은 사용자가 값을 바꾸는 인터페이스이다.
- 파라미터는 계산식이나 필터에 연결되어야 결과에 영향을 준다.
- Filter는 데이터 범위를, Parameter는 계산에 사용할 기준을 제공한다.
- CASE 계산으로 매출·이익·수량 등 지표를 전환할 수 있다.
- 목표값을 바꾸면 같은 데이터에 대한 판단도 달라질 수 있다.
- Top N은 표시 개수와 순위 기준, 필터 범위를 함께 확인해야 한다.
- Parameter Action은 마크의 선택을 입력에 연결할 수 있다.
- 동적 분석에서는 계산뿐 아니라 단위, 제목과 사용자의 해석도 점검한다.

---

## 오늘의 한 문장

> 파라미터는 값을 바꾸는 기능을 넘어, 사용자의 선택을 계산과 필터에 연결하여 하나의 뷰에서 분석 기준을 전환하는 입력 장치이다.
