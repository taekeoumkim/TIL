## 데이터 리터러시

### 데이터 리터러시란?

데이터 리터러시(Data Literacy)는 데이터를 읽고, 이해하고, 올바르게 해석하여 의사소통과 의사결정에 활용하는 능력이다.

단순히 표의 숫자나 그래프의 높낮이를 확인하는 것이 아니라, **숫자가 어떤 상황에서 만들어졌고 어떤 의미와 한계를 가지고 있는지 이해하는 것**이 중요하다.

예를 들어 매출이 전월 대비 20% 증가했다면 단순히 "매출이 올랐다"라고 판단하는 것이 아니라 다음과 같은 질문을 해야 한다.

- 매출이 증가한 이유는 무엇인가?
- 신규 고객 증가인가, 기존 고객의 구매액 증가인가?
- 이벤트나 할인 행사의 영향은 없는가?
- 매출뿐 아니라 이익도 증가했는가?
- 반품률이나 광고비는 어떻게 변했는가?

즉, **데이터 리터러시는 숫자 뒤에 있는 맥락을 읽는 능력**이다.

### 데이터 리터러시가 중요한 이유

데이터는 기업의 마케팅, 의료 진단, 제조 현장의 불량 예측 등 다양한 의사결정의 근거로 사용된다.

하지만 데이터가 존재한다고 해서 항상 올바른 결정을 내릴 수 있는 것은 아니다.

예를 들어 광고 클릭률이 높더라도 구매 전환율이 낮거나 목표 고객이 아닐 수 있다. 평균 고객 만족도가 높더라도 특정 연령대나 지역의 고객은 낮은 만족도를 보일 수 있다.

따라서 데이터 분석에서는 단순히 데이터를 많이 모으는 것보다 **데이터를 정확하게 읽고, 맥락에 맞게 해석하고, 적절한 질문을 만드는 것**이 중요하다.

### 데이터 리터러시의 핵심 구조

데이터 리터러시는 다음과 같은 흐름으로 이해할 수 있다.

```text
데이터 읽기
    ↓
데이터 이해하기
    ↓
데이터 분석하기
    ↓
데이터로 소통하기
    ↓
의사결정과 행동
```

#### 1. 데이터 읽기

데이터가 무엇을 담고 있는지 파악한다.

- 어떤 대상을 나타내는가?
- 각 열은 무엇을 의미하는가?
- 값의 단위는 무엇인가?
- 언제, 어디서 수집되었는가?
- 결측치나 이상한 값은 없는가?

#### 2. 데이터 이해하기

데이터가 만들어진 배경과 맥락을 파악한다.

- 왜 수집되었는가?
- 누가 데이터를 만들었는가?
- 어떤 방식으로 수집되었는가?
- 특정 집단이 과소대표 또는 과대표된 것은 아닌가?
- 이 데이터로 답할 수 있는 질문과 답할 수 없는 질문은 무엇인가?

#### 3. 데이터 분석하기

데이터에서 **패턴, 관계, 차이, 변화, 이상 징후를 찾아내는 단계**이다.

분석 질문에 따라 필요한 방법도 달라진다.

- 단순 비교
- 상관관계 분석
- 예측 분석 등

#### 4. 데이터로 소통하기

분석 결과를 다른 사람이 이해하고 행동할 수 있도록 전달한다.

- 결과를 듣는 사람은 누구인가?
- 핵심 질문은 무엇인가?
- 어떤 그래프나 표가 이해하기 쉬운가?
- 결론을 한 문장으로 표현하면 무엇인가?
- 어떤 행동을 제안할 수 있는가?

분석의 최종 목적은 멋진 그래프를 만드는 것이 아니라 **더 나은 의사결정을 돕는 것**이다.

### 데이터 라이프 사이클

데이터 분석은 다음과 같은 흐름으로 진행된다.

```text
문제 정의 → 데이터 수집 → 데이터 전처리
        → 분석 및 모델링 → 결과 해석 → 액션 도출
```

앞 단계의 문제가 뒤 단계에 영향을 줄 수 있다.

특히 수집 단계에서 편향된 데이터가 들어오면 복잡한 분석 기법을 사용하더라도 결과가 왜곡될 수 있다.

> Garbage In, Garbage Out

따라서 분석을 시작하기 전에 **데이터의 출처, 수집 방식, 품질, 한계**를 확인해야 한다.

## 데이터 유형 분류

### 왜 데이터 유형을 먼저 알아야 할까?

데이터의 유형을 알아야 적절한 분석 방법과 시각화 방법을 선택할 수 있다.

예를 들어:

- 고객의 나이 → 평균 계산 가능
- 고객의 성별 → 평균 계산 불가능
- 상품 카테고리 → 막대그래프가 적절
- 시간에 따른 매출 변화 → 선그래프가 적절

즉, 데이터 유형을 이해하는 것은 단순한 분류가 아니라 **어떤 분석을 할 수 있고 어떤 분석을 하면 안 되는지 판단하는 기초**이다.

### 구조에 따른 분류

데이터는 구조화된 정도에 따라 세 가지로 나눌 수 있다.

| 유형 | 특징 | 예시 |
| --- | --- | --- |
| 정형 데이터 | 행과 열로 구성된 표 형태 | Excel, DB Table, CSV |
| 반정형 데이터 | 일정한 구조나 규칙을 가지고 있지만 완전한 표 형태는 아님 | JSON, XML, 로그 |
| 비정형 데이터 | 정해진 표 구조가 없음 | 텍스트, 이미지, 음성, 영상, 문서 |

#### 정형 데이터

행과 열로 구성된 표 형태의 데이터이다.

매출 데이터, 고객 데이터, 재고 데이터, 출석 데이터, 설문 응답 데이터 등이 대표적이다.

#### 반정형 데이터

완전히 표 형태로 정리되어 있지는 않지만 일정한 구조나 규칙을 가지고 있다.

웹 서비스, 앱 로그, API 응답, 시스템 로그 등에서 자주 등장한다.

#### 비정형 데이터

정해진 표 구조가 없는 데이터이다.

텍스트, 이미지, 음성, 영상, 문서 등이 해당한다. 정형 데이터보다 분석하기 어렵지만 풍부한 정보를 담고 있으며, 생성형 AI와 딥러닝 기술의 발전으로 활용 가능성이 높아지고 있다.

### 값의 성격에 따른 분류

데이터는 값의 성격에 따라 **수치형 데이터와 범주형 데이터**로 나눌 수 있다.

#### 수치형 데이터

수치형 데이터는 다시 이산형과 연속형으로 나눌 수 있다.

| 유형 | 특징 | 예시 |
| --- | --- | --- |
| 이산형 | 셀 수 있는 값, 보통 정수 | 고객 수, 주문 건수, 클릭 횟수 |
| 연속형 | 측정 가능한 값, 소수점 가능 | 키, 몸무게, 온도, 시간, 거리, 매출액 |

주문 건수는 1건, 2건, 3건처럼 셀 수 있지만 1.5건은 존재할 수 없으므로 이산형 데이터이다.

반면 키는 160cm, 160.5cm, 160.52cm처럼 측정 정밀도에 따라 더 세밀하게 표현할 수 있으므로 연속형 데이터이다.

#### 범주형 데이터

범주형 데이터는 여러 범주로 구분되는 데이터이다.

학습 자료에서는 대표적으로 **명목형 데이터**를 설명했다.

명목형 데이터는 순서가 없는 범주 데이터이다.

예:

- 성별
- 지역
- 혈액형
- 상품 카테고리
- 결제 수단

결제 수단이 카드, 현금, 간편결제라고 할 때 특정 값이 더 크거나 작다고 말할 수 없다.

## 측정 수준과 분석 방법 선택

### 측정 수준이란?

측정 수준은 **데이터가 얼마나 많은 정보를 담고 있는지를 구분하는 기준**이다.

모든 데이터가 숫자로 표현될 수 있지만 숫자가 같은 의미를 가지는 것은 아니다.

예를 들어 고객 ID가 1001, 1002, 1003이라고 해서 1003번 고객이 1001번 고객보다 크다고 말할 수 없다.

반면 매출액 100만 원과 200만 원은 실제 크기를 비교할 수 있다.

따라서 숫자처럼 보인다고 해서 모두 같은 방식으로 계산할 수 있는 것은 아니다.

### 측정 수준의 4가지 종류

```text
명목척도 → 서열척도 → 등간척도 → 비율척도
```

| 척도 | 특징 | 예시 | 가능한 해석 |
| --- | --- | --- | --- |
| 명목척도 | 순서가 없는 이름/범주 | 성별, 혈액형, 지역, 고객 ID | 개수, 비율 |
| 서열척도 | 순서가 있지만 간격이 동일하다고 보기 어려움 | 만족도, 회원 등급, 위험 등급 | 순서 비교 |
| 등간척도 | 간격이 동일하지만 절대적 0이 없음 | 섭씨 온도, IQ | 더하기, 빼기 |
| 비율척도 | 간격이 동일하고 절대적 0이 존재 | 키, 몸무게, 매출액, 나이 | 더하기, 빼기, 곱하기, 나누기 |

#### 명목척도

대상을 구분하기 위한 이름이나 범주이다.

값 사이에 순서가 없기 때문에 평균을 구하거나 크기를 비교하는 것은 적절하지 않다.

예를 들어 혈액형 A형과 B형 중 어느 것이 더 크다고 말할 수 없다.

#### 서열척도

값 사이에 순서가 있지만 각 단계 사이의 간격이 동일하다고 보기는 어렵다.

예:

- 만족도
- 회원 등급
- 학력 수준
- 위험 등급
- 선호도 순위

순서를 비교할 수 있지만 평균을 해석할 때는 주의가 필요하다.

#### 등간척도

값 사이의 간격이 동일하지만 절대적인 0이 존재하지 않는다.

대표적인 예가 섭씨 온도이다.

20℃는 10℃보다 10℃ 높지만, 0℃가 온도가 전혀 없다는 의미는 아니다. 따라서 20℃가 10℃보다 두 배 더 덥다고 해석할 수 없다.

#### 비율척도

값 사이의 간격이 동일하고 절대적인 0이 존재한다.

예:

- 키
- 몸무게
- 매출액
- 구매 금액
- 시간
- 거리
- 나이
- 주문 수량

비율척도에서는 더하기, 빼기, 곱하기, 나누기가 모두 의미를 가진다.

예를 들어 매출액 200만 원은 100만 원의 두 배라고 표현할 수 있고, 주문 수량 0개는 실제 주문이 없음을 의미한다.

### 좋은 분석 질문의 조건

좋은 분석은 좋은 질문에서 시작한다.

좋은 분석 질문은 다음과 같은 특징을 가진다.

1. 구체적이다.
2. 데이터로 답할 수 있다.
3. 의사결정과 연결된다.
4. 분석 결과를 바탕으로 행동할 수 있다.

예를 들어,

> 고객이 왜 이탈할까?

는 범위가 너무 넓다.

반면,

> 최근 3개월 동안 첫 구매 후 30일 이내 재구매하지 않은 고객의 공통 특징은 무엇인가?

는 분석 범위가 명확하고 필요한 데이터와 분석 방향을 구체화할 수 있다.

## 오늘 배운 내용 정리

이번 학습을 통해 데이터 분석은 단순히 Python이나 SQL 같은 도구를 사용하는 것이 아니라 **문제를 정의하고 데이터를 올바르게 이해하는 것에서 시작한다**는 점을 정리했다.

특히 기억할 내용은 다음과 같다.

- 데이터 리터러시는 데이터를 읽고, 이해하고, 분석하고, 소통하여 의사결정에 활용하는 능력이다.
- 데이터 분석에서는 숫자 자체보다 **데이터가 만들어진 맥락과 한계**를 이해하는 것이 중요하다.
- 데이터의 구조와 값의 성격에 따라 적절한 분석 방법과 시각화 방법이 달라진다.
- 숫자로 표현된 데이터라도 명목척도, 서열척도, 등간척도, 비율척도에 따라 가능한 계산과 해석이 달라진다.
- 좋은 분석은 좋은 질문에서 시작하며, 질문은 구체적이고 데이터로 답할 수 있어야 한다.
- 분석 결과는 최종적으로 의사결정과 행동으로 연결되어야 한다.
