## 2. 상속(Inheritance)

### 2.1 상속이란?

이미 만들어진 부모 클래스의 속성과 메서드를 자식 클래스가 물려받아 사용하는 기능이다.

상속을 사용하면 공통 기능을 부모 클래스에 작성하고, 자식 클래스에서는 필요한 기능만 추가할 수 있다.

```python
class Member:
    def login(self):
        print("로그인되었습니다.")


class VIPMember(Member):
    def use_vip_lounge(self):
        print("VIP 라운지를 이용합니다.")


vip_user = VIPMember()
vip_user.login()
vip_user.use_vip_lounge()
```

`VIPMember`에는 `login()`을 직접 작성하지 않았지만 `Member`를 상속했기 때문에 사용할 수 있다.

### 핵심

- `class 자식클래스(부모클래스):` 형태로 상속한다.
- 자식 클래스는 부모 클래스의 속성과 메서드를 재사용할 수 있다.
- 공통 기능은 부모 클래스에 두고 자식 클래스에는 필요한 기능을 추가한다.
- 코드 중복을 줄이고 유지보수를 쉽게 할 수 있다.

## 3. 메서드 오버라이딩(Overriding)

부모 클래스에서 물려받은 메서드를 자식 클래스의 요구사항에 맞게 다시 정의하는 것을 **메서드 오버라이딩**이라고 한다.

```python
class Delivery:
    def deliver(self):
        print("일반 배송을 시작합니다.")


class MorningDelivery(Delivery):
    def deliver(self):
        print("새벽 배송을 시작합니다.")


normal = Delivery()
morning = MorningDelivery()

normal.deliver()
morning.deliver()
```

`MorningDelivery` 객체에서 `deliver()`를 호출하면 부모 클래스의 메서드가 아니라 자식 클래스에서 새롭게 정의한 메서드가 실행된다.

### 핵심

- 자식 클래스에서 부모와 같은 이름의 메서드를 다시 정의할 수 있다.
- 이를 메서드 오버라이딩이라고 한다.
- 자식 객체에서는 오버라이딩한 메서드가 우선 실행된다.

## 4. `super()`로 부모 클래스 호출하기

`super()`는 자식 클래스에서 부모 클래스의 메서드나 초기화 함수(`__init__`)를 호출할 때 사용한다.

특히 부모 클래스의 초기화 코드를 재사용하면서 자식 클래스의 속성을 추가할 때 유용하다.

```python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price


class DiscountProduct(Product):
    def __init__(self, name, price, discount_rate):
        super().__init__(name, price)
        self.discount_rate = discount_rate


product = DiscountProduct("노트북", 1000000, 10)

print(product.name)
print(product.price)
print(product.discount_rate)
```

`super().__init__(name, price)`를 사용하면 `Product`의 초기화 기능을 그대로 사용할 수 있다.

### 핵심

- `super()`는 부모 클래스의 기능을 호출할 때 사용한다.
- `super().__init__()`으로 부모의 초기화 코드를 재사용할 수 있다.
- 부모의 공통 속성을 먼저 설정한 후 자식만의 속성을 추가할 수 있다.

## 5. 캡슐화(Encapsulation)

**캡슐화**는 서로 관련된 데이터와 기능을 하나의 클래스에 묶어서 관리하는 개념이다.

예를 들어 주문 상품명, 주문 상태, 주문 취소 기능을 `Order` 클래스에서 함께 관리할 수 있다.

```python
class Order:
    def __init__(self, product):
        self.product = product
        self.status = "주문 완료"

    def cancel(self):
        self.status = "주문 취소"


order = Order("키보드")

print(order.product)
print(order.status)

order.cancel()
print(order.status)
```

데이터와 데이터를 변경하는 기능을 함께 관리하면 코드의 역할이 명확해지고, 어떤 기능에 의해 데이터가 변경되는지 이해하기 쉬워진다.

## 6. 정보 은닉

**정보 은닉**은 외부에서 객체 내부의 민감한 데이터를 함부로 조회하거나 수정하지 못하도록 하는 개념이다.

예를 들어 비밀번호처럼 객체 내부에서 관리해야 하는 값은 일반 속성처럼 외부에 그대로 노출하지 않는 것이 좋다.

파이썬에서는 속성 이름 앞에 `__`를 붙여 **이름 변형(Name Mangling)**을 적용할 수 있다.

```python
class User:
    def __init__(self, user_id, password):
        self.user_id = user_id
        self.__password = password


user = User("user01", "python1234")

print(user.user_id)

# print(user.__password)  # AttributeError
print(user._User__password)
```

`self.__password`는 내부적으로 `_User__password`와 같은 형태로 이름이 변형된다.

### 주의할 점

파이썬의 `__변수`는 완벽한 보안 기능이 아니다.

이름 변형된 `_User__password`를 이용하면 접근할 수 있기 때문에 **접근을 어렵게 만드는 기능**으로 이해해야 한다.

## 7. Getter와 Setter

Private 변수에 직접 접근하지 않고 값을 조회하거나 수정할 수 있도록 중간 통로를 만드는 방법이다.

- **Getter**: 값을 조회하는 메서드
- **Setter**: 값을 변경하는 메서드
- Setter에서는 값의 유효성을 검사할 수 있다.

예를 들어 재고는 음수가 될 수 없도록 만들 수 있다.

```python
class ProductStock:
    def __init__(self, stock):
        self.__stock = stock

    def get_stock(self):
        return self.__stock

    def set_stock(self, stock):
        if stock >= 0:
            self.__stock = stock
        else:
            print("재고는 음수가 될 수 없습니다.")


product = ProductStock(10)

print(product.get_stock())

product.set_stock(-5)
print(product.get_stock())

product.set_stock(20)
print(product.get_stock())
```

실행 결과는 다음과 같다.

```text
10
재고는 음수가 될 수 없습니다.
10
20
```

`set_stock(-5)`에서는 조건을 만족하지 않기 때문에 기존 값 `10`이 유지된다.

### 핵심

- Getter는 Private 속성의 값을 조회하는 통로다.
- Setter는 값을 변경하기 전에 조건을 검사할 수 있다.
- Getter와 Setter를 사용하면 객체의 데이터를 일정한 규칙에 따라 관리할 수 있다.

## 8. `MinusAccount` 구현

오늘 배운 상속과 오버라이딩을 실제 계좌 클래스에 적용했다.

일반 `BankAccount`는 잔액보다 많은 금액을 출금할 수 없지만, `MinusAccount`는 정해진 마이너스 한도까지 추가로 출금할 수 있도록 구현한다.

```python
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def withdraw(self, amount):
        if self.balance >= amount:
            self.balance -= amount
            print(f"{amount}원 출금 완료")
        else:
            print("잔액이 부족합니다.")


class MinusAccount(BankAccount):
    def __init__(self, owner, balance, limit):
        super().__init__(owner, balance)
        self.limit = limit

    def withdraw(self, amount):
        if self.balance + self.limit >= amount:
            self.balance -= amount
            print(f"{amount}원 출금 완료")
        else:
            print("마이너스 한도를 초과했습니다.")
```

예를 들어 잔액이 `5,000원`, 마이너스 한도가 `10,000원`이면 최대 `15,000원`까지 사용할 수 있다.

```python
account = MinusAccount("홍길동", 5000, 10000)

account.withdraw(12000)
print(account.balance)

account.withdraw(5000)
```

실행 결과:

```text
12000원 출금 완료
-7000
마이너스 한도를 초과했습니다.
```

### 여기서 사용된 개념

1. `MinusAccount`가 `BankAccount`를 상속한다.
2. `super().__init__()`으로 부모의 초기화 기능을 재사용한다.
3. `withdraw()`를 오버라이딩하여 마이너스 계좌만의 출금 규칙을 적용한다.
4. `limit`은 자식 클래스에서 추가한 고유 속성이다.

## 10. 오늘의 핵심 정리

오늘 학습에서 가장 중요한 부분은 **상속으로 코드를 재사용하고, 오버라이딩으로 필요한 기능을 변경하며, 캡슐화와 정보 은닉으로 객체의 데이터를 관리하는 것**이다.

특히 `super()`를 사용하면 부모 클래스의 초기화 코드를 다시 작성하지 않아도 되고, Setter를 사용하면 데이터가 잘못된 값으로 변경되는 것을 막을 수 있다.
