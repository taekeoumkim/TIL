## 1. 함수의 정의와 메모리 적재 구조

### 함수란?

함수(Function)는 **특정 목적을 가진 코드들을 하나의 독립된 구조로 묶어 이름을 붙여둔 재사용 가능한 코드 구조**이다.

동일하거나 유사한 코드가 여러 번 반복되면 프로그램의 크기가 커지고 유지보수가 어려워진다. 함수를 사용하면 반복되는 코드를 하나의 기능으로 묶고 필요한 시점에 호출하여 사용할 수 있다.

함수는 일반적으로 다음과 같은 흐름으로 동작한다.

> 입력값 → 정해진 처리 → 결과값

### 함수 정의와 호출

파이썬에서는 `def` 키워드를 사용하여 함수를 정의한다.

```python
def say_hello():
    print("안녕하세요! 파이썬 함수입니다.")
    print("함수가 실행되고 있습니다.")

say_hello()
```

함수를 정의하면 파이썬 인터프리터는 함수 블록을 메모리에 등록해 두고, 실제 함수가 호출되는 시점에 실행한다.

### 함수 이름 작성 규칙

함수 이름은 변수와 마찬가지로 숫자로 시작할 수 없다.

함수의 기능을 명확하게 알 수 있도록 **동사 위주**로 이름을 작성하는 것이 좋으며, 파이썬에서는 단어 사이를 `_`로 연결하는 **Snake Case** 방식이 권장된다.

```python
def calculate_sum():
    pass
```

## 2. 매개변수(Parameter)와 인수(Argument)

함수를 사용할 때 `매개변수`와 `인수`를 구분해야 한다.

### 매개변수(Parameter)

함수를 정의할 때 외부에서 데이터를 전달받기 위해 설정하는 **입력 통로의 이름**이다.

```python
def welcome(name):
    print(f"{name}님, 환영합니다!")
```

여기서 `name`이 매개변수이다.

### 인수(Argument)

함수를 실제로 호출할 때 매개변수를 통해 전달하는 **실제 데이터 값**이다.

```python
welcome("민수")
welcome("영희")
```

여기서 `"민수"`와 `"영희"`가 인수이다.

### 정리

| 구분 | 의미 | 위치 |
| --- | --- | --- |
| 매개변수(Parameter) | 입력받을 데이터의 이름 | 함수 정의부 |
| 인수(Argument) | 실제 전달하는 데이터 값 | 함수 호출부 |

---

## 3. 위치 인수와 키워드 인수

### 위치 인수(Positional Arguments)

함수를 호출할 때 **매개변수가 정의된 순서대로 인수를 전달하는 방식**이다.

```python
def introduce_self(name, age):
    print(f"이름: {name}, 나이: {age}")

introduce_self("홍길동", 30)
```

위치 인수는 순서를 기준으로 값을 매핑하기 때문에 순서를 지켜야 한다.

```python
introduce_self(30, "홍길동")
```

위와 같이 순서를 바꾸면 `30`이 `name`에 전달되고 `"홍길동"`이 `age`에 전달되어 의도하지 않은 결과가 발생할 수 있다.

### 키워드 인수(Keyword Arguments)

인수를 전달할 때 **매개변수 이름을 직접 지정하는 방식**이다.

```python
introduce_self(age=25, name="이영희")
```

키워드 인수를 사용하면 함수 정의부의 매개변수 순서와 관계없이 원하는 순서로 전달할 수 있다.

또한 인수의 의미가 명확해져 코드의 가독성을 높일 수 있다.

> 위치 인수와 키워드 인수를 함께 사용할 경우에는 위치 인수를 먼저 작성한다.

---

## 4. 기본값 매개변수(Default Parameter)

함수를 정의할 때 매개변수에 특정 값을 미리 설정하면, 호출할 때 해당 인수를 생략했을 경우 기본값이 자동으로 적용된다.

```python
def introduce(name, age=20):
    print(f"이름은 {name}이고, 나이는 {age}세입니다.")

introduce("철수")
introduce("지영", 25)
```

첫 번째 호출에서는 `age`를 전달하지 않았기 때문에 기본값인 `20`이 사용된다.

두 번째 호출에서는 `25`를 전달했으므로 기본값 대신 전달된 값이 사용된다.

### 기본값 매개변수의 순서

기본값이 설정된 매개변수는 **기본값이 없는 매개변수보다 뒤쪽에 배치**해야 한다.

```python
# 올바른 형태
def introduce(name, age=20):
    pass
```

반대로 다음과 같이 작성하면 문법 오류가 발생한다.

```python
# 잘못된 형태
def error_func(age=20, name):
    pass
```

## 5. 가변 인수 `*args`

입력될 인수의 개수가 실행 전에는 정확하게 정해지지 않았을 때 **가변 인수 `*args`**를 사용할 수 있다.

`*args`를 사용하면 전달된 여러 인수를 하나로 묶어서 처리할 수 있으며, 함수 내부에서는 **튜플(Tuple)** 구조로 다뤄진다.

```python
def add_all(*numbers):
    print(f"수집된 튜플 구조: {numbers}")

    total = sum(numbers)
    print(f"총합 결과: {total}")

add_all(1, 2, 3)
add_all(10, 20, 30, 40, 50)
```

입력되는 인수의 개수가 달라도 하나의 함수로 처리할 수 있다는 점이 특징이다.

## 6. 키워드 가변 인수 `**kwargs`

`**kwargs`는 인수의 이름을 지정하여 `키=값` 형태로 전달하는 방식이다.

전달된 데이터는 함수 내부에서 **딕셔너리(Dictionary)** 구조로 처리된다.

```python
def user_info(**data):
    print(f"수집된 딕셔너리 구조: {data}")

    for key, value in data.items():
        print(f"- {key}: {value}")

user_info(
    name="스파르타",
    level=5,
    active=True
)
```

### `*args`와 `**kwargs` 비교

| 구분 | 문법 | 내부 자료구조 | 특징 |
| --- | --- | --- | --- |
| 가변 인수 | `*args` | 튜플 | 여러 개의 값을 순서대로 전달 |
| 키워드 가변 인수 | `**kwargs` | 딕셔너리 | `키=값` 형태의 여러 데이터를 전달 |

## 7. `return` 문의 역할

`return`은 함수 내부에서 계산된 결과값을 **함수 밖의 호출부로 반환**하는 역할을 한다.

또한 함수 실행 중 `return`을 만나면 그 즉시 함수가 종료된다.

```python
def multiply(a, b):
    return a * b

result = multiply(10, 5)

print(result)
```

`multiply(10, 5)`의 결과인 `50`이 함수 밖으로 반환되어 `result`에 저장된다.

### 여러 개의 값 반환

파이썬에서는 여러 값을 쉼표로 구분하여 반환할 수 있다.

```python
def calculate_values(a, b):
    plus = a + b
    minus = a - b

    return plus, minus

res1, res2 = calculate_values(10, 5)

print(f"더하기: {res1}, 빼기: {res2}")
```

여러 값을 반환하면 하나의 튜플 구조로 묶여 반환되며, 여러 변수에 각각 나누어 저장할 수도 있다.

```python
all_result = calculate_values(20, 10)

print(all_result)
```

이 경우 반환된 튜플 전체를 하나의 변수에 저장할 수 있다.

## 8. `*args`를 활용한 평균값 계산

가변 인수를 활용하면 과목 수처럼 입력 데이터의 개수가 정해지지 않은 상황에서도 하나의 함수로 평균을 계산할 수 있다.

```python
def get_average(*scores):
    if len(scores) == 0:
        return 0

    total = sum(scores)
    avg = total / len(scores)

    return avg

result1 = get_average(80, 90, 100)
result2 = get_average(75, 60, 88, 92, 100, 45)

print(f"3과목 평균 점수: {result1:.2f}")
print(f"6과목 평균 점수: {result2:.2f}")
```

여기서는 `len()`을 사용하여 전달된 점수가 없는 경우를 먼저 확인한다.

이를 통해 입력값이 없는 상황에서 발생할 수 있는 오류를 방어하고, 값이 존재하는 경우 합계와 평균을 계산한다.

## 9. 함수를 활용한 기능 분리

함수의 중요한 장점 중 하나는 **기능을 독립적으로 분리할 수 있다는 것**이다.

사칙연산을 각각 별도의 함수로 만들면 각 기능이 서로 영향을 주지 않고 독립적으로 동작하도록 구성할 수 있다.

```python
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b


def multiply(a, b):
    return a * b


def divide(a, b):
    if b == 0:
        return "0으로 나눌 수 없습니다."

    return a / b


x, y = 20, 4

print(f"더하기 결과값: {add(x, y)}")
print(f"빼기 결과값: {subtract(x, y)}")
print(f"곱하기 결과값: {multiply(x, y)}")
print(f"나누기 결과값: {divide(x, y)}")
```

나누기 기능에서는 `b == 0`인지 먼저 확인하여 0으로 나누는 상황을 방어한다.

### 기능 분리의 장점

- 코드 재사용이 쉬워진다.
- 각 기능을 독립적으로 관리할 수 있다.
- 코드의 가독성이 높아진다.
- 특정 기능을 수정할 때 다른 기능에 미치는 영향을 줄일 수 있다.

## 10. 오늘 배운 내용 정리

### 함수

- `def` 키워드를 사용하여 함수를 정의한다.
- 함수를 사용하면 반복되는 코드를 재사용할 수 있다.
- 함수의 이름은 기능을 명확하게 나타내도록 작성하는 것이 좋다.
- 파이썬에서는 Snake Case 방식의 함수 이름을 권장한다.

### 매개변수와 인수

- **매개변수(Parameter)**: 함수 정의부에서 입력을 받기 위해 사용하는 이름
- **인수(Argument)**: 함수 호출부에서 실제로 전달하는 값

### 인수 전달 방식

- **위치 인수**: 정의된 순서에 따라 전달
- **키워드 인수**: `매개변수명=값` 형태로 전달
- **기본값 매개변수**: 인수를 전달하지 않을 때 사용할 기본값 설정
- **`*args`**: 여러 개의 위치 인수를 튜플로 수집
- **`**kwargs`**: 여러 개의 키워드 인수를 딕셔너리로 수집

### 반환

- `return`을 사용하여 함수의 결과값을 함수 밖으로 전달할 수 있다.
- `return`을 만나면 함수는 즉시 종료된다.
- 여러 값을 반환하면 튜플 형태로 묶여 반환된다.

## 11. 오늘의 회고

오늘은 파이썬 함수의 기본 구조부터 매개변수와 인수를 전달하는 여러 방법, 그리고 `return`을 이용한 결과값 반환까지 학습했다.

특히 **함수는 단순히 코드를 짧게 만드는 문법이 아니라, 하나의 기능을 독립적으로 분리하여 재사용할 수 있도록 만드는 구조**라는 점을 이해했다.

처음에는 매개변수(Parameter)와 인수(Argument)의 차이가 비슷하게 느껴졌지만, **함수를 정의할 때 사용하는 이름이 매개변수이고 실제 호출할 때 전달하는 값이 인수**라고 구분하면 이해하기 쉬웠다.

또한 `*args`는 여러 값을 튜플로, `**kwargs`는 `키=값` 형태의 데이터를 딕셔너리로 묶는다는 점도 기억해야 할 부분이었다.

앞으로 데이터를 분석하는 과정에서도 반복되는 처리나 특정 기능을 함수로 분리하면 코드의 재사용성과 가독성을 높일 수 있을 것 같다.
