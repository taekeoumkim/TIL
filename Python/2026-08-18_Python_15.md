## 1. Python 표준 라이브러리

Python 표준 라이브러리는 Python 설치 패키지에 기본으로 포함되어 있는 내장 모듈 세트이다. 별도의 외부 프로그램이나 복잡한 설치 과정 없이 `import`하여 사용할 수 있다.

라이브러리마다 담당하는 역할이 다르기 때문에 **하려는 작업에 맞는 라이브러리를 선택하여 불러오는 것**이 중요하다.

### 주요 표준 라이브러리

| 범주 | 라이브러리 | 핵심 역할 |
|---|---|---|
| 날짜와 시간 | `datetime`, `time` | 현재 날짜·시각 기록, 프로그램 실행 시간 측정 |
| 수학 연산 | `math` | 올림, 내림, 제곱근, 원주율 등 수학 연산 |
| 데이터 변환 | `json` | Python 객체와 JSON 문자열 간 변환 |
| 무작위 난수 | `random` | 난수 생성, 무작위 선택 및 섞기 |
| 시스템 정보 | `os`, `sys` | 파일·디렉토리 탐색, Python 실행 환경 확인 |

```python
import datetime
import random
import sys

print("현재 날짜:", datetime.date.today())

members = ["민수", "영희", "철수"]
print("무작위 선택:", random.choice(members))

print("파이썬 버전:", sys.version)
```

### 핵심

- 표준 라이브러리는 Python과 함께 기본으로 제공된다.
- 라이브러리마다 담당하는 역할이 다르다.
- 필요한 기능에 맞는 라이브러리를 `import`하여 활용한다.

## 2. `datetime` & `time` — 날짜와 시간

데이터 처리 작업에서는 프로그램이 **언제 실행되었는지**와 **얼마나 오래 걸렸는지**를 기록하는 것이 중요하다.

- `datetime.datetime.now()` → 현재 날짜와 시각을 가져온다.
- `time.perf_counter()` → 두 시점 사이의 작업 소요 시간을 정밀하게 측정한다.
- `time.sleep(secs)` → 지정한 초만큼 프로그램 실행을 일시 정지한다.
- `strftime()` → 날짜와 시간 객체를 원하는 문자열 형식으로 변환한다.

```python
import datetime
import time

start_datetime = datetime.datetime.now()

print(
    "작업 시작 시각:",
    start_datetime.strftime("%Y-%m-%d %H:%M:%S")
)

start_time = time.perf_counter()

print("데이터를 처리합니다.")
time.sleep(1)

end_time = time.perf_counter()

elapsed = end_time - start_time
print(f"작업 소요 시간: {elapsed:.2f}초")
```

### 주요 메서드

| 메서드 | 설명 |
|---|---|
| `datetime.datetime.now()` | 현재 날짜와 시각 반환 |
| `datetime.date.today()` | 현재 날짜만 반환 |
| `datetime.timedelta()` | 날짜·시간 사이의 간격을 계산하거나 더하고 뺄 때 사용 |
| `time.sleep(secs)` | 지정한 초만큼 실행을 일시 정지 |
| `time.perf_counter()` | 높은 해상도의 타이머 값을 반환하여 소요 시간 측정에 적합 |
| `datetime.strftime()` | 날짜와 시간 객체를 지정한 문자열 형식으로 변환 |

### `strftime()` 주요 포맷 코드

| 코드 | 의미 | 예시 |
|---|---|---|
| `%Y` | 4자리 연도 | `2026` |
| `%m` | 2자리 월 | `06` |
| `%d` | 2자리 일 | `30` |
| `%H` | 24시간 형식의 시 | `14` |
| `%M` | 분 | `45` |
| `%S` | 초 | `12` |
| `%A` | 요일 이름 | `Tuesday` |

### 기억할 점

`datetime.datetime.now()`는 **현재 날짜와 시각 자체를 얻는 것**이고, `time.perf_counter()`는 **작업에 걸린 시간을 측정하는 것**에 적합하다.

## 3. `math` — 수학 연산

`math` 모듈은 일반적인 산술 연산보다 정밀하고 다양한 수학 기능을 제공한다.

특히 실제 업무에서는 사람 수, 박스 수, 차량 수처럼 **일부만 사용할 수 없고 정수 단위로 확보해야 하는 값**을 계산할 때 올림이 유용하다.

### `math.ceil()`

```python
import math

product_count = 23
products_per_box = 5

box_count = math.ceil(product_count / products_per_box)

print("필요한 박스 수:", box_count)
```

`23 / 5 = 4.6`이지만 박스는 4.6개를 준비할 수 없기 때문에 `math.ceil(4.6)`의 결과인 `5`가 필요하다.

### 주요 메서드와 속성

| 메서드/속성 | 설명 |
|---|---|
| `math.ceil(x)` | `x`보다 크거나 같은 가장 작은 정수 반환 |
| `math.floor(x)` | `x`보다 작거나 같은 가장 큰 정수 반환 |
| `math.trunc(x)` | 소수점 이하를 버리고 정수 부분만 반환 |
| `math.fabs(x)` | 실수 `x`의 절대값 반환 |
| `math.sqrt(x)` | `x`의 제곱근 반환 |
| `math.pi` | 원주율 상수 제공 |

```python
import math

pi_value = 3.141592

print("올림:", math.ceil(pi_value))
print("내림:", math.floor(pi_value))
print("원주율:", math.pi)
print("절대값:", math.fabs(-5.5))
```

## 4. `json` — 데이터 표준 변환

서로 다른 프로그램이나 시스템 사이에서 데이터를 주고받을 때 JSON 형식을 자주 사용한다.

Python의 딕셔너리 같은 객체를 JSON 문자열로 변환하는 것을 **직렬화**라고 하고, JSON 문자열을 다시 Python 객체로 변환하는 것을 **역직렬화**라고 한다.

### `json.dumps()`와 `json.loads()`

- `json.dumps(obj)` → Python 객체를 JSON 문자열로 변환
- `json.loads(s)` → JSON 문자열을 Python 객체로 변환

```python
import json

product = {
    "name": "무선 마우스",
    "price": 25000,
    "in_stock": True
}

json_text = json.dumps(product, ensure_ascii=False)

print("JSON 데이터:", json_text)
print("변환 후 타입:", type(json_text))

restored_product = json.loads(json_text)

print("복원된 상품명:", restored_product["name"])
print("복원 후 타입:", type(restored_product))
```

실행 흐름은 다음과 같다.

```text
Python dict
    ↓ json.dumps()
JSON 문자열(str)
    ↓ json.loads()
Python dict
```

JSON에서는 Python의 `True`가 `true`로 표현되지만, 다시 Python 객체로 변환하면 `True`로 복원된다.

### 파일 입출력 관련 메서드

| 메서드 | 설명 |
|---|---|
| `json.dumps(obj)` | Python 객체를 JSON 문자열로 변환 |
| `json.loads(s)` | JSON 문자열을 Python 객체로 변환 |
| `json.dump(obj, fp)` | Python 객체를 JSON 형식의 파일로 직접 저장 |
| `json.load(fp)` | JSON 파일을 읽어 Python 객체로 변환 |

## 5. `random` — 무작위 난수 추출

`random`은 특정 범위의 난수를 생성하거나 리스트 요소를 무작위로 선택하고 섞을 때 사용한다.

예를 들어 이벤트 당첨자 추첨, 데이터 무작위 샘플링 등에 활용할 수 있다.

### `choice()`와 `sample()`

```python
import random

participants = ["민수", "영희", "철수", "지수", "준호"]

winner = random.choice(participants)
winners = random.sample(participants, 2)

print("한 명의 당첨자:", winner)
print("두 명의 당첨자:", winners)
```

- `random.choice()` → 하나의 요소를 무작위로 선택
- `random.sample()` → 중복 없이 여러 요소를 무작위로 선택

### 주요 메서드

| 메서드 | 설명 |
|---|---|
| `random.randint(a, b)` | `a` 이상 `b` 이하의 임의의 정수 반환 |
| `random.random()` | `0.0` 이상 `1.0` 미만의 임의의 실수 반환 |
| `random.choice(seq)` | 시퀀스에서 무작위로 하나의 요소 선택 |
| `random.shuffle(seq)` | 리스트의 요소 순서를 무작위로 변경하며 원본 리스트를 직접 변경 |
| `random.sample(seq, k)` | 중복 없이 `k`개의 요소를 무작위 추출하여 리스트로 반환 |

```python
import random

fruits = ["사과", "바나나", "오렌지", "포도"]

print("무작위 하나:", random.choice(fruits))

random.shuffle(fruits)
print("무작위 섞기:", fruits)
```

난수를 사용하는 코드는 일반적으로 실행할 때마다 결과가 달라질 수 있다.

## 6. `os` & `sys` — 시스템 및 파일 제어

데이터 분석 프로그램에서는 파일이나 디렉토리의 존재 여부를 확인하거나 Python 실행 환경에 대한 정보를 확인할 필요가 있다.

학습 자료에서는 `os`, `sys`를 시스템 정보 범주의 표준 라이브러리로 다루었다.

- `os` → 파일·디렉토리 탐색 등 운영체제 관련 기능
- `sys` → Python 실행 환경의 경로, 버전 등의 정보 확인

예를 들어 데이터 분석 프로그램에서 `sales.csv`를 읽기 전에 파일이 실제로 존재하는지 확인하면 파일이 없을 때 발생할 수 있는 오류를 미리 방지할 수 있다.

## 7. 오늘의 코딩 테스트 — 연속 출석일 계산

출석 기록에서 가장 긴 연속 출석 일수를 구하는 문제를 풀었다.

```python
def solution(attendance):
    current = 0
    longest = 0

    for record in attendance:
        if record == "O":
            current += 1
            if current > longest:
                longest = current
        else:
            current = 0

    return longest
```

### 풀이 과정

1. 현재 연속 출석일을 저장하는 `current`를 `0`으로 초기화한다.
2. 지금까지 가장 긴 연속 출석일을 저장하는 `longest`를 `0`으로 초기화한다.
3. 출석 기록을 앞에서부터 하나씩 확인한다.
4. `"O"`이면 `current`를 1 증가시킨다.
5. `"X"`이면 연속 출석이 끊겼으므로 `current`를 `0`으로 만든다.
6. 출석할 때마다 `current`와 `longest`를 비교한다.
7. `current`가 더 크면 `longest`를 갱신한다.
8. 모든 기록을 확인한 뒤 `longest`를 반환한다.

### 예시

```python
attendance = ["O", "O", "X", "O", "O", "O", "X"]

# 결과: 3
```

이 문제를 통해 단순히 리스트를 순회하는 것뿐 아니라, **현재 상태와 지금까지의 최댓값을 별도의 변수로 관리하는 방식**을 연습할 수 있었다.
