## 📚 학습 내용

### 1. 모듈(Module)

프로그램의 규모가 커지면 하나의 파일에 모든 로직을 작성하기 어렵기 때문에 기능별로 코드를 여러 `.py` 파일로 분리할 수 있다.

모듈은 **하나의 독립적인 `.py` 파일**이며, 자주 사용하는 변수·함수·클래스 등을 기능별로 모아 코드의 중복을 줄이고 재사용할 수 있도록 한다.

예를 들어 계산 기능을 `calculator.py`로 분리할 수 있다.

```python
# calculator.py

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b
```

다른 파일에서는 `import`를 이용해 모듈을 불러와 사용할 수 있다.

```python
# main.py

import calculator

print(calculator.add(10, 5))
```

모듈을 사용하면 특정 기능에 문제가 생겼을 때 전체 코드를 수정하지 않고 해당 모듈만 수정할 수 있어 코드 관리가 편리하다.

---

### 2. 패키지(Package)

모듈의 수가 많아지면 관련된 모듈을 폴더로 묶어 계층적으로 관리할 수 있다. 이러한 구조를 **패키지**라고 한다.

예시:

```text
shop/
├── main.py
├── user/
│   ├── account.py
│   └── profile.py
└── payment/
    ├── card.py
    └── point.py
```

여기서 `user`, `payment`와 같은 폴더가 패키지이고, 그 안에 있는 `.py` 파일들이 모듈이다.

패키지 내부의 위치는 `.`을 이용해 계층적으로 표현할 수 있다.

```python
payment.card
```

또한 패키지 내부에서는 상대 경로를 사용할 수 있다.

```python
from . import card
```

- `.` : 현재 패키지
- `..` : 한 단계 상위 패키지

상대 경로는 패키지 구조 안에서 실행해야 하며, 자료에서는 터미널에서 `-m` 옵션을 사용해 실행하는 방법을 제시한다.

```bash
uv run python -m 패키지명.모듈명
```

### 3. `import`, `from`, `as`

외부 모듈이나 패키지를 현재 파일에서 사용하기 위해 `import`, `from`, `as` 키워드를 사용할 수 있다.

#### `import`

모듈 전체를 가져오며, 사용할 때 모듈 이름을 함께 적는다.

```python
import math

print(math.sqrt(16))
```

#### `from`

모듈 전체가 아니라 필요한 함수나 클래스만 가져올 수 있다.

```python
from math import sqrt

print(sqrt(16))
```

이 경우 `math.sqrt()`가 아니라 `sqrt()`처럼 바로 사용할 수 있다.

#### `as`

모듈이나 함수에 별칭(alias)을 지정할 수 있다.

```python
import math as m

print(m.sqrt(16))
```

정리하면:

| 방식 | 사용 방법 |
| --- | --- |
| `import math` | `math.sqrt()` |
| `from math import sqrt` | `sqrt()` |
| `import math as m` | `m.sqrt()` |

세 방식의 차이는 **어떤 범위까지 가져오고 현재 코드에서 어떤 이름으로 사용할 것인지**에 있다.

### 4. 파이썬 표준 라이브러리

파이썬에는 별도의 추가 다운로드 없이 사용할 수 있는 **표준 라이브러리(Standard Library)**가 기본적으로 제공된다.

필요한 기능을 직접 구현하기 전에 표준 라이브러리에서 이미 제공하는 기능인지 확인하는 것이 좋다.

이번 학습에서는 다음 표준 라이브러리를 확인했다.

| 모듈 | 주요 기능 |
| --- | --- |
| `random` | 무작위 값 생성 |
| `datetime` | 날짜와 시간 처리 |
| `sys` | 파이썬 실행 환경 및 인터프리터 관련 기능 |

#### `random`

지정한 범위에서 무작위 값을 생성할 수 있다.

```python
import random

number = random.randint(1, 10)
print(number)
```

#### `datetime`

현재 날짜와 시간을 확인할 수 있다.

```python
import datetime

current_time = datetime.datetime.now()
print(current_time)
```

#### `sys`

파이썬 실행 환경의 정보를 확인할 수 있다.

```python
import sys

print(sys.version)
```

### 5. 사용자 정의 모듈

반복해서 사용하는 기능은 별도의 모듈로 분리하면 여러 프로그램에서 재사용할 수 있다.

예를 들어 주문, 결제, 이벤트 기능에서 동일한 가격 계산이 필요하다면 각각의 파일에 같은 함수를 작성하는 대신 `calculator.py`에 공통 기능을 만들 수 있다.

```text
project/
├── calculator.py
├── order.py
├── payment.py
└── event.py
```

```python
# calculator.py

def calculate_price(price, quantity):
    return price * quantity
```

그리고 필요한 곳에서 별칭을 사용해 불러올 수 있다.

```python
import calculator as calc

total_price = calc.calculate_price(5000, 3)
print(total_price)
```

실행 결과:

```text
15000
```

이처럼 공통 기능을 하나의 모듈로 분리하면 같은 코드를 여러 번 작성하지 않고 필요한 곳에서 재사용할 수 있다.

## 💡 오늘 배운 것

### 모듈과 패키지의 관계

오늘 학습에서 가장 중요했던 부분은 **모듈과 패키지의 차이**였다.

- **모듈**: 기능별로 코드를 나눈 하나의 `.py` 파일
- **패키지**: 관련된 여러 모듈을 디렉터리로 묶어 관리하는 구조

즉, 프로그램이 커질수록

```text
하나의 파일
    ↓
여러 모듈
    ↓
패키지로 계층화
```

하는 방식으로 코드를 체계적으로 관리할 수 있다.

### 재사용 가능한 코드의 중요성

같은 기능을 여러 파일에 반복해서 작성하면 기능이 변경될 때 모든 파일을 수정해야 한다.

반대로 공통 기능을 모듈로 분리하면 **한 곳에서 수정하고 여러 곳에서 재사용**할 수 있다.

따라서 모듈화는 단순히 파일을 나누는 것이 아니라, 코드의 **재사용성과 유지보수성을 높이는 방법**이라고 이해했다.
