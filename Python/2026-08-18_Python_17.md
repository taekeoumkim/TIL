## 1. Python 외부 라이브러리

Python의 기본 기능만으로도 다양한 프로그램을 만들 수 있지만, 데이터 분석에서는 외부 라이브러리를 활용하면 훨씬 적은 코드로 복잡한 작업을 처리할 수 있다.

이번 학습에서는 데이터 분석에서 자주 사용하는 세 가지 라이브러리를 학습했다.

| 라이브러리 | 주요 역할 |
|---|---|
| `NumPy` | 수치 데이터 계산 |
| `Pandas` | 표 형태의 데이터 처리 및 분석 |
| `Matplotlib` | 데이터 시각화 |

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
```

예를 들어 판매 데이터를 분석한다면,

```text

↓

```

와 같이 여러 라이브러리를 조합하여 사용할 수 있다.

외부 라이브러리는 특정 목적에 특화된 기능을 제공한다. 따라서 데이터 분석에서는 하나의 라이브러리만 사용하는 것이 아니라 **각 라이브러리의 강점을 조합하는 것**이 중요하다.


### 기억할 점

```text

   ↓
패키지 설치

   ↓
```

## 3. Pandas의 데이터 구조

Pandas의 핵심 자료구조는 `Series`와 `DataFrame`이다.

### Series

`Series`는 하나의 열과 같은 **1차원 데이터**를 표현한다.

```python
import pandas as pd

prices = pd.Series([4500, 5000, 5500])

print(prices)
```

결과:

```text
0    4500
1    5000
2    5500
dtype: int64
```

### DataFrame

`DataFrame`은 여러 개의 열을 가진 **2차원 표 형태의 데이터**를 표현한다.

```python
menu = pd.DataFrame({
    "메뉴": ["아메리카노", "카페라떼", "바닐라라떼"],
    "가격": [4500, 5000, 5500]
})

print(menu)
```

결과:

```text
       메뉴    가격
0  아메리카노  4500
1   카페라떼  5000
2  바닐라라떼  5500
```

### Series vs DataFrame

| 구분 | Series | DataFrame |
|---|---|---|
| 차원 | 1차원 | 2차원 |
| 형태 | 하나의 열 | 행과 열로 구성된 표 |
| 예시 | 가격 목록 | 메뉴 + 가격 |
| 활용 | 단일 변수 | 여러 변수로 구성된 데이터셋 |

DataFrame은 우리가 익숙하게 사용하는 **엑셀의 표나 데이터베이스 테이블**과 비슷한 구조라고 생각하면 이해하기 쉽다.

## 4. 딕셔너리로 DataFrame 만들기

Python 딕셔너리를 `pd.DataFrame()`에 전달하면 쉽게 DataFrame을 만들 수 있다.

```python
import pandas as pd

data = {
    "과목": ["파이썬", "장고", "데이터분석"],
    "수강생수": [120, 85, 95]
}

df = pd.DataFrame(data)

print(df)
```

결과:

```text
       과목  수강생수
0     파이썬    120
1      장고     85
2   데이터분석     95
```

즉,

```text
Python Dictionary
       ↓
pd.DataFrame()
       ↓
2차원 DataFrame
```

으로 변환할 수 있다.

데이터 분석을 할 때는 CSV나 JSON 등의 데이터를 불러온 뒤 DataFrame으로 변환하여 분석하는 경우가 많기 때문에 이 과정은 앞으로 자주 사용하게 될 것 같다.

## 6. Matplotlib을 이용한 선 그래프

Matplotlib은 Python에서 사용하는 대표적인 데이터 시각화 라이브러리이다.

이번 학습에서는 `matplotlib.pyplot`을 사용하여 선 그래프를 만드는 방법을 익혔다.

```python
import matplotlib.pyplot as plt

days = [1, 2, 3, 4, 5]
orders = [20, 35, 30, 45, 50]

plt.plot(days, orders)
plt.title("Daily Orders")
plt.grid(True)
plt.show()
```

각 함수의 역할은 다음과 같다.

| 함수 | 역할 |
|---|---|
| `plt.plot()` | 선 그래프 생성 |
| `plt.title()` | 그래프 제목 설정 |
| `plt.grid()` | 격자 표시 |
| `plt.show()` | 그래프 출력 |

### 그래프를 만드는 기본 흐름

```text
데이터 준비
   ↓
plt.plot()
   ↓
plt.title()
   ↓
plt.grid()
   ↓
plt.show()
```

숫자만 나열해서 보는 것보다 그래프로 표현하면 데이터의 **증가·감소 추세를 빠르게 파악할 수 있다.**

## 7. 축 이름과 범례 추가하기

데이터를 다른 사람에게 보여주는 경우 단순히 그래프를 그리는 것만으로는 부족할 수 있다.

X축과 Y축의 의미를 표시하고 범례를 추가하면 그래프를 더 쉽게 이해할 수 있다.

```python
import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu"]
users = [40, 55, 70, 65]

plt.plot(days, users, label="New Users")

plt.xlabel("Day")
plt.ylabel("Users")
plt.legend()

plt.show()
```

### 주요 함수

| 함수 | 역할 |
|---|---|
| `plt.xlabel()` | X축 이름 설정 |
| `plt.ylabel()` | Y축 이름 설정 |
| `plt.legend()` | 범례 표시 |
| `label` | 그래프 데이터의 이름 지정 |

예를 들어,

```python
plt.plot(days, users, label="New Users")
```

에서 `label`을 지정하고 `plt.legend()`를 호출하면 해당 선이 어떤 데이터를 의미하는지 확인할 수 있다.

### 시각화에서 중요한 것

그래프는 단순히 예쁘게 만드는 것이 목적이 아니라 **데이터의 의미를 전달하는 것**이 목적이다.

따라서 제목, 축 이름, 범례처럼 데이터를 설명하는 요소도 함께 설정해야 한다.

## 9. `info()`로 데이터 구조 확인하기

실제 데이터 분석에서는 데이터를 불러오자마자 바로 분석하기보다 먼저 데이터의 상태를 확인하는 것이 중요하다.

Pandas에서는 `info()`를 사용하여 DataFrame의 구조를 확인할 수 있다.

```python
import pandas as pd

product_data = {
    "상품": ["노트북", "마우스", "키보드", "모니터"],
    "가격": [1200000, 35000, 80000, 300000],
    "판매량": [15, 120, 80, 35]
}

df_products = pd.DataFrame(product_data)

df_products.info()
```

`info()`를 통해 확인할 수 있는 대표적인 정보는 다음과 같다.

- DataFrame의 크기
- 컬럼 이름
- 각 컬럼의 데이터 개수
- 결측값 여부를 판단할 수 있는 Non-Null 개수
- 데이터 타입

예를 들어 숫자형 데이터는 `int64`, 문자열 데이터는 `object` 등으로 표시될 수 있다.

### 왜 `info()`가 중요한가?

분석을 시작하기 전에

> "내가 지금 어떤 데이터를 가지고 있는가?"

를 파악해야 하기 때문이다.

데이터의 컬럼명이나 타입을 제대로 확인하지 않고 분석을 진행하면 예상하지 못한 오류가 발생할 수 있다.

## 10. `describe()`로 기초 통계 확인하기

`describe()`는 숫자로 구성된 열을 대상으로 주요 기술 통계를 보여준다.

```python
df_products.describe()
```

대표적으로 다음과 같은 값을 확인할 수 있다.

- `count` → 데이터 개수
- `mean` → 평균
- `std` → 표준편차
- `min` → 최솟값
- 사분위수
- `max` → 최댓값

예를 들어 상품의 가격과 판매량을 `describe()`로 확인하면 데이터의 대략적인 범위와 중심적인 값을 빠르게 파악할 수 있다.

### `info()` vs `describe()`

| 함수 | 목적 |
|---|---|
| `info()` | 데이터 구조와 타입 확인 |
| `describe()` | 수치형 데이터의 통계적 특징 확인 |

둘을 함께 사용하면 분석 전에 데이터의 전체적인 상태를 빠르게 점검할 수 있다.

```python
df_products.info()
df_products.describe()
```

## 11. Pandas + Matplotlib 데이터 분석 흐름

이번 학습에서 가장 중요하다고 생각한 부분은 Pandas와 Matplotlib을 연결하여 사용하는 흐름이다.

```text
외부 데이터
   ↓
Pandas DataFrame
   ↓
info() / describe()
   ↓
데이터 구조 및 통계 확인
   ↓
필요한 데이터 선택·정리
   ↓
Matplotlib
   ↓
그래프로 시각화
   ↓
데이터의 패턴과 추세 파악
```

즉, 시각화부터 시작하는 것이 아니라 **먼저 데이터를 이해한 후 시각화한다**는 순서가 중요하다.

## 12. 오늘의 핵심 코드

### 데이터프레임 생성

```python
import pandas as pd

data = {
    "월": ["1월", "2월", "3월", "4월", "5월"],
    "매출": [3500, 4200, 3800, 5100, 4900],
    "가입자수": [100, 120, 115, 150, 142]

df = pd.DataFrame(data)
```

### 데이터 구조 및 통계 확인

```python
df.info()
df.describe()
```

```python
import matplotlib.pyplot as plt

plt.plot(df["월"], df["가입자수"], label="New Users")

plt.ylabel("Users")
plt.legend()
```

이 코드를 통해 하나의 DataFrame에 저장된 데이터를 분석하고 그래프로 표현할 수 있다.

## 13. 오늘 배운 내용 정리

### Python 외부 라이브러리

- `NumPy` → 수치 연산
- `Pandas` → 데이터 처리 및 분석
- `Matplotlib` → 데이터 시각화

### Pandas

- `Series` → 1차원 데이터
- `DataFrame` → 행과 열로 구성된 2차원 데이터

- `df.info()` → 데이터 구조 및 타입 확인
- `df.describe()` → 수치형 데이터의 기술 통계 확인

- `plt.plot()` → 선 그래프 생성
- `plt.title()` → 제목 설정
- `plt.xlabel()` → X축 이름
- `plt.ylabel()` → Y축 이름
- `plt.legend()` → 범례 표시
- `plt.grid()` → 격자 표시
- `plt.show()` → 그래프 출력

### 패키지 관리

```bash
uv add pandas matplotlib numpy
```

`uv add`를 통해 필요한 외부 패키지를 프로젝트에 추가하고 의존성을 관리할 수 있다.

## 14. 느낀 점

오늘은 Python의 기본 문법을 넘어 **실제 데이터 분석을 위한 도구를 사용하는 방법**을 배웠다.

특히 Pandas의 `DataFrame`이 데이터 분석에서 중요한 이유를 이해할 수 있었다. 지금까지 Python의 리스트나 딕셔너리로 데이터를 저장했다면, DataFrame을 사용하면 행과 열을 가진 표 형태로 데이터를 관리할 수 있어서 실제 데이터셋을 다루기에 훨씬 적합하다는 생각이 들었다.

또한 `info()`와 `describe()`를 통해 **분석하기 전에 데이터를 먼저 확인하는 과정이 중요하다**는 것도 배웠다. 데이터를 바로 시각화하는 것이 아니라 데이터의 구조와 통계적 특징을 먼저 파악해야 정확한 분석을 할 수 있다는 점이 인상적이었다.

앞으로 데이터 사이언스를 공부하면서 CSV나 실제 데이터셋을 Pandas로 불러온 뒤 `info()`와 `describe()`로 데이터를 확인하고, 필요한 데이터를 가공한 다음 Matplotlib으로 시각화하는 흐름을 반복해서 연습해야겠다.

결국 오늘 배운 내용은 단순히 라이브러리 사용법을 익힌 것이 아니라,

> **데이터를 불러오고 → 구조를 파악하고 → 분석하고 → 시각화하는 기본적인 데이터 분석 흐름**

을 처음 경험했다는 점에서 의미가 있었다.
