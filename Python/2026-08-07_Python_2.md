# 2026-08-07 Python 기본 문법

## 변수와 동적 타이핑

### 변수란?

파이썬에서 `x = 10`을 작성하면 메모리에 `10`이라는 데이터(객체)가 생성되고, `x`는 해당 객체를 가리키는 이름표 역할을 한다.

즉, 변수 자체가 데이터를 직접 소유하는 것이 아니라 데이터가 있는 곳을 **참조(Reference)** 한다.

```python
x = 10
```

변수를 재할당하면 기존 데이터를 수정하는 것이 아니라 새로운 객체를 만들고 변수의 참조가 이동한다.

```python
age = 20
age = 25
```

`20`을 가리키던 `age`가 `25`를 가리키게 된다. 더 이상 참조되지 않는 기존 데이터는 파이썬의 **Garbage Collector**에 의해 자동으로 관리된다.

### 변수명 작성 규칙

- 영문 대소문자, 숫자, 언더바(`_`)를 사용할 수 있다.
- 숫자로 시작할 수 없다.
- 공백을 포함할 수 없다.
- `if`, `for`, `while`, `True`, `False` 같은 예약어는 변수명으로 사용할 수 없다.
- 여러 단어를 연결할 때는 **스네이크 케이스(snake_case)** 를 권장한다.

```python
user_age = 20
total_price = 10000
student_name = "Sparta"
```

### 동적 타이핑

파이썬은 변수를 선언할 때 `int`, `str` 같은 자료형을 직접 명시하지 않는다.

```python
x = 10
x = "Hello"
```

변수가 참조하는 객체의 형태에 따라 실행 시점(Runtime)에 자료형이 결정된다.

```python
x = 10
print(type(x))  # <class 'int'>

x = "Hello"
print(type(x))  # <class 'str'>
```

동적 타이핑은 자료형 선언이 필요하지 않아 코드가 간결하고 빠르게 작성할 수 있다는 장점이 있다. 반면 실행 시점에 타입 문제가 발견될 수 있어 `TypeError` 같은 오류가 발생할 가능성이 있다.

### `type()`과 `id()`

변수가 현재 어떤 자료형의 객체를 참조하는지 확인할 때 `type()`을 사용할 수 있다.

```python
x = 10

print(type(x))
```

객체가 저장된 메모리의 고유 주소값을 확인하려면 `id()`를 사용할 수 있다.

```python
print(id(x))

x = "Hello"

print(id(x))
```

재할당 전후의 `id()`를 비교하면 변수의 참조 대상이 변경되는 것을 확인할 수 있다.

## 주피터 노트북의 변수 관리

주피터 노트북에서는 하나의 노트북 안에서 여러 셀이 하나의 전역 메모리 공간을 공유한다.

따라서 셀의 **위치보다 실제 실행 순서가 중요하다.**

```python
# 셀 1
player_score = 100
```

```python
# 셀 2
player_score += 50
player_score
```

위와 같이 실행하면 두 번째 셀에서도 첫 번째 셀에서 만들어진 변수를 사용할 수 있다.

또한 주피터 노트북에서는 셀의 마지막 줄에 변수명만 작성하면 `print()` 없이도 현재 값을 자동으로 출력할 수 있다.

```python
player_score
```

## 기본 자료형

파이썬에서 데이터를 다루기 위해서는 자료형(Type)을 이해해야 한다.

### 정수형 `int`

소수점이 없는 양수, 음수, 0을 표현한다.

```python
age = 25
count = -5
```

### 실수형 `float`

소수점이 포함된 숫자를 표현한다.

```python
height = 175.5
pi = 3.14
```

### 문자열 `str`

텍스트 데이터를 표현하며 작은따옴표 또는 큰따옴표로 감싼다.

```python
name = "Sparta"
grade = 'A'
```

### 불리언 `bool`

`True`와 `False` 두 가지 상태를 표현한다.

조건문과 제어 흐름에서 핵심적인 역할을 한다.

```python
is_player_turn = True
is_player_win = False
```

파이썬에서는 값 자체를 통해 참과 거짓을 판단할 수도 있다.

```python
bool(0)      # False
bool("")     # False
bool([])     # False

bool(1)      # True
bool("hello") # True
bool([1, 2])  # True
```

`0`, 빈 문자열, 빈 리스트, `None` 등은 거짓으로 인식되고, 값이 존재하는 데이터는 참으로 인식된다.

## 명시적 형변환

외부에서 입력받은 데이터는 문자열로 들어오는 경우가 많기 때문에 필요한 경우 개발자가 직접 자료형을 변환해야 한다.

주요 형변환 함수는 다음과 같다.

| 함수 | 설명 |
| --- | --- |
| `int()` | 정수형으로 변환 |
| `float()` | 실수형으로 변환 |
| `str()` | 문자열로 변환 |
| `bool()` | 불리언으로 변환 |

### 문자열 → 숫자

```python
num_str = "100"
converted_int = int(num_str)

print(converted_int)
# 100
```

### 숫자 → 문자열

문자열끼리 연결할 때 숫자를 그대로 사용할 수 없으므로 `str()`을 이용할 수 있다.

```python
age = 20
message = "내 나이는 " + str(age) + "살입니다."

print(message)
```

### 실수 → 정수

`int()`로 실수를 정수로 변환할 때 소수점 이하를 **반올림하지 않고 버린다.**

```python
pi = 3.14

print(int(pi))
# 3
```

---

## 묵시적 형변환

파이썬은 서로 다른 자료형을 연산할 때 필요한 경우 내부적으로 타입을 자동 변환한다.

특히 `int`와 `float`를 연산하면 정수가 실수 형태로 자동 변환되어 계산된다.

```python
result = 10 + 3.5

print(result)
# 13.5
```

이는 데이터 손실을 줄이기 위한 업캐스팅의 예로 볼 수 있다.

```text
int → float
```

정수 `10`을 실수 `10.0`으로 바꾸는 것은 값을 잃지 않지만, 실수 `3.5`를 정수 `3`으로 바꾸면 소수점 이하 정보가 사라진다.

---

## 형변환 시 주의할 점

숫자로 변환할 수 없는 문자열을 `int()`나 `float()`으로 변환하면 `ValueError`가 발생한다.

```python
val = "20세"

int(val)
# ValueError
```

소수점이 포함된 문자열도 바로 `int()`로 변환할 수 없다.

```python
int("3.14")
# ValueError
```

이 경우 먼저 `float()`으로 변환한 후 `int()`를 사용할 수 있다.

```python
int(float("3.14"))
# 3
```

### `str.isdigit()`으로 사전 검증

문자열이 순수하게 숫자로 구성되어 있는지 확인할 때 `isdigit()`을 사용할 수 있다.

```python
user_input = "25"

if user_input.isdigit():
    age = int(user_input)
    print(age)
else:
    print("숫자만 입력해 주세요!")
```

## 오늘 배운 것 정리

- 파이썬 변수는 데이터를 직접 저장하기보다 객체를 **참조하는 이름표**에 가깝다.
- 변수에 새로운 값을 할당하면 참조 대상이 변경된다.
- 파이썬은 **동적 타이핑**을 사용하여 실행 시점에 객체의 자료형을 결정한다.
- `type()`으로 자료형을, `id()`로 객체의 메모리 주소값을 확인할 수 있다.
- 기본 자료형으로 `int`, `float`, `str`, `bool`을 배웠다.
- `int()`, `float()`, `str()`, `bool()`을 이용해 명시적 형변환을 할 수 있다.
- `int()`로 실수를 변환할 때 소수점 이하가 버림 처리된다.
- `int`와 `float`를 함께 연산하면 정수가 실수로 자동 변환된다.
- 숫자로 변환할 수 없는 문자열을 변환하면 `ValueError`가 발생한다.
- 주피터 노트북에서는 셀 간에 변수가 공유되므로 **실행 순서**가 중요하다.
