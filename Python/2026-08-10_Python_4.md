# 1. 시퀀스 자료구조

## 1.1 List와 Tuple

Python에서는 여러 개의 데이터를 하나의 단위로 묶어 관리하기 위해 **시퀀스 자료구조**를 사용할 수 있다.

대표적인 시퀀스 자료구조가 `List`와 `Tuple`이다.

둘 다 데이터를 순서대로 저장한다는 공통점이 있지만, **가변성(Mutability)** 에서 차이가 있다.

### List

List는 생성한 이후에도 내부 요소를 자유롭게 추가, 수정, 삭제할 수 있는 **가변 자료형(Mutable)** 이다.

```python
shopping_list = ["apple", "banana", "cherry"]

shopping_list[1] = "blueberry"

print(shopping_list)
# ['apple', 'blueberry', 'cherry']
```

리스트는 대괄호 `[]`를 사용하여 생성한다.

### Tuple

Tuple은 한 번 생성하면 내부 요소를 추가, 수정, 삭제할 수 없는 **불변 자료형(Immutable)** 이다.

```python
coordinate = (37.5665, 126.9780)

coordinate[0] = 38.0
# TypeError 발생
```

튜플은 소괄호 `()`를 사용하며, 소괄호를 생략하고 쉼표로 값을 나열해도 튜플로 인식된다.

```python
data = 1, 2, 3

print(data)
# (1, 2, 3)
```

### List와 Tuple 비교

| 구분 | List | Tuple |
| --- | --- | --- |
| 가변성 | Mutable | Immutable |
| 생성 기호 | `[]` | `()` |
| 요소 수정 | 가능 | 불가능 |
| 주요 용도 | 변경되는 데이터 | 변경되지 않아야 하는 데이터 |

**오늘 기억할 점**

데이터를 계속 변경해야 한다면 `List`, 생성 후 변경되지 않아야 하는 데이터라면 `Tuple`을 선택할 수 있다.

## 1.2 Indexing

시퀀스 자료구조는 데이터가 순서대로 저장되므로 각 요소의 위치를 **인덱스(Index)** 로 접근할 수 있다.

Python의 인덱스는 `0`부터 시작한다.

```python
colors = ["red", "green", "blue"]

print(colors[0])
# red
```

마지막 요소는 음수 인덱스를 사용하여 접근할 수 있다.

```python
print(colors[-1])
# blue
```

음수 인덱스는 마지막 요소부터 `-1`, `-2`, ... 순서로 접근한다.

---

## 1.3 Slicing

슬라이싱은 시퀀스에서 원하는 범위의 데이터를 추출하는 방법이다.

기본 형태는 다음과 같다.

```python
sequence[start:end:step]
```

중요한 규칙은 **시작 인덱스는 포함하고, 끝 인덱스는 포함하지 않는다**는 것이다.

```python
numbers = [0, 1, 2, 3, 4, 5]

print(numbers[1:4])
# [1, 2, 3]
```

`step`을 사용하면 일정한 간격으로 데이터를 추출할 수 있다.

```python
print(numbers[::2])
# [0, 2, 4]
```

`-1`을 사용하면 데이터를 역순으로 확인할 수 있다.

```python
print(numbers[::-1])
# [5, 4, 3, 2, 1, 0]
```

### Indexing과 Slicing 정리

- `sequence[index]` → 특정 요소 하나에 접근
- `sequence[start:end]` → 특정 범위 추출
- `sequence[start:end:step]` → 간격을 지정하여 추출
- `sequence[-1]` → 마지막 요소
- `sequence[::-1]` → 역순으로 추출

## 1.4 시퀀스 공통 연산

List, Tuple, 문자열처럼 순서가 있는 자료구조는 공통적인 연산을 사용할 수 있다.

### `+` : 시퀀스 결합

같은 자료형의 시퀀스를 연결할 수 있다.

```python
group1 = [1, 2]
group2 = [3, 4]

print(group1 + group2)
# [1, 2, 3, 4]
```

서로 다른 자료형을 결합하면 `TypeError`가 발생한다.

### `*` : 시퀀스 반복

정수를 곱하면 해당 시퀀스가 지정한 횟수만큼 반복된다.

```python
print(group1 * 3)
# [1, 2, 1, 2, 1, 2]
```

### `len()` : 길이 확인

시퀀스 내부의 요소 개수를 확인할 수 있다.

```python
user_roles = ["admin", "editor", "member"]

print(len(user_roles))
# 3
```

### `in`, `not in` : 포함 여부 확인

특정 요소가 시퀀스에 존재하는지 확인할 수 있다.

```python
print("admin" in user_roles)
# True

print("guest" not in user_roles)
# True
```

## 1.5 Packing과 Unpacking

Python에서는 여러 값을 하나의 변수로 묶거나, 하나의 시퀀스에 들어 있는 값을 여러 변수로 나누어 저장할 수 있다.

### Packing

여러 값을 쉼표로 나열하여 하나의 변수에 저장하면 자동으로 튜플 형태로 패킹된다.

```python
packed_data = 1, 2, 3

print(packed_data)
# (1, 2, 3)
```

### Unpacking

시퀀스의 값을 여러 변수에 순서대로 나누어 저장할 수 있다.

```python
packed_data = (1, 2, 3)

a, b, c = packed_data

print(a)
# 1
```

일반적인 언패킹에서는 데이터 개수와 변수 개수가 맞아야 한다.

### `*`를 이용한 가변 언패킹

변수 앞에 `*`를 사용하면 남은 요소들을 하나의 리스트로 묶을 수 있다.

```python
first, *others = [10, 20, 30, 40]

print(first)
# 10

print(others)
# [20, 30, 40]
```

**오늘 기억할 점**

Packing은 여러 값을 하나로 묶는 것이고, Unpacking은 하나의 시퀀스에 들어 있는 값을 여러 변수로 분리하는 것이다.

# 2. 매핑 및 집합 자료구조

## 2.1 Dictionary

시퀀스 자료구조가 데이터를 순서대로 나열한다면, Dictionary는 **Key-Value 매핑 구조**로 데이터를 관리한다.

```python
user_info = {
    "name": "Sparta",
    "age": 20
}
```

Dictionary에서는 고유한 `Key`를 이용하여 원하는 `Value`를 조회한다.

```python
print(user_info["name"])
# Sparta

print(user_info["age"])
# 20
```

### Dictionary의 특징

- `{}`를 사용하여 생성한다.
- `Key: Value` 형태로 데이터를 저장한다.
- Key는 중복될 수 없다.
- 같은 Key에 새로운 값을 대입하면 기존 값이 새로운 값으로 변경된다.
- Dictionary는 가변 자료형이다.

```python
user_info["age"] = 21
user_info["role"] = "admin"

print(user_info)
# {'name': 'Sparta', 'age': 21, 'role': 'admin'}
```

존재하지 않는 새로운 Key에 값을 대입하면 새로운 Key-Value 쌍이 추가된다.

---

## 2.2 Dictionary 주요 메서드

### `keys()`

모든 Key를 확인할 수 있다.

```python
menu = {
    "coffee": 4000,
    "tea": 4500
}

print(menu.keys())
# dict_keys(['coffee', 'tea'])
```

### `values()`

모든 Value를 확인할 수 있다.

```python
print(menu.values())
# dict_values([4000, 4500])
```

### `items()`

Key와 Value를 하나의 튜플로 묶어서 확인할 수 있다.

```python
print(menu.items())
# dict_items([('coffee', 4000), ('tea', 4500)])
```

특히 반복문과 함께 Dictionary의 Key와 Value를 순회할 때 활용할 수 있다.

---

## 2.3 `get()`을 이용한 안전한 조회

Dictionary에서 대괄호를 이용해 존재하지 않는 Key를 조회하면 `KeyError`가 발생한다.

```python
menu["juice"]
# KeyError
```

`get()`을 사용하면 존재하지 않는 Key를 조회하더라도 에러가 발생하지 않고 `None`을 반환한다.

또한 두 번째 인자로 기본값을 지정할 수 있다.

```python
price = menu.get("juice", 5000)

print(price)
# 5000
```

따라서 존재하지 않을 가능성이 있는 Key를 조회할 때 `get()`을 사용하면 안전하게 데이터를 다룰 수 있다.

# 3. Set

Set은 수학의 집합 개념을 사용하는 자료구조이다.

가장 중요한 특징은 **중복을 허용하지 않는다는 것**이다.

```python
my_set = set([1, 2, 2, 3, 3, 3])

print(my_set)
# {1, 2, 3}
```

중복된 데이터가 자동으로 제거된다.

또한 Set은 **순서가 없는(Unordered) 자료구조**이므로 인덱싱과 슬라이싱을 사용할 수 없다.

```python
set_data[0]
# 인덱싱 불가능
```

---

## 3.1 집합 연산

Set은 수학적인 집합 연산을 연산자로 표현할 수 있다.

```python
set_a = {1, 2, 3}
set_b = {3, 4, 5}
```

### 교집합 `&`

두 집합에 모두 존재하는 요소를 구한다.

```python
print(set_a & set_b)
# {3}
```

### 합집합 `|`

두 집합의 모든 요소를 합친다.

```python
print(set_a | set_b)
# {1, 2, 3, 4, 5}
```

### 차집합 `-`

첫 번째 집합에는 존재하지만 두 번째 집합에는 존재하지 않는 요소를 구한다.

```python
print(set_a - set_b)
# {1, 2}
```

### `in`, `not in`

특정 데이터가 집합에 포함되어 있는지도 확인할 수 있다.

```python
print(3 in set_a)
# True
```

학습자료에서는 Set의 해시 기반 구조 때문에 포함 여부 확인 연산이 List나 Tuple보다 빠르다는 점도 다루었다.

---

## 3.2 자료구조 변환과 데이터 정제

Python에서는 `list()`, `tuple()`, `set()`을 이용해 자료구조를 서로 변환할 수 있다.

특히 **중복 제거**가 필요할 때 다음과 같은 패턴을 사용할 수 있다.

```text
List
 ↓
Set
 ↓
중복 제거
 ↓
List
```

예를 들어 중복된 이메일 데이터를 정제할 수 있다.

```python
raw_emails = ["a@sparta.com", "b@sparta.com", "a@sparta.com"]

unique_set = set(raw_emails)
refined_emails = list(unique_set)

print(refined_emails)
# ['a@sparta.com', 'b@sparta.com']
```

다만 Set은 순서가 없는 자료구조이므로 **중복 제거 과정에서 기존 순서가 보장되지 않는다.**

따라서 중복 제거 후 인덱싱이나 슬라이싱이 필요하다면 다시 `list()`로 변환해야 한다.

# 4. 조건문

조건문은 프로그램이 상황에 따라 다른 동작을 수행하도록 실행 흐름을 제어하는 문법이다.

Python에서는 `if`, `elif`, `else`를 이용해 조건에 따른 분기를 작성한다.

---

## 4.1 `if`

`if`는 조건식의 결과가 `True`일 때만 하위 코드 블록을 실행한다.

```python
status = True

if status:
    print("조건이 참입니다.")
```

조건식이 `False`라면 해당 블록을 실행하지 않는다.

### 콜론 `:`

`if` 조건식 뒤에는 반드시 콜론 `:`을 작성해야 한다.

```python
if status:
    print("조건이 참입니다.")
```

콜론은 조건에 종속되는 코드 블록이 시작된다는 것을 나타낸다.

---

## 4.2 들여쓰기(Indentation)

Python은 다른 언어처럼 중괄호 `{}`를 사용하여 코드 블록을 구분하지 않고 **들여쓰기**를 사용한다.

학습자료에서는 PEP 8 표준으로 **공백 4칸**을 들여쓰기의 기준으로 설명했다.

```python
if status:
    print("조건이 참입니다.")
```

같은 실행 블록에 속한 코드의 들여쓰기 깊이가 맞지 않으면 `IndentationError`가 발생할 수 있다.

따라서 조건문을 작성할 때 들여쓰기를 정확하게 맞추는 것이 중요하다.

---

## 4.3 `if-else`

조건이 `True`일 때뿐만 아니라 `False`일 때 실행할 코드도 필요하다면 `if-else`를 사용한다.

```python
age = 18

if age >= 20:
    print("성인 인증이 완료되었습니다.")
else:
    print("미성년자는 접근할 수 없습니다.")
```

`else`는 별도의 조건식을 작성하지 않고, 위의 `if` 조건이 `False`일 때 실행된다.

`else`는 반드시 `if`와 함께 사용해야 하며, `if`와 동일한 들여쓰기 수준에 위치해야 한다.

---

## 4.4 `if-elif-else`

조건이 두 가지보다 많을 때는 `elif`를 사용하여 여러 조건을 분기할 수 있다.

```python
score = 95

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
else:
    print("C학점 이하")
```

Python은 조건을 **위에서 아래로 순서대로 검사**하고, 처음으로 `True`가 되는 코드 블록 하나만 실행한다.

따라서 조건의 순서가 중요하다.

### 잘못된 조건 순서

```python
score = 95

if score >= 80:
    print("B학점")
elif score >= 90:
    print("A학점")
```

95점은 `score >= 80`을 먼저 만족하기 때문에 `B학점`이 출력되고, 아래의 `elif`는 실행되지 않는다.

### 올바른 조건 순서

더 구체적이거나 기준값이 높은 조건을 먼저 작성한다.

```python
if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
else:
    print("C학점 이하")
```

**오늘 가장 중요하게 배운 부분 중 하나는 다중 조건에서 조건의 순서를 신중하게 설계해야 한다는 점이다.**

---

## 4.5 중첩 조건문과 논리 연산자

조건문 안에 또 다른 조건문을 작성할 수도 있다.

```python
is_logged_in = True
has_permission = True

if is_logged_in:
    if has_permission:
        print("관리자 대시보드 진입")
```

하지만 조건이 많아질수록 들여쓰기가 깊어져 코드가 복잡해질 수 있다.

이런 경우 `and`, `or` 같은 논리 연산자를 이용하여 조건을 하나로 합칠 수 있다.

```python
if is_logged_in and has_permission:
    print("관리자 대시보드 진입")
```

학습자료에서는 `and` 조건을 사용할 때 왼쪽 조건이 `False`이면 오른쪽 조건을 확인하지 않는 **단락 회로 평가**도 설명했다.

이를 통해 불필요한 연산을 줄이고 보다 깔끔한 조건문을 작성할 수 있다.

# 5. 오늘 배운 내용을 하나로 연결하기

오늘은 Python의 자료구조와 조건문을 함께 학습했다.

자료구조를 선택하는 기준을 정리하면 다음과 같다.

```text
순서가 있는 데이터
 ├─ 변경이 필요하다 → List
 └─ 변경되지 않아야 한다 → Tuple

Key를 이용해 데이터를 조회한다 → Dictionary

중복을 제거하거나 집합 연산이 필요하다 → Set
```

그리고 조건문을 이용하면 자료구조에 저장된 데이터를 기준으로 프로그램의 실행 흐름을 제어할 수 있다.

```python
user = {
    "name": "민수",
    "age": 25,
    "role": "admin"
}

if user["role"] == "admin":
    print("관리자 페이지에 접근합니다.")
else:
    print("접근할 수 없습니다.")
```

오늘 학습한 **자료구조 + 조건문**은 앞으로 데이터를 저장하고, 조회하고, 조건에 따라 처리하는 Python 코드의 기본이 된다는 것을 알게 되었다.

# 6. 핵심 정리

### Sequence

- `List` → 가변 자료형
- `Tuple` → 불변 자료형
- Indexing → 특정 위치의 요소 접근
- Slicing → 특정 범위 추출
- `+` → 시퀀스 결합
- `*` → 시퀀스 반복
- `len()` → 요소 개수 확인
- `in`, `not in` → 포함 여부 확인
- Packing → 여러 값을 하나로 묶기
- Unpacking → 하나의 시퀀스를 여러 변수로 분리

### Mapping & Set

- `Dictionary` → Key-Value 구조
- Key → 중복 불가능
- `keys()` → Key 조회
- `values()` → Value 조회
- `items()` → Key와 Value를 함께 조회
- `get()` → 존재하지 않는 Key를 안전하게 조회
- `Set` → 중복 제거, 순서 없음
- `&` → 교집합
- `|` → 합집합
- `-` → 차집합
- `list()`, `tuple()`, `set()` → 자료구조 변환

### Conditional

- `if` → 조건이 `True`일 때 실행
- `else` → `if`가 `False`일 때 실행
- `elif` → 여러 조건을 순서대로 검사
- 들여쓰기 → Python에서 코드 블록을 구분하는 핵심 규칙
- 조건이 서로 포함된다면 **구체적인 조건을 먼저 배치**
- 복잡한 중첩 조건은 `and`, `or` 등의 논리 연산자로 단순화할 수 있음

# 7. 느낀 점

오늘은 단순히 Python 문법을 외우는 것보다 **각 자료구조를 언제 사용해야 하는지**를 구분하는 것이 중요하다는 것을 배웠다.

특히 `List`와 `Tuple`의 차이는 결국 데이터가 변경되어야 하는지에 대한 문제이고, `Dictionary`는 위치가 아닌 `Key`를 통해 데이터를 찾고, `Set`은 중복을 제거하거나 집합 간의 관계를 확인하는 데 적합하다는 점을 정리할 수 있었다.

또한 조건문에서는 문법 자체보다 **조건의 순서와 들여쓰기**가 중요하다는 것을 알게 되었다.

앞으로 Python으로 데이터를 다룰 때 단순히 코드를 작성하는 것에 그치지 않고, 데이터의 특성에 맞는 자료구조를 선택하고 조건의 흐름까지 고려해서 코드를 작성해야겠다.
