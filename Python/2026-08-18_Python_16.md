## 1. 파일 입출력과 텍스트 파일

프로그램이 종료되면 메모리에 저장되어 있던 데이터는 복구되지 않는다. 데이터를 영구적으로 보존하고 필요할 때 다시 사용하려면 저장 장치에 파일 형태로 기록해야 한다.

Python에서는 기본적으로 다음과 같은 흐름으로 파일을 다룬다.

```text
파일 열기(open)
    ↓
읽기 / 쓰기
    ↓
파일 닫기(close)
```

파일을 열어 둔 상태에서 명시적으로 닫지 않으면 메모리나 파일 핸들 같은 시스템 자원이 낭비될 수 있다.

---

## 2. `with open()`을 활용한 안전한 파일 관리

`with open()`을 사용하면 블록을 벗어나는 순간 파일이 자동으로 닫힌다. 따라서 개발자가 직접 `close()`를 호출하지 않아도 파일을 안전하게 관리할 수 있다.

```python
with open("work_log.txt", "w", encoding="utf-8") as file:
    file.write("고객 문의 확인 완료\n")
    file.write("주간 보고서 작성 완료\n")

print("업무 기록 저장 완료")
```

`"w"`는 쓰기(write) 모드를 의미한다.

### 핵심

- `open()` → 파일을 열어 읽거나 쓸 수 있도록 한다.
- `with open()` → 파일을 자동으로 닫아준다.
- 파일 작업에서는 직접 `close()`를 관리하는 것보다 `with open()`을 사용하는 것이 안전하다.

## 3. 텍스트 파일 읽기

파일을 읽을 때는 목적에 따라 `read()`, `readline()`, `readlines()`를 사용할 수 있다.

### `read()`

파일 전체 내용을 하나의 문자열로 읽는다.

```python
with open("test.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)
```

파일 크기가 작을 때 한 번에 데이터를 가져오기 편리하지만, 파일이 너무 크면 메모리 부담이 발생할 수 있다.

### `readline()`

한 줄씩 문자열로 읽는다. 호출할 때마다 다음 줄을 가져온다.

```python
with open("test.txt", "r", encoding="utf-8") as file:
    line = file.readline()

print(line.strip())
```

`strip()`을 사용하면 줄바꿈 문자 등을 제거할 수 있다.

### `readlines()`

파일의 모든 줄을 읽어서 리스트로 반환한다.

```python
with open("test.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

print(lines)
```

### 세 가지 함수 비교

| 함수 | 반환 형태 | 특징 |
|---|---|---|
| `read()` | 문자열 | 파일 전체 내용을 한 번에 읽음 |
| `readline()` | 문자열 | 한 줄씩 읽음 |
| `readlines()` | 리스트 | 모든 줄을 리스트로 읽음 |

`readlines()`는 줄 단위 데이터를 리스트로 가져오기 때문에 이후 반복문으로 데이터를 가공하기 좋다.

## 4. 구조화된 데이터 포맷

실무에서는 단순한 텍스트뿐 아니라 표 형태의 데이터나 웹에서 주고받는 구조화된 데이터를 자주 사용한다.

대표적인 구조화된 데이터 형식으로 **CSV와 JSON**이 있다.

이번 학습에서는 CSV와 JSON을 Python의 `list`, `dict` 같은 내장 자료구조와 상호 변환하는 방법을 학습했다.

---

## 5. CSV

CSV(Comma-Separated Values)는 각 항목의 데이터를 쉼표(`,`)로 구분하여 표 형태의 구조를 표현하는 텍스트 파일 형식이다.

용량이 작고 엑셀이나 데이터베이스와 연동하기 쉽다는 장점이 있다.

### CSV 작성하기

Python에서는 `csv` 모듈의 `writer()`와 `writerow()`를 사용할 수 있다.

```python
import csv

with open(
    "employees.csv",
    "w",
    encoding="utf-8",
    newline=""
) as file:
    writer = csv.writer(file)

    writer.writerow(["이름", "부서", "직급"])
    writer.writerow(["김민수", "개발팀", "사원"])
    writer.writerow(["이영희", "데이터팀", "대리"])
```

### CSV 읽기

`csv.reader()`를 사용하면 CSV 파일의 각 행을 읽을 수 있다.

```python
import csv

with open("employees.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file)
    employees = list(reader)

print(employees)
```

결과:

```python
[
    ["이름", "부서", "직급"],
    ["김민수", "개발팀", "사원"],
    ["이영희", "데이터팀", "대리"]
]
```

CSV의 한 행은 Python에서 하나의 리스트로 읽힌다. 따라서 CSV 전체를 읽으면 **리스트 안에 여러 리스트가 들어 있는 2차원 리스트** 형태가 된다.

### 핵심

- CSV는 쉼표를 기준으로 데이터를 구분하는 텍스트 형식이다.
- `csv.writer()`로 CSV 파일을 작성할 수 있다.
- `csv.reader()`로 CSV 데이터를 읽을 수 있다.
- `list()`로 변환하면 2차원 리스트로 다룰 수 있다.

## 6. JSON

JSON(JavaScript Object Notation)은 웹에서 데이터를 주고받을 때 표준으로 사용되는 텍스트 형식이다.

JSON은 키(Key)와 값(Value)이 쌍을 이루는 구조를 사용하여 복잡한 계층 구조를 표현할 수 있다.

Python의 자료구조와 비교하면 다음과 같이 연결된다.

```text
JSON 객체  → Python dict
JSON 배열  → Python list
```

다만 구조가 유사할 뿐 자료형과 표현 규칙이 완전히 같은 것은 아니다.

### JSON 문자열을 Python 객체로 변환

```python
import json

json_data = '{"name": "민수", "point": 1500, "grade": "VIP"}'

user = json.loads(json_data)

print(type(user))
print(user["name"])
print(user["point"])
```

결과:

```text
<class 'dict'>
민수
1500
```

즉,

```text
JSON 문자열
    ↓ json.loads()
Python dict
```

로 변환된다.

## 7. JSON 직렬화와 역직렬화

Python 프로그램의 메모리에 있는 딕셔너리나 리스트 등의 객체는 프로그램이 종료되면 사라진다. 따라서 데이터를 저장하거나 다른 시스템으로 전달하려면 저장 또는 전송할 수 있는 형태로 변환해야 한다.

### 직렬화(Serialization)

Python 객체를 파일에 저장하거나 네트워크로 전송할 수 있는 형태로 변환하는 과정이다.

### 역직렬화(Deserialization)

저장된 데이터를 다시 Python 객체로 복원하는 과정이다.

### `dumps()` / `loads()`와 `dump()` / `load()`

| 함수 | 입력 | 결과 |
|---|---|---|
| `json.dumps()` | Python 객체 | JSON 문자열 |
| `json.loads()` | JSON 문자열 | Python 객체 |
| `json.dump()` | Python 객체 + 파일 객체 | JSON 파일 기록 |
| `json.load()` | JSON 파일 객체 | Python 객체 |

### JSON 파일에 저장하기

```python
import json

player = {
    "nickname": "python_master",
    "level": 7,
    "gold": 2500
}

with open("player.json", "w", encoding="utf-8") as file:
    json.dump(
        player,
        file,
        ensure_ascii=False,
        indent=4
    )
```

### JSON 파일 불러오기

```python
with open("player.json", "r", encoding="utf-8") as file:
    loaded_player = json.load(file)

print(loaded_player)
print(loaded_player["level"])
```

전체 흐름은 다음과 같다.

```text
Python 객체
    ↓ json.dump()
JSON 파일
    ↓ json.load()
Python 객체
```

## 8. 텍스트 파일을 읽고 가공하여 새로운 파일 만들기

파일 입출력과 Python 자료구조를 함께 활용하는 실습도 진행했다.

참석자 이름이 한 줄씩 저장된 파일을 읽은 뒤 각 참석자에게 번호를 붙여 새로운 파일로 저장하는 방식이다.

```python
with open("participants.txt", "r", encoding="utf-8") as file:
    participants = file.readlines()

with open("numbered_participants.txt", "w", encoding="utf-8") as file:
    for number, participant in enumerate(participants, start=1):
        file.write(f"{number}. {participant}")
```

결과:

```text
1. 김민수
2. 이영희
3. 박철수
```

여기서 `enumerate()`를 사용하면 데이터와 순서 번호를 함께 처리할 수 있다.

### `enumerate(..., start=1)`

```python
for number, participant in enumerate(participants, start=1):
    ...
```

- `number` → 1부터 시작하는 순서 번호
- `participant` → 리스트의 실제 데이터

따라서 원본 파일을 직접 수정하지 않고, **원본 데이터를 읽어 필요한 형태로 가공한 뒤 새로운 결과 파일로 저장**할 수 있다.

## 9. 오늘 배운 내용 정리

### 파일 입출력

- `open()` → 파일 열기
- `with open()` → 파일을 안전하게 열고 자동으로 닫기
- `read()` → 전체 내용을 문자열로 읽기
- `readline()` → 한 줄씩 읽기
- `readlines()` → 모든 줄을 리스트로 읽기
- `write()` → 파일에 내용 기록

### CSV

- `csv.writer()` → CSV 작성
- `writerow()` → 한 행 작성
- `csv.reader()` → CSV 읽기
- `list(reader)` → 2차원 리스트로 변환

### JSON

- `json.dumps()` → Python 객체 → JSON 문자열
- `json.loads()` → JSON 문자열 → Python 객체
- `json.dump()` → Python 객체 → JSON 파일
- `json.load()` → JSON 파일 → Python 객체

### 데이터 변환 흐름

```text
[텍스트 파일]
    ↓ readlines()
Python list
    ↓ 가공
새로운 텍스트 파일

[CSV 파일]
    ↓ csv.reader()
Python 2차원 list
    ↓ csv.writer()
CSV 파일

[Python dict/list]
    ↓ json.dump()
JSON 파일
    ↓ json.load()
Python dict/list
```

## 10. 느낀 점

오늘은 단순히 파일을 읽고 쓰는 방법뿐만 아니라, **파일에 저장된 데이터를 Python에서 가공하고 다시 새로운 형태로 저장하는 과정**을 배웠다.

특히 `with open()`이 중요하다고 느꼈다. 파일을 사용할 때 직접 `close()`를 관리하지 않아도 블록을 벗어나면 자동으로 파일이 닫히기 때문에, 파일 자원을 안전하게 관리할 수 있기 때문이다.

또한 CSV는 데이터를 2차원 리스트 형태로 다룰 수 있고, JSON은 Python의 딕셔너리나 리스트와 연결해서 사용할 수 있다는 점이 인상적이었다.

앞으로 데이터 분석을 공부하면서 CSV 데이터를 직접 불러와 분석하거나 JSON 형태의 데이터를 다룰 일이 많을 것 같기 때문에, 오늘 배운 **파일 입출력 → 데이터 구조 변환 → 데이터 가공 → 새로운 파일 저장**의 흐름을 익숙하게 사용할 수 있도록 반복해서 연습해야겠다.
