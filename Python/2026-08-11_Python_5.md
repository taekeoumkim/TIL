## 반복문과 종합 제어 실습

오늘은 Python의 반복문을 중심으로 `for`, `while`, `break`, `continue`,
중첩 반복문을 학습하고, 이를 조건문과 결합하여 데이터를 필터링하고
통계값을 계산하는 실습을 진행했다.

------------------------------------------------------------------------

## 1. for 문

### 1.1 for 문의 기본 구조

`for` 문은 리스트, 튜플, 문자열과 같이 순서가 있는 시퀀스 자료구조를
처음부터 끝까지 순회하면서 반복 작업을 수행할 때 사용한다.

``` python
fruits = ["사과", "바나나", "체리"]

for fruit in fruits:
    print(fruit)
```

핵심은 **시퀀스의 각 요소를 하나씩 꺼내어 같은 작업을 반복한다는
것**이다.

Python에서는 `:` 뒤에 반복할 코드를 작성하고, 들여쓰기를 통해 반복문에
포함되는 실행 영역을 구분한다.

------------------------------------------------------------------------

## 2. range() 함수

`range()`는 특정 횟수만큼 반복하거나 원하는 숫자 범위를 순회할 때
사용한다.

### 기본 형태

``` python
range(시작, 끝, 증감폭)
```

`range()`에서 **시작값은 포함하지만 끝값은 포함하지 않는다.**

### 5번 반복

``` python
for i in range(5):
    print(i + 1)
```

### 시작값과 증감폭 지정

``` python
for i in range(1, 6, 2):
    print(i)
```

출력:

``` text
1
3
5
```

### 기억할 점

``` text
range(5)        → 0, 1, 2, 3, 4
range(1, 6)     → 1, 2, 3, 4, 5
range(1, 6, 2)  → 1, 3, 5
```

`range()`는 필요한 정수를 순차적으로 생성하기 때문에 미리 모든 숫자를
리스트로 만들어 두는 방식보다 메모리를 효율적으로 사용할 수 있다.

------------------------------------------------------------------------

## 3. while 문

`while` 문은 **특정 조건이 참인 동안 반복**해야 할 때 사용한다.

``` python
numbers = 1

while numbers <= 3:
    print(f"현재 숫자는 {numbers}입니다.")
    numbers += 1
```

`while` 문에서는 반복이 종료될 수 있도록 **종료 조건을 반드시 고려해야
한다.**

반복문 내부에서 조건을 변경하는 코드가 없다면 조건식이 계속 `True`가
되어 무한 루프에 빠질 수 있다.

### while 문의 핵심 구조

``` text
조건 확인
  ↓
True → 반복문 실행
  ↓
조건 변경
  ↓
다시 조건 확인
  ↓
False → 반복 종료
```

------------------------------------------------------------------------

## 4. 무한 루프와 종료 방법

`while` 문의 조건이 항상 `True`이거나 종료 조건을 만족하도록 상태를
변경하지 않으면 무한 루프가 발생할 수 있다.

``` python
count = 3

while count > 0:
    print(count)
    count -= 1

print("발사")
```

`count -= 1`을 통해 조건이 `False`가 되도록 만들어 반복을 종료한다.

주피터 노트북이나 VS Code에서 무한 루프가 발생한 경우 실행을 강제로
중단해야 한다.

-   Jupyter Notebook: `[Interrupt]` 버튼 사용
-   터미널: `Ctrl + C`

------------------------------------------------------------------------

## 5. break

`break`는 반복문을 **즉시 종료**할 때 사용한다.

``` python
for num in range(1, 6):
    if num == 4:
        print("4를 찾았습니다.")
        break

    print(f"현재 수치: {num}")
```

`break`를 만나면 반복문의 남은 작업을 수행하지 않고 반복문 전체를
빠져나온다.

### 활용

데이터를 순회하면서 원하는 값을 찾았을 때 더 이상 데이터를 확인할 필요가
없다면 `break`를 사용하여 불필요한 연산을 줄일 수 있다.

------------------------------------------------------------------------

## 6. continue

`continue`는 현재 반복의 남은 코드를 건너뛰고 **다음 반복으로 이동**할
때 사용한다.

``` python
for num in range(1, 6):
    if num % 2 == 0:
        continue

    print(f"필터링된 홀수 수치: {num}")
```

위 코드는 짝수를 만나면 `continue`를 실행하여 출력 부분을 건너뛰고 다음
숫자를 확인한다.

### break와 continue의 차이

  키워드       동작
  ------------ -------------------------------------
  `break`      반복문 전체 종료
  `continue`   현재 반복만 건너뛰고 다음 반복 진행

------------------------------------------------------------------------

## 7. 중첩 반복문

반복문 안에 또 다른 반복문을 작성하는 것을 **중첩 반복문(Nested
Loop)**이라고 한다.

``` python
for dan in range(2, 10):
    for times in range(1, 10):
        print(f"{dan} x {times} = {dan * times}")
```

바깥쪽 반복문이 한 번 실행될 때마다 안쪽 반복문은 처음부터 끝까지 모두
실행된다.

따라서 전체 반복 횟수는 일반적으로

``` text
외부 반복 횟수 × 내부 반복 횟수
```

형태로 증가한다.

2차원 데이터나 행과 열로 구성된 데이터를 순회할 때 활용할 수 있다.

# 종합 제어 실습

## 8. 반복문과 조건문을 활용한 데이터 필터링

데이터 처리에서는 대량의 원시 데이터 중에서 원하는 조건에 맞는 데이터만
골라내는 작업이 중요하다.

반복문으로 데이터를 하나씩 확인하면서 조건문으로 필요한 데이터인지
판단할 수 있다.

``` python
scores = [65, 82, 90, 74, 88, 55]

for score in scores:
    if score >= 80:
        print(score)
```

위 코드에서는 모든 점수를 순회하면서 80점 이상인 점수만 출력한다.

------------------------------------------------------------------------

## 9. 중첩 조건문을 활용한 다단계 필터링

실제 데이터는 하나의 조건만으로 분류하기 어려운 경우가 많다.

예를 들어 회원 데이터에서

1.  활성 회원인지 확인
2.  활성 회원이라면 등급 확인
3.  VIP와 Gold를 각각 처리

하는 방식으로 조건을 단계적으로 적용할 수 있다.

``` python
for user in user_database:
    if user["active"]:
        if user["level"] == "VIP":
            print(f"[우수 등급] {user['name']} 회원님에게 VIP 전용 쿠폰이 발송되었습니다.")
        elif user["level"] == "Gold":
            print(f"[일반 등급] {user['name']} 회원님에게 Gold 기본 쿠폰이 발송되었습니다.")
```

이처럼 `for`와 `if`, `elif`를 조합하면 데이터의 조건을 단계적으로
필터링할 수 있다.

------------------------------------------------------------------------

## 10. 누적 변수를 활용한 데이터 집계

반복문을 이용하면 조건에 맞는 데이터의 개수나 합계를 계산할 수 있다.

이때 반복문이 시작되기 전에 **누적 변수를 초기화**해야 한다.

``` python
total_vip_points = 0
active_user_count = 0

for user in user_database:
    if user["active"]:
        active_user_count += 1

        if user["level"] == "VIP":
            total_vip_points += user["point"]
```

핵심은 다음과 같다.

-   개수 → `count += 1`
-   합계 → `total += 값`
-   반복 전 누적 변수 초기화 → `변수 = 0`

이 방법을 이용하면 특정 조건에 맞는 데이터만 선택하여 통계값을 계산할 수
있다.

------------------------------------------------------------------------

## 11. 최댓값, 최솟값, 합계, 평균 구하기

외부 라이브러리 없이 반복문과 조건문만 사용해서 기본적인 통계값을 계산할
수 있다.

``` python
student_scores = [85, 92, 78, 60, 99, 71, 88, 65]

highest_score = student_scores[0]
lowest_score = student_scores[0]
score_sum = 0

for score in student_scores:
    if score > highest_score:
        highest_score = score

    if score < lowest_score:
        lowest_score = score

    score_sum += score

total_students = len(student_scores)
score_average = score_sum / total_students
```

### 최댓값과 최솟값의 초기 기준

첫 번째 데이터를 기준값으로 설정한다.

``` python
highest_score = student_scores[0]
lowest_score = student_scores[0]
```

이후 데이터를 하나씩 비교하면서 더 큰 값이나 더 작은 값이 발견되면
기준값을 갱신한다.

### 평균

합계를 전체 데이터 개수로 나누어 평균을 구한다.

``` python
score_average = score_sum / len(student_scores)
```

하나의 반복문에서 최댓값, 최솟값, 합계를 동시에 계산할 수 있다는 점이
중요하다.

## 12. Up-Down 숫자 맞추기 게임

반복문과 조건문, `break`, 입력값 처리, 난수 생성을 함께 사용하는 종합
실습으로 Up-Down 숫자 맞추기 게임을 구현했다.

### 핵심 구조

``` python
import random

computer_number = random.randint(1, 100)
try_count = 0

while True:
    user_input = input("컴퓨터의 숫자를 맞춰보세요 (1~100): ")
    guess = int(user_input)

    try_count += 1

    if guess < computer_number:
        print("Up! 더 큰 숫자입니다.")
    elif guess > computer_number:
        print("Down! 더 작은 숫자입니다.")
    else:
        print(f"정답입니다! {try_count}회 만에 숫자를 맞추셨습니다.")
        break
```

### random.randint()

`random.randint(1, 100)`은 1부터 100 사이에서 임의의 정수를 생성한다.

### input()과 int()

`input()`으로 입력받은 값은 숫자를 입력하더라도 문자열(`str`)로
처리된다.

따라서 숫자 크기를 비교하려면 `int()`를 사용하여 정수로 변환해야 한다.

``` python
guess = int(input("숫자를 입력하세요: "))
```

### while True와 break

사용자가 언제 정답을 맞힐지 미리 알 수 없기 때문에 `while True`로 반복을
계속 수행한다.

정답을 맞힌 순간 `break`를 실행하여 반복문을 종료한다.

즉,

``` text
while True
   ↓
사용자 입력
   ↓
정답과 비교
   ├─ 작음 → Up
   ├─ 큼   → Down
   └─ 같음 → 정답 출력 → break
```

와 같은 흐름으로 동작한다.

## 13. 오늘 배운 핵심 정리

### 반복문의 선택

  상황                                 사용
  ------------------------------------ -------------------
  정해진 횟수만큼 반복                 `for` + `range()`
  리스트 등의 데이터를 순서대로 처리   `for`
  특정 조건이 유지되는 동안 반복       `while`
  반복문을 즉시 종료                   `break`
  현재 반복만 건너뜀                   `continue`
  반복문 안에서 반복                   중첩 반복문

### 데이터 처리 흐름

``` text
데이터 순회
   ↓
조건 확인
   ↓
원하는 데이터 필터링
   ↓
누적 변수로 집계
   ↓
합계 / 평균 / 최댓값 / 최솟값 계산
```

## 14. 오늘의 핵심 포인트

1.  `for` 문은 **정해진 횟수나 시퀀스 데이터를 순회**할 때 사용한다.
2.  `range()`는 반복 횟수와 숫자 범위를 제어할 때 유용하다.
3.  `while` 문은 **조건이 참인 동안 반복**하므로 종료 조건을 주의해야
    한다.
4.  `break`는 반복문 전체를 종료하고, `continue`는 현재 반복만 건너뛴다.
5.  중첩 반복문은 2차원 데이터처럼 여러 단계의 데이터를 순회할 때 활용할
    수 있다.
6.  반복문과 조건문을 조합하면 원하는 조건의 데이터를 필터링할 수 있다.
7.  누적 변수를 사용하면 데이터의 개수와 합계를 계산할 수 있다.
8.  첫 번째 데이터를 기준으로 설정하면 반복문을 통해 최댓값과 최솟값을
    갱신할 수 있다.
9.  `input()`의 결과는 문자열이므로 숫자 비교가 필요하면 `int()` 등의
    형변환이 필요하다.
10. `while True`와 `break`를 조합하면 종료 시점을 미리 알 수 없는 반복
    로직을 구현할 수 있다.

## 15. 느낀 점

오늘 학습을 통해 반복문이 단순히 같은 코드를 여러 번 실행하는 문법이
아니라, **데이터를 순회하고 조건에 맞는 데이터를 찾아 가공하는 기본적인
도구**라는 점을 이해했다.

특히 `for`와 `if`를 조합하면 데이터 필터링이 가능하고, 누적 변수를 함께
사용하면 합계나 평균과 같은 통계값까지 계산할 수 있다는 점이
인상적이었다.

앞으로 데이터 분석을 공부하면서 Pandas와 같은 도구를 사용하게 되더라도,
오늘 배운 반복문과 조건문의 동작 원리를 이해하고 있어야 데이터 처리
과정을 제대로 이해할 수 있을 것 같다.
