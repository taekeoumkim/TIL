## 연산자

### 산술 연산자

파이썬에서는 기본적인 사칙연산뿐만 아니라 몫, 나머지, 거듭제곱을 위한 연산자도 제공한다.

| 연산자 | 의미 | 예시 | 결과 |
| --- | --- | --- | --- |
| `+` | 덧셈 | `7 + 3` | `10` |
| `-` | 뺄셈 | `7 - 3` | `4` |
| `*` | 곱셈 | `7 * 3` | `21` |
| `/` | 나눗셈 | `7 / 3` | `2.333...` |
| `//` | 몫 | `7 // 3` | `2` |
| `%` | 나머지 | `7 % 3` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

`/` 연산자는 정수끼리 나누더라도 결과를 `float`로 반환한다.

```python
print(4 / 2)
# 2.0
```

`//`은 소수점 이하를 버리고 몫을 구하고, `%`는 나머지를 구한다.

```python
print(7 // 3)
# 2

print(7 % 3)
# 1
```

`%` 연산자는 짝수/홀수 확인이나 배수 검사 등에 활용할 수 있다.

### 복합 대입 연산자

변수의 기존 값에 연산을 수행한 뒤 다시 같은 변수에 저장할 때 사용할 수 있다.

```python
score = 100

score += 50  # score = score + 50
score -= 20  # score = score - 20
score *= 2   # score = score * 2
score /= 2   # score = score / 2
score %= 3   # score = score % 3
```

복합 대입 연산자를 사용하면 코드를 짧게 만들 수 있고 변수명을 반복해서 작성하는 과정에서 발생할 수 있는 실수를 줄일 수 있다.

## 비교 연산자

비교 연산자는 두 값을 비교하여 `True` 또는 `False`를 반환한다.

### 동등 비교

```python
10 == 10  # True
10 != 5   # True
```

여기서 `=`과 `==`을 구분하는 것이 중요하다.

- `=` : 값을 대입
- `==` : 두 값이 같은지 비교
- `!=` : 두 값이 다른지 비교

### 대소 비교

```python
10 > 5
10 < 20
10 >= 10
10 <= 10
```

숫자뿐만 아니라 문자열도 비교할 수 있다.

```python
print("apple" < "banana")
# True
```

문자열은 알파벳 순서 및 유니코드 주소값을 기준으로 선후 관계를 비교한다.

## 논리 연산자

여러 조건을 하나로 결합할 때 `and`, `or`, `not`을 사용한다.

### `and`

모든 조건이 `True`일 때만 `True`가 된다.

```python
is_adult = True
has_ticket = False

print(is_adult and has_ticket)
# False
```

### `or`

조건 중 하나라도 `True`이면 `True`가 된다.

```python
print(is_adult or has_ticket)
# True
```

### `not`

현재 논리 상태를 반대로 뒤집는다.

```python
print(not is_adult)
# False
```

---

## 단락 회로 평가

논리 연산에서는 왼쪽 항만 확인해도 전체 결과가 확정되는 경우 오른쪽 항을 실행하지 않는다.

### `and`의 단락 회로 평가

`and`는 왼쪽이 `False`라면 오른쪽 결과와 관계없이 최종 결과가 `False`이므로 오른쪽을 평가하지 않는다.

```python
result = False and (10 / 0 > 1)

print(result)
# False
```

오른쪽의 `10 / 0`은 실행되지 않기 때문에 `ZeroDivisionError`가 발생하지 않는다.

### `or`의 단락 회로 평가

`or`는 왼쪽이 `True`라면 최종 결과가 무조건 `True`이므로 오른쪽을 평가하지 않는다.

```python
result = True or (10 / 0 > 1)

print(result)
# True
```

단락 회로 평가는 단순한 논리 규칙뿐만 아니라 불필요한 연산을 생략하는 방식이라는 점을 기억해야 한다.

## 연산자 우선순위

복합적인 연산식을 작성할 때는 연산자마다 실행되는 순서가 다르다.

자료에서 배운 기본적인 순서는 다음과 같다.

```text
**
↓
*, /, //, %
↓
+, -
↓
비교 연산자
↓
not
↓
and
↓
or
```

예를 들어:

```python
result1 = 10 + 2 * 5 > 25
# 2 * 5 → 10 + 10 → 20 > 25
# False
```

괄호를 사용하면 원하는 연산을 먼저 실행할 수 있다.

```python
result2 = (10 + 2) * 5 > 25
# (10 + 2) → 12 * 5 → 60 > 25
# True
```

복잡한 식에서는 우선순위를 암기하는 것보다 **괄호를 명시적으로 사용하여 의도를 드러내는 것**이 가독성과 안전성 측면에서 유리하다.

# 문자열 형식화

문자열 형식화(Formatting)는 변수에 담긴 데이터를 일정한 문자열 틀에 넣어 정형화된 형태로 출력하는 방법이다.

파이썬에서는 크게 `%` 연산자, `str.format()`, `f-string` 세 가지 방식을 배웠다.

## 1세대: `%` 연산자

문자열 안에 `%s`, `%d`, `%f`와 같은 서식 지정자를 넣고 뒤에서 값을 전달한다.

```python
print("이름: %s, 나이: %d" % ("홍길동", 20))
```

주요 서식 지정자는 다음과 같다.

- `%s` : 문자열
- `%d` : 정수
- `%f` : 실수

출력 너비와 소수점 자리도 지정할 수 있다.

```python
print("[%5d]" % 123)
# 오른쪽 정렬, 5칸 확보

print("%.2f" % 3.14159)
# 3.14
```

레거시 코드에서 볼 수 있는 방식이지만 변수의 자료형과 서식 지정자의 타입이 맞지 않으면 문제가 발생할 수 있다.

---

## 2세대: `str.format()`

`str.format()`은 문자열 내부의 중괄호 `{}`에 값을 넣는 방식이다.

```python
menu_name = "Cafe Latte"
quantity = 2
menu_price = 5000

message = "주문 내역: {0} {1}잔 - 총 {2}원".format(
    menu_name,
    quantity,
    menu_price * quantity
)

print(message)
```

인덱스 대신 이름을 사용할 수도 있다.

```python
message = "메뉴: {item} | 결제금액: {total}원".format(
    item=menu_name,
    total=menu_price * quantity
)

print(message)
```

이름을 사용하면 가독성을 높일 수 있다는 장점이 있다.

다만 변수가 많아지면 문자열과 `.format(...)` 사이의 거리가 멀어져 코드를 한눈에 파악하기 어려워질 수 있다.

---

## 3세대: f-string

f-string은 파이썬 3.6부터 도입된 문자열 형식화 방식으로, 현재 표준적으로 많이 사용하는 방식이다.

문자열 앞에 `f`를 붙이고 `{}` 안에 변수나 간단한 수식을 직접 작성한다.

```python
name = "Cheese Cake"
price = 6500
qty = 1

print(f"주문하신 {name} {qty}개의 최종 청구액은 {price * qty}원입니다.")
```

변수뿐만 아니라 간단한 계산식도 직접 넣을 수 있어 편리하다.

---

## f-string 정렬 및 숫자 형식 지정

중괄호 안에서 `:` 뒤에 서식 지정자를 사용하면 출력 형식을 제어할 수 있다.

### 왼쪽 / 오른쪽 정렬

```python
name = "Cheese Cake"
price = 6500

print(f"{name:<12}")
print(f"{price:>10}")
```

- `<` : 왼쪽 정렬
- `>` : 오른쪽 정렬
- 숫자 : 확보할 너비

### 천 단위 쉼표

```python
price = 15000

print(f"{price:,}")
# 15,000
```

정렬과 천 단위 쉼표를 함께 사용할 수도 있다.

```python
print(f"{price:>10,}")
# 10칸 확보 + 오른쪽 정렬 + 천 단위 쉼표
```

---

## f-string 디버깅 조절자 `=`

f-string의 `{변수명=}` 문법을 사용하면 변수 이름과 현재 값을 함께 출력할 수 있다.

```python
score = 95

print(f"{score=}")
# score=95
```

로그를 확인하거나 디버깅할 때 변수의 이름을 따로 작성하지 않아도 되기 때문에 유용하다.

```python
current_status = "정산 진행중"
price = 6500

print(f"디버깅 로그 -> {current_status=}, {price=}")
```

## 일일 정산 영수증 만들기

f-string의 정렬 기능을 이용하면 데이터를 표 형태로 깔끔하게 출력할 수 있다.

```python
orders = [
    ("Cafe Latte", 5000, 2),
    ("Americano", 4500, 1),
    ("Cheese Cake", 6500, 1)
]

print("=" * 35)
print(f"{'메뉴명':<12}{'단가':>8}{'수량':>4}{'금액':>9}")
print("-" * 35)

total_receipt_amount = 0

for menu, item_price, qty in orders:
    subtotal = item_price * qty
    total_receipt_amount += subtotal

    print(
        f"{menu:<12}"
        f"{item_price:>8,}"
        f"{qty:>4}"
        f"{subtotal:>9,}"
    )

print("-" * 35)
print(f"{'합계 금액':<12}{total_receipt_amount:>21,}원")
print("=" * 35)
```

이 예제를 통해 단순히 문자열을 출력하는 것뿐만 아니라 **정렬, 천 단위 쉼표, 반복문에서 계산한 값의 출력**까지 하나의 형식으로 묶을 수 있다는 것을 확인했다.

## 오늘 배운 것 정리

- 산술 연산자에는 `+`, `-`, `*`, `/`, `//`, `%`, `**`가 있다.
- `//`은 몫, `%`는 나머지, `**`는 거듭제곱을 계산한다.
- `+=`, `-=`, `*=`, `/=`, `//=`, `%=` 등의 복합 대입 연산자를 사용할 수 있다.
- 비교 연산자의 결과는 `True` 또는 `False`이다.
- `and`, `or`, `not`을 이용하여 여러 조건을 결합할 수 있다.
- 파이썬은 단락 회로 평가를 통해 결과가 확정되면 불필요한 오른쪽 연산을 수행하지 않는다.
- 연산자가 여러 개 섞인 식에서는 우선순위를 고려하고, 복잡한 경우 괄호를 활용하는 것이 좋다.
- 문자열 형식화에는 `%`, `str.format()`, `f-string` 방식이 있다.
- f-string은 변수와 계산식을 문자열 안에 직접 넣을 수 있어 직관적이다.
- f-string의 `:<12`, `:>10,` 같은 서식을 이용하면 정렬과 숫자 표현을 제어할 수 있다.
- `{변수=}`를 사용하면 디버깅 시 변수 이름과 값을 함께 확인할 수 있다.
