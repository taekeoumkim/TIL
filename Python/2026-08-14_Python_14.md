## 1. 오늘 배운 내용

오늘은 파이썬에서 기본으로 제공하는 **내장 함수(Built-in Function)**를 학습했다.

내장 함수를 활용하면 복잡한 반복문이나 조건문을 직접 작성하지 않고도 데이터의 **유효성 검증, 상태 확인, 통계 계산, 데이터 변환 및 필터링, 정렬과 데이터 결합** 등을 간단하게 처리할 수 있다.

## 2. `isinstance()` - 자료형 검증

`isinstance()`는 특정 값이 지정한 자료형인지 확인하는 함수이다.

```python
order_count = 3

if isinstance(order_count, int):
    print("정상적인 주문 수량입니다.")
else:
    print("주문 수량을 숫자로 입력해주세요.")
```

`isinstance(값, 자료형)`의 결과는 `True` 또는 `False`이다.

- 입력값의 자료형을 확인할 수 있다.
- 실제 데이터 처리 전에 입력값을 검증하는 용도로 사용할 수 있다.

## 3. `all()`과 `any()` - 여러 조건 확인

### `all()`

전달된 모든 요소가 `True`일 때 `True`를 반환한다.

```python
task_status = [True, True, False]
print(all(task_status))  # False
```

### `any()`

하나 이상의 요소가 `True`이면 `True`를 반환한다.

```python
task_status = [True, True, False]
print(any(task_status))  # True
```

회원 가입 시 모든 필수 약관에 동의했는지 확인할 때는 `all()`, 여러 로그인 수단 중 하나라도 활성화되어 있는지 확인할 때는 `any()`를 활용할 수 있다.

### 빈 데이터 주의

```python
empty_list = []

print(all(empty_list))  # True
print(any(empty_list))  # False
```

`all([])`은 `True`이므로 데이터 자체가 없는 상황을 정상 상태로 잘못 판단할 수 있다.

따라서 다음처럼 데이터 존재 여부를 먼저 확인하는 것이 안전하다.

```python
user_inputs = []

if user_inputs and all(user_inputs):
    print("안전하게 검증 통과")
else:
    print("입력 데이터가 없거나 조건에 맞지 않습니다.")
```

## 4. `len()`, `sum()`, `round()` - 데이터 요약

```python
order_amounts = [12500, 23000, 17500, 32000]

order_count = len(order_amounts)
total_amount = sum(order_amounts)
average_amount = total_amount / order_count

print("주문 건수:", order_count)
print("총 주문 금액:", total_amount)
print("평균 주문 금액:", round(average_amount, 2))
```

결과:

```text
주문 건수: 4
총 주문 금액: 85000
평균 주문 금액: 21250.0
```

| 함수 | 역할 |
| --- | --- |
| `len()` | 데이터 개수 |
| `sum()` | 숫자 데이터의 합계 |
| `round()` | 원하는 소수점 자리까지 반올림 |

## 5. `statistics.mean()`과 `statistics.median()`

평균과 중앙값을 비교하여 데이터의 특징을 파악할 수 있다.

```python
import statistics

response_times = [5, 6, 7, 8, 60]

average_time = statistics.mean(response_times)
median_time = statistics.median(response_times)

print("평균 처리 시간:", average_time)
print("중앙 처리 시간:", median_time)
```

결과:

```text
평균 처리 시간: 17.2
중앙 처리 시간: 7
```

`60`이라는 큰 값 때문에 평균은 `17.2`까지 올라갔지만 중앙값은 `7`이다.

- `statistics.mean()` : 데이터의 평균
- `statistics.median()` : 정렬했을 때 가운데 위치하는 값
- 극단적인 값이 있는 경우 평균과 중앙값을 함께 확인하면 데이터의 특징을 더 잘 파악할 수 있다.

## 6. `map()` - 데이터 일괄 변환

`map()`은 모든 요소에 동일한 함수를 적용하여 데이터를 변환한다.

```python
product_prices = [10000, 15000, 20000]

final_prices = list(
    map(lambda price: price + 3000, product_prices)
)

print(final_prices)
```

결과:

```text
[13000, 18000, 23000]
```

`lambda`와 함께 사용하면 간단한 변환 규칙을 만들 수 있다.

```python
original_prices = [1000, 2000, 3000]

discounted = list(
    map(lambda x: x * 0.9, original_prices)
)

print(discounted)
```

결과:

```text
[900.0, 1800.0, 2700.0]
```

## 7. `filter()` - 조건에 맞는 데이터 추출

`filter()`는 조건 함수의 결과가 `True`인 요소만 선택한다.

```python
stock_counts = [3, 15, 8, 20, 12]

available_stocks = list(
    filter(lambda stock: stock >= 10, stock_counts)
)

print(available_stocks)
```

결과:

```text
[15, 20, 12]
```

### `map()`과 `filter()` 비교

| 함수 | 목적 |
| --- | --- |
| `map()` | 모든 요소를 같은 규칙으로 변환 |
| `filter()` | 조건을 만족하는 요소만 추출 |

## 8. `enumerate()` - 인덱스 자동 부여

반복문에서 데이터와 함께 순서 번호를 가져올 수 있다.

```python
tasks = ["데이터 확인", "보고서 작성", "결과 공유"]

for number, task in enumerate(tasks, start=1):
    print(f"{number}. {task}")
```

결과:

```text
1. 데이터 확인
2. 보고서 작성
3. 결과 공유
```

`start=1`을 지정하면 번호를 1부터 시작할 수 있다.

## 9. `zip()` - 여러 데이터 결합

`zip()`은 여러 데이터 목록에서 같은 위치에 있는 요소들을 묶어준다.

```python
products = ["노트북", "키보드", "마우스"]
prices = [1200000, 80000, 40000]

for product, price in zip(products, prices):
    print(f"{product}: {price}원")
```

결과:

```text
노트북: 1200000원
키보드: 80000원
마우스: 40000원
```

서로 관련된 여러 리스트를 동시에 순회할 때 유용하다.

## 10. `sorted()`, `min()`, `max()` - 정렬 및 최솟값·최댓값

```python
order_amounts = [25000, 12000, 48000, 31000]

print(sorted(order_amounts))
print(sorted(order_amounts, reverse=True))
print(min(order_amounts))
print(max(order_amounts))
```

결과:

```text
[12000, 25000, 31000, 48000]
[48000, 31000, 25000, 12000]
12000
48000
```

- `sorted()` : 정렬한 새로운 리스트 반환
- `reverse=True` : 내림차순 정렬
- `min()` : 최솟값 반환
- `max()` : 최댓값 반환

## 12. 오늘의 핵심 정리

오늘은 내장 함수를 목적에 맞게 조합하면 반복문과 조건문을 직접 많이 작성하지 않고도 데이터를 효율적으로 처리할 수 있다는 것을 배웠다.

특히 기억할 내용:

```text
isinstance()
→ 자료형을 검증한다.

all() / any()
→ 여러 조건을 한 번에 판단한다.

len() / sum() / round()
→ 데이터를 간단하게 요약한다.

mean() / median()
→ 평균과 중앙값으로 데이터의 특성을 파악한다.

map()
→ 모든 데이터를 같은 규칙으로 변환한다.

filter()
→ 조건을 만족하는 데이터만 추출한다.

enumerate()
→ 데이터와 순서 번호를 함께 사용한다.

zip()
→ 서로 관련된 데이터를 묶어서 처리한다.

sorted() / min() / max()
→ 데이터를 정렬하고 최솟값·최댓값을 구한다.
```

가장 주의할 부분은 **`all([])`이 `True`를 반환한다는 점**이다. 따라서 데이터 검증에서는 데이터가 비어 있지 않은지 먼저 확인하는 것이 중요하다.
