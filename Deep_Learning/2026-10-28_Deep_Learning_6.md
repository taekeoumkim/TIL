## 1. 순차 데이터와 순서의 중요성

순차 데이터(Sequential Data)는 **데이터가 나타나는 순서나 시점 사이의 관계가 중요한 데이터**이다.

| 데이터 유형 | 예시 | 순서가 중요한 이유 |
| --- | --- | --- |
| 텍스트 | 문장을 이루는 단어 | 단어의 순서와 역할에 따라 의미가 달라짐 |
| 시계열 | 일별 판매량, 기온, 센서 측정값 | 이전 값과 변화 흐름이 현재·미래 값과 관련될 수 있음 |
| 음성 | 시간에 따른 소리 신호 | 소리가 발생한 순서와 문맥이 중요함 |

예를 들어 최근 3일 주문량이 다음과 같다고 하자.

| 날짜 | 상품 A | 상품 B |
| --- | ---: | ---: |
| 1일차 | 10 | 40 |
| 2일차 | 20 | 35 |
| 3일차 | 30 | 30 |

마지막 값은 모두 30이지만 A는 증가하고 B는 감소하는 흐름이다. 다음 날을 예측할 때는 현재 값뿐 아니라 **이전 값들이 어떤 순서로 나타났는지**도 활용할 수 있다.

순차 데이터에서 입력 하나를 처리하는 단위를 Time Step(시점)이라고 한다. $x_t$는 $t$번째 시점의 입력을 뜻한다.

## 2. RNN과 Hidden State

RNN(Recurrent Neural Network)은 현재 입력과 이전 시점의 상태를 함께 사용해 순차 데이터를 처리하는 신경망이다.

기본적인 관계는 다음과 같다.

$$
h_t=\tanh(W_xx_t+W_hh_{t-1}+b)
$$

이 식은 입력과 상태를 열벡터로 나타낸 표기이다.

| 기호 | 의미 |
| --- | --- |
| $x_t$ | 현재 시점의 입력 |
| $h_{t-1}$ | 이전 시점의 Hidden State |
| $h_t$ | 현재 시점의 Hidden State |
| $W_x$ | 입력에 적용하는 가중치 |
| $W_h$ | 이전 상태에 적용하는 가중치 |
| $b$ | 편향 |
| $\tanh$ | 새로운 상태를 계산하는 활성화 함수 |

초기 상태 $h_0$를 정한 뒤 첫 입력부터 순서대로 계산한다. 각 시점에서 구한 상태가 다음 시점으로 전달되는 연결을 순환 연결(Recurrent Connection)이라고 한다.

### Hidden State의 역할

Hidden State(은닉 상태)는 현재 시점까지 처리한 정보를 반영하는 중간 표현이다.

두 번째 시점의 $h_2$는 $x_2$와 $h_1$을 사용하고, 세 번째 시점의 $h_3$는 $x_3$와 $h_2$를 사용한다. 따라서 현재 입력뿐 아니라 이전 시점에서 전달된 정보도 반영될 수 있다.

다만 **Hidden State는 모든 과거 입력을 그대로 저장하는 공간은 아니다.** 입력을 변환하고 요약한 결과이므로 일부 정보가 약해지거나 사라질 수 있다.

Hidden State 자체를 곧바로 최종 확률이나 예측값으로 해석하지도 않는다. 과제에 맞는 출력층을 연결해 분류 점수나 회귀값 등을 계산할 수 있다.

### 시간축에서의 가중치 공유

각 시점의 계산은 다음과 같다.

$$
h_1=\tanh(W_xx_1+W_hh_0+b)
$$

$$
h_2=\tanh(W_xx_2+W_hh_1+b)
$$

$$
h_3=\tanh(W_xx_3+W_hh_2+b)
$$

모든 시점에서 사용하는 $W_x$, $W_h$, $b$는 동일하다. **같은 계산 규칙을 시간축을 따라 반복 적용**하는 것이다.

시퀀스가 길어져도 가중치 개수가 시점 수에 비례해 늘어나는 것은 아니다. 다만 처리해야 할 계산 단계는 늘어난다.

## 3. NumPy로 RNN 순전파 확인하기

입력과 상태가 각각 숫자 하나인 예제로 계산한다.

$$
x=[1,2,3],\qquad W_x=0.5,\qquad W_h=0.5,\qquad b=0,\qquad h_0=0
$$

$$
h_t=\tanh(0.5x_t+0.5h_{t-1})
$$

| 시점 | 현재 입력 | 이전 상태 | 현재 상태 |
| ---: | ---: | ---: | ---: |
| 1 | 1 | 0.000 | 0.462 |
| 2 | 2 | 0.462 | 0.843 |
| 3 | 3 | 0.843 | 0.958 |

예를 들어 두 번째 상태는 다음과 같다.

$$
h_2=\tanh(0.5\times2+0.5\times0.462\ldots)\approx0.843
$$

계산에는 반올림하지 않은 상태를 사용하고, 표에서는 소수 셋째 자리까지 표시했다.

```python
import numpy as np

X = np.array([1.0, 2.0, 3.0])
Wx, Wh, b = 0.5, 0.5, 0.0
h = 0.0
hidden_states = []

for t, x in enumerate(X, start=1):
    previous_h = h
    z = Wx * x + Wh * previous_h + b
    h = np.tanh(z)
    hidden_states.append(h)

    print(
        f"시점 {t}: 입력={x:.1f}, "
        f"이전 상태={previous_h:.3f}, 현재 상태={h:.3f}"
    )

print(np.round(hidden_states, 3))  # [0.462 0.843 0.958]
print(round(h, 3))                # 0.958
```

이 예제는 학습된 예측 모델이 아니라, 현재 입력과 이전 상태가 다음 상태에 반영되는 과정을 확인하는 순전파 예제이다.

## 4. 장기 의존성과 RNN의 한계

장기 의존성(Long-Term Dependency)은 **멀리 떨어진 시점의 정보가 현재 처리나 예측에 중요한 영향을 미치는 관계**이다.

긴 문장에서 뒤에 나온 대명사를 이해하려면 앞부분의 인물이나 사물 정보를 활용해야 하는 경우가 대표적인 예이다.

RNN에서는 오래전 정보가 여러 상태 갱신을 거쳐 전달된다. 학습할 때도 시간축을 따라 역전파를 수행하며, 이를 BPTT(Backpropagation Through Time)라고 한다.

### 시간축의 기울기 전달

Chain Rule에 따라 작은 미분값이 반복해서 곱해지면 기울기가 점점 작아질 수 있다.

| 전달 단계 수 | 매 단계 0.5가 곱해지는 경우 |
| ---: | ---: |
| 0 | 1 |
| 1 | 0.5 |
| 2 | 0.25 |
| 4 | 0.0625 |
| 8 | 0.00390625 |

이렇게 기울기가 매우 작아지면, 오래전 입력이 현재 손실에 미친 영향을 학습하기 어려워질 수 있다.

실제 RNN에서는 가중치와 활성화 함수의 미분값 등이 함께 작용하므로 모든 RNN에서 반드시 같은 현상이 생기는 것은 아니다. 다만 기본 RNN은 긴 시퀀스의 정보를 유지하고 장기 의존성을 학습하는 데 어려움을 겪을 수 있다.

## 5. LSTM의 두 상태와 Gate 구조

LSTM(Long Short-Term Memory)은 기본 RNN의 장기 의존성 학습 문제를 완화하기 위한 신경망이다. **Hidden State 외에 Cell State를 사용하고, Gate로 정보의 유지와 갱신을 조절**한다.

### Hidden State와 Cell State

| 구분 | Hidden State $h_t$ | Cell State $c_t$ |
| --- | --- | --- |
| 주요 역할 | 현재 시점의 표현 | 시점 사이의 정보 유지·갱신 |
| 활용 | 다음 시점의 계산, 출력층의 입력 등 | 다음 시점으로 전달하는 별도 상태 |
| 갱신에 관여하는 요소 | Cell State와 Output Gate | Forget Gate와 Input Gate |

두 상태는 같은 값이 아니다. Cell State는 정보를 유지하는 경로를 제공하지만, 과거 정보를 모두 완벽하게 보관하는 것은 아니다.

### 세 가지 Gate

| Gate | 역할 |
| --- | --- |
| Forget Gate $f_t$ | 이전 Cell State를 얼마나 유지할지 조절 |
| Input Gate $i_t$ | 새로운 정보 후보를 얼마나 반영할지 조절 |
| Output Gate $o_t$ | 갱신된 Cell State를 현재 Hidden State로 얼마나 내보낼지 조절 |

Gate는 일반적으로 현재 입력과 이전 Hidden State를 이용해 계산하며, Sigmoid로 0과 1 사이의 값을 만든다.

0에 가까우면 해당 정보의 반영 정도가 작고, 1에 가까우면 크다. 실제 Gate는 벡터일 수 있으며, 원소마다 다른 값을 적용한다. Gate 값들은 서로 다른 역할을 하므로 합이 1이어야 하는 것은 아니다.

## 6. LSTM의 상태 갱신 계산

일반적인 LSTM에서 새로운 정보 후보를 $\tilde c_t$라고 하면, 핵심 관계는 다음과 같다.

$$
c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t
$$

$$
h_t=o_t\odot\tanh(c_t)
$$

$\odot$는 행렬곱이 아니라 **원소별 곱셈**이다. 새로운 정보 후보는 현재 입력과 이전 Hidden State를 바탕으로 계산하며, 일반적인 LSTM에서는 Tanh를 사용한다.

### 이전 정보 유지와 새로운 정보 추가

다음 값이 주어졌다고 하자.

| 항목 | 값 |
| --- | ---: |
| 이전 Cell State $c_{t-1}$ | 0.8 |
| Forget Gate $f_t$ | 0.9 |
| 새로운 정보 후보 $\tilde c_t$ | 0.5 |
| Input Gate $i_t$ | 0.2 |

유지할 이전 정보는 $0.9\times0.8=0.72$이고, 새로 추가할 정보는 $0.2\times0.5=0.1$이다.

$$
c_t=0.9\times0.8+0.2\times0.5=0.82
$$

Output Gate를 계산 예시로 $o_t=0.7$이라고 두면 현재 Hidden State는 다음과 같다.

$$
h_t=0.7\tanh(0.82)\approx0.473
$$

### NumPy로 원소별 상태 갱신 확인하기

```python
import numpy as np

c_previous = np.array([0.8])
forget_gate = np.array([0.9])
input_gate = np.array([0.2])
candidate = np.array([0.5])
output_gate = np.array([0.7])

c = (
    forget_gate * c_previous
    + input_gate * candidate
)
h = output_gate * np.tanh(c)

print(round(c[0], 2))  # 0.82
print(round(h[0], 3))  # 0.473
```

이 코드는 Gate 값이 주어졌을 때 상태를 갱신하는 예제이다. 실제 모델에서는 Gate와 정보 후보를 계산하는 가중치도 학습한다.

### LSTM이 장기 의존성을 완화하는 이유

LSTM은 이전 Cell State의 일부를 유지하는 경로와 새로운 정보를 더하는 경로를 제공한다. Forget Gate가 1에 가까우면 이전 Cell State의 정보를 상당 부분 유지할 수 있다.

이러한 구조는 기본 RNN보다 긴 시퀀스에서 정보와 기울기를 전달하는 데 도움이 될 수 있다. 하지만 **기울기 소실이나 모든 장기 의존성 문제를 완전히 해결한다는 의미는 아니다.**

## 7. 입력과 출력 구조에 따른 활용

RNN과 LSTM은 문제에 따라 마지막 상태를 활용하거나 여러 시점의 상태를 활용할 수 있다.

| 구조 | 입력 | 출력 | 대표 사례 |
| --- | --- | --- | --- |
| Many-to-One | 여러 시점의 입력 | 하나의 결과 | 리뷰 감정 분류, 다음 날 판매량 예측 |
| Many-to-Many | 여러 시점의 입력 | 여러 결과 | 단어별 품사 분류, 여러 미래 시점 예측 |

### Many-to-One

리뷰의 단어들을 순서대로 처리한 뒤, 마지막 상태를 출력층에 전달해 긍정·부정을 예측할 수 있다.

최근 7일의 판매량으로 다음 날의 판매량 하나를 예측하는 것도 이 구조로 표현할 수 있다. 여러 입력을 사용한다는 점은 같지만, 출력은 분류 확률일 수도 있고 연속적인 수치일 수도 있다.

### Many-to-Many

각 단어를 처리하면서 그 단어의 품사를 예측하는 경우에는 입력 시점마다 대응하는 결과를 계산한다.

입력과 출력의 길이가 반드시 같아야 하는 것은 아니다. 과거 7일로 미래 3일을 예측하는 것처럼, 입력을 처리하는 부분과 출력을 생성하는 부분을 나눈 Encoder-Decoder 구조 등을 사용할 수도 있다.

출력 시퀀스를 생성하는 모델의 학습에서는 Teacher Forcing을 사용할 수 있다. 이는 이전에 예측한 값 대신 이전 시점의 실제 정답을 다음 입력으로 사용하는 방법이다.

## 8. RNN·LSTM 비교와 모델 선택

두 모델은 순차 데이터를 처리하고, 이전 상태를 현재 계산에 활용하며, 같은 가중치를 여러 시점에 공유한다. 학습에도 순전파·손실 계산·역전파·Optimizer 업데이트라는 기본 흐름이 적용된다.

비슷한 입력 크기와 은닉 크기를 기준으로 비교하면 다음과 같다.

| 구분 | 기본 RNN | LSTM |
| --- | --- | --- |
| 전달하는 상태 | Hidden State | Hidden State와 Cell State |
| 정보 조절 | 상태의 반복 갱신 | Gate를 이용한 선택적 유지·갱신 |
| 장기 의존성 | 학습이 어려울 수 있음 | 문제를 완화하는 구조 |
| 구조 | 비교적 단순 | 상대적으로 복잡 |
| 파라미터 수 | 상대적으로 적음 | 상대적으로 많음 |
| 계산 비용 | 일반적으로 적음 | 일반적으로 더 많음 |

### 활용 분야

| 분야 | 활용 사례 |
| --- | --- |
| 텍스트 | 리뷰 감정 분류, 문장 주제 분류, 단어별 품사 분류 |
| 시계열 | 판매량·전력 사용량·기온·센서 측정값 예측 |
| 음성 | 음성 인식, 음성 신호 분류, 구간별 특징 분석 |

짧은 시퀀스에서 장기 의존성이 중요하지 않다면 기본 RNN을 비교 모델로 고려할 수 있다. 오래전 정보가 중요한 문제라면 LSTM의 구조가 도움이 될 수 있다.

하지만 **시퀀스가 길다는 이유만으로 LSTM의 성능이 항상 더 좋은 것은 아니다.** 입력 길이, 과거 정보의 중요성, 학습·추론 비용과 검증 성능을 함께 확인해야 한다.

시계열 문제에도 RNN이나 LSTM만 사용할 수 있는 것은 아니다. 통계 모델과 다른 머신러닝 모델도 문제에 따라 비교할 수 있다.

### Transformer와의 연결

RNN과 LSTM은 이전 상태를 다음 시점으로 전달하므로 기본 순전파에 시점 간 계산 의존성이 있다. Transformer는 Attention을 이용해 시퀀스 내 위치 사이의 관계를 계산한다.

| 구분 | RNN·LSTM | Transformer |
| --- | --- | --- |
| 핵심 처리 방식 | 이전 상태를 다음 시점으로 전달 | Attention으로 위치 간 관계 계산 |
| 주요 정보 구조 | Hidden State, Cell State 등 | 위치 간 Attention |
| 계산의 특징 | 시간축의 상태 계산이 순차적으로 연결됨 | 입력의 여러 위치 간 관계를 병렬 계산할 수 있음 |

두 구조는 순차 정보를 처리하는 방식이 다르다. 실제 모델 선택은 구조의 이름만으로 결정하기보다 데이터와 처리 환경, 검증 결과를 바탕으로 판단해야 한다.

## 핵심 정리

- 순차 데이터는 값 자체뿐 아니라 순서와 시점 사이의 관계도 중요한 데이터이다.
- RNN은 현재 입력과 이전 Hidden State로 새로운 상태를 계산한다.
- 같은 가중치를 여러 시점에 공유하므로 시퀀스 길이에 비례해 가중치 개수가 늘어나지는 않는다.
- 긴 시퀀스에서 시간축을 따라 기울기를 전달하면 장기 의존성 학습이 어려워질 수 있다.
- LSTM은 Hidden State와 Cell State를 구분하고, Forget·Input·Output Gate로 정보의 흐름을 조절한다.
- LSTM은 장기 의존성 문제를 완화하지만, 모든 과거 정보를 완벽하게 기억하거나 항상 더 좋은 성능을 보장하지는 않는다.
- Many-to-One과 Many-to-Many는 필요한 출력의 형태에 따라 구분하며, 입력·출력 길이가 항상 같을 필요는 없다.

## 오늘의 한 문장

> RNN은 은닉 상태로 이전 정보를 전달하며, LSTM은 Cell State와 Gate를 추가해 어떤 정보를 유지하고 새로 반영할지 조절하면서 순차 데이터를 처리한다.
