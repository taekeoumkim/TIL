## 1. Pretrained Model: 구조와 학습된 가중치 구분

**사전학습 모델(Pretrained Model)**은 다른 데이터나 작업으로 미리 학습한 가중치를 가진 모델이다.

같은 ResNet 구조라도 가중치를 새로 초기화한 모델과 기존 데이터로 학습한 가중치를 불러온 모델은 출발점이 다르다.

| 개념 | 의미 |
| --- | --- |
| 모델 구조 | 레이어의 종류와 연결 방식 |
| 사전학습 가중치 | 기존 학습 과정에서 업데이트되어 저장된 파라미터 |
| Pretraining | 다른 작업에도 활용할 수 있는 표현이나 가중치를 미리 학습하는 과정 |

**ResNet이라는 구조를 사용한다는 사실만으로 사전학습 모델이 되는 것은 아니다.** 어떤 가중치를 사용했는지 함께 확인해야 한다.

CNN은 학습 과정에서 경계·선·질감과 여러 특징이 조합된 복잡한 형태 등을 표현하는 가중치를 학습할 수 있다. 이러한 특징 중 일부는 다른 이미지 문제에도 유용할 수 있다.

## 2. Transfer Learning과 Training from Scratch

### Source Task에서 배운 정보를 Target Task에 활용

**전이학습(Transfer Learning)**은 기존 모델이 학습한 가중치나 표현을 새로운 문제에 활용하는 접근 방법이다.

학습자료의 예시는 일반 이미지 분류에서 학습한 CNN을 강판 결함 분류에 활용하는 것이다.

| 구분 | 예시 |
| --- | --- |
| Source Task | 대규모 일반 이미지의 사물 분류 |
| Target Task | 강판 이미지의 7가지 결함 유형 중 하나를 분류 |
| 재사용할 정보 | 이미지의 경계·질감 등 특징을 추출하는 가중치 |
| 새로 학습할 정보 | 강판 결함을 구분하는 분류층과 필요에 따라 특징 추출 가중치 |

전이학습의 핵심은 **사전학습 가중치를 새로운 문제를 해결하는 출발점으로 활용**하는 것이다.

### 처음부터 학습하는 방식과 비교

| 구분 | Training from Scratch | Transfer Learning |
| --- | --- | --- |
| 초기 가중치 | 새롭게 초기화 | 사전학습 가중치 활용 |
| 기존 학습 정보 | 사용하지 않음 | 활용 |
| 특징 학습 | 새로운 데이터로 처음부터 학습 | 기존 특징을 재사용하거나 조정 |
| 고려 사항 | 데이터의 양과 학습 자원 | Source·Target의 유사성과 기존 특징의 적합성 |
| 학습 비용 | 클 수 있음 | 학습 범위에 따라 줄일 수 있음 |

전이학습은 데이터와 계산 자원이 제한된 상황에서 유용할 수 있지만, 항상 더 빠르거나 높은 성능을 보장하지는 않는다.

### Negative Transfer: 기존 학습이 오히려 불리할 수도 있다

일반 사물 이미지와 강판 결함 이미지는 중요한 특징이 다를 수 있다. 기존 특징이 새 작업에 맞지 않으면 전이학습의 효과가 제한되거나 오히려 성능에 불리할 수 있다.

기존 학습 정보의 활용이 새로운 작업에 불리하게 작용하는 현상을 **Negative Transfer(부정적 전이)**라고 한다.

사전학습 모델을 사용했다는 사실보다 Target Task의 Validation 성능이 실제로 좋아지는지가 중요하다.

## 3. Feature Extraction: Backbone을 고정하고 분류층 학습

Feature Extraction 방식의 전이학습은 사전학습된 특징 추출 가중치를 고정하고, 새로운 문제에 맞는 분류층을 학습한다.

### Backbone과 Classifier Head의 역할

| 구분 | Backbone | Classifier Head |
| --- | --- | --- |
| 역할 | 입력 이미지에서 특징 추출 | 특징을 이용해 클래스별 점수 계산 |
| 대표 구성 | Convolution 레이어 등 | Linear 레이어 등 |
| 출력 | 특징 벡터 | 클래스별 Logit |
| Feature Extraction에서의 학습 | 사전학습 가중치 고정 | 새롭게 구성하여 학습 |

기존 1,000개 클래스 분류층은 Source Task에 맞춰 학습되어 있다. 새로운 작업이 7개 클래스 분류라면 해당 작업에 맞게 분류층을 변경한다.

### Freeze는 업데이트 대상에서 제외한다는 뜻

Freeze는 특정 파라미터가 학습 중 업데이트되지 않도록 설정하는 것이다.

| 처리 | 고정한 Backbone | 새로운 분류층 |
| --- | --- | --- |
| 순전파에 사용 | 사용 | 사용 |
| 특징·예측 계산 | 특징 계산 | Logit 계산 |
| 가중치 업데이트 | 수행하지 않음 | 수행 |

Backbone은 계속 입력을 처리하여 특징을 계산한다. 가중치를 고정했다고 해당 레이어의 연산이 사라지는 것은 아니다.

PyTorch에서는 파라미터의 `requires_grad` 설정과 Optimizer에 전달할 파라미터를 통해 학습 대상을 제어할 수 있다.

### 가중치 고정과 실행 모드도 구분

Batch Normalization이 포함된 Backbone은 가중치의 Gradient 계산을 중지해도 학습 모드에서 통계값이 변경될 수 있다.

| 관리 대상 | 확인할 내용 |
| --- | --- |
| 파라미터 | 업데이트하지 않을 가중치가 고정되었는가? |
| Optimizer | 의도한 학습 대상이 전달되었는가? |
| 실행 상태 | BN 통계 등 고정하려는 상태도 적절히 관리되는가? |

따라서 고정된 특징 추출기를 사용하려면 **파라미터의 학습 여부와 학습·평가 모드를 별도로 관리**해야 한다.

## 4. ResNet18 예시로 Shape와 새로운 분류층 확인

학습자료에서는 이미지 4개를 한 배치로 처리하고, 강판의 7개 결함 유형을 분류하는 예시를 사용한다.

| 단계 | Shape | 의미 |
| --- | --- | --- |
| 입력 이미지 | $(4,3,224,224)$ | 배치 4, 채널 3, 높이·너비 224 |
| 최종 분류층 직전의 특징 | $(4,512)$ | 이미지마다 512차원 특징 벡터 |
| 새로운 분류층의 출력 | $(4,7)$ | 이미지마다 7개 클래스의 Logit |

위 설정에서는 기존 `Linear(512, 1000)`을 새로운 `Linear(512, 7)`로 바꿀 수 있다. 입력 크기와 특징 차원은 모델과 구성에 따라 달라질 수 있으므로 위 값은 ResNet18 예시로 이해한다.

**가중치 업데이트 여부와 순전파의 출력 Shape는 별개의 개념이다.** Backbone을 고정해도 위 특징 벡터의 Shape는 유지된다.

### 선형 분류층의 계산과 파라미터 수

특징을 행으로 모은 행렬을 $H$라고 하면 NumPy의 행렬 표현으로 다음과 같이 계산할 수 있다.

$$
Z=HW+b
$$

$$
(4,512)\times(512,7)+(7)
\;\longrightarrow\;
(4,7)
$$

가중치와 편향을 포함한 새로운 선형 분류층의 파라미터 수는 다음과 같다.

$$
512\times7+7=3{,}591
$$

이는 **새 분류층의 파라미터 수**이며, Backbone까지 포함한 모델 전체 파라미터 수와 구분한다.

### NumPy로 출력 Shape 확인

아래 코드는 임의의 특징과 가중치로 분류층 계산을 확인하는 예시다. 사전학습 모델을 불러오거나 실제 이미지를 학습한 결과는 아니다.

```python
import numpy as np

rng = np.random.default_rng(0)
features = rng.standard_normal((4, 512))
weights = rng.standard_normal((512, 7))
bias = np.zeros(7)

logits = features @ weights + bias
num_parameters = weights.size + bias.size

print("특징 Shape:", features.shape)
print("Logit Shape:", logits.shape)
print("새 분류층 파라미터 수:", f"{num_parameters:,}")

# 특징 Shape: (4, 512)
# Logit Shape: (4, 7)
# 새 분류층 파라미터 수: 3,591
```

출력은 클래스별 점수인 Logit이다. 특징 벡터의 차원과 예측할 클래스 수를 구분해야 한다.

### Feature Extraction의 장점과 한계

| 장점 | 한계 |
| --- | --- |
| 업데이트할 파라미터 수를 줄일 수 있음 | 기존 특징을 Target Task에 맞게 바꾸지 못함 |
| Backbone 업데이트를 위한 계산 부담을 줄일 수 있음 | 필요한 특징이 충분하지 않으면 성능이 제한될 수 있음 |
| 적은 데이터에서도 기존 특징을 활용할 수 있음 | Source·Target의 차이가 크면 효과가 작을 수 있음 |

고정된 특징을 미리 계산해 저장하는 방식도 사용할 수 있다. 다만 기존 특징만으로 새 문제를 충분히 구분하기 어렵다면 Fine-tuning을 검토할 수 있다.

## 5. Fine-tuning: 기존 특징을 새로운 문제에 맞게 조정

Fine-tuning은 사전학습 가중치를 출발점으로 삼아 Backbone의 일부 또는 전체를 새로운 데이터로 추가 학습하는 방법이다.

일반 사물 이미지에서 유용했던 특징만으로 강판의 미세한 균열이나 질감 차이를 충분히 구분하지 못한다면, 특징 추출 가중치를 조정하는 것이 도움이 될 수 있다.

### Partial Fine-tuning과 Full Fine-tuning

| 레이어 | Feature Extraction | Partial Fine-tuning 예시 | Full Fine-tuning |
| --- | --- | --- | --- |
| Conv1 | 고정 | 고정 | 학습 |
| Conv2 | 고정 | 고정 | 학습 |
| Conv3 | 고정 | 학습 | 학습 |
| Conv4 | 고정 | 학습 | 학습 |
| 새로운 분류층 | 학습 | 학습 | 학습 |

- **Partial Fine-tuning:** 사전학습 모델의 일부 레이어를 추가 학습한다.
- **Full Fine-tuning:** 사전학습 모델의 전체 가중치를 추가 학습한다.
- **Unfreeze:** 고정했던 파라미터를 다시 학습 가능하도록 설정하는 것이다.

CNN의 앞부분은 비교적 일반적인 특징, 뒷부분은 작업에 관련된 복잡한 특징을 학습하는 경우가 많아 뒷부분부터 조정하는 방법을 검토할 수 있다. 학습할 레이어는 모델 구조와 데이터 특성을 기준으로 결정한다.

전체 가중치를 학습하면 조정 범위가 넓어지지만, 계산 비용과 과적합 가능성도 커질 수 있다. 실제 비용은 구조와 선택한 레이어, 학습 환경에 따라 달라진다.

## 6. Fine-tuning의 학습률과 주의점

### 사전학습 가중치와 새 분류층의 출발점 차이

Fine-tuning도 새로운 작업의 손실을 줄이는 방향으로 업데이트한다.

$$
\theta_{t+1}
=
\theta_t-\eta\nabla_{\theta}L_{\text{target}}
$$

사전학습된 Backbone에 지나치게 큰 업데이트를 적용하면 기존의 유용한 특징이 손상될 수 있다. 따라서 Backbone에는 상대적으로 작은 학습률을 적용하는 방법을 검토할 수 있다.

| 학습 대상 | 학습률 예시 | 목적 |
| --- | ---: | --- |
| 사전학습된 Backbone | $10^{-4}$ | 기존 특징을 크게 바꾸지 않도록 조절 |
| 새롭게 초기화한 분류층 | $10^{-3}$ | 새로운 클래스 구분을 학습 |

위 수치는 설정 원리를 설명하는 예시다. 모든 모델에서 적절한 값이거나, 반드시 서로 다른 학습률을 써야 한다는 의미는 아니다.

### 과적합과 기존 정보의 손상

| 확인할 문제 | 의미 |
| --- | --- |
| 과적합 | 적은 Target Data에 많은 파라미터를 지나치게 맞출 수 있음 |
| 기존 특징 손상 | 큰 업데이트로 재사용하던 유용한 표현이 바뀔 수 있음 |
| 학습 비용 증가 | 학습할 범위가 넓어지면 업데이트와 계산 부담이 증가할 수 있음 |
| 파국적 망각 | 새 작업을 학습하며 기존 정보나 이전 작업의 성능이 크게 손상될 수 있음 |

파국적 망각(Catastrophic Forgetting)은 새로운 작업을 학습하면서 기존에 학습한 정보나 성능을 크게 잃는 현상이다. Target Task만 평가하면 이전 작업의 성능 저하를 직접 확인하지 못할 수도 있다.

Training Loss와 Validation Loss를 함께 관찰하며, 학습 범위와 학습률이 적절한지 확인해야 한다.

## 7. 전이학습 전략을 선택하고 검증하는 흐름

다음과 같은 순서로 전이학습을 진행할 수 있다.

1. **사전학습 모델과 가중치 준비:** Source Task의 특징이 Target Task에도 유용할지 검토한다.
2. **입력 전처리 확인:** 선택한 모델·가중치에 맞는 이미지 크기, 채널, 정규화 기준을 확인한다.
3. **분류층 변경:** 새로운 클래스 수에 맞는 출력을 구성한다.
4. **학습 범위 설정:** Feature Extraction 또는 일부·전체 Fine-tuning 중 필요한 방식을 선택한다.
5. **새 데이터로 학습:** 의도한 파라미터를 업데이트한다.
6. **Validation 성능 확인:** 성능과 계산 비용을 비교하고 범위·학습률 등을 조정한다.

먼저 새 분류층만 학습하고, 성능이 부족하면 Backbone 일부를 Unfreeze하는 단계적 방법도 사용할 수 있다. 필수적인 순서는 아니며 데이터와 모델에 따라 다르게 구성할 수 있다.

### 학습 범위를 바꿀 때 확인할 사항

| 확인 항목 | 검토 내용 |
| --- | --- |
| 학습 가능한 파라미터 | 고정·해제할 레이어가 의도대로 설정되었는가? |
| Optimizer | 새롭게 학습할 파라미터도 업데이트 대상에 포함되는가? |
| 실행 모드 | BN 등 상태를 가진 레이어가 의도대로 동작하는가? |
| 출력 | Target Task의 클래스 수에 맞는 Logit을 생성하는가? |
| 평가 | Validation 성능이 실제로 개선되는가? |

기존 특징만으로 충분한 성능을 얻는다면 Feature Extraction을 유지할 수 있다. 특징 조정이 필요하다면 Partial 또는 Full Fine-tuning을 검토한다.

**학습하는 레이어가 많을수록 항상 좋은 모델이 되는 것은 아니다.** 데이터의 양과 특성, 자원과 시간, Validation 성능을 함께 고려해 선택한다.

## 핵심 정리

- 사전학습 모델은 기존 데이터로 학습한 가중치를 가진 모델이며, 모델 구조와 구분해야 한다.
- 전이학습은 기존 가중치나 표현을 새로운 작업의 출발점으로 활용한다.
- Source·Target의 차이가 크면 기존 특징이 적합하지 않거나 Negative Transfer가 발생할 수 있다.
- Feature Extraction은 Backbone을 고정하고 새로운 분류층을 학습한다.
- Freeze 상태에서도 특징 계산은 수행되며, BN 통계 등 실행 상태도 별도로 관리해야 한다.
- ResNet18 예시에서는 512차원 특징을 새 분류층에 전달하여 7개 클래스의 Logit을 계산한다.
- Partial Fine-tuning은 일부 레이어를, Full Fine-tuning은 전체 가중치를 추가 학습한다.
- Fine-tuning에서는 학습률, 기존 특징의 손상, 과적합과 계산 비용을 함께 고려한다.
- 적용 방식과 학습 범위는 Target Task의 Validation 성능을 기준으로 판단한다.

## 오늘의 한 문장

> 전이학습은 이미 배운 표현을 활용하면서, 새로운 문제에 맞게 무엇을 유지하고 어디까지 다시 학습할지 선택하는 과정이다.
