## 1. 활성화 함수의 역할과 종류

뉴런은 입력값의 가중합에 편향을 더한 뒤, 활성화 함수(Activation Function)를 적용해 출력값을 계산한다.

$$
z=\sum_i w_ix_i+b,\qquad h=f(z)
$$

활성화 함수는 **값의 범위를 변환하거나 신경망에 비선형성을 추가하는 역할**을 한다. 은닉층에서는 새로운 중간 표현을 만들고, 출력층에서는 예측 문제에 맞는 형태로 값을 변환하는 데 활용한다.

### Sigmoid

Sigmoid는 실수 입력을 0과 1 사이로 변환한다.

$$
\sigma(z)=\frac{1}{1+e^{-z}},\qquad 0<\sigma(z)<1
$$

입력이 0이면 0.5를 출력한다. 큰 양수에서는 1에, 큰 음수에서는 0에 가까워진다.

이진 분류의 출력에 사용하면 클래스 1의 예측 확률을 계산할 수 있다. 예를 들어 $\sigma(1.5)\approx0.818$이면 모델이 클래스 1에 약 81.8%의 확률을 부여한 것이다.

다만 은닉층에서도 Sigmoid를 사용할 수 있으므로, 모든 Sigmoid 출력을 최종 클래스의 확률로 해석하는 것은 아니다.

### Tanh

Tanh(Hyperbolic Tangent)는 실수 입력을 -1과 1 사이로 변환한다.

$$
\tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}},
\qquad -1<\tanh(z)<1
$$

출력이 0을 중심으로 대칭이고, 입력이 0이면 출력도 0이다. 음수 출력이 가능하며, 일부 RNN의 은닉 상태 계산 등에 사용된다.

### ReLU

ReLU(Rectified Linear Unit)는 음수 입력을 0으로 만들고 양수 입력은 그대로 출력한다.

$$
\mathrm{ReLU}(z)=\max(0,z)
$$

출력은 0 이상이며 상한이 없다. 일반적인 DNN의 은닉층에서 널리 사용된다.

### 동일한 입력에 대한 출력 비교

| 입력 $z$ | Sigmoid | Tanh | ReLU |
| ---: | ---: | ---: | ---: |
| -2 | 0.119 | -0.964 | 0 |
| -1 | 0.269 | -0.762 | 0 |
| 0 | 0.500 | 0.000 | 0 |
| 1 | 0.731 | 0.762 | 1 |
| 2 | 0.881 | 0.964 | 2 |

| 구분 | Sigmoid | Tanh | ReLU |
| --- | --- | --- | --- |
| 출력 범위 | $(0,1)$ | $(-1,1)$ | $[0,\infty)$ |
| 음수 출력 | 불가능 | 가능 | 불가능 |
| 입력 0에서의 출력 | 0.5 | 0 | 0 |
| 대표 활용 | 이진 분류 확률 출력 | 특정 은닉층, 일부 RNN | DNN 은닉층 |

```python
import numpy as np

z = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])

sigmoid_values = 1 / (1 + np.exp(-z))
tanh_values = np.tanh(z)
relu_values = np.maximum(0, z)

print(np.round(sigmoid_values, 3))  # [0.119 0.269 0.5   0.731 0.881]
print(np.round(tanh_values, 3))     # [-0.964 -0.762  0.     0.762  0.964]
print(relu_values)                 # [0. 0. 0. 1. 2.]
```

PyTorch에서는 `torch.sigmoid()`, `torch.tanh()`, `torch.relu()`를 사용할 수 있다. 레이어로 구성할 때는 `nn.Sigmoid()`, `nn.Tanh()`, `nn.ReLU()`를 이용한다.

## 2. 활성화 함수의 미분과 학습에 미치는 영향

역전파는 Chain Rule을 이용하므로, 활성화 함수의 미분값도 이전 레이어로 전달되는 기울기에 영향을 준다.

| 활성화 함수 | 도함수 |
| --- | --- |
| Sigmoid | $\sigma(z)(1-\sigma(z))$ |
| Tanh | $1-\tanh^2(z)$ |
| ReLU | $z>0$이면 1, $z<0$이면 0 |

ReLU는 $z=0$에서 수학적으로 미분 가능하지 않지만, 여기서 다루는 구현에서는 역전파에 사용할 값을 0으로 정한다.

### Sigmoid와 Tanh의 포화

입력값의 절댓값이 매우 커지면 Sigmoid와 Tanh의 출력 변화가 작아지고, 도함수도 0에 가까워진다. 이러한 상태를 포화와 연결해 이해할 수 있다.

깊은 신경망에서 작은 미분값들이 반복해서 곱해지면 앞쪽 레이어로 전달되는 기울기가 작아질 수 있다. 이는 **기울기 소실(Vanishing Gradient)**과 관련된다.

### ReLU의 양수 영역과 음수 영역

ReLU는 양수 영역에서 미분값이 1이므로 Sigmoid나 Tanh처럼 양수 입력이 커지면서 포화되는 특성은 없다. 반면 음수 영역에서는 미분값이 0이므로 해당 경로로 전달되는 기울기도 0이 된다.

뉴런이 계속 비활성 상태로 머무르면 학습이 어려워질 수 있으며, 이를 Dead ReLU 문제와 연결할 수 있다.

즉, 활성화 함수는 **순전파의 출력값뿐 아니라 역전파에서 기울기가 전달되는 방식에도 영향**을 준다.

## 3. 비선형 활성화 함수가 필요한 이유

### 아핀 변환만 연결하는 경우

입력에 가중치를 곱하고 편향을 더하는 계산을 아핀 변환(Affine Transformation)이라고 한다.

$$
h=2x+1,\qquad y=3h-2
$$

두 레이어를 연결해도 다음처럼 하나의 아핀 변환으로 정리된다.

$$
y=3(2x+1)-2=6x+1
$$

행렬을 사용하는 경우에도 같은 관계가 성립한다.

$$
H=XW_1+\mathbf b_1,\qquad Y=HW_2+\mathbf b_2
$$

$$
Y=X(W_1W_2)+(\mathbf b_1W_2+\mathbf b_2)
$$

**비선형 활성화 함수 없이 아핀 변환만 반복하면, 전체 모델을 하나의 아핀 변환으로 합칠 수 있다.**

### ReLU를 추가하는 경우

첫 번째 아핀 변환 뒤에 ReLU를 적용한다.

$$
h=\mathrm{ReLU}(2x+1),\qquad y=3h-2
$$

ReLU의 입력인 $2x+1$이 양수인지에 따라 계산이 나뉜다.

$$
y=
\begin{cases}
-2,&x\leq-0.5\\
6x+1,&x>-0.5
\end{cases}
$$

| 입력 $x$ | 아핀 변환만 사용 | 중간에 ReLU 적용 |
| ---: | ---: | ---: |
| -2 | -11 | -2 |
| -1 | -5 | -2 |
| 0 | 1 | 1 |
| 1 | 7 | 7 |
| 2 | 13 | 13 |

ReLU를 사용하면 입력에 따라 다른 규칙으로 계산되어 전체 관계를 하나의 직선으로 표현할 수 없다. 이 예제의 $y$는 계산 차이를 보여주는 수치이며, 구매 확률은 아니다.

```python
import numpy as np

x = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])

y_affine = 3 * (2 * x + 1) - 2
y_relu = 3 * np.maximum(0, 2 * x + 1) - 2

print(y_affine)  # [-11.  -5.   1.   7.  13.]
print(y_relu)    # [-2. -2.  1.  7. 13.]
```

### 출력층의 Sigmoid와 은닉층의 비선형성 구분하기

아핀 변환을 여러 번 연결하고 마지막에만 Sigmoid를 적용하면, Sigmoid 이전의 연산은 여전히 하나의 아핀 변환이다.

$$
p=\sigma(\mathbf x\mathbf w+b)
$$

이 모델에서 임계값 0.5로 클래스를 정하면 경계는 $\mathbf x\mathbf w+b=0$이다. 따라서 이진 분류의 결정 경계는 선형으로 유지된다.

은닉층에 ReLU 같은 비선형 함수를 사용하면 중간 표현 자체가 비선형적으로 변환되므로 더 다양한 결정 경계를 표현할 수 있다. 다만 표현 능력이 커진다고 항상 예측 성능까지 좋아지는 것은 아니며, 데이터와 학습 방법도 함께 영향을 준다.

## 4. DNN의 순전파와 레이어별 계산

순전파(Forward Propagation)는 입력 데이터를 레이어에 순서대로 전달하고, 현재 가중치와 편향으로 최종 예측값을 계산하는 과정이다.

입력 특성 3개, 은닉층 4개·2개, 출력 뉴런 1개인 이진 분류 모델을 생각해 보자.

$$
Z_1=XW_1+\mathbf b_1,\qquad H_1=\mathrm{ReLU}(Z_1)
$$

$$
Z_2=H_1W_2+\mathbf b_2,\qquad H_2=\mathrm{ReLU}(Z_2)
$$

$$
Z_3=H_2W_3+\mathbf b_3,\qquad P=\sigma(Z_3)
$$

앞선 레이어의 출력이 다음 레이어의 입력이 된다.

### Batch로 계산할 때의 Shape

| 항목 | Shape |
| --- | --- |
| 입력 $X$ | $(4,3)$ |
| 가중치 $W_1$ / 편향 $\mathbf b_1$ | $(3,4)$ / $(4,)$ |
| 첫 번째 은닉층 $H_1$ | $(4,4)$ |
| 가중치 $W_2$ / 편향 $\mathbf b_2$ | $(4,2)$ / $(2,)$ |
| 두 번째 은닉층 $H_2$ | $(4,2)$ |
| 가중치 $W_3$ / 편향 $\mathbf b_3$ | $(2,1)$ / $(1,)$ |
| 로짓 $Z_3$와 확률 $P$ | $(4,1)$ |

Batch Size인 4는 유지되고, 특성 차원은 각 레이어의 출력 뉴런 수에 따라 달라진다.

### 고객 한 명의 순전파 계산

다음 절의 NumPy 코드에서 설정하는 가중치와 편향을 이용해 입력 $[1,2,1]$을 계산하면 다음과 같다.

| 단계 | 계산 결과 |
| --- | --- |
| 입력 $\mathbf x$ | $[1,2,1]$ |
| 첫 은닉층의 활성화 전 값 $\mathbf z_1$ | $[2,1,0,0]$ |
| ReLU 적용 후 $\mathbf h_1$ | $[2,1,0,0]$ |
| 두 번째 은닉층의 활성화 전 값 $\mathbf z_2$ | $[2,-1]$ |
| ReLU 적용 후 $\mathbf h_2$ | $[2,0]$ |
| 출력 로짓 $z_3$ | $0.25$ |
| Sigmoid 예측 확률 $p$ | 약 0.562 |

두 번째 은닉층의 음수 값 $-1$은 ReLU를 거쳐 0이 된다. 출력층에서는 다음과 같이 계산한다.

$$
z_3=2\times1+0\times(-0.5)-1.75=0.25
$$

$$
p=\sigma(0.25)\approx0.562
$$

## 5. NumPy로 DNN의 순전파 구현하기

계산 과정을 확인하기 위해 가중치와 편향을 직접 설정하고, 고객 4명을 한 번에 계산한다.

```python
import numpy as np

def relu(z):
    return np.maximum(0, z)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

X = np.array([
    [1.0, 2.0, 1.0],
    [2.0, 0.0, 1.0],
    [0.0, 1.0, 2.0],
    [1.0, 1.0, 0.0],
])

W1 = np.array([
    [1.0,  0.0, -1.0,  0.5],
    [0.0,  1.0,  0.5, -0.5],
    [1.0, -1.0,  0.0,  0.5],
])
b1 = np.zeros(4)

W2 = np.array([
    [ 0.5, -0.5],
    [ 1.0,  0.5],
    [-0.25, 1.0],
    [ 0.5,  0.5],
])
b2 = np.array([0.0, -0.5])

W3 = np.array([[1.0], [-0.5]])
b3 = np.array([-1.75])

# 은닉층
z1 = X @ W1 + b1
h1 = relu(z1)
z2 = h1 @ W2 + b2
h2 = relu(z2)

# 출력층과 클래스 결정
logits = h2 @ W3 + b3
probabilities = sigmoid(logits)
predictions = (probabilities >= 0.5).astype(int)

print(X.shape, h1.shape, h2.shape, probabilities.shape)
# (4, 3) (4, 4) (4, 2) (4, 1)

print(h1[0])  # [2. 1. 0. 0.]
print(h2[0])  # [2. 0.]

print(np.round(logits.ravel(), 3))
# [ 0.25   0.5   -0.625 -0.25 ]

print(np.round(probabilities.ravel(), 3))
# [0.562 0.622 0.349 0.438]

print(predictions.ravel())
# [1 1 0 0]
```

`ravel()`은 결과를 표시하기 편하도록 $(4,1)$ 배열을 1차원으로 바꾼다. 계산 과정에서의 출력 Shape는 $(4,1)$이다.

| 고객 | 로짓 | 예측 확률 | 임계값 0.5의 예측 클래스 |
| --- | ---: | ---: | ---: |
| A | 0.250 | 0.562 | 1 |
| B | 0.500 | 0.622 | 1 |
| C | -0.625 | 0.349 | 0 |
| D | -0.250 | 0.438 | 0 |

이 값들은 직접 설정한 파라미터의 계산 결과이다. 순전파를 수행할 수 있다는 사실만으로 실제 구매 패턴을 잘 학습했다고 판단할 수는 없다.

## 6. 로짓·예측 확률·예측 클래스 구분하기

이진 분류의 출력에서는 다음 세 가지를 구분한다.

| 구분 | 계산 방법 | 값의 예시 | 의미 |
| --- | --- | --- | --- |
| 로짓(Logit) | 출력층의 아핀 변환 | $0.25$ | 확률 변환 전의 점수 |
| 예측 확률 | 로짓에 Sigmoid 적용 | 약 0.562 | 클래스 1에 부여한 확률 |
| 예측 클래스 | 확률에 임계값 적용 | $1$ | 최종 분류 결과 |

임계값을 $\tau$라고 하면 클래스를 다음처럼 결정할 수 있다.

$$
\hat y=
\begin{cases}
1,&p\geq\tau\\
0,&p<\tau
\end{cases}
$$

예측 확률이 0.562라면 임계값 0.5에서는 클래스 1, 임계값 0.6에서는 클래스 0이 된다.

**임계값을 바꿔도 모델이 계산한 로짓과 예측 확률은 달라지지 않는다.** 달라지는 것은 확률을 최종 클래스로 변환하는 기준이다.

## 7. 활성화 함수와 손실 함수의 조합

은닉층과 출력층은 역할이 다르므로 같은 활성화 함수를 사용할 필요가 없다.

| 사용 위치·문제 유형 | 대표 출력 방식 |
| --- | --- |
| 일반적인 DNN 은닉층 | ReLU |
| 이진 분류의 확률 출력 | Sigmoid |
| 다중 클래스 분류의 확률 출력 | Softmax |
| 범위 제한이 없는 수치 회귀 | 출력 활성화 함수 생략 |

학습할 때는 손실 함수가 어떤 값을 입력받는지도 확인해야 한다.

| PyTorch 손실 함수 | 입력할 모델 출력 | 예측 확률이 필요할 때 |
| --- | --- | --- |
| `BCEWithLogitsLoss` | Sigmoid 적용 전의 로짓 | Sigmoid 적용 |
| `CrossEntropyLoss` | 일반적으로 Softmax 적용 전의 클래스별 로짓 | Softmax 적용 |

**이 손실 함수들을 사용할 때는 모델에서 Sigmoid나 Softmax를 미리 적용하지 않는다.** 학습에는 로짓을 전달하고, 예측 확률이 필요할 때 확률 변환을 수행하는 구조로 구성할 수 있다.

## 8. PyTorch 순전파와 모델 학습의 차이

### 로짓을 반환하는 DNN

아래 모델은 은닉층에 ReLU를 사용하고, 마지막 Linear 레이어에서 로짓을 반환한다.

```python
import torch
import torch.nn as nn

torch.manual_seed(42)

X = torch.tensor([
    [1.0, 2.0, 1.0],
    [2.0, 0.0, 1.0],
    [0.0, 1.0, 2.0],
    [1.0, 1.0, 0.0],
], dtype=torch.float32)

model = nn.Sequential(
    nn.Linear(3, 4),
    nn.ReLU(),
    nn.Linear(4, 2),
    nn.ReLU(),
    nn.Linear(2, 1),
)

model.eval()

with torch.no_grad():
    logits = model(X)
    probabilities = torch.sigmoid(logits)
    predictions = (probabilities >= 0.5).int()

print(tuple(X.shape))              # (4, 3)
print(tuple(logits.shape))         # (4, 1)
print(tuple(probabilities.shape))  # (4, 1)
print(predictions.flatten().tolist())
```

`model(X)`를 호출하면 정의한 순서대로 레이어의 계산이 실행된다. `model.eval()`은 평가 모드로 전환하고, `torch.no_grad()`는 해당 구간에서 기울기 계산을 위한 기록을 하지 않도록 한다.

이 모델은 NumPy 예제와 구조가 같지만, 가중치와 편향의 초기값이 다르므로 예측값도 같다고 볼 수 없다. 동일한 계산 결과를 재현하려면 구조뿐 아니라 파라미터도 맞춰야 한다.

PyTorch 예제는 PyTorch가 설치된 환경에서 실행한다.

### 순전파와 학습 구분하기

| 단계 | 역할 |
| --- | --- |
| 순전파 | 현재 파라미터로 예측값 계산 |
| 손실 계산 | 예측값과 실제 정답 비교 |
| 역전파 | 각 파라미터의 Gradient 계산 |
| 파라미터 업데이트 | Optimizer가 가중치와 편향 변경 |

**순전파 자체는 파라미터를 업데이트하지 않는다.** 실제 학습에는 손실 계산·역전파·업데이트를 추가해 반복하는 과정이 필요하다.

학습하지 않은 모델도 확률 형태의 값을 출력할 수 있지만, 그 값이 실제 구매 가능성을 정확하게 나타낸다고 보장할 수는 없다.

## 핵심 정리

- Sigmoid는 $(0,1)$, Tanh는 $(-1,1)$, ReLU는 $[0,\infty)$ 범위의 값을 출력한다.
- 활성화 함수의 미분값은 역전파에서 이전 레이어로 전달되는 기울기에 영향을 준다.
- 아핀 변환만 여러 번 연결하면 하나의 아핀 변환으로 합칠 수 있으므로 은닉층의 비선형성이 중요하다.
- 순전파는 각 레이어에서 아핀 변환과 활성화 함수를 순서대로 적용해 예측값을 계산하는 과정이다.
- 로짓·예측 확률·예측 클래스는 서로 다른 값이며, 임계값은 확률을 클래스로 바꾸는 기준이다.
- `BCEWithLogitsLoss`와 `CrossEntropyLoss`에는 해당 확률 변환을 적용하기 전의 로짓을 전달한다.
- 순전파로 예측값을 계산하는 것과, 파라미터를 학습해 유용한 예측을 얻는 것은 구분해야 한다.

## 오늘의 한 문장

> 비선형 활성화 함수는 신경망의 표현 능력과 기울기 전달에 영향을 주며, 순전파는 각 레이어의 변환을 차례로 적용해 최종 예측값을 계산하는 과정이다.
